## H1 年齢は「判定日の終了時に達している年齢」を返す1つの関数で求め、生年月日の範囲はパラメータに持たない

- 内容：
  1. 判定コアの年齢関数を `年齢(生年月日, 判定日)` ＝「判定日の終了時までに達した年齢」とする。n 歳に達するのは、出生の日を起算日として n 年目の応当する日の前日の終了時（応当する日がなければその月の末日の終了時）。
  2. 所得税の扶養親族等の年齢は 判定日＝その年の12月31日（判定に係る者がその前に死亡していれば死亡の時）で求める。この場合、関数の値は `Y − 生まれた年 ＋（1月1日生まれなら1）` と同じになる。
  3. 年齢の区分の境目（16・19・23・30・65・70歳など）は年齢の値のパラメータとして持つ。国税庁が示す「平成X年1月2日から…」の生年月日の範囲は、年分ごとに導けるのでパラメータにしない。生年月日の範囲は D15 ②（年分ごとの境目のテスト）の**期待値**として使う。
- 根拠：
  - 法文（年齢計算ニ関スル法律、民法143条）と所法85③の判定時点［SA］§3、［CON］§2.2・§5.1、［PS］§1.1。
  - 国税庁の生年月日の範囲（令和7年分8行・令和8年分10行）と、式L（上の1）・式A（上の2の式）の全日付での照合で不一致0件。「誕生日の当日に1つ増える」式は1月1日生まれでだけ食い違う［M］§4.2、［PS］§1.2・§1.3。
  - 作成コーナーの `jsGetAge` も式Aと同じ［SAK］。
  - 健康保険の被扶養者の19歳以上23歳未満も「その年の12月31日現在の年齢」「1月1日生まれは12月31日に加算」［SH］§1.2 Q4。所得税と同じ関数・同じ判定日で求められる (I)。
- 判定日を引数にする理由：源泉徴収票の「未成年者」欄の範囲（令和7年分「平成20年1月3日以後」、令和8年分「平成21年1月3日以後」）は、12月31日の終了時ではなく翌年1月1日の終了時の判定と一致した［M］§4.2、［PS］§1.2。年齢の判定日は制度・欄ごとに違いうるので、判定日を関数の外から渡す (I)。
- 未確定の点：死亡者の「死亡の時の現況」で、死亡日が「年齢が加わる日（誕生日の前日）」に当たる場合に加算後の年齢とするか（死亡の時刻と「日の終了時」の前後）は、原文で確かめていない［PS］§6 (I)。国税庁の資料は「死亡の日の現況」（年末調整のしかた）・「その死亡の時」（国外居住親族Q&A Q4）と書くだけで、この点には触れていない［PS］§7。

## H2 所得税の「親族」は民法上の親族として判定コアが導く。記録層は、民法上の関係を生む事実を持つ

- 内容：
  1. 所得税の「親族」（所法2①三十四ほか）は民法725条の親族（6親等内の血族、配偶者、3親等内の姻族）と同じ意味として扱う。U14 はこれで閉じてよい。
  2. 親等・血族か姻族かは**判定コア**が、記録層の事実から計算する。記録層が持つ事実（区間・日付つき）：
     - 出生による法律上の親子関係（母子、父子は婚姻中の出生か認知か。認知の日）
     - 婚姻（届出日）と解消（離婚の日、死亡の日）
     - 姻族関係を終了させる意思表示（生存配偶者。日付）
     - 養子縁組（日付）と離縁（日付）
     - 里親への委託（児童福祉法の措置）・養護受託者への委託（老人福祉法の措置）（親族ではないが扶養親族・特定親族の対象になる）
  3. 事実婚（内縁）の関係、事実婚の相手の連れ子・未認知の子との関係も、**事実として**記録する。ただし所得税の親族・配偶者の判定には使わず、健康保険の被扶養者（事実婚の配偶者とその父母・子を含む）の判定だけに使う。
- 根拠：
  - 最判平成3年10月17日「所得税法…二条一項三四号に規定する親族は、民法上の親族をいうものと解すべきであり、したがって、…未認知の子又はその者の連れ子は、同法八四条に規定する扶養控除の対象となる親族には該当しない」［PS］§2.2。
  - 国税庁：質疑応答事例「ここでいう「親族」とは、民法の規定に従い、6親等内の血族及び3親等内の姻族をいい（民法第725条）」、養子は民法727条で1親等の血族、死亡した配偶者の父母は意思表示をしない限り姻族（民法728条2項）。国外居住親族Q&A Q3「所得税法における「親族」は、民法の規定による親族」［PS］§2.3。
  - 所得税法・同施行令・同施行規則の本則に民法725条を参照する規定は無く、定義規定も無い［PS］§2.1、［M］§3.3。判決と国税庁の扱いが「民法による」で一致している。
  - 配偶者は民法上の配偶者（内縁を含まない）、健保は事実婚を含む［CON］§3.1、［PS］§2.3（年末調整のしかたの「婚姻の届出をしている配偶者」）。
  - 民法の親族の規定（725〜729条、739条）［CON］§3.1。
- (I)：親等の計算をコアに置くのは、D3（記録は事実だけ）と HANDOFF §3 の境界（法的な判断はコア）に合わせるため。「続柄」（子・孫・兄弟姉妹など）を記録層に直接書く案もあるが、続柄は婚姻・縁組・意思表示の日付で変わるので、日付つきの事実から導く方が年の途中の変化（年の中途の離婚・死亡・縁組）に強い。
- 未確定の点：外国人の親族の範囲（法の適用に関する通則法による扱い）を親族一般について書いた原文は見つかっていない［PS］§2.3・§6。当面は外国人を含む家族は「検査で止める」対象にする (I)。

## H3 扶養の所属（所令218・218の2・219）は、判定コアの「所属の割当て」の段で、申告書等の記載という事実から決定的に解ける（U2）

- 内容：
  1. 所属の規則は、申告書等に**誰が・いつ・誰を・どの区分で記載したか**という事実だけで動く。記録層は、申告書等の提出を事実として持つ（申告書等の種類、年分、提出日、提出者、提出先（給与の支払者など）、記載された人と区分）。所得税の判定は「記載した（する予定の）事実」を入力にする。
  2. 判定コアの中、OpenFisca の状況（situation）を組み立てる前に、純粋関数「所属の割当て」を置く。手順：
     - (a) 同一生計配偶者か他の居住者の扶養親族か：双方が記載したとき・定められないときは**夫又は妻である居住者の同一生計配偶者**（所令218②）。特別控除対象配偶者か特定親族かも同じ（所令218の2②）。
     - (b) 扶養親族・特定親族：記載が1人の居住者だけならその居住者（所令219①）。
     - (c) 二以上の居住者が記載した、又は定められないとき：その年において**既に**申告書等の記載によりその扶養親族・特定親族としている居住者（所令219②一）。
     - (d) それでも定まらないとき：「総所得金額、退職所得金額及び山林所得金額の合計額」又は判定すべき時の見積額が**最も大きい**居住者（所令219②二）。
     - (e) (d) で同額のとき：原文に規則が無いので、決めずに止め、人の判断（D4）を求める。
  3. (d) の額は所得控除の前の額なので、所属の割当てより先に、各居住者の総所得金額・退職所得金額・山林所得金額を求められる。計算は「所得の計算 → 所属の割当て → 控除・税額の計算」の順で、循環しない (I)。
  4. 割当ての結果には、どの規則で決まったか（219①、219②一、219②二、218②、218の2②）を根拠として付ける（D13）。
- 根拠：
  - 所令218・218の2・219 の原文、3つの版で同文（令和7年分・令和8年分で同じ規則）［PS］§3.1・§3.2、［M］§3.2。
  - 所令219② の構造（前提、第1号、第2号）と、第2号で比べる額が「総所得金額、退職所得金額及び山林所得金額の合計額」であること、同額の規則が無いこと［PS］§3.2。
  - 国税庁：「重複しない限り、いずれの者の扶養親族としても差し支えありません」「「給与所得者の扶養控除等申告書」に記載されたところによる」（質疑応答事例）、兄弟で送金していても1人だけ（TA1180 Q5）［PS］§3.3。
  - OpenFisca は同じ人を同じ種類の2つのグループに入れられない［OF-run］T02。重複は状況の組み立ての前に解消しておく必要がある。
  - 所得控除は総所得金額等から差し引く（所法84「その居住者のその年分の総所得金額、退職所得金額又は山林所得金額から…控除する」）［PS］§4.1。
- 未確定の点：所令219②一の「既に…としている」が、提出日の前後（年の中で先に提出した申告書等）を指すのか、それ以外の意味を含むのかを説明した原文は見つかっていない［PS］§3.3・§6 (I)。

## H4 年の中途の死亡と再婚（所令220）は、「所属の割当て」で、配偶者の候補を2人まで持てるようにして解く（U7）

- 内容：
  1. 年の中途で配偶者が死亡し、その年中に再婚した居住者について、同一生計配偶者（又は配偶者特別控除の対象の配偶者）になれるのは死亡した配偶者・再婚した配偶者の**うち一人**（所令220①）。どちらにするかは居住者の記載（D4 の選択、提出後は事実）で決まる (I)。
  2. 死亡した配偶者の該当性は死亡の時の現況、再婚した配偶者は12月31日の現況で判定する（所法85③）。判定時点の違う2人を同じ居住者の配偶者候補として扱う。
  3. 選ばれなかった方は、他の居住者（例：生計を一にする子）の扶養親族になりうるが、所令220②③ の制約がある：
     - 居住者が一人を同一生計配偶者としたとき、選ばれなかった方は**当該他の居住者の扶養親族に該当しない**（所令220②前段）。
     - 居住者がどちらも同一生計配偶者としないとき、一人に限り他の居住者の扶養親族（同後段）。
     - 死亡の日までに提出された申告書等（期限未到来なら前年分の最後の申告書等）の記載に従って死亡した配偶者が他の居住者の扶養親族とされていた場合は、死亡した配偶者は他の居住者の扶養親族、再婚した配偶者は居住者の同一生計配偶者又は他の居住者の扶養親族（所令220③）。
  4. このため、OpenFisca の「法律婚」グループ（2人）に3人目を入れるのではなく、「所属の割当て」（H3）の段で、居住者ごとに「この年分の配偶者控除等の対象となる配偶者（0人か1人）」を決め、OpenFisca には決まった1人だけを渡す (I)。所令220③ のために、記録層の申告書等の事実には**提出日**が要る（H3 と同じ）。
- 根拠：所法85③⑦、所令220①〜③ の原文（3つの版で同文）［PS］§3.1・§3.2。OpenFisca のグループの制約［OF-run］T02・T03。年の中途の死亡者は死亡時の現況（TA1180 Q7、所基通83から84の2−1。TA の表記は「所基通83〜84-1」）［PS］§3.3・§7。
- 未確定の点：所令220② の文言は「同一生計配偶者としたとき」で、配偶者特別控除の「生計を一にする配偶者」とした場合を書き分けていない［PS］§3.2。その場合の扱いを説明した資料は見ていない (I)。

## H5 「扶養親族とされた人が、別の人を扶養する申告者になる」ことは法令上ありうる。モデルは1人が「扶養される側」と「申告者」を同時に持てる形にする（U1）

- 内容：
  1. 扶養控除（所法84）には、扶養親族である人が自分の扶養親族について控除を受けることを制限する文言が無い。扶養親族の定義も、その人が他の居住者の扶養親族でないことを要件にしていない。したがって、AがXを扶養親族とし、XがCを扶養親族とする連鎖は法令上ありうる。
  2. 配偶者特別控除・特定親族特別控除には、明文の除外がある。特定親族特別控除では：
     - Y（特定親族）自身が特定親族特別控除を受けているとき、Y についての X の控除は適用しない（所法84の2②一）。
     - Y が自分の源泉控除対象親族（特定親族）を記載して月々の源泉徴収を受けているとき（年末調整・確定申告をした場合を除く）、同じ（所法84の2②二。**令和8年分以後**）。
     - X 自身が他の者 Z の源泉控除対象親族（特定親族）として源泉徴収で扱われているとき（Z が年末調整・確定申告をした場合を除く）、X の控除は適用しない（所法84の2②三・所令217の2。2025-12-31 の版では所令217の3。**令和8年分以後**）。
     - 令和7年分は、上の3つのうち所法84の2②一だけが適用される（令和7年法律第13号附則第6条、令和7年政令第120号附則第11条）［PS］§4.2「適用年分」。判定コアは、この除外の規則を年分ごとに切り替える必要がある。
  3. 「他の者の同一生計配偶者又は扶養親族とされている」ことを要件に使う規定がある（ひとり親の子：所令11の2②、住民税は地令7の2の2②・46の2の2②。雑損控除の親族の所属：所令205）。人が「誰の扶養親族とされているか」は、他の人の控除の要件にもなる。
  4. したがって、モデルでは「扶養される側としての所属（誰の扶養親族等とされているか）」と「申告者としての役割（自分の扶養親族等を持つか）」を同じ人が同時に持てる必要がある。OpenFisca の1種類のグループ「扶養所属」（1人1インスタンス・1役割）ではこれを表せない。
  5. 表し方の候補（どれも H3 の「所属の割当て」の出力を入力にする）：
     - 案A：所属の割当ての結果を、人の変数（「所属先の申告者」「申告者との続柄」など）と、申告者ごとの集計の入力に分けて OpenFisca に渡す。扶養親族ごとの区分（一般・特定・老人・特定親族と控除額）は扶養される側の人の変数として OpenFisca で計算し、申告者への合計だけを割当ての表に従って集める。
     - 案B：同じ形のグループを2種類（例：「扶養所属・甲」「扶養所属・乙」）用意し、申告者のグループを交互に割り当てる。扶養の所属は各人に上が高々1人なので木の形になり、2色で塗り分けられる (I)。式が2種類のグループに重複する。
     - 案C：連鎖を検出したら止めて別の要求にする（R4 の当初案）。
  6. 当面の推奨：案A を基本にし、連鎖が無い家族では従来の「扶養所属」グループと同じ結果になることをテストで確かめる (I)。案B は式の重複が大きい。案C は法令上ありうる状態を拒むので、少なくとも特定親族特別控除の除外（2.）を正しく計算できない。
- 根拠：所法84・所法2①三十四・所法83の2②・所法84の2②・所令217の2/217の3 の原文と、その適用年分（改正法令の附則）［PS］§4.2、全文の走査で「居住者として…適用を受けている場合」が第83条の2と第84条の2にしか無いこと［PS］§4.1・§4.2、［M］§3.3。国税庁「この控除の適用を受けている親族を特定親族として適用を受けることはできません」（年末調整のしかた、TA2511）［PS］§4.2。所令11の2②ほか［PS］§4.3。OpenFisca の制約［OF-run］T02・T03。
- 未確定の点：扶養控除について、扶養親族とされた人が自分の扶養親族について扶養控除を受けることを明示的に認める（又は禁じる）国税庁の資料・判例は見つかっていない［PS］§4.2・§6。

## H6 源泉徴収の区分（甲欄・乙欄・丙欄）はラベルとして記録しない。区分を生む事実と、源泉徴収票の記載事項を記録する

- 内容：
  1. 記録層（D3）に持つのは、次の**書類の提出と記載**という事実：
     - 給与の支払者（雇用）ごと・年分ごとに：給与所得者の扶養控除等申告書を提出したか（提出日、異動の申告の日、記載した源泉控除対象配偶者・源泉控除対象親族・障害者等・16歳未満の扶養親族）。従たる給与についての扶養控除等申告書を提出したか（記載した人）。特定親族特別控除申告書・配偶者控除等申告書・基礎控除申告書を提出したか（記載した人と見積額）。
     - 雇用契約の期間（2か月以内か）・日々雇い入れか（丙欄の要件の事実）。
     - 源泉徴収票の記載事項：支払金額、源泉徴収税額、年末調整をしたか（給与所得控除後の金額・所得控除の額の合計額の欄に記載があるか）、「乙欄」欄・摘要の「乙欄適用者」、控除対象扶養親族等・特親・16歳未満の扶養親族の氏名、中途就・退職。
     - 確定申告書を提出したか（年分、提出日、記載した同一生計配偶者・扶養親族・特定親族）。
  2. 甲欄・乙欄・丙欄の区分は、上の事実と所法185① から導けるが、所得税の年分の計算（D14）には区分そのものは要らない。年分の計算に要るのは源泉徴収票の「源泉徴収税額」（事実）と、年末調整をしたかどうか (I)。
  3. 子の側の事実（子が勤務先に扶養控除等申告書を出しているか、子の年末調整・確定申告の有無）は、次の判定で**親の**控除にも効く：
     - 所令219①②：所属は申告書等の記載で決まり、扶養控除等申告書は申告書等に含まれる。
     - 所法84の2②二（令和8年分以後）：子（特定親族）が自分の源泉控除対象親族（特定親族）を記載して月々の源泉徴収を受け、年末調整も確定申告もしていない場合、親の特定親族特別控除は適用しない。
     - 所令217の2（令和8年分以後）：親自身が他の者の源泉控除対象親族（特定親族）として源泉徴収で扱われ、その者が年末調整も確定申告もしていない場合、親の特定親族特別控除は適用しない。
     - 令和7年分では上の2つは適用されない［PS］§4.2「適用年分」。令和7年分で子の側の事実が親の控除に効くのは、所令219①②（所属）と所法190二ホ（年末調整）。
     - 所法190 二ホ：年末調整の特定親族特別控除の計算で「その特定親族がこの条に規定する居住者として当該申告書を提出しているかどうか」を見る。
  4. 子自身については、扶養控除等申告書を出していなければ年末調整が行われず［PS］§5.2、確定申告の要否（所法121①）にも効く。
  5. 扶養控除等申告書は住民税の給与所得者の扶養親族申告書と統合された様式で、16歳未満の扶養親族の記載は住民税の側で使われる。住民税の扶養の判定（D14）の入力としても同じ事実を使える (I)。
- 根拠：所法185①・190・194・195・195の3・121① の原文［PS］§5.1。TA2511・2514・2520・1900、手続の案内（申告をしない場合は諸控除が受けられず年末調整も行われない、2以上の支払者には一か所だけ、丙欄の人は不要、住民税の申告書と統合）［PS］§5.2。源泉控除対象親族の定義と施行日（2026-01-01）［PS］§5.3、［IT］§1。源泉徴収票の様式に「乙欄」欄、記載要領に「乙欄適用者」・年末調整をした場合に限る欄［PS］§5.4。所法84の2②・所令217の2［PS］§4.2。
- 未確定の点：給与明細・源泉徴収票が手元に無い場合（日払いのアルバイトなど）に、甲欄・乙欄・丙欄の別を雇用主に確かめずに事実として埋められるか。源泉徴収票の記載から確実に読めるのは「乙欄」欄と年末調整の有無の欄だけで、丙欄であることを示す欄は様式の読み取りでは見つけていない［PS］§5.4 (I)。
