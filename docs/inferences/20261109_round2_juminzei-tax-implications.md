# 推測：住民税の税額の計算の仮説から導く、実装・テスト・データ注入への帰結と検証の方法

- 作成日：2026-11-09
- 種別：仮説をもとに行った推測
- 前提の仮説：`docs/hypotheses/20261109_round2_juminzei-tax-calc-model.md`（以下 H1〜H10）。扶養・非課税の判定は `docs/hypotheses/20261109_impl-prep_juminzei-judgment-model.md`（以下［判定H］）。
- 文中の［実測］は H1〜H10 の根拠にした `docs/measurements/20261109_round2_juminzei-tax-fetch-and-checks.md`、［所得税］は同じく H1〜H10 の根拠の
  `docs/public-sources/20261109_impl-prep_zeigaku-tax-calc.md`（§9 の基礎控除の額）を指す。

## I1 判定コアの住民税の変数は、所得税の変数と「事実」と「前年分の所得税の結果」だけを共有し、税額の層は別系統にできる（H1・H3・H4 から）

- 推測：住民税の税額は、①所得の層（所得税と共通の計算の例）＋住民税だけの違い、②住民税の所得控除、③税率（注入）、④法定の率の控除、⑤端数、で閉じる。
  所得税の層への依存は「前年分の所得税の基礎控除の額」「課税総所得金額等」「住宅借入金等特別税額控除額」「控除前の所得税額」「確定申告書の記載（特定配当等・申告特例の失効）」の5種類に限られる。
  これを概念辞書の「年をまたぐ依存」として明記すれば、SCOPE §6 の依存の検査（逆向き・循環・未登録の依存の検出）に載る。
- 検証の方法：概念辞書を作るときに、住民税の変数から所得税の変数への依存を機械的に列挙し、上の5種類以外が出てこないかを確かめる（依存グラフのテスト）。

## I2 自治体の計算例は「注入値つきの回帰テスト」としてそのまま使える（H1・H2・H5 から）

- 推測：［実測］の 2 件のように、計算例のページには税率・均等割が書かれているので、注入値（出典＝そのページ）と期待値の組にしてテストにできる（D15 の①・②）。
  標準と違う税率（7.7%、2.025%）・均等割（2,800円、3,900円、1,500円、1,300円）を含む例は、注入の口が正しく効くことの確認にもなる。
- 検証の方法：令和9年度分の計算例（2027年に各自治体が公表するもの）、指定都市以外、寄附金・住宅借入金等・配当控除を含む例を 5 件以上集め、同じ関数で再現できるかを見る。
  再現できない例は、H5 の端数③の慣行の違いか、読みの誤りかを切り分ける。

## I3 端数③（途中の 1円未満）は、団体の慣行を注入できるようにしても、正しい値は申告者の側からは確定できない（H5 から）

- 推測：法令に定めがなく、団体ごとに扱いが違いうる。違いは年税額で 100〜200円、まれ（［実測］では 20,000 件中 15〜225 件）。
  ライブラリは既定を「途中で丸めない」にし、結果に「端数の扱いは一次情報で未確定」の印を付ける。家族全体の損得の比較（D19 の利用側の責務）では、この幅（±200円程度）を誤差として扱えば足りる。
- 検証の方法：①同じ人の実際の税額決定通知書（家族の実データ。文書には書かない）と計算結果を照合し、差が出たら団体の慣行を調べる。
  ②総務省の通知・逐条解説で「1円未満」の扱いを探す（未決 JT2）。③複数の団体に、算出所得割・税額控除の 1円未満の扱いを問い合わせる。

## I4 注入がない団体について返せるのは「判定」と「税額の式」まで（H6 から）

- 推測：所得割・均等割の額は「未確定」になるが、非課税の判定（所得割：附則第3条の3、均等割：級地の幅）・扶養の判定・森林環境税（級地があれば）・課税総所得金額・
  法定の控除の額は返せる。利用側（アプリ）は、標準税率を自分の責任で入れて試算することもできる（ライブラリは既定値として使わない）。
  寄附金税額控除の 20% の上限と「所得割の額を超えない」制限だけは税率に依存するので、寄附金が多い人では控除の額も「未確定」になりうる。
- 検証の方法：注入なしの入力で、①税額が「未確定」、②判定と式が返る、③標準税率を注入すると自治体の計算例（標準税率の団体）と一致する、の 3 つをテストで確かめる。

## I5 ふるさと納税・住宅借入金等の計算では、所得税の基礎控除の段階の境目が住民税の境目になる（H3・H4・H7 から）

- 推測：令和8年度分から、人的控除差調整額と住宅借入金等の控除限度額に「所得税の基礎控除の額 − 48万円」が入る。所得税の基礎控除は合計所得金額の段階で変わる
  （［所得税］の値：令和7年分は 132万円以下で 95万円、令和8年分は 489万円以下で 104万円など）。したがって、所得税の基礎控除の段階の境目（合計所得金額）をまたぐと、
  住民税の特例控除の割合の区分や住宅借入金等の控除限度額が跳ぶ。D19 の「判定ごとの境目の説明」には、住民税の側のこの境目も含める必要がある。
- 検証の方法：所得税の基礎控除の段階の境目の前後（各境目 ±1円）で、特例控除の割合と控除限度額を計算する境目のテスト（D15②）を作る。
  期待値は条文から手で求め、総務省のふるさと納税の控除額の説明（取得していない）や自治体のシミュレーションとも比べる。

## I6 住宅借入金等特別税額控除は、令和9年度分では「居住年」だけで条文の版を選べる（H4 から）

- 推測：2027-01-01 の版の附則第5条の4 は「2026-01-01 以後に居住の用に供した場合」に適用され、居住年が令和8年なら新しい文（控除限度額に基礎控除の差を足さない）、
  令和7年以前なら従前の文（平成28年〜令和7年は足す）になる。居住年は1月1日〜12月31日で数えるので、「居住の日が 2026-01-01 以後」と「居住年が令和8年以後」は一致する。
  入力の事実は居住年（と特定取得の別）で足り、居住の日付は要らない。
- 検証の方法：令和8年法律第2号附則第11条第10項の文言（「令和八年一月一日以後に…居住の用に供する場合」）と措法第41条の「居住年」の定義を突き合わせ、
  居住年＝居住の用に供した年であることを措法の原文で確かめる（所得税の側の調査で取得する）。

## I7 森林環境税の非課税は、均等割の非課税とずれる場合がある（H9 から）

- 推測：均等割の非課税の条例額が政令の上限より低い市町村では、合計所得金額がその条例額を超え政令の式の額以下の人は、均等割を課され森林環境税は非課税になる。
  判定コアは均等割と森林環境税の非課税を別の変数で持ち、テストでこの組み合わせを作れるようにしておく。
- 検証の方法：条例の基本額が 35万円×級地の率 より低い市町村を条例で探す（未決 JT7）。見つかれば、その市町村の税額決定の案内で「均等割のみ課税・森林環境税なし」の例があるかを見る。
  見つからなければ、ずれは理論上の可能性としてテストだけに残す。

## I8 法令の変更の監視（D9）は、HTTP 200 だけでなく本文の検査で取得の成否を判定する必要がある（［実測］§2.2 と、H4 の「規定ごとに改正附則で版を選ぶ」から）

- 推測：e-Gov API が HTTP 200 で HTML を返すことがあった。監視が状態コードだけを見ると、空の差分や誤った「改正なし」を出しうる。
  また、適用年度は改正附則で決まり、e-Gov は施行前の項を表示しないので、監視は「改正附則の新しい項が見えるようになったこと」も変更として拾う必要がある。
- 検証の方法：監視の取得処理で「JSON として読めるか」「law_revision_id があるか」を検査し、同じ URL を時間をおいて複数回取得したときの失敗率を記録する。
  改正附則の項の数を版ごとに数え、増えたら issue にするテストを作る（asof を進めた版で項が増えることは［実測］で観察済み）。

## I9 SCOPE の「住宅借入金等特別控除は外部で計算した額を受け取る」は、住民税の側では「所得税の側の値を受け取り、住民税の控除額はコアで計算する」と読むのがよい（H3 から）

- 推測：住民税の住宅借入金等特別税額控除は、所得税の住宅借入金等特別税額控除額と控除前の所得税額などから、法定の配分・率・上限で決まる（注入も判断も要らない）。
  所得税の住宅借入金等特別控除の額だけを外部から受け取れば、住民税の控除額はコアで決定的に出せる。
- 検証の方法：SCOPE §3 の文言を改めるかをユーザーに確認する（ここでは SCOPE を書き換えない）。仮の例B（［実測］§3.7）のような境目のテスト（控除限度額にかかる・かからない）で確かめる。
