## 1. 健康保険の被扶養者の収入基準（130万円など）の根拠

### 1.1 昭和52年通知（基準の本体）[通知]

- 「収入がある者についての被扶養者の認定について」**昭和52年4月6日 保発第9号・庁保発第9号**（厚生省保険局長・社会保険庁医療保険部長通知、各道府県知事あて）
- URL：https://www.mhlw.go.jp/web/t_doc?dataId=00tb0189&dataType=1&pageNo=1
- 内容（データベースに登載されている現行の文言）：
  - 健康保険法に規定する被扶養者の要件のうち「主トシテ其ノ被保険者ニ依リ生計ヲ維持スルモノ」に当たるかの判定は「専らその者の収入及び被保険者との関連における生活の実態を勘案して、保険者が行う取扱い」。保険者による差異を避けるため、次の要領を参考とする。
  - 同一世帯：年間収入 **130万円未満**（60歳以上または概ね障害厚生年金の受給要件に該当する程度の障害者は **180万円未満**）かつ被保険者の年間収入の **2分の1未満** → 原則として被扶養者。2分の1以上でも、130万円未満（180万円未満）で被保険者の年間収入を上回らず、被保険者が世帯の生計維持の中心的役割を果たしていると認められるときは被扶養者として差し支えない。
  - 別世帯：年間収入 130万円未満（180万円未満）かつ **被保険者からの援助による収入額より少ない** → 原則として被扶養者。
  - 実態と著しくかけ離れ社会通念上妥当性を欠く場合は、最も妥当と認められる認定を行う。
- 分かったこと：130万円・180万円・2分の1 という数値は**法律ではなく通知**に書かれている。通知の後続（令和7年）通知は、被扶養者の定義を「健康保険法第3条第7項に規定する被扶養者」と引用している。
- 分からなかったこと：データベースの文言は 130万円になっているが、昭和52年の発出時の金額と、その後いつ・どの文書で130万円に改められたか（改正履歴）は、データベースのページ上に表示がなく、確認できなかった。

### 1.2 19歳以上23歳未満は150万円未満（令和7年10月1日から）[通知]

- 「19歳以上23歳未満の被扶養者に係る認定について」**令和7年7月4日**
  - **保発0704第1号・年管発0704第1号**（日本年金機構理事長あて、厚生労働省保険局長・大臣官房年金管理審議官）https://www.mhlw.go.jp/web/t_doc?dataId=00tc9249&dataType=1&pageNo=1
  - **保発0704第2号**（全国健康保険協会理事長・健康保険組合理事長あて、保険局長）https://www.mhlw.go.jp/web/t_doc?dataId=00tc9250&dataType=1&pageNo=1
- 本文：
  1. 年間収入要件のうち130万円未満とするものは、認定対象者（**被保険者の配偶者を除く**）が19歳以上23歳未満なら **150万円未満** として取り扱う。年間収入の額以外の取扱いは昭和52年通知と同じ。
  2. 船員保険も準じる。
  3. **令和7年10月1日から適用**。
  - 趣旨：令和7年度税制改正で19歳以上23歳未満への特定扶養控除の要件の見直しと特定親族特別控除の創設が行われたことを踏まえたもの。
- Q&A：「19歳以上23歳未満の被扶養者に係る認定に関するＱ＆Ａについて」令和7年7月4日 **事務連絡**（保険局保険課・年金局事業管理課）https://www.mhlw.go.jp/web/t_doc?dataId=00tc9628&dataType=1&pageNo=1
  - Q2：学生であることは要件ではない。年齢で判断。
  - Q4：年齢は所得税法と同様**その年の12月31日現在の年齢**で判定。民法の期間の規定を準用し、年齢は誕生日の前日に加算（1月1日生まれは12月31日に加算）。19歳の誕生日を迎える年〜22歳の誕生日を迎える年は150万円未満、23歳の誕生日を迎える年以降60歳までは130万円未満。
  - Q5：年間収入は従来どおり「過去の収入、現時点の収入又は将来の収入の見込みなどから、**今後1年間の収入を見込む**」。所得税のような暦年の実績ではない。
  - Q8：令和7年10月1日以降の届出で、それより前に遡って認定する期間は130万円未満で判定。
  - Q9：150万円を一時的に超えた場合も、年収の壁・支援強化パッケージの**事業主証明**で認定継続できる。
- 日本年金機構の案内：https://www.nenkin.go.jp/oshirase/taisetu/2025/202508/0819.html （扶養認定日が令和7年10月1日以降。年齢は扶養認定日が属する年の12月31日時点。令和7年9月30日以前に認定済みの人は、10月1日以降に150万円以上が見込まれる場合に削除の届出）
- **国民年金の第3号被保険者は配偶者だけ**（後述 §3）なので、この150万円の特例は第3号には関係しない（通知が配偶者を除いているため）。

### 1.3 労働契約の内容による年間収入の判定（令和8年4月1日から）[通知]

- 「労働契約内容による年間収入が基準額未満である場合の被扶養者の認定における年間収入の取扱いについて」**令和7年10月1日 保保発1001第3号・年管管発1001第3号**（保険局保険課長・年金局事業管理課長から協会けんぽ・健保組合・日本年金機構あて）https://www.mhlw.go.jp/web/t_doc?dataId=00tc9348&dataType=1&pageNo=1
  - 従来は「認定対象者の過去の収入、現時点の収入または将来の収入の見込みなどから、今後1年間の収入の見込み」で判定していたが、**労働契約で定められた賃金**（注1：**労働基準法第11条の賃金。諸手当及び賞与を含む**）から見込まれる年間収入が130万円未満（注2：60歳以上・障害者 180万円、19歳以上23歳未満（配偶者を除く）150万円）で、かつ他の収入が見込まれず、同一世帯なら被保険者の年間収入の2分の1未満（別世帯なら援助額より少ない）なら、原則として被扶養者に該当。
  - 確認は労働基準法第15条の「労働条件通知書」等の添付と、本人の「給与収入のみである」旨の申立て。契約更新・条件変更のたびに書面を求める。
  - 当初想定されなかった臨時収入で結果的に130万円以上になっても、社会通念上妥当な範囲なら取扱いを変えない。
  - 給与以外の収入（年金・事業収入等）がある場合は従来どおり。
  - **令和8年4月1日から適用**。
- Q&A：同日付 **事務連絡** https://www.mhlw.go.jp/web/t_doc?dataId=00tc9349&dataType=1&pageNo=1
  - Q1・Q2：労働契約に明確な規定がなく契約段階で見込み難い**時間外労働の賃金は年間収入に含まない**。時給・労働時間・日数等から算出。
  - Q3・Q6：契約内容が分かる書類がない場合や給与以外の収入がある場合は、収入証明書や課税（非課税）証明書等で判定。
  - Q7：認定年度は確認不要、翌年度以降は少なくとも年1回確認。
  - Q9：**認定日**が令和8年4月1日以降のものに適用。それより前に遡って認定する期間は従来の取扱い。
- 二次情報（E）：Q&A 第2版（令和8年3月9日事務連絡、`https://www.mhlw.go.jp/hourei/doc/tsuchi/T260310S0010.pdf`）があるとの検索結果があったが、この URL は取得時に 404 だった（`docs/measurements/20261109_R3-tsutatsu_fetch-and-monitor-probe.md` §2-5）。データベースでの所在は未確認。
- 日本年金機構の案内（2026年5月1日掲載）：https://www.nenkin.go.jp/oshirase/taisetu/jigyosho/2026/202605/0501.html
  - 添付：労働契約内容がわかる書類（労働条件通知書、雇用契約書、労働条件が記載された事業主証明）と「給与収入のみである」旨の申立書。
  - 認定できない例：(ア) 「被扶養者になった日」から起算して契約期間が1年未満 (イ) 「シフト制による」など労働時間の記載が不明確 (ウ) **「通勤手当有」等で手当の金額が不明確**。
- 協会けんぽの案内：https://www.kyoukaikenpo.or.jp/event/cat550/nenshuunokabe/

### 1.4 「年間収入」の定義

| 観点 | 一次情報で確認できたこと | 出典 |
|---|---|---|
| 見込みか実績か | 今後1年間の見込み（過去・現在の収入、将来の見込みから） | 19〜23歳 Q&A Q5（事務連絡）、日本年金機構の手続ページ |
| 月額の目安 | 給与収入等なら月額108,333円以下、雇用保険等の受給者なら日額3,611円以下で要件を満たす | 日本年金機構 https://www.nenkin.go.jp/service/kounen/tekiyo/hihokensha1/20141202.html （※1。150万円の場合の月額は同ページに記載なし） |
| 非課税収入 | 障害年金、遺族年金、傷病手当金、出産手当金、失業給付等の非課税対象の収入がある場合は受取金額のわかる通知書等のコピーが必要（＝年間収入に数える扱い） | 同上 |
| 収入の種類 | 協会けんぽのリーフレット「★被扶養者の年収とは？」：給与収入、事業収入、地代・家賃収入などの財産収入、老齢・障害・遺族年金などの公的年金、雇用保険の失業給付、健康保険の傷病手当金・出産手当金。給与所得者は総収入額、自営業者は年間総収入から経費を差し引いた額 | https://www.kyoukaikenpo.or.jp/assets/dependent_status_r8leaf.pdf （令和8年度被扶養者資格の再確認。画像の文字を目視で読んだため、自営業者の「経費」の前の語は判読できなかった） |
| 通勤手当 | 労働契約による判定では「賃金」は労働基準法第11条の賃金で諸手当を含み、日本年金機構は「通勤手当有」で金額不明確なら本取扱いで認定できないとしている。従来の判定方法で通勤手当を含むかを明記した**厚労省・日本年金機構・協会けんぽの一次情報は見つからなかった** | 保保発1001第3号（注1）、日本年金機構 0501 |

### 1.5 「年収の壁」対応策（事業主の証明）の現状 [通知]

- 元の通知：「『年収の壁・支援強化パッケージ』について」令和5年9月29日 **保保発0929第7号**（当面の対応として事業主の証明による被扶養者認定の円滑化を実施）。本文は R3 では取得していない（後続通知の引用で確認）。
- 運用の通知：「『年収の壁・支援強化パッケージ』における、社会保険適用促進手当の標準報酬算定除外及び事業主の証明による被扶養者認定の円滑化の取扱いについて」**令和5年10月20日 保保発1020第3号**（データベース上の表記は「保保発第1020003号」。恒久化通知の本文では「令和5年10月20日付け保保発第3号」と引用。同年12月25日一部改正）https://www.mhlw.go.jp/web/t_doc?dataId=00tc8012&dataType=1&pageNo=1 （健康保険法版 00tc8005、厚生年金保険法版 00tc8006）
  - 添付の Q&A：一時的な事情として認定するため、同一の者について**原則として連続2回まで**。収入確認を年1回行う場合は、連続する2年間の各年の確認で事業主証明を用いることが「連続2回」。
- **恒久化**：「『年収の壁・支援強化パッケージ』における事業主の証明による被扶養者認定の円滑化の取扱いの恒久化について」**令和7年10月1日 保保発1001第1号**（保険局保険課長から地方厚生(支)局・協会けんぽ・健保組合等あて）https://www.mhlw.go.jp/web/t_doc?dataId=00tc9347&dataType=1&pageNo=1
  - 「当面の対応ではなく、恒久的な取り扱いとすることとした」。運用は令和5年10月20日付通知（12月25日一部改正）と同様。
- 結論：2026-11-09 時点で、事業主の証明による認定継続は**有効（恒久化済み）**。協会けんぽの案内も「原則、連続2回まで被扶養者の認定が可能」と記載（https://www.kyoukaikenpo.or.jp/event/cat550/nenshuunokabe/ ）。

## 2. 国民健康保険

- 横浜市「被保険者について」https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/kokuho/hokensho/hihokensha.html （最終更新日 2026年10月27日）：「国民健康保険では**一人ひとりが被保険者**になります」。届出義務・保険料の納付義務は世帯主（同ページ）。
- 分かったこと：国保には健康保険のような「被扶養者」の区分がなく、子供も一人の被保険者として保険料（均等割など）の対象になる。保険料の算定は自治体ごと（R3 では条例・算定式は調べていない）。
- 同ページの Q&A は職場の健康保険の扶養を「130万円未満（60歳以上や身障者の方は180万円未満）」とだけ書いており、19〜23歳の150万円に触れていない。自治体の案内は更新が遅れることがある例。

## 3. 国民年金の第3号被保険者

- 日本年金機構の手続ページ（https://www.nenkin.go.jp/service/kounen/tekiyo/hihokensha1/20141202.html ）：届書は健康保険被扶養者（異動）届と国民年金第3号被保険者関係届が一体化。「従業員の**配偶者**が20歳以上60歳未満であり、厚生年金保険の被保険者でない場合は、原則、国民年金の第3号被保険者」。
- 分かったこと：第3号は配偶者に限られる。扶養されている子供が20歳以上なら第3号にはならない（第1号として国民年金保険料の対象になる。根拠条文は R1）。
- 分からなかったこと：第3号被保険者の収入の認定基準を定めた通知（二次情報では「平成5年3月5日 庁保発第15号」とされる）は、厚労省法令等データベースで平成5年3月5日・平成5年3月中の日付検索をしても該当が見つからなかった（`docs/measurements/20261109_R3-tsutatsu_fetch-and-monitor-probe.md` §2-6）。

## 4. 住民税（自治体の公表資料）

住民税の扶養の扱いは地方税法で決まる（条文は R1）。R3 では自治体の公表資料で、所得税との違いを確認した。

- 令和8年度（令和7年中の所得）：横浜市「住民税税制改正のお知らせ（令和８年度実施分）」https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/zeikin/y-shizei/kojin-shiminzei-kenminzei/kaisei/zeiseikaiseiR8.html 、千葉市 https://www.city.chiba.jp/zaiseikyoku/zeimu/kazeikanri/zeiseikaiseijuminzei2026.html
  - 同一生計配偶者・扶養親族の合計所得金額 48万 → **58万円**、勤労学生 75万 → 85万円、給与所得控除の最低保障額 55万 → 65万円。
  - 特定扶養親族の控除額：所得税 63万円、**住民税 45万円**。
  - 特定親族特別控除（住民税）：合計所得金額 58万超95万以下は **45万円**（所得税は 63/61/51万円）、95万超100万以下 41万、以後 31/21/11/6/3万円（所得税と同額）、123万超 0円。
- 令和9年度（令和8年中の所得）：千葉市 https://www.city.chiba.jp/zaiseikyoku/zeimu/kazeikanri/zeiseikaiseijuminzei2027.html 、神戸市 https://www.city.kobe.lg.jp/a83576/kurashi/tax/shikenminze/r9kaisei.html
  - 扶養親族等の合計所得金額要件 58万 → **62万円**（勤労学生 85万 → 89万円）、給与所得控除の最低保障額 65万 → 69万円、令和9・10年度はさらに5万円上乗せして **74万円**。
- 所得税との違い（確認できた範囲）：①控除額が小さい（特定扶養 45万円など）②課税年度が1年ずれる（令和8年度住民税＝令和7年分所得）③令和8年度の特定親族特別控除の上段（95万円以下）が45万円で一定。
- 分からなかったこと：総務省自身の公表資料は今回取得していない。住民税の非課税限度額や、16歳未満の扶養親族の扱い（所得税にはない住民税固有の論点）は未調査。
