# rules/juminzei：住民税（個人の市町村民税・道府県民税）と森林環境税の判定と税額

SCOPE §5.3：扶養・非課税の判定と、税額（所得割・均等割・調整控除・税額控除）。各人の1月1日の住所の市町村ごと。
標準税率・非課税の法律の額は法令の構造（パラメータ）、超過課税・均等割の上乗せ・条例の非課税額・級地は注入データ。

状態（2026-11-12）：**登録済み**（`rules/__init__.py`）。令和8年度分・令和9年度分（所得の年分 2025・2026 の situation で計算）。
概念は `concepts.yaml`（約束の15件に、事実・判定・所得控除・税額の概念を足した。足したものは「（足した）」）。
2026-11-12：§7 の (c) のうち、条例で定める寄附金・共同募金会・日赤、第311条の均等割の軽減、家屋敷課税（型 B・2つ以上の市町村）、特定取得、
源泉徴収選択口座の配当割額等、附則第5条の5、分離課税の所得への所得控除、道府県の団体コード、均等割と所得割を合わせた百円未満、

## 3. 時点と所得税の値

- 年度 F の値は所得の年分 F−1 の situation で計算する（`timepoints.py`）。所得税の値は同じ期間の変数を「制度をまたぐ依存」で引く。
- 前年の所得は所得税の計算の例（措置法の所得計算の特例を含む：`docs/hypotheses/20261109_round3_chiho-sochi-reading.md` H1）。
  **分離課税に係る退職所得**（地法第328条：源泉徴収の対象の退職手当等）は前年の所得に入れない（`住民税_合計所得金額`・`住民税_総所得金額等`）。
- 扶養親族・同一生計配偶者・特定親族・障害者・寡婦・ひとり親・勤労学生に当たるかは、地法第292条第1項の定義が所得税法と同じ形で、判定の時は前年の12月31日、
  上限の額も所得の年で見て同じ（58万円〔令和8年度分〕・62万円〔令和9年度分〕。法令の読み）。違いは、合計所得金額（分離課税に係る退職所得を除く）、
  所属の規則（地令46の5②：所得税の「既に記載している人」の段がない）、納税義務者（賦課期日に住所を有する人）の3つ。
  非課税の判定の寡婦だけは取扱通知の扶養費の一部負担を足す（§6）。
- 住民税の扶養の割当て（2026-11-12。JM-24〜26）：段 `住民税の扶養の割当て` が、所得税と共有の純粋関数（`okura_core/dependents`：親族・生計・事業専従者の組の要件、
  所属の規則、申告者との関係の事実、扶養の区分）を住民税の値と規則で呼んで、住民税扶養所属のグループを組み立てる。所得税と割当て・合計所得金額・判定の時が
  同じ人は所得税の判定（`所得税_扶養親族に当たるか` など）をそのまま使い、違う人だけ段が住民税の区分（`住民税_別の判定の…`）を書く（式は
  `住民税_扶養の判定を所得税と別に行うか`・`住民税_本人の判定を所得税と別に行うか` で切り替える：`住民税_扶養親族に当たるか` などの判定の変数）。
  扶養の連鎖の人は自分のインスタンスの納税義務者に置き、1人分の額を段 `住民税の扶養の連鎖の合計` が納税義務者の入力（`住民税_連鎖の…`）に足す。

## 4. 段 `住民税の扶養の割当て` の規則（2026-11-12。以前の検出 D1〜D3 の対象外はやめた）

| 場合 | 住民税の扱い |

| 判定される人がその年の中途に出国した | 判定の時（前年の12月31日）の現況（住所が国外・年齢・障害：`dependents/person_at.py`）。その時に住所が国外の人は同居を常況としない（法令の読み） |

市町村の注入データを読むように変えるときは、この宣言も変える**（宣言が実際と違うと、評価した組の中でしか食い違いを見つけられない）。

## 6. 法令の読み（根拠に「法令の読み」の印）

- 課税標準額の千円未満の切捨て（第20条の4の2第1項）の当て先（JT1：一次情報がない）は、法令の読みの候補（`ReadingSlotSpec`。packages/core/README.md §5）で、控除後の課税総所得金額等に当てる読みと控除前の総所得金額に当てる読みの両方で評価する（金額だけが違えば幅、判定が分かれたら未確定。式は読みで値が違う人がいるときだけ候補を引く：§7 の JM-22。2026-11-12）。
- 税額控除の順序：調整控除 → 配当控除・住宅借入金等・寄附金（順序は結果に効かない）→ 附則第3条の3第5項の調整 → 申告特例控除 → 配当割額等の控除（最後）。
  申告特例控除と配当割額等の控除は、確定申告書の提出で申告特例がなかったものとみなされ、配当割額等の控除は確定申告書の記載が要件なので、同じ人に両方は当たらない（D22 S15 の両方の順序の評価は生じない）。
- 上場株式等の分離課税の所得割（3%・2%、指定都市 4%・1%）を第314条の3 の所得割の額に加える。分離課税の所得は総所得金額等に含める（所得税と同じ）。
- 寄附金税額控除は申告（確定申告書・住民税の申告書・申告特例通知書）があったものとして計算する（申告の計画は利用側）。寄附金の合計額（総所得金額等の30%が上限）は
  市町村民税（市町村の条例）と道府県民税（道府県の条例）で別に求める（第314条の7第1項・第37条の2第1項）。
- 特例控除の割合：課税総所得金額−人的控除差調整額が0未満（課税総所得金額等がない場合を含む）で上場株式等の分離課税の所得がある人は、附則第5条の5 の第5号の割合
  （100分の75を附則第5条の6 で読み替えた 74.685%。第1号〜第4号はこの版では当たらないので最も低い割合はこれ）。上限は所得割の額（分離課税の所得割を含む：附則第33条の2第7項第4号）の20%。
- 総所得金額から引ききれない所得控除は、上場株式等に係る配当所得等の金額 → 譲渡所得等の金額の順に控除する（所得税の措通31・32共−4 の順。住民税の一次情報なし：
  もう一つの順と課税標準の合計が違う人は分かれ目〔一次情報〕で未確定。住民税の率は区分の間で同じなので、違うのは千円未満の切捨ての差だけ）。
- 住宅借入金等特別税額控除：居住年 平成28年〜令和3年の基礎控除の差の加算は現行の文言どおり（法令の経路は未確認：extra-model H3-2 の読み A）。
  居住年が平成26年〜令和3年で特定取得・特別特定取得なら控除限度は 4.2%・81,900円（指定都市 5.6%・109,200円、道府県民税 2.8%・54,600円〔1.4%・27,300円〕）。
- 均等割：住所を有する者の市町村民税・道府県民税は均等割額と所得割額の合算額で課し、確定金額の百円未満を切り捨てる。所得割の額は百円未満を切り捨てて示し、
  合算額の切捨ての差を均等割の側に置く（税率が百円の倍数なら差はない）。家屋敷課税の均等割は市町村ごと・税目ごとに百円未満を切り捨てる。
- 家屋敷課税の運用の型 B：その市町村に住所を有する配偶者が住所地で均等割を課されている（`住民税_住所地の均等割を課すか`）なら課さない。
- 第311条第1号の「同一生計配偶者又は扶養親族」は所得税の判定（`所得税_同一生計配偶者に当たるか`・`住民税_非課税の判定で数える扶養親族か`）、第2号の「有する」は
  所得税の扶養の申告者と同一生計配偶者を持つ人。両方に当たり条例の額が違えば未確定（注入）。
- 非課税の判定の寡婦（第295条第1項第2号）：寡婦に当たる人に加え、離婚した後婚姻をしていない者で、扶養親族が他の納税義務者の扶養親族とされているがその扶養費の
  一部を負担している人（判断.扶養費の一部負担。総務省の取扱通知 第2章第1節第1の3：根拠の種類は通知）。所得税・住民税の寡婦控除には使わない。
- 申告特例のなかったものとみなす事由の第4号：寄附をした日の住民票の市町村が賦課期日の住所と同じなら当たらない。違う人は未確定（決める手段：事実。§7 の JM-21）。
- 非課税の判定で数える扶養親族の人数・年齢は前年の12月31日の現況（時点の一次情報が未発見）。
- セルフメディケーション税制の額は所得税の特例の額を写す（附則第4条の5 の読替えの額を docs に写していない：原文未確認）。
- 退職所得の分離課税：年度 F の値は F−1 年中に支払を受けるべき退職手当等の分。千円未満・百円未満の切捨ては第20条の4の2 の読み。
