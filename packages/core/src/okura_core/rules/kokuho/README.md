## 3. 計算の中身

- **所得の段階（H11）**：`calc.ResidentIncome` が住民税の所得の段階（総所得金額等・雑損失の繰越控除・専従者給与・分離課税の所得・公的年金等に係る所得）を持ち、
  所得割の基礎（`shotokuwari_base`：雑損失の繰越控除を足し戻す）と軽減の判定（`keigen_income`：専従者給与を足し戻す・65歳以上の年金の15万円）で段階を選ぶ。
  上場株式等に係る譲渡所得等の金額は、譲渡損失の繰越控除（地方税法附則第35条の2の6第11項）の後の額（`住民税.上場株式等に係る分離課税の所得の金額`）
  （2026-11-12：軽減は国保令第29条の7第6項第1号のかっこ書きの明文、所得割の基礎〔同条第2項第4号〕は附則第35条の2の6第13項の読替えを通した法令の読み。[PS4-KH] §2、H8・I8）。
- **軽減の判定**：合算額が 43万円＋10万円×(k−1)（7割）、＋n×a（5割）、＋n×b（2割）を超えない（[KHP] §6.1）。
  2026-11-12（境目の説明。D19・`boundaries.undeclared`）：基準額を `国保.7割軽減の基準額`・`国保.5割軽減の基準額`・`国保.2割軽減の基準額`（円。年度の政令の値・k・n で変わるので
  境目の説明の基準の概念）に、比較を `国保.7割軽減の所得基準を満たすか` など（真偽。境目 `国保.7割軽減の所得基準` など：軽減判定所得と基準額、以下）に分け、
  `国保.軽減の区分` はその3つを読む（値は変えない）。
- **保険料の額**（`calc.household_premium`）：区分（基礎・後期・介護〔40〜64歳〕・子ども〔令和8年度から〕）ごとに、所得割（＋資産割〔方式イ〕）＋被保険者均等割
  （＋18歳以上被保険者均等割〔子ども〕）＋世帯別平等割（方式イ・ロ）。均等割・平等割は軽減の割合で減額、未就学児の均等割は軽減の後の額に割合を掛けて減額、
  子どもの区分の18歳未満の均等割は全額減額。限度額は減額の後の区分ごとの額に当てる（法令の読み）。税は確定金額の100円未満を切り捨てる（地方税法第20条の4の2第3項）。
- **国保法第116条の2（入院等の特例。2026-11-12：[PS4-KH] §1、H7・I7。`facts.deem_institution`）**：住所（市町村）だけをみなす。入院等の前の市町村は、
  kokuho_event（institution_special_case）の when の始まり（入院等の日。継続して入院等をしている人は最初の病院等への入院等の日として記録する：第2項第1号と同じ市町村になる）の
  前日の住民票の市町村で、賦課期日の市町村と違えばその市町村の被保険者として賦課の定め（注入データ）を引く（未確定にしない）。前日の住民票がなければ分かれ目（事実）。
  世帯は第116条の「当該世帯に属するものとみなす」の文言がないので事実の世帯（入院等により属することとなった世帯：国保則第5条の2 の語）で計算し、`国保_被保険者か` の根拠に
  法令の読みの印（`inputs.INSTITUTION_BASIS`）。ただし児童福祉施設への措置入所（admission_type が child_welfare_placement）で扶養義務者（親）がほかの世帯にいる子は、
  注入点 `国保.児童福祉施設に措置入所した子の世帯`（2026-11-12 に足した。候補は「入所により属することとなった世帯」と「入所前の扶養義務者の世帯」〔柏市の案内：[PS4-KH] §1.2〕の2つの型）
  で世帯を決め、未注入なら両方で評価して分かれれば未確定（決める手段＝注入）。親元の世帯は、親の世帯のうち入所の前日の世帯、なければ1つに決まる親の世帯（決まらなければ分かれ目：事実）。
  admission_type の欄がない institution_special_case：住所のみなしはどの号でも同じなので市町村は同じに決める。世帯は、親がほかの世帯にいなければ事実の世帯、いれば号で分かれうるので
  分かれ目（事実：admission_type）。市町村がみなした世帯（deemed_household_id）があれば世帯はそれを使う（住所の市町村は上のとおり）。みなされる住所の市町村と属する世帯の市町村が
  違う被保険者は分かれ目（一次情報）。
- **注入データ**：世帯の市町村×賦課期日の1か所で、10の注入点を引く（`inputs.INJECTIONS`。端数処理・月割り・産前産後・特定世帯の4つは要る世帯だけに1か所を置く）。
  第116条の2 の子の世帯の注入点は、みなされる住所の市町村×賦課期日の1か所（その子がいるときだけ。`inputs.child_slots`。世帯の組み方を変えるので、ほかの注入点の1か所は
  両方の組み方の世帯の市町村について宣言する）。
  料か税か・軽減の割合・端数処理は候補の全部で評価し、率と額・方式・限度額・（税の）未就学児の減額・月割り・産前産後・特定世帯の額は未注入なら
  保険料の額・所得割額が未確定（決める手段＝注入）。

  特定世帯の「経過する月」の読み、非自発的失業者の特例の所得金額調整控除・一時所得との関係、第116条の2 でみなされる住所と世帯の市町村が違う被保険者。
- 公表待ち：令和9年度の政令の基準（賦課限度額・軽減の基準額。[PS3-KH] §1：2026-11-11 時点で未公布）。令和9年度の18歳までの均等割の減額の割合（法律は改正済み、政令は未改正）も同じ。
- 根拠のない端数（候補で評価し、金額だけ違えば幅）：非自発的失業者の特例の給与所得の100分の30の1円未満。

2026-11-11 の実装（D24③）：
- 非自発的失業者の特例（国保令第29条の7の2・地法第703条の5の2）：段 `国保の所得の段階` が、住民税の給与所得の金額の100分の30（1円未満は候補）に置き換えて
  総所得金額（損益通算の後・繰越控除の前）から減る額を書き、所得割の基礎と軽減の判定の所得から引く（`calc.unemployment_cut`。0 で止める。繰越控除はその後に当てる読み）。
- 端数処理・月割り・産前産後・特定世帯の注入点を `InjectionSpec` で宣言して使う（`inputs.INJECTIONS`）。端数処理は率と額が注入された市町村だけに1か所を置く。
  月割りは「取得した月から喪失した月の前月まで」の月数（`facts.rule_months`）×1月分の割合で、人ごとの所得割・資産割・均等割と、被保険者のいる月数で平等割を月割りする。
  産前産後は出産被保険者の所得割額・均等割額（介護の区分を含む）の期間の月数×1月分の割合を減額する（資産割・平等割は対象外：国保令第29条の7第6項第8号）。
  特定世帯・特定継続世帯は基礎・後期・子どもの区分の平等割を注入データの額にする（特定月は特定同一世帯所属者になった日の月。年度の途中や読みで区分が変われば分かれ目）。
- 雑損失の繰越控除と退職所得：繰越控除の順序（所令204①二・②）で退職所得から控除した雑損失を分け、足し戻さない（`calc.resident_income`）。
- 国保法第116条：修学中の特例の人を、賦課期日に住民票の世帯がある親の世帯にみなす（読み：仮説 round2 kokuho-core-vs-injected の「親の世帯」）。

2026-11-12 の共有の変更（語彙と注入点の欄）：
- `kokuho_event.attributes.deemed_household_id`（市町村がみなした世帯）：第116条・第116条の2 の人は、この記録があればその世帯に入れる（なければ従来どおり）。
- `medical_insurance.attributes.nhi_association`（国民健康保険組合の被保険者か）：真なら都道府県と市町村が行う国保の被保険者に数えない（組合の保険料は組合の規約で、このモジュールは計算しない。世帯主なら擬制世帯主と同じ扱い）。
- 注入点 `国保.年度の途中の資格の月割り` の欄 `月割りと賦課限度額の順序`（月割りした後の額に賦課限度額を当てる／その他）。
- **出産の記録**：国保の産前産後の減額（国保令第29条の7第6項第8号）と国年の産前産後・育児期間の免除（国年法第88条の2・第88条の3）は、
  共通の事実の種類 `childbirth`（出産予定日・出産の日・多胎・出産に係る子 `child_ids`）を使う（kokunen と同じ記録）。以前の書き方 `kokuho_event` の `childbirth` も読み、
  同じ出産予定月の記録は1つの出産として扱う（減額の月は集合なので二重に数えない）。
