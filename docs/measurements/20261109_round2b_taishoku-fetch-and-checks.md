## 6. 実測で分かったこと（まとめ）

1. 所得税法第30条・第31条・第89条・第199〜203条、別表第六は、asof 2024-12-31 から 2027-01-01 まで同文（令和7年分・令和8年分で退職所得の金額の式・源泉徴収の式は変わらない）。
2. 所得税法施行令第70条第1項第2号は、asof 2025-12-31 と 2026-11-09 の間で変わった。改正附則（令和7年政令第120号附則第4条）は「新令第七十条第一項（第二号に係る部分に限る。）の規定は、令和八年分以後の所得税について適用」。ただし C7 のとおり、令和7年分・令和8年分の計算結果は改正前と同じになる組合せしかない。
3. 地方税法の分離課税（第50条の2〜第50条の10、第328条〜第328条の16）は 2026-01-01 から 2027-01-01 まで同文。2027-01-01 に退職手当等の定義の引用先（措法29の4→29の5）だけが変わる。
4. 国税庁・総務省の設例（源泉徴収税額、退職所得の金額、住民税の早見表）は、条文から組み立てた式と端数処理の順で、すべて再現できた。

## 7. 実測で確かめていないこと

- 国税通則法施行令第40条の本文は、この実測では取得していない（TA2732 の根拠法令に「通令40」とある）。独立した検証で取得した：第40条（見出し「課税標準等の端数計算の特例」）は、所法201① の適用を受ける第199条の所得税を通則法118②・119② の対象から除いている（`docs/measurements/20261109_round2b_taishoku-verification.md` §6）。
- 所令71の2第7項（一般・短期・特定役員の3つがある場合）と第9項（控除額に満たない場合の調整）の式は、設例（TA2741 の後半）を読んだが検算していない。
- 地方税法施行令の分離課税に関する条（第8条の4、第48条の17 ほか）の本文は抜き出していない（索引だけ）。
- 確定申告で退職所得を申告する場合の所得税額（課税退職所得金額への所得控除の当て方、第89条の別々の表の適用、復興特別所得税の合算）の検算はしていない（構造は［PS］§4.1）。
