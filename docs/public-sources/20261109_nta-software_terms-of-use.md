## 原文で確認したこと

### 1. 作成コーナーの利用規約（令和５年４月１日改定後）

- 前文：「作成コーナーから直接国税電子申告・納税システムにデータを送信した場合には、『国税電子申告・納税システムの利用規約』が適用されます。」
- 「４　コンテンツの利用」：「作成コーナーで公開している情報（以下『コンテンツ』といいます。）の利用については、別に定める『国税庁ホームページ利用規約』が適用されます。」
- 「６　禁止行為」に、リバースエンジニアリング・逆コンパイル・解析を名指しで禁じる項目は**ない**。ただし次の包括的な項目がある。
  - 「第三者又は国税庁の財産及びプライバシー等を侵害する行為又は侵害するおそれのある行為。」
  - 「第三者又は国税庁に不利益若しくは損害を与える行為又はそのおそれのある行為。」
  - 「法律、法令又は条例に違反する行為又はそのおそれのある行為。」
  - 「その他国税庁が不適切と判断する行為。」
- 作成コーナーのプログラム（ブラウザで動く JavaScript など）の著作権や利用許諾について定めた条項は**ない**。

### 2. 年調ソフトの利用規約（令和７年10月１日施行版）

- 「４　利用許諾」：許諾されるのは「（１）年調ソフトを対象機器にインストールして、対象機器上で年調ソフトを利用すること」と「（２）自然人たる利用者の個人的利用又は法人たる利用者の法人組織内部での利用の目的で年調ソフトを複製すること」だけ。
- 「５　著作権等」：「（１）年調ソフトの著作権は、国税庁が保有しており、国際条約及び著作権法により保護されています。」「（２）年調ソフトには、国税庁に対するライセンス付与者（以下『供給者』といいます。）が権利を保有するソフトウェアが含まれています。」
- 「６　禁止行為」に、リバースエンジニアリングを名指しで禁じる項目は**ない**。作成コーナーと同じ包括的な項目（財産の侵害、不利益、法令違反、「その他国税庁が不適切と判断する行為」）がある。違反した場合やそのおそれがある場合は「事前に通告することなく、年調ソフトの利用を直ちに停止させることができる」。

### 3. 国税電子申告・納税システム（e-Tax）の利用規約（令和７年１月６日施行版）

- 第２条第二号：「『システム利用者』とは、本システムを利用して申告等手続又は国税の納付手続を行う者をいいます。」
- 第４条第１項：「国税庁がシステム利用者に提供する一切のプログラム又はその他の著作物（本利用規約及び本システムの取扱マニュアル等を含みます。以下同じ。）に関する知的財産権（…）は、国税庁に帰属し、システム利用者に移転又は帰属しません。」
- 第４条第２項：「システム利用者は、国税庁がシステム利用者に提供する一切のプログラム又はその他の著作物を次の各号のとおり取り扱うものとします。」
  - 第一号：「本利用規約に従って本システムを利用するためにのみ使用すること。」
  - 第二号：「**複製、改変、編集、頒布等を行わず、また、リバースエンジニアリングを行わないこと。**」
- 第19条第３項：「本利用規約の変更後に、システム利用者が本システムを利用するときは、システム利用者は変更後の利用規約に同意したものとみなされます。」

### 4. 国税庁ホームページの利用規約・著作権

- コンテンツは、別段の明記がない限り「公共データ利用規約（第1.0版）」に従って利用できる、とされている（ページは Shift_JIS。WebFetch による読み取りで確認。条文の全文はまだ逐語で確認していない）。
- 作成コーナーの JavaScript などのプログラムが、ここでいう「コンテンツ」に含まれるかどうかは、このページからは判断できなかった。

## 分からなかったこと

- 作成コーナーの利用規約の**現行版**がどれか。確認できたのは「お知らせ」に置かれた令和５年４月１日改定後の PDF で、作成コーナー上の利用規約ページそのものはまだ見つけていない。
  - 追記（2026-11-09）：作成コーナー上の現行の利用規約は「最終更新日：令和７年１月６日」だった。この版にも、解析を名指しで禁じる条項はない。詳細と取得の記録は実測 `docs/measurements/20261109_sakusei-corner_client-analysis.md` の §0.1 を参照（このファイルは公開資料の情報だが、出典の版の特定に実測の結果を使っている）。
- 作成コーナーのプログラムが e-Tax 利用規約第４条の「国税庁がシステム利用者に提供する…プログラム」に当たるか。作成コーナーの利用規約は、e-Tax に送信した場合に e-Tax の利用規約が適用されるとしている。
- 公共データ利用規約（第1.0版）がプログラムをどう扱うか（未確認）。
- 著作権法上、解析（リバースエンジニアリング）と、そこから得た知見を自分で実装し直すことがどこまで許されるか。条文（e-Gov）はまだ確認していない。

## 気づいたこと（事実の整理）

- e-Tax の利用規約は、リバースエンジニアリングを**名指しで禁止している**。この規約は「システム利用者」（e-Tax で申告等を行う者）に適用され、規約の変更後に e-Tax を使うと変更後の規約に同意したとみなされる。
- 作成コーナーの利用規約と年調ソフトの利用規約には、名指しの禁止はない。ただし包括的な禁止項目（「その他国税庁が不適切と判断する行為」など）がある。
- 年調ソフトには、第三者（供給者）が権利を持つソフトウェアが含まれている。その部分には、別の許諾条件がある可能性がある。
