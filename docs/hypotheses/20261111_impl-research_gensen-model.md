# 仮説（impl-research gensen）：源泉徴収税額の精算のモデル

- 作成：2026-11-11。根拠：［PS-GS］`docs/public-sources/20261111_impl-research_gensen-laws-and-nta.md`、［PS-JJ］`docs/public-sources/20261111_impl-research_joto-junjo-laws.md`、［PS-ZG］`docs/public-sources/20261109_impl-prep_zeigaku-tax-calc.md`、［YS］`docs/public-sources/20261109_round2_yoshiki-forms-r07.md`。

## H1 精算

- 第一表の ㊾ 源泉徴収税額（所得税及び復興特別所得税の合計額）＝ その年の申告に含める所得についての「源泉徴収をされた又はされるべき」額の合計（所法120①四）。第一表 ㊿ 申告納税額で ㊻−㊼−㊽−㊾（［YS］）。
- 除外：源泉分離課税の所得、確定申告をしないことを選択した配当所得等（手引き 3-4_38、TA1330。［PS-GS］§1・§3）。選択した配当の源泉徴収税額は控除しない。
- 含める：総合課税・申告分離課税で申告した配当所得、給与（源泉徴収票の金額）、退職所得を申告に含める場合の退職所得（所法120①四「…若しくは退職所得金額…の計算の基礎となった各種所得」。第121条第2項の適用で申告しない退職所得は除く）、公的年金等、一時所得、報酬等。申告分離の上場株式等の配当・譲渡は第二表「所得の内訳」と第三表で併せて記入（手引き 3-4_38）。
- 根拠：［PS-GS］§1・§3、［PS-ZG］§4。

## H2 入力の事実（源泉徴収票の欄）

- 各種所得の源泉徴収票等の「源泉徴収税額」欄の額を事実として受ける（K4：源泉徴収票の値を優先）。
- 欄：給与所得の源泉徴収票「源泉徴収税額」、退職所得の源泉徴収票「源泉徴収税額」（法定調書の手引 3-2-6）、報酬料金等の支払調書「源泉徴収税額」（同 4-2-6）。公的年金等の源泉徴収票の欄名は未確認（［PS-GS］§5-2）、配当等の支払通知書・特定口座年間取引報告書は未確認（同 §5-4）。
- 復興特別所得税分は「所得税及び復興特別所得税の合計額」で入力（手引き・法定調書の手引の欄の説明）。分けて入力しない。

## H3 復興特別所得税の算出と端数

- 所法の税額（第一表 ㊹ 基準所得税額）×2.1%、1円未満切捨て（手引き［ZG］§3.3／［PS-HS］§4）。切捨ての法令上の根拠は未解決だったが、通基通119−6 が根拠の候補（［PS-HS］§5）。根拠の種類は「通達」とする。

## H4 公的年金等の源泉徴収の額の算定

- 精算に使うのは実際の源泉徴収税額。所法203の3 の算定は年金受給者の控除額の見込みの説明に使うときだけ必要（［PS-GS］§2。令和8年分の改正の適用の時点は未確認で、本スコープでは入力された金額を使う）。
