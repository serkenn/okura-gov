
## 4. 気づいたこと（測定の限界）

- e-Gov の改正附則の収録は一部が「略」になっている（令和6年法律第47号 附則第1条第2号〜第5号、令和7年法律第74号 附則第1条第2号など）。
- asof に年の末日を使っているので、年の途中に変わって戻った条は見落とす。第89条については `scripts/IMPL4_verify_recheck.py` で 2023-01-01・2023-06-30 の版も確かめた（`docs/measurements/20261112_impl-research4_verification.md`）。
- 「UnEnforced」の版の施行日は改正法の附則で確かめる必要がある（sochi の 2026-12-31 は施行日 None）。
