## 2. ⑯地震保険料控除の計算欄（第二表の「支払保険料等の計」）

出典：手引き 手順3「地震保険料控除」 https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/03/order3/3-3_13.htm （写し `t_3_3_13.txt`）。

- 計算欄：A 地震保険料のみの契約の合計、B・C 地震保険料と旧長期損害保険料の両方がある契約の地震保険料・旧長期損害保険料、D 旧長期損害保険料のみの契約の合計、
  E＝A＋B、F＝C＋D、G＝D の段階の式（10,000円以下は D、超えれば D×0.5＋5,000円、最高15,000円）、H＝E＋G（最高5万円）、I＝F の段階の式、J＝A＋I（最高5万円）、
  K 地震保険料控除額＝「HとJのいずれか多い方の金額」。1円未満の端数は切り上げて差し支えない。
- 第二表：「計算欄Kに計算欄Hの金額を記入したとき」は「地震保険料」欄に E、「旧長期損害保険料」欄に D を「支払保険料等の計」欄に記入。
  「計算欄Kに計算欄Jの金額を記入したとき」は「地震保険料」欄に A、「旧長期損害保険料」欄に F。
- 「地震保険料及び旧長期損害保険料の両方の支払が証明された保険契約が2以上ある場合は、「確定申告書等作成コーナー」での申告書の作成が便利です。」

## 3. 第一表 60「雑所得・一時所得等の源泉徴収税額の合計額」

出典：手引き 手順5「その他」 https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/03/order5/3-5_01.htm （写し `t_3_5_01.txt`）。

> ㊿ 欄 … 「源泉徴収税額㊾」欄に記入した税額のうち、雑所得、一時所得、臨時所得、株式等の譲渡所得及び退職所得の金額に対する所得税等の源泉徴収税額の合計額を記入します。
> ※ 株式等の譲渡所得等を併せて申告する場合は、それらの所得に係る所得税等の源泉徴収税額も合計します。

## 4. 第二表「住民税に関する事項」の配当の欄

出典：手引き 手順6「住民税」 https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/03/order6/3-6_02.htm （写し `t_3_6_02.txt`）。

- 「非上場株式の少額配当等」：「住民税は、所得税等において確定申告不要制度を選択した非上場株式の少額配当等についても、他の所得と総合して課税されますので、記入が必要です。」
  計算欄 A 配当所得の金額（第一表⑤欄の金額）、B 確定申告不要制度を選択した非上場株式の少額配当等、C 配当に関する住民税の特例（A＋B）。
  「計算欄Bに該当する金額がある方は、計算欄Cの金額を転記します。」「特別徴収された住民税額（配当割額）は、配当割額控除額欄に記入してください。」
- 「配当割額控除額・株式等譲渡所得割額控除額」：令和7年中に道府県民税配当割額（5%）が特別徴収された特定配当等・道府県民税株式等譲渡所得割額（5%）が特別徴収された
  特定株式等譲渡所得金額について、「所得税等の確定申告をして所得税等の源泉徴収税額の控除や還付を受ける場合には、住民税についても特別徴収税額の控除や還付を受ける」。
  「所得税等の確定申告をした場合は、配当割額及び株式等譲渡所得割額を記入します（記入がない場合、この控除を受けることができませんのでご注意ください。）。」
