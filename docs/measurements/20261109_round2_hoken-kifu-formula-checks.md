## 2. 1円未満の端数

条文（所法76、措法41の15の5、地方税法314の2①五）には端数の処理が書かれていない（`docs/measurements/20261109_round2_hoken-kifu-fetch.md` §3.5 の全文検索も参照）。式の上で端数が出る支払額の数を数えた。

| 式 | 範囲 | 端数（1円未満）が出る支払額の数 | 例 |
|---|---|---|---|
| 所得税・新（計算式Ⅰ） | 0〜200,000 円の整数 | 40,000 | 20,001 円 → 40001/2 円、40,003 円 → 120003/4 円 |
| 所得税・特例（計算式Ⅱ） | 同上 | 60,000 | |
| 所得税・旧（計算式Ⅲ） | 同上 | 50,000 | |
| 住民税・新（地法314の2①五イ（１）） | 同上 | 28,000 | |
| 住民税・地震保険料（地法314の2①五の三、1/2） | 0〜100,000 円 | 25,000 | 10,001 円 → 10001/2 円 |

端数を切り上げるか切り捨てるかで、区分ごとに最大1円の差が出る。国税庁「令和8年分 年末調整のしかた」p.24 注2・p.26 注3 は「1円未満の端数があるときは、その端数を切り上げます」と書く（この文書の取得の記録と、`docs/public-sources/20261109_round2_hoken-kifu-nta-soumu.md`）。

## 4. 雑損控除

| 確かめたこと | 範囲 | 結果 |
|---|---|---|
| 所法72①一〜三（災害関連支出の金額 D の大きさで足切り額を変える3つの場合分け）＝ TA1110 の「(1)（損失の金額 − 総所得金額等×10%）と (2)（災害関連支出の金額 − 5万円）のいずれか多い方」 | 境目の組（L∈{0, 3万, 5万, 50,001, 8万, 30万}、D∈{0, 3万, 5万, 50,001, 8万}、T∈{0, 30万, 50万, 60万, 500万}、D≦L）と、乱数（seed 20261109）の20万組（L≦300万、D≦L、T≦2,000万） | 200,100 組で不一致 0 |

ここで L は損失の金額（災害等関連支出を含み、保険金等で補塡される部分を除いた額）、D はそのうちの災害関連支出の金額、T は総所得金額・退職所得金額・山林所得金額の合計額。保険金等をどちらから先に差し引くか（TA1110 は「まず損害金額から」）は、この検算の入力（L と D）を作る前の段の話で、ここでは確かめていない。
