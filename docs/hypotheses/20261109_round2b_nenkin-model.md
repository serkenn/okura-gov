## H1 公的年金等の雑所得の式は令和7年分・令和8年分で同じ。条文どおりに組めば国税庁の速算表と一致する

- 根拠：[PS] §2.1・§2.2、[M] V1（所法35①〜④・措法41の15の3①④ が 2025-12-31 版と 2026-12-31 版で同文）、[M] V2（6表・210,677 点で不一致 0）、[M] V4。
- 法令が決める構造（F）：
  1. A ＝ その年の公的年金等の収入金額の合計（全支払者・全種類の合計。§H3 で課税の年金だけ）。
  2. O ＝ 公的年金等に係る雑所得以外の合計所得金額 ＝「公的年金等の収入金額がないものとして計算した場合における」合計所得金額（所法35④一）。所得金額調整控除の第2項は適用しないものとして計算する（所基通35−8、E）。
  3. 区分：O ≤ 1,000万円 → (40万, 最低60万)、1,000万円 < O ≤ 2,000万円 → (30万, 最低50万)、O > 2,000万円 → (20万, 最低40万)。65歳以上は最低額を 110万・100万・90万に読み替え。
     - 読み（I）：措法41の15の3①が読み替えるのは各号の最低額（第1号の「六十万円に」「六十万円）」、第2号の「五十万円」、第3号の「四十万円」）だけで、第1号ロの「五十万円を控除した残額」は第1号の中の語なので読み替えの対象（第2号の「五十万円」）ではない。この読みで組んだ式が速算表と全整数で一致する（[M] V2、[MV]）。
  4. b ＝ f(max(0, A − 50万))：残額 ≤ 360万 → 25%、≤ 720万 → 90万＋15%、≤ 950万 → 144万＋5%、超 → 155万5千。
  5. 公的年金等控除額 ＝ max(最低額, 定額＋b)。公的年金等の雑所得（所法35②一）＝ max(0, A − 控除額)。
  6. 雑所得の金額 ＝ ⑤ ＋ 公的年金等以外の雑所得（所法35②二。業務・その他。こちらは負になりうる）。
- 計算の順序（I）：O の計算は公的年金等を含まない → 控除額 → 公的年金等の雑所得 → 所得金額調整控除（第2項は給与と公的年金等の両方を使う：[PS-GAPS] §3.1）→ 合計所得金額。循環はない。
- 所法35⑤（給与所得控除額＋公的年金等控除額が 280万円超の調整）は令和9年分から。令和7年分・令和8年分のパラメータには入れない（[PS] §2.1）。
- 実装の形：公的年金等控除は「区分（O の帯）× 年齢区分」で最低額だけが変わる。パラメータは「定額（40/30/20万）」「最低額（60/50/40万、65歳以上 110/100/90万）」「控除の帯（50万・360万・720万・950万）と率（1/4, 15/100, 5/100）と上限 155万5千」「O の境目（1,000万・2,000万。以下／超）」。率は整数の分数で持つ（SCOPE §8・§10 T2）。

## H2 65歳の判定は「その年12月31日（死亡・出国の年はその時）」。住民税は前年の12月31日

- 根拠：[PS] §2.2（措法41の15の3④）、[PS] §2.3（暮らしの税情報の注）、[M] V6、[M-AGE]（式A）、[PS] §7.2（東京都・東大阪市）。
- 構造（F）：所得税は措法41の15の3④。年の中途で死亡・出国した人はその時の年齢。
- 年齢の数え方（I：[M-AGE] の式A をそのまま使う）：12月31日の年齢 ＝ その年 − 生まれた年 ＋（1月1日生まれなら1）。令和8年分は 1962-01-01 以前に生まれた人が 65歳以上（[M] V6 で国税庁の注と一致）。
- 住民税（I）：地法313② の「所得税法その他の所得税に関する法令の規定による…計算の例」により、前年分の所得税と同じ計算になる、と読む。地方税法に別の定めは見つからなかった（[M] §2）。国税庁は「住民税を算出する際の…計算方法も同様」とする（E）。判定は前年の12月31日。
  - 東大阪市の「1月1日の現況」と東京都の「前年の12月31日現在」は、**1月2日生まれの人で結果が分かれうる**（I。[M-AGE] の式L：n 歳に達するのは応当日の前日の終了時）。1月2日生まれの人は1月1日の終了時に年齢が1つ増えるので、「1月1日の現況」を1月1日の終了時の年齢と読めば、前年12月31日の年齢より1つ上になる（例：1962-01-02 生まれは 2026-12-31 の終了時に 64歳、2027-01-01 の終了時に 65歳：[MV]）。1月1日の始まり（＝12月31日の終了時）と読めば同じ。1月1日生まれは12月31日の終了時に増えるので、どちらの読みでも同じ。案内（E）だけではどちらか決まらないので、判定コアは法令の構造（措法41の15の3④ を地法313② で前年に当てはめる読み）どおり前年12月31日で判定し、1月2日生まれの人には根拠に「地方公共団体の案内と食い違いうる」と注記する案を採る（検証方法は推測 I7）。
- 入力として必要な事実：生年月日、死亡日、出国日（出国の事実は非居住者の判定の入力と共通）。
- 健保の 60歳（180万円）・公的年金からの特別徴収の 65歳（4月1日）は別の判定時点で、この関数を使わない（[PS] §7.1、§8）。

## H3 年金の「課税・非課税」と「公的年金等か」は、事実（制度と支給事由）から判定コアが表で決める

- 根拠：[PS] §1・§4。
- 中間表現に入れる事実（法的な解釈を含めない：D3・D5）：年金の支払ごとに
  - 受給者、支払者（名称と、国内の支払者か国外か）、**制度**（国民年金・厚生年金・国家公務員共済・地方公務員共済・私学共済・企業年金〔確定給付・確定拠出・厚生年金基金等〕・恩給・外国の制度・その他）、**給付の名称／支給事由**（老齢・退職、障害、遺族、付加、老齢福祉、寡婦、未支給、年金生活者支援給付金…）
  - 法令等による支給日（§H5）、計算の対象の期間、支払金額（社会保険料の控除前）、天引きされた社会保険料（種類別）、源泉徴収税額、証憑（源泉徴収票・改定通知書・振込通知書）。
- 判定コアの表（F を根拠とする行。根拠の条を結果に付ける：D13）：

| 制度 × 支給事由 | 所得税・住民税 | 根拠 |
|---|---|---|
| 国民年金：老齢基礎年金・付加年金 | 課税（公的年金等） | 国年法25 ただし書、所法35③一 |
| 国民年金：上記以外（障害基礎・遺族基礎・寡婦年金・老齢福祉年金など） | 非課税 | 国年法25 本文 |
| 厚生年金：老齢厚生年金 | 課税（公的年金等） | 厚年法41② ただし書 |
| 厚生年金：障害厚生・遺族厚生など | 非課税 | 厚年法41② 本文 |
| 共済（国・地方）：退職年金 | 課税（公的年金等） | 国共済法49・地共済法52 ただし書 |
| 共済：障害を支給事由とする年金 | 非課税 | 同 本文 |
| 共済：公務遺族年金（私学は職務遺族年金） | **未確定**（共済法上は公課の禁止の対象外。所法9①三ロ・所基通9−2 では遺族の年金は非課税と読めるが、名指しした一次情報なし：[PS] §10-3） | — |
| 確定給付企業年金・確定拠出年金（老齢給付）など | 課税（公的年金等。本人負担分を除く） | 所法35③三、所令82の2② |
| 企業年金などに基づく遺族年金 | 非課税 | 所法9①三ロ、所基通9−2（E）、TA1605（E） |
| 未支給年金（遺族が自分の名で受けるもの） | 遺族の一時所得（法律で非課税とされるものを除く） | TA1605（E）。一時所得の規則へ回す |
| 年金生活者支援給付金 | 非課税 | 支援給付金法33 |

| 生命保険契約・共済契約に基づく年金、互助年金 | 公的年金等ではない（その他の雑所得。本書の範囲外） | TA1600（E） |

- 各年金法の公課の禁止は「租税その他の公課」と書くので、所得税だけでなく住民税にも及ぶ（文言の読み。I。[PS] §4.1）。表の「所得税・住民税」の列はこの読みによる。
- 表にない組合せは「対象外（未知の年金）」として止める（SCOPE §2 の4）。
- 人の判断（D4）に当たるもの：外国の年金が「公的な制度」か、企業年金の本人負担分の額（支払者の書類にないとき）、公務遺族年金の扱い（未確定のまま判断で決めるなら判断者・日時を記録）。

- 概念ごとの数え方（課税の年金＝老齢・退職の公的年金等、非課税の年金＝障害・遺族・支援給付金など）：

## H5 年分は「法令等による支給日」で決まる。さかのぼって払われた分は元の支給日の年分に戻す

- 根拠：[PS] §3（所基通36−14、E）、所法36①（F）。
- 構造：年分 ＝ 法令・規約等で定められた支給日の年。改正がさかのぼって実施された差額は、支給日が定められていればその日、なければ改正の効力が生じた日。裁定・改定の遅延・誤りでさかのぼって払われた分は「計算の対象とされた期間に係る各々の支給日」。
- 入力として必要な事実：入金の日（記録）とは別に、**計算の対象の期間と法令上の支給日**（年金機構などの通知書から）。記録アダプタは入金の日しか知らないので、支給日は事実台帳の項目にする（D5：法的な解釈ではなく、通知書に書かれた事実）。
- 効果（I）：過去の年分の公的年金等の収入金額が後から増えると、その年分の受給者の合計所得金額が変わり、**別の家族の過去の扶養の判定**が変わりうる（人をまたぐ依存×年をまたぐ依存：SCOPE §6 の5）。判定コアは「年分 Y の結果が、年分 Y 以降に記録された事実に依存する」ことを根拠に出す。
- 一次情報で決まらないもの：繰下げ受給の特例的なみなし増額で一括して払われる過去分の扱い（[PS] §10-8）。

## H6 所得税の申告不要（所法121③）は、4つの事実の組から決定的に判定できる。源泉徴収税額は計算しない

- 根拠：[PS] §6、[PS] §5.1、[M] V1（121条は3つの版で同文）。
- 構造（F）：次のすべてを満たすとき、課税総所得金額・課税山林所得金額に係る所得税の確定申告を要しない。
  1. その年の公的年金等の収入金額（課税の公的年金等の合計）≤ 400万円。
  2. その公的年金等の**全部**（所法203の7 の適用を受けるもの、措法41の15の4① のものを除く）が、所法203の2 の源泉徴収を「された又はされるべき」もの。
  3. 公的年金等に係る雑所得以外の所得金額 ≤ 20万円。数えるのは利子・配当・不動産・事業・給与・山林・譲渡・一時の各所得の金額と、公的年金等以外の雑所得の金額の合計（2分の1にする前の一時所得の金額。退職所得は入らない）。給与所得の金額は、所得金額調整控除（措法41の3の11②。給与と公的年金等の両方がある人）の控除後の額で数える（措法41の3の11⑥：F。[PS-GAPS] §3.1、[MV]）。
- 2. の読み（I）：203の7（年額が少なくて源泉徴収されない）と措法41の15の4 の年金は「全部」から除かれるので、**2. が満たされないのは、所法203の2 の対象にならない公的年金等がある場合**、すなわち「国内において」支払われない年金（外国の年金：TA1600 注3、E）がある場合に限られる。国内の支払者が誤って源泉徴収しなかったものも「されるべき」で満たす。
  - → 判定に要る事実は「その年金は国内の支払者から支払われたか」だけで、源泉徴収を要しない額（[M] V5 の 155万・205万円など）は判定に要らない。これらは参考のパラメータとしても持たない案を採る（源泉徴収税額は源泉徴収票の事実として受け取る）。
- 所法121①（給与所得者）とは独立で、どちらかを満たせば申告を要しない（I：両項とも「前条第一項の規定にかかわらず…要しない」）。第1項の 20万円には公的年金等の雑所得が入り、第3項の 20万円には給与所得が入るので、給与と年金の両方がある人は両方を判定して結果に両方の理由を出す。
- 納税者の選択（D4 の「選択」）：申告不要でも還付申告はできる（TA1600 注1、E）。判定コアは「申告義務：なし（121③）」と「申告した場合の税額（還付額）」の両方を出し、出すかどうかは利用者の選択にする。申告するなら公的年金等も含めてすべて記載する（I）。
- 申告不要は合計所得金額に影響しない（H4）。
- 未確定：措法の申告不要制度を選んだ配当・株式の所得が 3. の「配当所得の金額」「譲渡所得の金額」に入るか（株式の調査の範囲。ここでは確かめていない）。
- 第120条第1項の申告義務そのもの（税額が出るか）は既存の税額の仮説の範囲。本仮説は「121③ に当たるか」だけを返す。

## H7 住民税：所得の計算は同じ。申告不要の条件は所得税より狭い

- 根拠：[PS] §7.1、[PS-JU] §6、[PS] §6（TA1600 注2）。
- 構造（F）：
  - 所得：前年分の所得税と同じ計算（地法313②の「計算の例」。年齢は前年12月31日：H2）。
  - 申告不要（地法317の2①ただし書）：1月1日現在、公的年金等支払報告書を出す義務のある者から公的年金等の支払を受けていて、前年に**公的年金等に係る所得以外の所得が一切ない**こと。かつ、所定の控除（天引き以外の社会保険料控除、小規模企業共済等掛金控除、生命保険料控除、地震保険料控除、勤労学生控除、一部の配偶者特別控除、同居老親等に係る扶養控除〔地法314の2④の 45万円〕、一部の特定親族特別控除、雑損・医療費控除、純損失等の控除、寄附金税額控除）を受けようとしないこと。
  - 公的年金等支払報告書を出す義務がある者（地法317の6④：F。[PS] §7.1、[MV]）：1月1日現在において公的年金等の支払をする者で、その支払の際に所法203の2 により所得税を徴収する義務があるもの（＝国内の支払者。外国の年金の支払者は当たらない）。
- 帰結（I）：所得税は 121③で申告不要（その他の所得 ≤ 20万円）でも、その他の所得が 1円でもあれば住民税の申告が要る（確定申告書を出せば住民税の申告とみなされる：地法317の3、既存 [PS-JU]）。判定コアは所得税と住民税の申告の要否を別々に返す。
- 入力として必要な事実：1月1日現在の公的年金等の支払者と、その支払者が国内の支払者（所法203の2 の徴収義務がある者）か。年額が少なく源泉徴収を要しない（所法203の7）年金だけの支払者も「徴収する義務があるもの」に当たるかは、条文の文言からは決めきれない（I）。事実として入力がないときは「未確定」。
- 住民税の税額は SCOPE §5.3 で対象だが、この仮説では扱わない（住民税の税額の調査の範囲）。公的年金からの特別徴収（地法321の7の2。徴収の方法）は計算しない。

## H8 端数処理：条文にない。境目の判定を変えるときだけ「未確定」にする

- 根拠：[PS] §2.1・§10-1、[M] V3。
- 事実：百分の二十五・十五・五を掛ける帯（収入 130万円以上〔65歳以上は 330万円以上〕〜1,000万円未満）で、収入金額の多くの値で円未満が出る。
- 一次情報で決まらないもの：公的年金等控除額・公的年金等の雑所得の円未満の扱い（切り捨てか、切り上げか、合計所得金額まで分数のまま持つか）。
- 提案（I）：
  1. 判定コアは分数のまま計算し、名前つきの関数 `公的年金等控除額の円未満処理` を通す。既定は「未確定」（出典未確認の印）とし、候補（控除額の切り上げ＝雑所得の切り捨て、など）を並べて評価する。
  2. 候補で結論（扶養に当たるか、非課税か、税額）が変わらなければ結論を出し、変われば「未確定（端数処理）」を返す（D19）。
  3. 扶養親族の 62万円（令和8年分）・58万円（令和7年分）の境目は、公的年金等の雑所得だけの人なら収入が「A − 60万／110万」の帯にあり（境目の収入は 65歳未満 122万／118万円、65歳以上 172万／168万円）、端数は出ない。端数が効くのは、収入が率の帯にある人の合計所得金額の境目（住民税の 135万円、基礎控除・配偶者特別控除の段階など）。
- 検証：作成コーナー（令和7年分）で率の帯の収入を入れ、表示される雑所得を見る（推測の文書 I6）。

## H9 範囲と対象外

- 根拠：[PS] §1.2、§2.1、§2.2、§6、D20。
- 対象（第1段に入れる）：国内の公的年金等（老齢・退職）の雑所得、非課税の年金の判定、65歳の特例、121③の判定、住民税・健保での数え方。
- 対象外または止めるもの：
  - 非居住者の公的年金等（措法41の15の3③、所法169 など）：非居住者本人の申告は対象外（D20）。
  - 外国の年金：公的年金等の雑所得として計算できる（H3。所令82の2②一・72③九：F）が、121③ は当たらない（H6）。外国で税が課されていれば外国税額控除は対象外と返す（D20）。
  - 所法35⑤（令和9年分〜）：令和9年分を足すときに入れる。
  - 公務遺族年金：未確定（H3）。
- 源泉徴収税額（所法203の3）と扶養親族等申告書の計算はしない。源泉徴収票の「源泉徴収税額」を事実として受け取り、確定申告の精算に使う（H6）。
