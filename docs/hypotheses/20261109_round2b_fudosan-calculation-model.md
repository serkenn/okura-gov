## H1 不動産所得かどうかは「資産の種類と貸し方の事実」と少数の判断で決まり、借地権の設定の一部は譲渡所得（対象外）に分かれる

- 根拠：所法26①［PS §1.1］、所法33①・所令79・80［PS §1.2］、基通26−1〜26−8・27−2・27−3［PS §1.3］。
- 入力として必要な事実（取引・契約ごと）：貸し付けるもの（土地・建物〔室・独立家屋〕・不動産の上の権利・船舶〔総トン数〕・航空機）、食事を供するか、広告のための使用か、使用人の寄宿舎か、借地権・地役権の設定か（その対価、土地の価額、地代の年額）、貸主が不動産業者で販売目的の資産の一時的な貸付けか。
- 人の判断（D4）：有料駐車場などで「自己の責任において他人の物を保管する」か（基通27−2）。バンガロー等が「簡易な施設」か（基通27−3）。
- 法令が決める構造：
  - 不動産所得＝不動産等の貸付けによる所得から、事業所得・譲渡所得に当たるものを除いたもの。
  - 借地権・地役権の設定の対価が所令79①各号の金額の10分の5を超える → 譲渡所得。D20 で土地建物等の譲渡は対象外なので、判定コアは「対象外」と返す。所令79③（対価が地代の年額の20倍以下なら該当しないと推定）は「推定」なので、20倍以下でも判断で覆り得る形にする。
  - 下宿（食事あり）・保管責任のある駐車場などは事業所得又は雑所得として、既存の事業所得の計算（［J］）に回す。
- 一次情報で決まらないもの：所令79 の「土地の価額」は時価で、記録からは決まらない（判断として入力する。入力がなければ、対価が地代の年額の20倍以下のときだけ不動産所得として進め、それ以外は「未確定」）。

## H2 総収入金額の年分への帰属は「契約上の支払日」を基本にし、期間対応（直所2−78）は納税者の選択として持てる

- 根拠：基通36−5〜36−7、直所2−78、TA1370、内訳書の書き方 p.2［PS §2.2］。
- 入力として必要な事実：契約ごとの支払日の定め（ない場合は実際の受領日、請求払いなら請求日）、賃貸料の対象期間、権利金・礼金・更新料・名義書換料・頭金の額と、引渡しの要否・引渡し日・契約の効力発生日、敷金・保証金の額と返還を要しない部分の種類（期間に関係なく／期間の経過に応じて／終了時に確定）と確定日、共益費として受ける電気代・水道代・掃除代など、係争の判決・和解の日。
- 納税者の選択（判断台帳に「選択」として記録する）：
  - 直所2−78 の期間対応の計上（事業的規模なら1年超の期間の賃貸料も、業務的規模なら1年以内の期間の賃貸料だけ）。要件（継続的な記帳、全部の賃貸料に継続して適用、前受・未収の経理、1年超の期間は明細書の添付）は事実として持ち、満たさない選択は拒否する。
  - 基通36−6 ただし書（引渡しを要するものを効力発生日で計上）。
- 法令が決める構造：上の選択がなければ、各入金の「収入すべき日」を通達の順で決め、その日の属する年分に入れる（中間表現の作成は日付を移さない。年分への割当ては判定コアが行う。D5）。
- 一次情報で決まらないもの：直所2−78 が引く「第67条の2」と現行の条番号の対応（［PS］§9-7）。現金主義（所法67）を選んだ人には直所2−78 を使わない、という形で実装し、条番号は出典未確認の印を付ける。

## H3 必要経費のうち「土地等を取得するために要した負債の利子」は、借入れごとの使途と取得の契約から計算でき、措令26の6② は納税者の選択として持つ

- 根拠：TA1370・TA2210（注）・内訳書の書き方 p.2［PS §2.3］、措法41の4・措令26の6・措通41の4−1〜41の4−3［PS §4.3］、［M §3 C2］。
- 入力として必要な事実：借入れごとの元本・利子・返済（元本の返済は必要経費にしない）、借入れで取得した資産（土地等・建物・附属設備・構築物）とその取得の対価、土地等と建物を「一の契約により同一の者から」取得したか、負債の額が資産ごとに区分されているか、建物を業務とそれ以外に併用しているか。
- 人の判断（D4）：併用建物の業務の部分の割合（措通41の4−1。家事関連費の按分〔［J］〕と同じ形の判断）。
- 納税者の選択：措令26の6②（負債をまず建物、次に土地等に充てたものとして計算することが「できる」）。選択しない場合は、区分の根拠（判断）が要る。
- 法令が決める構造：その年の土地等の負債の利子＝（土地等に充てられた負債の利子）。措令26の6②を選んだときは、措通41の4−3 の式「建物・土地等の負債の利子 ×（土地等の対価に充てられたとされる負債の額／負債の額）」。
- 一次情報で決まらないもの：措通41の4−3 の割合の端数処理（［PS］§9-3）。名前つきの関数にして、結果に「出典未確認」の印を付ける。

## H4 事業的規模かどうかは判断（D4）として受け取り、基通26−9 の「おおむね10室・5棟」は判断と事実が食い違うときの警告にだけ使う

- 根拠：基通26−9・TA1373［PS §3.1］（数値は「おおむね」で、「準ずる事情」と「反証」の余地がある）。土地については数値の基準が見つからない［PS §9-1］。
- 入力として必要な事実：年ごと（判定の時点は年分）の、貸与することができる独立した室の数、独立家屋の棟数、貸地・駐車場の契約件数と面積（収支内訳書2頁「貸付不動産の保有状況」の欄と同じ粒度。空室・空地を含む［PS §8.1］）、管理の状況（自主管理か委託か、入居者の募集・修繕の手配など。自由記述）、賃貸料の総額。
- 人の判断（D4）：「不動産の貸付けが事業として行われている」か（真偽、根拠、判断者・日時。年分ごと）。
- 法令が決める構造（判断の結果で切り替わるもの。［PS §3.2〜§3.4］）：

| 規則 | 事業 | 業務 |
|---|---|---|
| 資産損失 | 所法51①：全額 | 所法51④：その年の不動産所得の金額（51④適用前）を限度 |
| 賃貸料の貸倒れ | 所法51②：その年の必要経費 | 所法64①・所令180②：計上した年分の所得の再計算（更正の請求。所法152） |
| 専従者給与・専従者控除 | 所法57①③（同一生計配偶者・扶養親族から外れる） | 不可 |
| 青色申告特別控除（令和7・8年分） | 措法25の2③④：55万円・65万円 | 措法25の2①：10万円 |
| 事業の廃止後の費用 | 所法63 | （所法63 の対象外） |
| 直所2−78 | 1年超の期間も可 | 1年以内だけ |
| 所法56（家族への対価） | 適用（H6） | 条文上は不適用（H6 の未確定） |

- 判定コアの補助：事実から「推定」を計算する（室数 ≥ 10 又は 棟数 ≥ 5 → 事業と推定）。判断が「業務」で推定が「事業」のとき、判断に反証の記録がなければ警告する。判断が「事業」で室・棟の数が基準に届かないとき、「準ずる事情」の記録がなければ警告する。基準の数（10・5）はパラメータにし、出典を基通26−9 とする。室と棟が混ざるとき、土地だけのときは推定を出さない（［PS］§9-1）。
- 一次情報で決まらないもの：土地の基準、室と棟の混在、「おおむね」の幅。
- 年分で変わる点：措法25の2 は令和9年分から組み替わる：55万円がなくなり、第4項が65万円・第5項が75万円になる。前々年分の不動産所得の総収入金額が1,000万円を超える事業的規模の者は、第4項（65万円）の場合に当たらなければ第1項（10万円）も受けられない（第2項）。1,000万円超は65万円・75万円の要件ではない［PS §3.4、M §3 C1］。令和8年分までの実装では、措法25の2 のパラメータを施行日つきで持ち、令和9年分の式は対象外とする（D14）。

## H5 不動産所得の損失は「青色申告特別控除 → 不動産所得内の制限（別荘・土地の負債利子）→ 所令198 の順序」で通算できる

- 根拠：措法25の2①②（控除は不動産所得の金額そのものを減らす。不動産、事業、山林の順）、TA2072（注2）（注3）［PS §3.4］、所法69①②・所令178①二・所令198［PS §4.1〜§4.2］、措法41の4・措令26の6［PS §4.3］、［M §3 C4］。
- 入力として必要な事実：資産ごとの収入と必要経費（別荘等の生活に通常必要でない資産の貸付けを区分するため）、土地等の負債の利子（H3）、他の所得の金額（利子・配当・事業・給与・雑・譲渡・一時・山林・退職）。
- 人の判断（D4）：貸している家屋が「主として趣味、娯楽又は保養の用に供する目的で所有するもの」（所令178①二）か。
- 法令が決める構造：
  1. 不動産所得の金額（所法26②）を計算する。青色なら措法25の2 の控除額を「黒字の所得の合計」（10万円〔第1項〕は不動産・事業・山林、55万円・65万円〔第3項・第4項〕は不動産・事業。山林所得は D20 で対象外）と上限の少ない方として、不動産所得から先に引く（TA2072 の「損失をないものとして」は国税庁の説明で、措法25の2①二の「合計額」の読み方として採る）。不動産所得が赤字なら、不動産所得からの控除は0。
  2. 不動産所得が赤字なら、別荘等の貸付けに係る損失は生じなかったものとみなす（所法69②。競走馬以外は他の所得と通算しない）。
  3. 残る赤字のうち、措令26の6①の金額（＝min(赤字, 土地等の負債の利子)）を生じなかったものとみなす（措法41の4）。
  4. 残る赤字を所令198 の順序で通算する（一 まず経常所得〔利子・配当・不動産・事業・給与・雑〕、三 次に譲渡・一時、五 次に山林・退職）。所令198三・六の「及び」→「又は」（令和8年政令第93号、2026-04-01 施行）は、順序の計算を変えない文言の整理と見る［M §5］。概念辞書には条文の版を記録するが、関数は令和7年分・令和8年分で同じにする。
- 一次情報で決まらないもの：2 と 3 が同じ年に重なるとき（別荘の貸付けに土地の負債利子もある）の順序。H5 では別荘の分を先に除く（別荘の損失は全額が通算されないので、どちらが先でも他の所得との通算の結果は同じになると見込むが、確かめていない）。
- 対象外にするもの（入口で「対象外」と返す）：組合事業・信託から生ずる不動産所得（措法41の4の2）、国外中古建物（措法41の4の3）。どちらも D18 の状況に含まれない。

## H6 家族の間の賃貸・対価（所法56）は、4つの事実がそろったときに「支払う側の必要経費と受け取る側の所得」を組み替える規則として書ける

- 根拠：所法56 の原文、基通56−1・51−5、TA2210、QA04-14、所法57、地方税法313③④［PS §5］、［M §3 C2-56］（条文に「業務」の語がない）。
- 適用の条件（すべて満たすとき）：
  1. 支払う人 P が、不動産所得・事業所得・山林所得を生ずべき**事業**を営む居住者である（P の活動の区分〔事業所得か業務に係る雑所得か、不動産の貸付けが事業か〕は判断 D4。［J］と H4）。
  2. 受け取る人 R が P の配偶者その他の親族である（事実：続柄）。
  3. R が P と生計を一にする（事実・判断。期間ごと）。
  4. R が「その事業に従事したことその他の事由により」その事業から対価を受ける（取引の事実：支払者・受取人・対象の資産・対価の種類〔家賃・地代・給与・利子など〕）。
- 法令が決める構造：
  - P：対価は必要経費に算入しない。R のその対価に係る必要経費（例：R が所有する建物の固定資産税・減価償却費・損害保険料・修繕費のうち、P の事業が使う部分）を P の事業の必要経費に算入する。
  - R：受け取った対価と、その対価に係る必要経費は、R の各種所得の金額の計算上「ないものとみなす」（R の不動産所得から、その対価の分の収入と経費の両方を外す）。
  - R が資産を無償で使わせている場合も、対価があったとしたら P が算入できる金額を P の必要経費にする（基通56−1）。P の事業の用に供している R の固定資産に損失が生じたら、P が所有しているものとみなして所法51① を適用できる（基通51−5）。
  - 例外：給与は所法57（青色事業専従者給与・事業専従者控除）。家賃・地代に例外はない。住民税は地方税法313③④ が同じ構造を持つ。
- 入力として必要な事実：上の4条件、R が所有する資産の経費の明細（R 自身の他の貸付けと共通の経費なら按分）。
- 人の判断（D4）：P の事業が使う部分の割合（面積など）、R の経費のうち「その対価に係る」部分、生計を一にするか。
- 一次情報で決まらないもの（「未確定」の印を付ける）：
  - P の活動が業務的規模（業務に係る雑所得、業務的規模の不動産所得）のとき：条文は「事業」に限るが、TA2210 は「業務」と書く［PS §9-2］。判定コアは条文どおり「適用しない」を既定にし、結果に「解釈未確認（所法56 の事業／TA2210 の業務）」の印を付け、判断で切り替えられるようにする。
  - 年の途中で生計を一にしなくなった（又はなった）場合に、どの支払いに所法56 を当てるか（支払日の状況で判定するのが自然だが、一次情報を確かめていない）。
- 人をまたぐ依存（SCOPE §6-5）：所法56 は P と R の所得を同時に変える。概念辞書に「所得税.事業から対価を受ける親族」の依存（P の必要経費 ← R の経費、R の各種所得 ← P への対価）を明記する場所が要る。

## H7 判定ごとの「所得」の数え方は、所得税・住民税は同じ不動産所得（控除・通算・制限の後）で、健保は収入から保険者が認める経費を引いた別の値になる

- 根拠：所法2①三十イ(2)・三十二・三十四［PS §6、M §3 C3］、措法25の2①（不動産所得そのものを減らす）［PS §3.4］、措法41の4（「所得税法第六十九条第一項の規定その他の所得税に関する法令の規定の適用については、生じなかつたものとみなす」）［PS §4.3］、地方税法313②〜④［PS §4.5、§5.3］、［JZ］§1〜§5、［KP］§1.2〜§1.3、［R1］§2・§3（特定親族の合計所得金額123万円以下は §3）。
- 不動産所得がある人の、判定ごとの扱い：

| 判定 | 使う値（概念） | 不動産所得の入り方 |
|---|---|---|
| 所得税：扶養親族・同一生計配偶者・配偶者特別控除・特定親族特別控除・寡婦／ひとり親・基礎控除の段階 | 合計所得金額（純損失・雑損失の繰越控除の前） | 青色申告特別控除の後の不動産所得。赤字は所令198 の順で他の所得から引く。別荘の損失と措法41の4 の部分は引かない。所法56 で「ないものとみなす」家族からの家賃は入れない |
| 所得税：勤労学生 | 合計所得金額 ≤ 85万円（令和7年分）・89万円（令和8年分）、かつ「給与所得等以外の所得に係る部分」≤ 10万円 | 不動産所得は「給与所得等」に入らないので、黒字なら10万円の枠に数える。赤字のときの扱いは未確定（［PS］§9-4） |
| 青色事業専従者・事業専従者になった家族 | — | 所法2①三十三・三十四で同一生計配偶者・扶養親族から外れる（事業的規模の不動産所得でだけ起こる） |
| 住民税：扶養・非課税（均等割・所得割）・所得割の課税標準 | 前年の合計所得金額・総所得金額等 | 地方税法313② の「計算の例」で、所得税と同じ不動産所得（措法25の2・措法41の4 を含むと読む。明文の確認は未了：［PS］§9-5）。専従者は地方税法313③④ |
| 国民健康保険料（所得割の基礎など） | 総所得金額等（国保のトピックで確定） | 住民税と同じ値を使う（このトピックでは確かめていない） |
| 健康保険の被扶養者 | 今後1年の年間収入の見込み（判断台帳） | 不動産収入から、保険者が認める経費だけを引いた額。協会けんぽの公表では減価償却費・租税公課・損害保険料・利子割引料・青色申告特別控除などは引けない。所法56 の家族の家賃、赤字の通算の扱いは保険者の一次情報が見つからない |

- 実装の形：
  - 所得税・住民税・国保は、同じ「不動産所得の金額（措法25の2・所法56 の後）」と「損益通算に回る不動産所得の損失（別荘・措法41の4 を除いた後）」の2つの概念から計算する。概念辞書の ID の例：`所得税.不動産所得の金額`、`所得税.損益通算の対象となる不動産所得の損失`。
  - 健保は別の系統：`健保.年間収入.不動産` ＝ 見込みの不動産収入 − Σ（保険者が認める経費の種類に当たる見込みの経費）。経費の種類ごとの可否は保険者ごとの注入データ（T8）。注入がなければ、下限＝収入−所得税の必要経費の全部、上限＝収入、の範囲で評価し、結論が決まらなければ「未確定」（D19）。
- 一次情報で決まらないもの：勤労学生の「給与所得等以外の所得に係る部分」の赤字の扱い、住民税での措法41の4 の明文、健保での家族の家賃と赤字の扱い。
