## H1 第313条第2項（第32条第2項）の「所得税法その他の所得税に関する法令の規定」には租税特別措置法と同施行令が含まれ、その所得計算の特例は、地方税法・同政令に別の定めがない限り住民税の総所得金額等の計算に及ぶ

- 内容：住民税の所得割の総所得金額・退職所得金額・山林所得金額は、措置法の所得計算の特例（収入・必要経費・所得の金額・損益通算・総所得金額からの除外）を当てた後の所得税の計算の例による。
- 根拠：
  1. 条文の形：第313条第2項は「所得税法**その他の所得税に関する法令**の規定による…計算の例」とし、例によらないのは所得税法第60条の2〜第60条の4 だけ（F：［PS］§1.1）。
     措置法第1条は、措置法を所得税の「課税標準若しくは税額の計算…につき、所得税法…の特例を設ける」法律とする（F：［PS］§6）。6つの条はいずれも措置法の「第二章　所得税法の特例」にある（F：［実測］§3.1）。
  2. 政令が前提にしている：施行令第48条の5の2（第7条の10の5）は「法第三百十三条第二項の規定により同条第一項の総所得金額を算定する場合には」、措法第41条の3の11 と第41条の15の3 の中の語を
     住民税の定義に読み替えて「これらの規定の例によるものとする」と定める（F：［PS］§2.1）。第313条第2項で措置法の規定の例によらないなら、この読替えは意味を持たない。令和4年度分から（F：［PS］§2.2）。
  3. 省令が名指ししている：施行規則第6条の8第1号ニは「法第三十二条第二項の規定においてその例によるものとされる租税特別措置法第二十六条第一項の規定」と書く（F：［PS］§3）。
  4. 同じ言い回しの扱い：施行令の原始附則第18条第1項は「所得税法その他の所得税に関する法令の規定」から租税特別措置法施行令の特定の項を除いている。言い回しが措置法令を含む前提でないと、除く必要がない（F：［PS］§4）。
  5. 措置法を除きたいときは名指しする：地方税法第72条の49の12第1項（個人の事業税）は「租税特別措置法第二十八条の四の規定の例によらない」と書く（F：［PS］§1.4）。第313条第2項にはそうした措置法の除外がない。
  6. 総務省の通知：取扱通知（市町村税）12 は「収入金額の計算、必要経費の計算、損益の通算等については、原則として所得税の例による」とし、12(3) は措置法第3条第1項・第41条の10第1項などの規定で
     所得税法第22条第2項の総所得金額から除かれるものは住民税の総所得金額にも含まれないとする（F：［PS］§7.1）。道府県民税の計算は市町村民税と「全く同様」（同）。
  7. 総務省の事務連絡：平成30年度改正について、青色申告特別控除・家内労働者等の所得計算の特例の見直しは「個人住民税にも適用」、所得金額調整控除は「所得税に係る法令の規定が個人住民税にも適用」とする（F：［PS］§7.2）。
- 確からしさ：**高い**。ただし、範囲を一般的な形で述べた法令・通知の文は見つかっていない（［PS］§0・§8）。H1 は条文の形と、上の 2〜7 の個別の文からの読み。
  反証を探した範囲：地方税法・施行令の本則で6つの条を引く文の数（［実測］§3.2）、地方税法の全文の「の例によらない」（［PS］§1.4）。措置法第29条の4 を住民税で適用しない・読み替える規定は、
  既存の調査でも見つかっていない（［給与M］§6、［給与PS］§3.2）。

## H3 措置法と住民税で扱いが違うのは、地方税法・同政令が自ら定めた場合だけで、それは次の型に分かれる

1. **計算の例によらない**：所得税法第60条の2〜第60条の4（第313条第2項ただし書。F：［PS］§1.1）。
2. **住民税の定義に読み替えて例による**：施行令第48条の5の2 が、所得税法第35条第4項第1号（公的年金等控除の「合計所得金額」）、措法第41条の3の11（所得金額調整控除の「扶養親族」「同一生計配偶者」）、
   措法第41条の15の3 の引用を、住民税の定義（第292条第1項第13号・第9号・第7号、第313条第2項）に置き換える（F：［PS］§2.1）。取扱通知 12(5)：公的年金等控除の基礎の合計所得金額は退職手当等（第328条）を含まない（F：［PS］§7.1）。
3. **地方税法の附則で別に定める**：肉用牛（措法第25条）は、住民税では総所得金額に算入したうえで所得割の額の一部を免除する（原始附則第6条、取扱通知 12(4)。F：［PS］§5）。
4. **所得控除は計算の例の外**：所得控除は地方税法第314条の2 が自ら定める（F：［PS］§1.6）。措置法の所得控除の特例（措法第41条の17 の特定一般用医薬品等購入費）は、地方税法の原始附則第4条の5 で別に定めている（F：［PS］§5）。
   したがって H1 で及ぶのは「総所得金額等の計算」（所得の側）の特例で、所得控除・税額控除・税率の特例は、地方税法に規定があるものだけ。
5. **第313条第3項以下の住民税だけの規定**：青色事業専従者・事業専従者、純損失・雑損失の繰越、特定支出控除、特定配当等・特定株式等譲渡所得の除外など（F：［住民PS］§2）。

- 確からしさ：1〜4 は条文の組み合わせで高い。「これ以外にない」は、地方税法・施行令の本則と地方税法の「の例によらない」を探した範囲での話（［実測］§3.2、［PS］§1.4）。施行令の附則・施行規則の全文は探していない。

## H4 住民税（N年度）に当てる措置法の版は、賦課期日の版ではなく「前年分の所得税に適用された版」で、条番号ではなく中身で特定する必要がある

- 内容：第292条第5項（第23条第5項）により、市町村民税で引用する所得税法令は「前年の所得について適用されたもの」（F：［PS］§1.2）。第313条（第二款）はこの規定の除外に当たらない（F：［実測］§3.1）。
  したがって令和9年度分は令和8年分に適用された措置法（第29条の4 の 74万円を含む）、令和8年度分は令和7年分に適用された措置法による。措置法の条番号は版で変わる
  （第29条の4 は asof 2026-11-09 では未払賃金の特例、2026-12-01 から給与所得控除の特例。所得金額調整控除は asof 2022-04-01〜2024-12-31 の施行令が第41条の3の3 として引き、2025-01-01 から第41条の3の11）（F：［PS］§1.5・§2.2）。
- 施行令の引用の更新の時期も、この読みと合う：措置法で所得金額調整控除が第41条の3の11 になったのは令和6年6月1日、施行令第48条の5の2 の引用が変わったのは令和7年1月1日（F：［PS］§2.2、［検証M］§5.2）。
  令和6年度分（令和5年分の所得。当時の措置法では第41条の3の3 が所得金額調整控除）までは旧番号、令和7年度分（令和6年分の所得）から新番号で、引用の切替えが住民税の年度（前年分）にそろっている（H）。
- 例外：第292条第1項第6号（退職手当等の定義。分離課税の退職所得）は第292条第5項の除外に入っている（F：［PS］§1.2）。この号が asof 2026-12-01 の版でも「第二十九条の四」を引くことの扱いは分からない（［PS］§8）。
  引用を「第二十九条の五」に改める規定の施行は令和9年1月1日で、措置法の繰下げ（令和8年12月1日）の1か月後。2026年12月の扱いを定めた経過措置・読替えは、探した範囲では見つからなかった（F：［PS］§8、［検証M］§5.3）。
- 確からしさ：前半は条文の組み合わせと、施行令の引用の更新の時期で高い。例外の扱いは分からない。

## H5 既存の未決への答え（部分的）

- impl-prep の JU2（措法第29条の4 が住民税に及ぶことの法令上の根拠）：**一般的な明文はない**が、第313条第2項の「所得税法その他の所得税に関する法令」が措置法を含むことは、政令（施行令第48条の5の2）・
  省令（施行規則第6条の8）・政令の附則（施行令の原始附則第18条）が前提にしている（H1）。第29条の4 そのものについては、総務省の事務連絡・改正(案)が効果（令和9年度分・令和10年度分に 74万円）を書くだけ（H2）。
- kyuyo の H4（住民税の給与所得は措置法第29条の4 を含む）の根拠に、H1 の 2〜5（政令・省令・附則・事業税の書き方）を足せる。H4 の結論は変わらない。
