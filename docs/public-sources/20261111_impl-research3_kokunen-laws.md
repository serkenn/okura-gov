## 1. 135万円の経路（全額免除・一部免除・学生納付特例・納付猶予）

- 国年法90①（全額免除）：次の各号のいずれかに該当する被保険者等から申請があったとき（「ただし、世帯主又は配偶者のいずれかが次の各号のいずれにも該当しないときは、この限りでない。」）：
  - 一 前年の所得（1月から厚生労働省令で定める月〔国年規77の2：6月。学生納付特例は3月〕までの月分は前々年）が扶養親族等の有無・数に応じて政令で定める額以下
  - 二 被保険者又は世帯員が生活扶助以外の扶助その他の援助で厚生労働省令で定めるものを受けるとき
  - **三「地方税法（…）に定める障害者、寡婦その他の同法の規定による市町村民税が課されない者として政令で定める者であつて、当該保険料を納付することを要しないものとすべき月の属する年の前年の所得が政令で定める額以下であるとき。」**
  - 四 天災その他の厚生労働省令で定める事由
  - ④：第1号・第3号の所得の範囲・額の計算方法は政令。
- 国年令6の7の2：法90①三の政令で定める者は「地方税法第二百九十二条第一項第十号に規定する障害者、同項第十一号に規定する寡婦及び同項第十二号に規定するひとり親とする。」
- **国年令6の8：「法第九十条第一項第三号に規定する政令で定める額は、百三十五万円とする。」**
- 国年法90の2①②③（4分の3・半額・4分の1免除）の各項：「次の各号のいずれかに該当する…から申請があつたとき」「ただし、世帯主又は配偶者のいずれかが次の各号のいずれにも該当しないときは、この限りでない。」一 前年の所得が政令で定める額以下（国年令6の8の2：88万円＋加算、6の9：128万円＋加算、6の9の2：168万円＋加算。加算は扶養親族等1人38万円、同一生計配偶者・老人扶養親族48万円、特定扶養親族等63万円）、**二「前条第一項第二号及び第三号に該当するとき。」**、三 天災その他。
- 国年法90の3①（学生納付特例）：学生等である被保険者等で、一 前年の所得が政令で定める額以下（国年令6の9：128万円＋加算）、**二「第九十条第一項第二号及び第三号に該当するとき。」**、三 天災その他。（世帯主・配偶者のただし書はない）
- **納付猶予（平成16年法律第104号附則第19条②、平成26年法律第64号附則第14条①）**：
  - 平成16年法附則19②：「平成十八年七月から令和十七年六月までの期間において、三十歳に達する日の属する月の前月までの被保険者期間がある第一号被保険者等であつて次の各号のいずれかに該当するものから申請があつたとき」、一 前年の所得が「その者の所得税法に規定する同一生計配偶者及び扶養親族の有無及び数に応じて、政令で定める額以下」、**二「国民年金法第九十条第一項第二号及び第三号に該当するとき。」**、三 天災その他。④：納付猶予の保険料は法90の3①（学生納付特例）の規定により納付を要しないものとされた保険料とみなす。
  - 平成26年法附則14①：「平成二十八年七月から令和十七年六月までの期間において、五十歳に達する日の属する月の前月までの被保険者期間（三十歳に達した日の属する月以後の期間に限る。…）がある第一号被保険者等であつて次の各号のいずれかに該当するもの」、一〜三は平成16年法附則19② と同じ形（二「国民年金法第九十条第一項第二号及び第三号に該当するとき。」）。③：法90の3① の保険料とみなす。
  - 納付猶予の第1号の「政令で定める額」の政令の条は、国年令の本則・原始附則に見つからなかった（国年令の本則で平成16年改正法附則第19条に触れるのは第1条の2・第9条・第14条の16 の事務・手続の条だけ。［M3-F］§7）。日本年金機構の説明は「納付猶予制度（扶養親族等の数+1）×35万円+32万円」（全額免除と同じ式）。

- 日本年金機構（免除・納付猶予）：「全額免除（扶養親族等の数+1）×35万円+32万円」「4分の3免除 88万円+扶養親族等控除額+社会保険料控除額等」「半額免除 128万円+…」「4分の1免除 168万円+…」「納付猶予制度（扶養親族等の数+1）×35万円+32万円」「留意点：地方税法に定める障害者、寡婦またはひとり親の場合、基準額が変わります。詳しくは、お手続きの際にお問い合わせください。」（どの免除に135万円が当たるかは書かれていない）。

## 2. 学生等の期間

- 国年法90①柱書：厚生労働大臣が指定する期間から「学校教育法…第五十条に規定する高等学校の生徒、同法第八十三条に規定する大学の学生その他の生徒若しくは学生であつて政令で定めるもの（以下『学生等』という。）である期間若しくは学生等であつた期間を除く。」（90の2①②③ も「学生等である期間若しくは学生等であつた期間を除く」。平成16年法附則19②・平成26年法附則14① も同じ）。
- 国年法90の3①：「その指定する期間（学生等である期間又は学生等であつた期間に限る。）」。
- 国年令6の6（学生等）：一 夜間等の中学校の生徒、二 高等学校、三 中等教育学校、四 特別支援学校の高等部、五 大学（大学院を含む）、六 短期大学、七 高等専門学校、八 専修学校、九 各種学校（修業年限1年以上の課程）、十 これらに準ずる厚生労働省令の教育施設。
- 国年規77の4〜77の4の3：学生納付特例の申請・委託の手続（`grep_kokunenki_2026-04-01.txt`）。

## 3. 付加保険料（国年法87の2）

- ①：「第一号被保険者（第八十九条第一項、第九十条第一項又は第九十条の三第一項の規定により保険料を納付することを要しないものとされている者、第九十条の二第一項から第三項までの規定によりその一部の額につき保険料を納付することを要しないものとされている者及び国民年金基金の加入員を除く。）は、厚生労働大臣に申し出て、その申出をした日の属する月以後の各月につき、前条第三項に定める額の保険料のほか、**四百円**の保険料を納付する者となることができる。」
- ②（FY8）：付加保険料の納付は、定額の保険料が納付された月（第94条第4項の納付みなしの月を除く）又は第88条の2（産前産後）の規定で納付を要しないとされた期間の各月だけ。FY9 の版（2026-10-01 施行）：「第八十八条の二**若しくは第八十八条の三第一項若しくは第二項**の規定により納付することを要しないものとされた保険料に係る期間の各月」。
- ③：いつでも申出で付加保険料の納付者でなくなれる。④：国民年金基金の加入員となったときは③の申出をしたものとみなす。

## 4. 産前産後・育児期間の免除

- 国年法88の2：「被保険者は、出産の予定日（厚生労働省令で定める場合にあつては、出産の日。…）の属する月（以下この条において『出産予定月』という。）の前月（多胎妊娠の場合においては、三月前）から出産予定月の翌々月までの期間に係る保険料は、納付することを要しない。」（申請ではなく法律上当然。届出は国年規73の7。国年規73の6：厚生労働省令で定める場合は「次条第一項の規定による届出を行う前に出産した場合」）
- **国年法88の3（FY9 の版に新設、令和7年法律第74号、施行 2026-10-01）**：①88の2 の適用を受けた被保険者がその子を養育する場合、出産予定日から起算して3月を経過した日の属する月から12月を経過した日（子の死亡等の事由があればその翌日）が属する月の前月までの期間の保険料は納付を要しない。②特別養子縁組の請求・養子縁組里親など（厚生労働省令の要件）。③子ども・子育て支援納付金で補塡。
- 国年法89①（法定免除）は FY9 で「第八十八条の二、前条第一項及び第二項並びに第九十条の二第一項から第三項までの規定の適用を受ける被保険者を除く」に改正。
- 日本年金機構（産前産後）：出産予定日又は出産日の属する月の前月から4か月間（多胎は3か月前から6か月間）の保険料を免除（ページ本文 `nenkin_sanzen.txt`）。
