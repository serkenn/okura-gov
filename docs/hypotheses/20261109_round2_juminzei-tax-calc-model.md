## H1 一人・一年度の住民税は、次の順の純粋な計算で決まる（所得割は線形、端数は3か所）

1. **課税する団体**：その年度の1月1日（賦課期日）に住所がある市町村とそれを含む道府県（［既存PS］§3、［法令］§13）。住所がなく事務所・家屋敷だけがある市町村は均等割だけ
   （第294条第1項第2号）。指定都市かどうかは政令の20市の一覧で決まる（［法令］§4）。
2. **前年の所得**：総所得金額・退職所得金額・山林所得金額（第313条）。所得税と同じ計算の例による部分は所得税の層の結果を共有し、住民税だけの違い
   （白色の事業専従者控除は住民税の申告書の記載が要件、純損失・雑損失の繰越は住民税の申告書の連続提出が要件、特定支出控除、特定配当等・特定株式等譲渡所得は確定申告書に記載がなければ除外）
   を住民税の側で持つ（［法令］§2）。
3. **所得控除**：同じ事実（前年12月31日の現況）から、住民税の額で計算する（［法令］§3）。
4. **課税総所得金額**＝ 総所得金額等 − 所得控除 を **1,000円未満切捨て**（端数①。［法令］§15、［行政］§2.1・§2.2）。
5. **算出所得割**＝ 課税総所得金額等 × 税率（市・県それぞれ。税率は注入。［法令］§4）。
6. **調整控除**：前年の合計所得金額 2,500万円以下なら、法定の率（3%/2%、指定都市 4%/1%）で算出所得割から引く（［法令］§5）。注入する税率が標準と違っても率は変わらない
   （［行政］§2.1 の名古屋市の例は 7.7% の市民税に 4% の調整控除。［実測］§3.7 で再現）。
7. **税額控除**（基は調整控除の後の所得割。［法令］§11）：配当控除、住宅借入金等特別税額控除、寄附金税額控除（特例控除の上限は同じ基の 20%）、申告特例控除（寄附金税額控除の後）、
   外国税額控除（D20 で対象外）、配当割額等の控除（最後、控除しきれない分は還付）。
8. **所得割の非課税と境目の調整**（附則第3条の3第4項・第5項。［法令］§10）。
9. **均等割**（注入）と均等割の非課税（第295条第1項・第3項。［既存PS］§1・§3）。
10. **確定金額**：市町村民税＝（所得割＋均等割）、道府県民税＝（所得割＋均等割）をそれぞれ **100円未満切捨て**（端数②。［法令］§15、［行政］§2.1）。
11. **森林環境税**：1,000円。課税・非課税は森林環境税法で決まる（［法令］§14）。
12. **分離課税**は別の系統：退職所得はその年の1月1日の住所の市町村が、その年の退職所得に 6%・4%（［法令］§12）。上場株式等の配当・譲渡は 3%・2%（指定都市 4%・1%）。

- 根拠：［法令］§2〜§15。［実測］§3.7 で、この順の計算に注入値を与えるだけで自治体の計算例 2 件（名古屋市・横浜市、令和8年度）が一致した。
- 確からしさ：流れは高い（条文の「…を適用した場合の所得割の額」の連鎖：［法令］§11）。端数①の当て先と、途中の 1円未満（端数③：H5）は一次情報で決まらない。

## H2 法令が決める構造（コア）と、注入するデータの境目

| 項目 | コアに置く（法令で決まる） | 注入するデータ（団体ごと・年度ごと、出典つき） | 根拠 |
|---|---|---|---|
| 所得割の税率 | 標準税率（市 6%・県 4%、指定都市 8%・2%）は「参考値」としてだけ持つ。市は一の率、県は同一の標準税率ごとに一の率という制約（県は指定都市の住民向けと他で2つの率を持ちうる） | 市町村の率、道府県の率（指定都市の住民向けと、それ以外）。標準より高い（豊岡市・神奈川県）ことも低い（名古屋市）こともある | ［法令］§4、［行政］§2・§3 |
| 均等割 | 標準税率（3,000円・1,000円）は参考値 | 市町村・道府県の均等割の額（超過：37道府県、横浜市・神戸市。減税：名古屋市）。第311条の軽減の定め | ［法令］§13、［行政］§3 |
| 均等割の非課税 | 政令の式（35万円×級地の率、10万円、21万円×級地の率）と第295条第1項 | 条例の基本額・加算額、級地（既存の H6 のとおり） | ［既存PS］§1 |
| 調整控除・寄附金の基本控除と特例控除・申告特例・住宅借入金等・配当控除の率と上限 | すべてコア（市と県の配分、指定都市の配分を含む）。超過課税・減税があっても変わらない | なし | ［法令］§5〜§8、［実測］§3.5・§3.7 |
| 寄附金税額控除の対象 | 都道府県等・共同募金会（住所の道府県）・日赤（同）・所得税の特定寄附金の区分 | 市町村・道府県の **条例で定める寄附金**（第314条の7第1項第3号・第4号、第37条の2）の一覧 | ［法令］§8.1 |
| 特例控除対象寄附金 | 「寄附した時に指定されていたか」で判定する規則 | 総務大臣の指定と取消し（団体・期間）。市町村の条例ではなく国のデータ | ［行政］§1（24の3） |
| 指定都市 | 政令の20市の一覧（施行日つき） | なし | ［法令］§4 |
| 森林環境税 | 1,000円、非課税（政令の式で級地から直接決まる）、事務所・家屋敷だけの者は課さない、均等割の軽減・減免は及ばない | 級地（国のデータ） | ［法令］§14 |
| 分離課税の税率 | 退職 6%・4%、上場株式等 3%・2%（4%・1%） | なし（条文に「標準税率」の語がない。超過課税が及ぶかは未確認） | ［法令］§12 |
| 端数 | 1,000円未満・100円未満の切捨て | 1円未満の扱い（団体の慣行。法令に定めなし。H5） | ［法令］§15、［行政］§2・§4 |
| 申告不要の条例・減免 | 第317条の2・第323条の枠 | 条例の定め、減免の決定（個別の処分＝事実） | ［既存PS］§6、［法令］§14 |

- 確からしさ：高い（どの値が条文に書かれ、どれが「条例で定める」「標準税率」かは原文で確かめた）。
- 帰結：注入するデータの単位は「団体（市町村または道府県）× 年度」。一人の住民税には、1月1日の住所の市町村と道府県の2団体のデータが要る。
  家族が別々の市町村に住む場合（D18）は、人ごとに別の団体のデータを引く。

## H3 入力として必要な事実と、人の判断（D4）

| 規則 | 入力として必要な事実 | 人の判断・手続きの事実（D4） |
|---|---|---|
| 課税団体 | 1月1日の住所（市町村）、事務所・家屋敷の所在 | なし（住民基本台帳の記録。第294条第2項〜第4項） |
| 所得 | 所得税の層と共通の所得の事実。白色の事業専従者の住民税の申告書への記載、住民税の申告書の連続提出（繰越控除）、確定申告書への特定配当等の記載 | 上場株式等の配当・譲渡の課税方式の選択（所得税の確定申告書に書くか。住民税も従う）、特定支出控除を住民税の申告で受けるか |
| 所得控除 | 所得税と同じ事実（支払額、人の該当、前年12月31日の現況） | 扶養の所属（申告書・給与支払報告書の記載：既存の H4） |
| 調整控除 | 人的控除の該当（障害者、寡婦、ひとり親が父か母か、勤労学生、控除対象配偶者、扶養の区分、同居の別）、前年の合計所得金額 | なし |
| 寄附金税額控除 | 寄附ごとの寄附先の区分、寄附した日、金額、特例控除対象かどうか（指定の有無）、条例指定かどうか | ワンストップ特例の申請（申告特例通知書が送られたか）、確定申告・住民税の申告をしたか（したら申告特例は失効：［行政］§1 の 24の6(8)）、申請先の団体数（5 を超えたら失効） |
| 申告特例控除・特例控除の割合 | **前年分の所得税の基礎控除の額**（措法第41条の16の2 適用後）、人的控除差 | なし |
| 住宅借入金等特別税額控除 | 前年分の所得税の住宅借入金等特別税額控除額・控除前の所得税額・課税総所得金額等・基礎控除の額、居住年、特定取得・特別特定取得の別 | 所得税側の申告（外部で計算した値を受け取る：SCOPE §3） |
| 配当控除 | 総合課税を選んだ配当所得の種類別の額、課税総所得金額 | 課税方式の選択（上と同じ） |
| 均等割・森林環境税 | 非課税の判定の事実（［既存PS］）、級地 | 減免の申請・決定（事実として受け取る） |
| 退職所得の分離課税 | 退職手当等の支払を受けるべき日、その年の1月1日の住所、退職所得の金額 | 退職所得申告書の提出の有無（第328条の6） |

- 根拠：［法令］§2〜§14、［行政］§1。
- **年をまたぐ依存**：住民税（N年度）は、前年分の所得税の結果（基礎控除の額、課税総所得金額等、住宅借入金等特別税額控除額、控除前の所得税額）を読む。
  SCOPE §6 の規則どおり、概念辞書に「住民税.人的控除差調整額 ← 所得税.基礎控除の額（前年分）」などとして明記する。

|---|---|---|---|
| 所得割の税率・均等割・調整控除 | 4版で同じ | 同じ | ［実測］§3.2 |
| 人的控除差調整額への基礎控除の差の加算（寄附金・申告特例・住宅借入金等の控除限度額） | **あり**（2026-04-01 施行、令和8年度分から） | あり | ［法令］§1、［実測］§3.3 |

| 住宅借入金等の居住年 | 平成21年〜令和7年 | 居住年が令和7年以前は従前の文（基礎控除の差の加算あり）、令和8年は 2027-01-01 の版の文（加算なし） | ［法令］§1・§7 |
| 同一生計配偶者・扶養親族の所得要件 | 58万円 | 62万円 | ［法令］§1 |

- 確からしさ：高い。ただし令和9年度分は、2027年に成立する改正で変わりうる（［法令］§16）。
- 帰結：パラメータは「施行日」ではなく「適用年度」で引く（既存の H1 の訂正と同じ方針）。基礎控除の差の加算のように、施行が賦課期日（2026-01-01）より後でも

## H5 一次情報で決まらない端数処理は、名前つきの関数にして結果に印を付ける

| 箇所 | 法令 | 行政・自治体の扱い（E） | 提案（既定） |
|---|---|---|---|
| ① 1,000円未満の切捨ての当て先 | 第20条の4の2第1項は「課税標準額」。所得割の課税標準は控除前の総所得金額等（第313条） | 名古屋市・横浜市とも控除後の課税総所得金額を切り捨てる | `round_kazei_shotoku_1000`：課税総所得金額（課税退職・課税山林も別々に）を切り捨て。「出典：自治体の計算例」の印 |
| ② 100円未満の切捨て | 第20条の4の2第3項（確定金額）。第8項で「全額が100円未満」の判定だけ市＋県＋森林環境税を一つとみなす | 名古屋市は（所得割−控除＋均等割）を税目ごとに切捨て。横浜市は所得割を切り捨ててから均等割を足す（均等割が100円単位なので同じ結果） | `round_kakutei_100`：市町村民税・道府県民税ごとに（所得割＋均等割）を切り捨て。法令どおり |
| ③ 途中の 1円未満（算出所得割、生命保険料控除、税額控除、附則第3条の3 の調整） | 定めなし（全文の語の検索：［実測］§3.4） | 横浜市：算出所得割を1円未満切捨て。中央区：配当控除を1円に切上げ | `round_intermediate`：既定は「途中で丸めない（有理数で持つ）」。団体の慣行を注入できる口を作る。結果に「端数の扱いは一次情報で未確定」の印 |

- 根拠：［法令］§15・§16、［行政］§2・§4、［実測］§3.4・§3.8。
- 影響の大きさ：［実測］§3.8 では、扱いを変えると 20,000 件中 15〜225 件で年税額が 100〜200円変わった。税率が 1,000円の倍数に掛けて整数にならない団体（2.025% など）と、
  税額控除が分数になる場合に起きる。
- 確からしさ：①・②の提案は自治体の計算例 2 件と一致（［実測］§3.7）。③はどれが正しいかを決める一次情報がない。

## H6 注入がない団体の税額は「未確定」を返し、税率に対する一次式を根拠として添える

- 内容：所得割の税率・均等割の額には、法令に上限・下限の定めが見当たらず、標準より低い団体もある（［法令］§4、［行政］§2.1・§3）。
  D19 の「取りうる範囲で評価」をすると、税額の範囲は有界にならない。したがって注入がなければ、所得割・均等割の **額** は「未確定」とする。
  - ただし、課税総所得金額、調整控除・税額控除の額（法定の率なので注入に依存しない。ただし寄附金の 20% 上限と「所得割の額を超えない」の制限は税率に依存する）、
    非課税・扶養の判定（既存の H2・H6）、森林環境税（級地があれば決まる）は決まる。
  - 根拠として「所得割 ＝ max(0, 課税総所得金額 × 税率 − 控除)」の形と、決まった部分の値を返せば、利用側は税率を入れて計算できる。
- 根拠：［法令］§4・§13・§14、［行政］§3、HANDOFF D19。
- 確からしさ：中（D19 の文言に合わせた設計の判断。法令からは「範囲が有界でない」ことまでしか言えない）。

## H7 調整控除の表は条文どおり実装し、（７）の行は令和8・9年度分では効かないことをテストで固定する

- 内容：表の（７）（配偶者特別控除の差、配偶者 55万円未満）は、同一生計配偶者の要件が 58万円・62万円になったため当たる組み合わせがない（［実測］§3.6）。
  条文から外さず実装し、「令和8年度分・令和9年度分で（７）の値は常に 0」を性質のテスト（D15④）にする。
  特定親族特別控除には人的控除差の行がない（［法令］§5）。表の「5万円」は定額で、所得税の基礎控除の引上げに連動しない。
- 帰結：調整控除の額は、所得税と住民税の実際の控除額の差からは計算しない。表の値をパラメータとして持つ。
  一方、寄附金税額控除・申告特例・住宅借入金等の控除限度額には、表の合計に加えて「所得税の基礎控除の額 − 48万円」を足す（［法令］§7・§8）。同じ「人的控除差」でも用途で中身が違う。
- 確からしさ：高い。

## H8 税額控除の順序は最終の税額に影響しない。順序は「どの控除が使い切れなかったか」の説明にだけ使う

- 内容：配当控除・住宅借入金等特別税額控除・寄附金税額控除は、いずれも「調整控除の後の所得割の額」を基に計算し、寄附金の上限（所得割の額、20%）もこの額による（［法令］§11）。
  各控除が 0 以上で、所得割が 0 を下回らないなら、所得割（控除後）＝ max(0, 基 − 控除の合計) で、引く順序によらない。申告特例控除（寄附金の後）、配当割額等の控除（最後、還付あり）も同じ。
  控除しきれなかった額の帰属（どの控除が無駄になったか）は順序で変わるので、結果の説明には行政の案内の順序（調整 → 配当 → 住宅 → 寄附金 → 外国 → 配当割：［行政］§2.3）を使う。
- 根拠：［法令］§11、［行政］§2.3（中央区）・§1（取扱通知 26(2)：調整控除が先）。
- 確からしさ：中〜高（順序を定めた法令の文言がないことは確かめた。附則第3条の3第5項の B・C は控除の後の額を使うので、ここも順序によらない）。

## H9 森林環境税は均等割と「同じ紙で取る別の税」として、非課税・減免・課税対象を別に判定する

- 内容：
  - 課税対象は住所を有する個人だけ（事務所・家屋敷だけの者は均等割だけ課され、森林環境税は課されない）。
  - 非課税の金額は政令の式で級地から直接決まり、市町村の条例の額によらない。条例の額が政令の上限より低い市町村では、「均等割は課税、森林環境税は非課税」がありうる。
  - 第311条の均等割の軽減と第323条の減免は森林環境税に及ばない。森林環境税の免除は森林環境税法第11条で別に決まる。
- 根拠：［法令］§14（森林環境税法第3条・第4条・第7条、施行令第1条）、［既存PS］§1.2（施行令第47条の3 は「参酌して定める」）。
- 確からしさ：高い（条文の組み合わせ）。条例の額が政令の上限より低い市町村が実在するかは確かめていない。

## H10 退職所得の分離課税は「その年の住民税」として、年度の問いとは別の問いで扱う

- 内容：退職手当等の所得割は、支払を受けるべき日の属する年の1月1日の住所の市町村が、その年の退職所得に課する（前年の所得ではない）。税率は 6%・4% で、指定都市の区分も
  調整控除もない（［法令］§12）。判定コアの「住民税の年度」の問いとは別に、「退職手当等ごと」の問いにする。
- 根拠：［法令］§12（第328条・第328条の2・第328条の3・第50条の4）。
  退職所得申告書を出さないときは、その支払う退職手当等の金額だけで計算する（第328条の6第2項：［法令］§12）。
- 確からしさ：中（端数の扱い、所得税の側との対応など、細部は未確認）。
