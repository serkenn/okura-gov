## I1 給与所得の関数とパラメータの形（前提：H1、H2、H6、H7）

- 推測：判定コアに名前つきの関数 `kyuyo_shotoku(年分, その年中の給与等の収入金額の合計)` を1つ置き、次のパラメータだけで決まるようにすれば、令和6〜9年分を1つの実装で扱える。
  - `beppyo5`：版ごとの表データ（`scripts/results/IMPL_kyuyo_beppyo5/beppyo5_<asof>.csv` と同じ列：下限・上限・種類（fixed / minus / rate_minus / point）・値・定数）。年分 → 版の対応は「令和7年分：340AC0000000033_20251218_507AC0000000013」「令和8年分・令和9年分：340AC0000000033_20261201_508AC0000000012」のように law_revision_id で持つ（D13 の根拠に使う）。
  - `sochi_29_4_2`：措置法第29条の4第2項の5区分。適用年分 2026・2027 だけ（「令和八年又は令和九年において」）。
  - 660万円以上の式（第28条第3項第2〜4号）と、端数処理の名前つき関数（例 `floor_yen`：給与所得の1円未満切捨て）。
  - 適用の順番：①660万円以上 → 式、②措法の年分で 69万1千円以上220万円未満 → 措法の表、③それ以外 → 別表第五。
- 検証方法：
  1. `scripts/IMPL_kyuyo_spotcheck.py` の 152 点（国税庁の表から書き写した値）を判定コアの単体テストにして、すべて一致することを確かめる。
  2. 性質のテスト（D15 ④）：各年分で関数が非減少、`kyuyo_shotoku(y, x) <= x`、0 ≤ 値。
  3. 表データは e-Gov から再抽出し（`IMPL_kyuyo_fetch.py` → `IMPL_kyuyo_beppyo5.py`）、パッケージに入れたデータと SHA-256 で一致を確かめる。

## I3 住民税の給与所得は所得税の関数を年度−1で呼ぶ（前提：H4、H5）

- 推測：住民税（扶養・非課税の判定のみ、D14）では、`jumin_kyuyo_shotoku(年度, 前年の給与収入) = kyuyo_shotoku(年度に対応する前年の年分, 前年の給与収入)` とすればよく、住民税専用の給与所得控除のパラメータは要らない。令和9年度分・令和10年度分は措置法第29条の4 が効き、令和8年度分は令和7年分の別表第五。
  - 期待値の例：令和8年度 扶養 1,230,000円、未成年者等の非課税 2,043,999円／令和9年度 扶養 1,360,000円、非課税 2,090,000円、特定親族（住民税、満額45万の上限 95万）1,690,000円 [M2 §3]。
- この推測が外れる場合：地方税法の側に「措置法第29条の4 の例によらない」趣旨の規定が後から入る、または総務省が別の解釈を示す場合。そのときは住民税に別のパラメータ（例：令和9年度 69万円の表）が要る。
- 検証方法：
  1. 総務省の、成立した地方税法等の改正に関する通知・解説（令和8年度の改正の留意事項など）を取得して、給与所得控除の扱いの記述を読む（未取得 [PS §6]）。
  2. 令和9年度分の住民税の税額決定通知（令和9年6月ごろ）または市区町村の試算ツールで、令和8年の給与収入 1,190,000円（単身・非課税ライン）と 1,360,000円の扱いを確かめる。
  3. `IMPL_kyuyo_fetch.py` を asof 2027-06-01 などで再実行し、地方税法の全文検索（[M1 §6] のキーワード）で新しい規定が入っていないことを確かめる。

## I4 年末調整（源泉徴収票）と確定申告の給与所得の食い違いを判定コアで扱う（前提：H3、H10）

- 推測：令和8年中に退職して最後の給与が11月30日以前の子供（給与収入 651,000円〜2,199,999円）は、源泉徴収票の「給与所得控除後の金額」が旧表の値（例：給与 1,000,000円 → 350,000円）になり、判定コアの確定申告の値（260,000円）と最大 90,999円（給与収入 740,999円のとき。741,000〜1,900,000円では 90,000円）違う [M2 §4]。判定コアは源泉徴収票の「給与所得控除後の金額」を入力に使わず、支払の事実から計算し、違いがあれば「確定申告で改正後の控除等を受けられる可能性」を出力に添えるのがよい。
  - 扶養の判定（親の側）は確定申告の値（新しい規定）で行う。
  - 前提の注意（2026-11-09 の独立検証で追記）：この推測は「11月30日以前に退職した子供に年末調整が行われ、源泉徴収票に『給与所得控除後の金額』が載る」ことを前提にしている。H3 の根拠の国税庁 Q&A Q7−1 は、11月30日以前に年末調整を受けた人の例として非居住者・死亡退職・休業休職の3つを挙げ、年の中途の退職者は「年末調整を受けていない方」として別に書いている（[PS §4.2]）。年の中途で退職したアルバイトに年末調整が行われるかどうか、行われないときに源泉徴収票の「給与所得控除後の金額」欄がどうなるかは、一次情報で確認していない。年末調整が行われないなら、源泉徴収票と判定コアの値の食い違いはこの形では生じない（照合用の事実として「年末調整の有無」も持つ必要がある）。
- 検証方法：
  1. 国税庁「令和8年分 年末調整のしかた」の旧表の扱いの説明（11月以前に退職した人の源泉徴収票の作り方）を読み、旧表の値が源泉徴収票に載ることを確かめる（今回は Q&A まで）。
  2. 架空の令和8年分の源泉徴収票（11月退職、支払金額 1,000,000円）を作成コーナー（令和8年分が公開されたら）に入れ、給与所得が 260,000円になるかを見る。

## I5 令和10年分以後の境目は下がる（現行の条文のまま改正がない場合）（前提：H1）

- 推測：措置法第29条の4 は令和8・9年だけなので、令和10年分は別表第五（asof 2026-12-01 の版、最低 69万円）に戻る。所得要件が今のまま（扶養 62万円など）なら、扶養の給与収入の上限は 1,360,000円 → **1,310,000円**、勤労学生 1,630,000円 → 1,580,000円、特定親族 123万円 1,970,000円 → 1,920,000円 になる（`scripts/results/IMPL_kyuyo_thresholds/thresholds.md` の 2028 の行。仮定のシナリオ）。ただし令和8年法律第12号附則第101条（[IT] §2）は令和10年分以後の基礎控除と給与所得控除の最低保障額を2年ごとに見直すとしており、令和10年分の前に改正が入る見込みが高い。
- 実装への含意：年分のパラメータに「令和8・9年だけ」の期間を正しく持たせ、令和10年分を既定値で計算できてしまわないようにする（未確定の年分はエラーにする等）。
- 検証方法：D9 の毎日の確認で、所得税法・租税特別措置法の改正（令和9年・令和10年の通常国会）を検知し、`IMPL_kyuyo_fetch.py` の asof に 2028-12-31 などを足して再実行する。

## I6 中間表現に入れる給与の事実（前提：H7、H10）

- 推測：中間表現（D5 の「役割つきの事実」）の給与の明細は、1件ごとに「受給者（人）」「支払者」「支払日」「支払金額（総支給額）」「根拠の取引ID」を持てば足りる。年分の合計、別表第五・措置法の適用、年末調整の旧表の判定（最後の支払日）は判定コアで行う。源泉徴収票は「支払者ごとの年の支払金額・給与所得控除後の金額・源泉徴収税額」の照合用の事実として別に持つ。
  - 「給与等」に当たるかどうか（給与か事業・雑所得か）は法的な判断なので、中間表現には入れない（HANDOFF §3 の境界）。
- 検証方法：中間表現の JSON Schema 案に、2か所のバイト先（11月退職を含む）の架空データを入れ、判定コアが ①合計に1回だけ表を当てること、②源泉徴収票の「給与所得控除後の金額」を旧表で再現できることを、テストで確かめる。

## I7 措置法第27条（家内労働者等）との組合せは別途調べる必要がある（前提：H1）

- 推測：扶養されている子供が内職・外交員等の収入（事業所得・雑所得）と給与を両方持つ場合、措置法第27条の必要経費の最低額（令和8年分以後 69万円から給与所得控除額を引いた額）に、措置法第29条の4第1項の給与所得控除額（74万円、収入が74万円未満ならその収入金額）が入る（[PS §2.4]）。給与収入が 69万円以上なら 69万円−給与所得控除額 ≦ 0 になり、特例の効果がなくなる可能性がある。
- 検証方法：措置法第27条の全文・措置法施行令の対応条・国税庁タックスアンサー（家内労働者等の必要経費の特例）を取得して読み、給与収入 0円・50万円・70万円・100万円の4例で必要経費の最低額を計算する。作成コーナーで確かめられるのは令和7年分（65万円）だけ。
