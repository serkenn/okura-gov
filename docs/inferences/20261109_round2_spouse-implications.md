## IS2 配偶者の給与収入が 130万円ちょうどだと、税の控除は満額だが、健保の被扶養者・第3号には当たらない

- 前提：HS2（所得税）、HS4（住民税）、HS6・HS7（健保・第3号は「130万円未満」）、［HK］H4（令和9年度分の住民税にも給与所得控除 74万円）。
- 推測（配偶者の収入は給与だけ、給与収入 1,300,000、本人は給与所得者で合計所得金額 900万円以下）：

| 制度 | 令和7年（分）の所得 | 令和8年（分）の所得 |
|---|---|---|
| 配偶者の給与所得 | 1,300,000 − 650,000 = 650,000 | 1,300,000 − 740,000 = 560,000 |
| 所得税（本人） | 配偶者特別控除 380,000（58万円超95万円以下） | 配偶者控除 380,000（62万円以下） |
| 住民税（本人） | 令和8年度分：配偶者特別控除 330,000 | 令和9年度分：配偶者控除 330,000（［HK］H4 が前提） |
| 健保の被扶養者・第3号 | 今後1年の見込みが 130万円なら「130万円未満」に当たらず、対象外 | 同左 |

  同じ「配偶者の扶養」でも、税は区分が年分で入れ替わり（特別控除→配偶者控除）、額は変わらない。健保・第3号は「未満」なので 130万円ちょうどで外れる。
- 検証の方法：所得税は作成コーナーで照合（令和7年分）。住民税の令和9年度分の給与所得は［HK］H4 の検証（総務省の資料）に従う。健保は［PS-K］の協会けんぽ・日本年金機構の案内の「130万円未満」の書き方で十分（境目の比較は単体テスト）。

## IS3 年の途中で結婚した年は、所得税と健保・第3号で結論が逆になりうる

- 前提：HS3-4（年の中途の婚姻は年間の合計所得金額で判定。国税庁の明示なし）、HS6・HS7（健保・第3号は認定日以後の今後1年の見込み）。
- 推測（令和8年分。配偶者は1月〜6月に給与 2,000,000 を受けて退職し、7月に婚姻、その後は収入なし）：
  - 所得税：配偶者の合計所得金額 = 2,000,000 − 740,000 = 1,260,000（措法第29条の4 の区分）→ 配偶者特別控除 60,000（125万円超130万円以下、本人 900万円以下）。給与 2,100,000 なら 1,360,000 で対象外。
  - 健保・第3号：婚姻の日を認定日として、今後1年の見込みが 0 なら被扶養者・第3号に当たりうる（同一世帯なら本人の年収の2分の1未満も満たす）。
  - 住民税（令和9年度分）：前年（令和8年）12月31日に配偶者で、前年の合計所得金額 1,260,000 → 配偶者特別控除（住民税）60,000。
- 検証の方法：
  1. 国税庁の資料で「年の中途で結婚」の扱いを明示したものを探す（令和8年分の確定申告の手引きの用語・Q&A は 2027 年に公開される見込み。公開後に `scripts/R2X_spouse_fetch.py` に set を足して取得する）。
  2. 作成コーナーは配偶者の「合計所得金額」を入力させるので、法令の読みそのものは照合できない。照合できるのは額の計算だけ（IS1）。
  3. 見つからない間は、結果に「解釈（国税庁の明示なし）」の印を付けて出す（HS9）。

## IS4 住民税では、配偶者控除を受けている側の配偶者が、相手について配偶者特別控除を受けられない（令和8年度分から）。所得税では条文上の除外がない

- 前提：HS4（相互適用の除外の範囲の違い）、HS5（申告書等の記載を入力で受け、コアは整合を検査）。
- 推測（令和8年の所得、令和9年度分の住民税。夫婦A・B、生計一、専従者でない。Aの合計所得金額 500,000、Bの合計所得金額 1,200,000、ともに本人の上限以下）：
  - 所得税（令和8年分）：BはAについて配偶者控除 380,000（Aは62万円以下）。AはBについて配偶者特別控除 160,000（Bは115万円超120万円以下）。所法第83条の2第2項第1号はBが配偶者特別控除を受けている場合だけを除くので、条文上はAの控除も成り立つ。ただしAの合計所得金額 500,000 は基礎控除（令和8年分 104万円）以下なので、Aの所得税額は控除の有無にかかわらず 0 で、実害はない。
  - 住民税（令和9年度分）：BはAについて配偶者控除 330,000。AのBについての配偶者特別控除は、Bが「前号」（配偶者控除）の適用を受けているので**適用されない**。Aの前年の合計所得金額 500,000 は基礎控除 430,000 を超えるので、Aに所得割が生じうる（所得割の非課税の判定は［JUMIN］の規則による）。令和7年度分までの文言なら、Aの配偶者特別控除（住民税）は除外されなかった。
- 検証の方法：
  1. 令和7年法律第7号（地方税法等の一部を改正する法律）の施行通知（総務省）か、「地方税法等の一部を改正する法律の概要」で、第314条の2第1項第10号の2 の括弧書きの改正の趣旨を確認する。
  2. 所得税側で「配偶者控除を受けている配偶者は、相手について配偶者特別控除を受けられない」とする国税庁の資料があるかを探す（年末調整のしかたの「配偶者控除の適用を受けている人は、配偶者特別控除の適用を受けることができません」は、同じ人が同じ配偶者について両方を受けられないという意味と読めるので、別の論点。［PS-SP］§1.6 の［N26-106］p.17 の（注）1）。
  3. 実装では、所得税は条文どおり（除外しない）、住民税は令和8年度分から除外する。両者が違うことをテスト（D15②）で固定する。

## IS5 住民税の調整控除の表（７）（55万円未満の配偶者特別控除の配偶者）は、令和8年度分から当たる人がいない

- 前提：HS4（調整控除の表と、同一生計配偶者の上限の変化）。
- 推測：表（７）は「第10号の2 に規定する配偶者（前年の合計所得金額が55万円未満）で控除対象配偶者に該当しないもの」かつ「本人の前年の合計所得金額が1,000万円以下」を求める。第10号の2 の配偶者は専従者でなく生計一なので、前年の合計所得金額 55万円未満なら同一生計配偶者（令和8年度分 58万円以下・令和9年度分 62万円以下）であり、本人が1,000万円以下なら控除対象配偶者になる。よって（７）の条件を同時に満たす人はいない。令和7年度分まで（同一生計配偶者 48万円以下）は、48万円超55万円未満の配偶者が（７）に当たった。
- 検証の方法：
  1. 性質のテスト：配偶者の前年の合計所得金額 0〜1,330,000 と本人の段階を全部回し、（７）の条件が令和8年度分・令和9年度分で一度も真にならず、令和7年度分では 480,001〜549,999 で真になることを確かめる。
  2. 表（７）を改正しなかった理由を、総務省の資料（改正の解説）で確認する（立法の意図の確認。実装には影響しない）。

## IS6 年の途中の死亡・再婚、離婚、本人の死亡は、所得税と健保・第3号で別の時点の規則になる

- 前提：HS3（所得税は12月31日・死亡時）、HS7（第3号は日単位の資格）、HS6（健保の削除事由）。
- 推測：
  1. 配偶者が9月に死亡：所得税は死亡時の現況・1月1日〜死亡日の所得で配偶者控除を判定し、12月31日に寡婦・ひとり親に当たれば併用（所基通80-1・81-1）。健保の被扶養者は死亡で削除。
  2. 本人（第2号・納税者）が9月に死亡：準確定申告では、配偶者の1月1日〜12月31日の所得の見積りで判定する（所基通85-1、［PS-SP］§1.8 Q3）。年末に配偶者が別の親族の扶養親族にもなりうる（所基通83から84の2−1）。残された配偶者は「第2号被保険者の配偶者」でなくなるので、第3号の要件を満たさなくなる（国内に住む60歳未満なら第1号への種別の変更になると読める。種別の変更の効力の日は条文未確認：HS7）。
  3. 10月に離婚：所得税は12月31日に配偶者でないので対象外（HS3-5）。健保は離婚で削除。第3号の要件も満たさなくなり、日本年金機構の案内どおり第1号の手続が要る（［PS-SP］§2.3）。
- 検証の方法：
  1. 場面のテスト（D15③）に、死亡・離婚・再婚の日付を入れた場面を足す（既存の場面 S1〜S8 に無い）。
  2. 2 の「見積り」は、D19 の「見込みの事実が入っていたら申告用の値の出力を拒否する」と衝突する（下の IS8）。

## IS7 第3号と健保の被扶養者は、保険者の運用が違うと結果が食い違いうる

- 前提：HS6（健保は保険者ごとの運用を注入データとする）、HS7（第3号は日本年金機構が認定する。保険者の注入データを使わない）。
- 推測：健康保険組合の被保険者の配偶者について、健康保険組合が独自の運用（例えば事業収入から差し引く経費の範囲）で被扶養者と認定し、日本年金機構が協会けんぽ・機構の案内どおりの運用で第3号を判定すると、配偶者が健保の被扶養者なのに第3号でない（又はその逆）という結果が出うる。日本年金機構は、健康保険組合の被保険者の配偶者については「国民年金第3号関係者届」のみを機構に提出させる（［PS-SP］§4）。
- 検証の方法：日本年金機構・厚労省の資料で、健康保険組合の認定と第3号の認定が食い違った場合の扱い（機構が健保組合の認定を参照するのか、独自に判定するのか）を探す。見つかるまでは、両方の結果を出し、食い違いがあれば理由（注入データの有無・内容）を添える。

## IS8 法令が「見積り」を求める判定（本人の年の中途の死亡、年末調整）は、D19 の「見込み」と区別して持つ必要がありそうだ（ユーザーへの確認事項）

- 前提：HS3-3（所基通85-1：本人が年の中途で死亡したときは、配偶者のその年の所得を死亡時の現況で見積もって判定し、後の所得の発生は判定に影響しない）、HANDOFF の D19（見込みの事実が入っていたら申告用の値の出力を拒否する）。
- 推測：準確定申告では、法令（通達）がそもそも「見積り」で判定することを求めており、後から実績が出ても判定は変わらない。これを D19 の「見込み」として扱うと、準確定申告の値を出せなくなる。「判断としての見込み」（D19）と「法令が判定の基礎として求める見積り」は別の種類の事実として持つ案が考えられる。
- 検証の方法：これは決定事項（D19）の解釈に関わるので、根拠（所基通85-1、［TA1191QA］Q3）を示してユーザーに確認する（AGENTS.md の規則）。実装の前に、準確定申告を対象に含めるか（D14・D17 の範囲か）もあわせて確認する。

## IS9 第3号の年齢と第2号の65歳は「誕生日の前日」で切り替わる。税の「12月31日」とは別の日付関数が要る

- 前提：HS7（資格は日単位、20歳・60歳に「達したとき」。65歳以上で受給権のある厚生年金保険の被保険者は第2号被保険者でない＝国年法附則第3条）、［HS］HS9。
- 推測（架空の例）：4月1日生まれの配偶者は、20歳の誕生日の前日の3月31日に20歳に達し、その日に（被扶養配偶者なら）国民年金の被保険者の資格を取得し、第3号の要件を満たす（国年法第8条第1号）。60歳も同様に誕生日の前日に達し、第9条本文の括弧書き（第3号から第5号までに該当するに至ったときは「その日」）により、その日（誕生日の前日）に資格を喪失する。第2号の配偶者（本人）が65歳に達し老齢・退職の年金の受給権があると、日本年金機構の案内では「65歳に到達（誕生日の前日）」した時点で第3号から第1号への切替えが要る。
- 検証の方法：
  1. 日付の単体テストで、誕生日の前日の規則（1月1日生まれ、2月29日生まれを含む）を確かめる（既存の年齢の実測 `docs/measurements/20261109_impl-prep_misc-fetch-and-age-check.md` の方法を写す）。
  2. 65歳の除外の根拠の条文は国民年金法 原始附則第3条で見つかった（2026-11-09 の独立検証。HS7・HS9 を更新済み）。残りは、附則第3条が引く「政令で定める給付」の政令の中身と、日本年金機構の案内の「70歳未満」の部分の根拠を確かめること。確かめたら HS7・HS9 の残りの「条文未確認」の印を外す。
