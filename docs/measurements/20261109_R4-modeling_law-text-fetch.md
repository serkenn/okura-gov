# 法令本文と所得税基本通達の取得・抜き出し（R4）

- 作成日：2026-11-09
- 種別：実測（measurements）。e-Gov 法令API v2 と国税庁のサイトから原文を取得し、条を抜き出して比べた記録。
- 目的：`docs/public-sources/20261109_R4-modeling_concepts.md`（概念の定義の原文）の根拠になる本文を、後日同じ手順で取り直せるようにする。

## 1. スクリプトと実行方法

| スクリプト | 内容 | 出力 |
|---|---|---|
| `scripts/R4_fetch_laws.py` | e-Gov 法令API v2 で14法令の本文（JSON）を取得し、指定した条と、見出しが正規表現に合う条を抜き出してテキストにする。所得税法・同施行令は4つの時点の版を取得して差分をとる。キーワード検索API で「家計」を検索する | `scripts/results/R4_fetch_laws/` |
| `scripts/R4_fetch_nta.py` | 国税庁「所得税基本通達」の5ページ（HTML）を取得し、本文をテキストにする | `scripts/results/R4_fetch_nta/` |

```
python -I scripts/R4_fetch_laws.py
python -I scripts/R4_fetch_nta.py
```

- 環境：Python 3.11.9（Windows）。標準ライブラリだけを使う（`urllib`、`json`、`html.parser`、`difflib`、`hashlib`）。サードパーティのライブラリは使わない。
- ダウンロードしたファイルは、実行のたびに新しく作る空のディレクトリ `.work/downloads/<YYYYMMDD-HHMMSS>_R4_laws/`・`..._R4_nta/` に置く（git 管理外）。その中でインタプリタは実行しない。
- User-Agent は `okura-gov-research/0.1`。リクエストの間は 1.5 秒あける。
- この記録の元になった実行：法令は `20261109-133843`（`.work/downloads/20261109-133843_R4_laws/`）、通達は `20261109-133617`（`.work/downloads/20261109-133617_R4_nta/`）。

## 2. 取得の手順（R4_fetch_laws.py）

1. `GET https://laws.e-gov.go.jp/api/2/laws?law_title=<法令名>&response_format=json&asof=2026-11-09` で法令IDを調べる（法令名の完全一致で選ぶ）。
2. `GET https://laws.e-gov.go.jp/api/2/law_data/<法令ID>?response_format=json&asof=<日付>&omit_amendment_suppl_provision=true` で本文を取得する。API の仕様（`swagger-ui/lawapi-v2.yaml`）では、`asof` を指定すると「指定時点以前で最新の履歴」の本文が返る。
3. 本則（`MainProvision`）の条（`Article`）のうち、指定した条番号、または見出し（`ArticleCaption`）が正規表現に合う条を、項・号・イロハの構造を残したテキストにする。条がない古い法令（年齢計算ニ関スル法律）は本則全体を出す。
4. 所得税法・所得税法施行令は、2026-11-09 に加えて 2025-12-31、2026-12-01、2027-01-01 の版も取得し、抜き出した条の unified diff をとる。
5. `GET .../law_revisions/<法令ID>?response_format=json&amendment_date_from=2025-01-01` で、所得税法・同施行令の改正履歴（2025年以降の施行分）を取得する。
6. 本則全体で、定義規定らしい書き方（`「世帯」とは`、`「世帯主」とは`、`「家計」とは`、`「生計を一にする」`、`「親族」とは`、`「配偶者」とは／には`、`「被扶養者」とは`、`「被保険者」とは`、`「住所」とは`）を探す。
7. 法令の全文（附則を含む）で `百三十万円`・`百五十万円`・`百八十万円` の出現回数を数える。
8. キーワード検索API `GET .../keyword?keyword=<語>&response_format=json&asof=2026-11-09&limit=1000&sentences_limit=3` で「家計」と「「家計」とは」を検索する。

### 3.2 定義規定らしい書き方の検索（手順6）

- 14法令の本則全体で、ヒットしたのは健康保険法第3条の `「被扶養者」とは`・`「被保険者」とは` だけ。
- **`「世帯」とは`・`「世帯主」とは`・`「家計」とは`・`「生計を一にする」`・`「親族」とは`・`「住所」とは` は、どの法令にも出てこなかった。**
- 限界：この検索は「「X」とは」の形だけを拾う。「「配偶者」、「夫」及び「妻」には」（国民年金法第5条第7項）のような書き方は拾えない（国民年金法第5条第7項は条文を直接読んで確認した）。

### 3.4 キーワード検索「家計」（手順8）

- `keyword=家計`：`total_count=140`、`sentence_count=65`、`next_offset=null`、法令数（items）35（法律19、政令5、府省令11）。一覧は `scripts/results/R4_fetch_laws/keyword_summary.md`、要約データは `keyword_0.json`。
  - 用例は「平均的な家計」「費用の負担の家計に与える影響」（健康保険法、国民健康保険法、高齢者の医療の確保に関する法律など）、「家計改善支援事業」（生活困窮者自立支援法、生活保護法）、統計の規則（家計調査規則、全国家計構造調査規則など）、「「住宅」とは、家計を営む者が、独立して居住することができるように設備された…」（建築動態統計調査規則）など。
  - 所得税法・地方税法・住民基本台帳法・民法の本則には「家計」が出てこない（手順6の本則全条のキーワード集計 `fetch_log.json` の `keyword_hits` でも、これらの法令に「家計」はない）。
- `keyword=「家計」とは`：HTTP 404、本文 `{"code":"404001","message":"取得結果が０件です。"}`。存在しない語（`zzqqxxnotaword`）でも同じ 404 と本文になることを curl で確認したので、この 404 は「0件」の意味。
- 限界：キーワード検索API の分かち書き・かぎ括弧の扱いは仕様書に書かれておらず、「「家計」とは」0件が「定義規定がない」ことの十分な証明かは分からない。e-Gov の収録対象（法律・政令・府省令など）に限られ、告示・通知は対象外。
