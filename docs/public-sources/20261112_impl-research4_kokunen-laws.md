## 2. 第88条の3（育児期間の免除）の施行と経過措置：令和6年法律第47号 附則第10条

- 第88条の3 を本則に入れた改正法は、国民年金法の本文データに収録された附則の上では **令和6年法律第47号**（令和6年6月12日。附則第10条の見出し「国民年金法の一部改正に伴う経過措置」、「第九条の規定による改正後の国民年金法第八十八条の三」）。
  README KN-19 の「令和7年法律第74号の附則」とは別の法律である。令和7年法律第74号（令和7年6月20日）の附則（同じ写しに収録）に第88条の3 を名指す規定はなかった（語「第八十八条の三」の走査：`grep_kokunen_2026-11-12.txt` の附則のヒットは原始附則第9条の2の6 と令和6年法律第47号附則第10条だけ）。

- **附則第10条**：

> （国民年金法の一部改正に伴う経過措置）第十条　第九条の規定による改正後の国民年金法第八十八条の三の規定は、令和八年十月以後の各月の同法第八十七条第一項に規定する保険料について適用する。

- 附則第46条：この附則に定めるもののほか、施行に関し必要な経過措置は政令で定める。国年令（asof 2026-11-12）で第88条の3 を名指す条は第6条の4の3（子ども・子育て支援納付金により補塡する額）・第9条・第11条の2 で、経過措置を定める条は見つからなかった（`grep_kokunenrei_2026-11-12.txt`）。
- 国年法第88条の3（asof 2026-11-12）第1項：「前条の規定の適用を受けた被保険者が同条の出産に係る子を養育する場合においては、当該被保険者は、当該出産予定日から起算して三月を経過した日の属する月から当該出産予定日から起算して十二月を経過した日（…）が属する月の前月までの期間（当該子以外の子に係る同条の規定の適用を受ける期間を除く。）に係る保険料は、納付することを要しない。」第2項は前項以外の被保険者が子を養育することとなった日の属する月から子が1歳に達する日の翌日が属する月の前月まで。

## 3. 第89条第1項第1号の「政令で定める」障害の給付と除かれる者：国年令第6条の5

国年法第89条第1項第1号（asof 2026-11-12）：「障害基礎年金又は厚生年金保険法に基づく障害を支給事由とする年金たる給付その他の障害を支給事由とする給付であつて政令で定めるものの受給権者（最後に同法第四十七条第二項に規定する障害等級に該当する程度の障害の状態…に該当しなくなつた日から起算して障害状態に該当することなく三年を経過した障害基礎年金の受給権者（現に障害状態に該当しない者に限る。）その他の政令で定める者を除く。）であるとき。」

> （法第八十九条第一項第一号の政令で定める給付等）第六条の五　法第八十九条第一項第一号に規定する障害を支給事由とする給付であつて政令で定めるものは、次のとおりとする。

- 第2項（政令で定める者＝除かれる者）：第1号 障害基礎年金・障害厚生年金等・移行障害共済年金の受給権者で、最後に厚生年金保険法第47条第2項の障害等級の程度に該当しなくなった日から3年を経過したもの（現に該当しない者）。第2号〜第8号は旧法・旧厚年・旧船保・国共済・地共済・私学共済・移行農林の障害年金について同じ形（それぞれの法の別表の程度）。
- 障害厚生年金（第1項第1号）は「第4条の6 に定める障害の状態」に該当する者に支給するものに限られる。国年令第4条の6（asof 2026-11-12、写し `kokunenrei_2026-11-12.txt`「## Num=4_6」）：「（障害等級）法第三十条第二項に規定する障害等級の各級の障害の状態は、別表に定めるとおりとする。」国年法第30条第2項（asof 2026-11-12、写し `kokunen_2026-11-12.txt`「## Num=30」）：「障害等級は、障害の程度に応じて重度のものから一級及び二級とし、各級の障害の状態は、政令で定める。」（別表の本文は取り出していない）。
  したがって **障害等級3級の障害厚生年金は、国年令別表の1級・2級の状態に当たらなければ含まれない**、と文言から読める（読みは仮説の文書）。
- 確認した範囲で、労働者災害補償保険の障害（補償）年金、民間の企業年金の障害給付は第1項の列挙にない。
