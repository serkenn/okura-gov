## 2. 「前年分の所得税につき納税義務を負わない」（A）

### 2.1 地方税法の中の同じ言い回し（`grep_chiho_<asof>.txt`。語「納税義務を負わない」）

両版とも、「納税義務を負わない」を含む条は 第32条・第72条の49の12・第313条・第317条の2 の4つだけ（附則にはない）。

- 第313条第11項・第32条第11項（両版で同じ文言）：「前年分の所得税につき納税義務を負わない所得割の納税義務者について、前年中の所得税法第五十七条の二第二項に規定する特定支出の額の合計額が
  同法第二十八条第二項に規定する給与所得控除額の二分の一に相当する金額を超える場合には、この項の規定の適用を受ける旨及び当該特定支出の額の合計額を記載した
  第三百十七条の二第一項〔第32条は第四十五条の二第一項〕の規定による申告書が、当該特定支出に関する明細書その他の総務省令で定める必要な書類を添付して提出されているときに限り、…」
  （以下は impl-research8 §6 と同じ）。
- 第313条第3項・第32条第3項（青色事業専従者）・第72条の49の12第2項（事業税）：「前年分の所得税につき納税義務を負わないと認められたことその他政令で定める理由により
  同条第二項の書類を提出しなかつた所得割〔事業税〕の納税義務者に係る青色事業専従者が当該事業から給与の支払を受けた場合において、…」
- 第317条の2第1項ただし書：「…並びに所得割の納税義務を負わないと認められる者のうち当該市町村の条例で定めるものについては、この限りでない。」（住民税の申告書の提出義務の除外。所得割の側の言い回し）
- **どの条にも「納税義務を負わない」の定義・判定の基準（所得税の額のどの段階で見るか）は書かれていない。**
- 地方税法施行令（両版）に「納税義務を負わない」「特定支出」を含む条はない（`grep_chihorei_<asof>.txt` は見出しだけ）。

### 2.2 所得税法・国税通則法（`shoho_<asof>.txt`・`tsusoku_<asof>.txt`）

- 所得税法第5条第1項（納税義務者）：「居住者は、この法律により、所得税を納める義務がある。」（第2項〜第4項は非居住者・法人）。第7条は課税所得の範囲（非永住者以外の居住者は全ての所得）。
- 所得税法第120条第1項（確定所得申告）：「居住者は、その年分の総所得金額、退職所得金額及び山林所得金額の合計額が…雑損控除その他の控除の額の合計額を超える場合において、
  …第八十九条（税率）の規定を適用して計算した場合の所得税の額の合計額が**配当控除の額を超えるとき**（…外国税額控除の額…、…源泉徴収税額…又は…予納税額がある場合を除く。）は、
  …申告書を提出しなければならない。」第3号は「…第三章（税額の計算）の規定を適用して計算した所得税の額」。asof 2025-12-31 と 2026-12-31 で第120条の本文は違う（`sames.json`）が、上の文言は両版にある。
- 所得税法第121条：給与所得者の確定所得申告を要しない場合（給与等 2,000万円以下・年末調整・給与以外の所得 20万円以下など）。
- 国税通則法第15条第1項：「国税を納付する義務（源泉徴収等による国税については、これを徴収して国に納付する義務。以下「納税義務」という。）が成立する場合には、…」、
  第2項第1号「所得税（次号に掲げるものを除く。）　暦年の終了の時」、第2号「源泉徴収による所得税　利子、配当、給与、報酬、料金その他源泉徴収をすべきものとされている所得の支払の時」。
