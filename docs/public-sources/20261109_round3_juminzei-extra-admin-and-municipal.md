## 1. 総務省「地方税法の施行に関する取扱いについて（市町村税関係）」改正後全文

- URL：https://www.soumu.go.jp/main_content/001071661.pdf （Last-Modified 2026-05-07、142 頁、SHA-256 先頭16桁 107ba94cd6bd4b5e）
- 版：平成22年4月1日総税市第16号。p.1 の改正の列の最後は **令和8年4月1日総税市第25号**。
- 「家屋敷」は全文で 1 回だけ（p.31、4の3）（検査 C06）。

### 1.1 家屋敷課税（第2章第1節）

- **4の3**（p.31）：「法の施行地…に住所を有しない者が、賦課期日現在において、法施行地に事務所、事業所又は家屋敷を有する場合においては、その所在する市町村において、均等割を課する。
  この場合においては、**法第２９５条第１項の規定による非課税の措置は適用されない** ことに留意すること。（法２９４①Ⅱ）」（検査 N01）
- **5**（p.31）：住所の認定。(1) 住民基本台帳に記録されている者（法294②）、(2) 記録されていない者も住所があれば課税でき、住所地で課された者には記録のある市町村は課税できない（法294③・④）。
- **6**（p.31〜32）：「この場合における住所とは、納税義務者本人の生活の本拠をいい、地方税法上その施行地を通じて **１人１箇所** に限られるものであること。」（検査 N02）
  - (1)「勤務する事務所又は事業所との関係上家族と離れて居住している者の住所は、本人の日常生活関係、家族との連絡状況の実情を調査確認して認定するものであるが、確定困難な者で、
    **勤務日以外には家族のもとにおいて生活をともにする者については、家族の居住地にあるものとする**。」（検査 N03）
  - (2) 職業の関係上家族の居住地を離れて転々と居を移している者、職務の性質上年間の一定期間家族の居住地を離れて別に起居している者の住所は、家族の居住地にあるものとして取り扱う。
    **ただし、同一場所に１年以上居住している場合においては、本人の住所は、当該場所にあるもの** として取り扱う（検査 N04）。
  - (3) 船員、(4) たまたま出国した者、(5) 公務員に所得税法第3条第1項は適用しない、(6) 自衛隊員、の取扱いが続く。
- **第1章第1節 6**（p.6）：事務所又は事業所とは、自己の所有に属するか否かにかかわらず、事業の必要から設けられた人的及び物的設備であって、そこで継続して事業が行われる場所（検査 N05・C04）。
  (2) 2、3か月程度の一時的な事業の用に供する現場事務所・仮小屋等は入らない。**家屋敷の定義に当たる項は見当たらない**。
- **32**（p.57）：「市町村民税（分離課税に係る所得割を除く。）の賦課期日は１月１日とされているので納税義務の有無に関する事実の認定は、**同日の現況** においてこれを行うものであること。（法３１８）」（検査 N06）
- **33の2**（p.57〜58）：個人の道府県民税（法第24条第1項第2号の者の均等割と分離課税の所得割）と個人の市町村民税（法第294条第1項第2号の者の均等割と第328条の所得割）の還付加算金・延滞金・
  過少申告加算金・重加算金は、道府県民税と市町村民税の合算額で計算する（検査 C01）。

### 1.2 配当割額・株式等譲渡所得割額の控除（第2章第2節 25の2）

- (1)（p.49〜50）：法第313条第13項の確定申告書に記載した特定配当等…について配当割額を課された場合…には、その **５分の３** を所得割の額から控除する（法314の9①）（検査 N07）。
- (2)（p.50）：(1) で控除できなかった金額と法第37条の4 で控除できなかった金額の合計額（「控除不足額」）があるときは、**賦課決定後、納税通知書を発する前に**、還付をすべき金額により
  **同一年度分** の個人の道府県民税・市町村民税・森林環境税を納付・納入する（法314の9②・③、令48の9の3①）（検査 N08・S2）。
- (3) 納税通知書の交付に併せて通知。(4)（p.50）：なお残る部分は未納の地方団体の徴収金・森林環境税に係る徴収金に充て、それでも残れば **還付** する（検査 S1）。(5) 通知。
- (6)（p.50）：還付加算金の計算の始期は控除不足額が確定した日の翌日で、**確定した日とは (2) の賦課決定の日**（検査 N09）。(7) 端数は法第20条の4の2第2項・第5項（令48の9の5②）。

### 1.3 住宅借入金等特別税額控除（第2章第2節 28）

- 28 柱書（p.51）：「法附則第５条の４の規定に基づく住宅借入金等特別税額控除の適用に当たっては、次の諸点に留意すること。（法附則５の４⑤～⑧）」（検査 S3・C03）
- (1)：「この控除は、取得した住宅を居住の用に供した年が **平成２１年から令和１２年まで** の各年である所得割の納税義務者を対象とするものであること。」（検査 N10）
  → 令和9年1月1日施行の版（居住年 令和12年まで）の文言で書かれている。
- (2)：附則第5条の4第5項第1号の住宅借入金等特別税額控除額は、**措法第41条の3の2**（特定の増改築等に係る住宅借入金等特別税額控除の控除額の特例）を適用しないで計算する（検査 N11）。
- (3)：同項第2号の前年分の所得税額は、**住宅借入金等特別税額控除を行う前の段階の所得税額**（検査 N12）。
- (4)：「市町村は、**給与支払報告書等の記載により**、控除額を算出するために必要な情報を把握するものであること。」（検査 N13）
- 28の3：前年中に非居住者であった期間がある者も、個人の市町村民税の税額控除の範囲は異ならない（検査 S4）。
- 「基礎控除」「48万円」の加算（令和8年改正）は 28 に書かれていない（28 の柱書〜(4) に「基礎控除」「４８万円」「四十八万円」が 0 回。検査 C09）。

### 1.4 申告制度（第2章第3節 29・30）と、ほかの項

- 29（p.51〜52）：市町村内に住所を有することにより市町村民税の納税義務を負う者は、毎年3月15日までに法第317条の2第1項の申告書を提出しなければならない。
  ただし、給与支払報告書・公的年金等支払報告書の提出義務者から1月1日現在支払を受けている者で前年中にそれ以外の所得がなかったもの（一定の控除を受けようとする者を除く）などは申告義務が免除（検査 N16・S5）。
- 30（p.52）：法第294条第1項第1号の者が前年分の所得税の確定申告書を提出した場合、その提出の日に法第317条の2 の申告書が提出されたものとみなす（法317の3）（検査 N15）。
- 26(2)（p.50〜51）：「この控除の額は、他の税額控除に先立ち、税率適用後の所得割の額から控除するものであること。」— これは **26 調整控除** の (2) で、住宅借入金等特別税額控除の項ではない（検査 N14・C02）。

### 2.2 総務省「所得税から住宅ローン控除額を引ききれなかった方」（個人住民税の住宅ローン控除）

- URL：https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/090929.html （Last-Modified 2026-05-20、Shift_JIS）
- 「平成21年から令和12年12月31日までの間に居住し、所得税の住宅ローン減税制度（住宅借入金等特別控除）を受けた方で、所得税において控除しきれなかった金額がある場合は、

- 算出例：居住開始 平成21年5月12日、住宅ローン控除可能額 225,000円、控除適用前の前年の所得税額 190,000円 → 個人住民税の控除額 35,000円（検査 W05）。
  注「源泉徴収税額の項目が0円のときのみ、住宅ローン控除が適用になる場合があります。」（検査 E10）

  「期限までに申告されなかった場合は、自動的に、申告を不要とする新たな住宅ローン控除の適用を受けることになります。」（検査 E12）
- このページに「基礎控除」「48万」の語は **ない**（checks2 §3）。令和8年改正の加算はこのページには反映されていない。

## 3. 自治体の案内：家屋敷課税

### 3.1 船橋市「事業所課税・家屋敷課税とは」

- URL：https://www.city.funabashi.lg.jp/kurashi/zei/007/001/p108828.html （ページの更新日 令和6(2024)年5月2日。検査 E09）
- 対象：「賦課期日（毎年1月1日）現在、船橋市内に事務所、事業所または家屋敷を持っている人のうち、船橋市に住民登録をしていない人」。
  「※前年の合計所得金額が条例で定める金額以下の方は、課税されません。」（検査 W24）根拠条文として地方税法第294条第1項第2号を挙げる。
- 年税額：「均等割 4,000円（市民税3,000円＋県民税1,000円）」「※均等割については月割課税は行っていません。一括納付となります。」（検査 E07・E08）
- **家屋敷とは**：「自己または家族の居住を目的に設けられた **独立性のある住宅** であり、**自己所有でなくても、また現に居住していなくても、常に居住できる状態にあるもの** です。
  例えば、住所地以外の場所に設ける別荘やマンション、**生活の本拠地を別に設けている単身赴任者が妻子を常時住まわせている住宅（実家）等** が該当します。
  なお、自己所有であっても、他人に貸し付ける目的で所有しているものや、現に他人に貸しているものには課税されません。」（検査 W21〜W23）
- 「「常に居住できる状態」とは、電気・ガス・水道などのライフラインが現在開通している状態であるかどうかではなく、**住居の実質的な支配権を持っている状態** のことをいいます。」（検査 W25）

### 3.2 熊本市「単身赴任の方へ～家屋敷課税の申告が必要です～」

- URL：https://www.city.kumamoto.jp/kiji003367/index.html （最終更新日 2022年8月19日。検査 E03）
- 家屋敷課税の対象：(1) 熊本市内に事務所・事業所・家屋敷を有する個人で熊本市外にお住まいの方、(2) **熊本市内のお住まいの区以外の区に**、事務所や事業所、家屋敷を有する個人の方（検査 W31）。
  「(※住民登録は関係ありません）」（検査 E03c）。根拠法令として「地方税法第24条第1項第2号、第294条第1項第2号、第737条」を挙げる（検査 W33）。
- 家屋敷とは：「自己または家族居住の目的で、住所地以外の場所に設けられた住宅で、「いつでも自由に居住できる状態である」建物のことをいいます。」（検査 E03b）
- **単身赴任中の方** は、次の (1)〜(3) の **全て** に該当する方：(1) 熊本市内に本人または家族が住むことを目的とした住宅を持っている方（※借家・持家は関係ありません）、
  (2) 熊本市以外の市区町村で市民税・県民税が課されている方、(3) **熊本市内に居住する配偶者に市民税・県民税が課されていない方**（検査 E01・W32）。
  「※家屋敷課税対象者の配偶者の方は、市県民税申告が必要です」（検査 E02）。
- (3) の条件は法令（［法令］§1）に対応する文言がない。この市の運用の条件と読める。

## 4. 自治体の案内：配当・住宅

### 4.1 杉並区「住宅借入金等特別税額控除（住宅ローン控除）について」

- URL：https://www.city.suginami.tokyo.jp/s028/2058.html （更新日 2026年6月13日。検査 E14）
- 対象：平成21年から令和12年12月末までに入居し、所得税の住宅ローン控除の適用を受け、所得税において控除可能額が控除しきれなかった方。控除額は 5%（9万7,500円が限度）、
  平成26年4月から令和3年12月末までに入居し、消費税額等の税率が 8% 又は 10% の場合は 7%（13万6,500円が限度）。
- 「区への申告（個人住民税の「住宅借入金等特別税額控除申告書」の提出）は不要です。」（検査 W11）
  「年末調整を行う勤務先から提出される給与支払報告書や所得税の確定申告書等から内容を確認します。」（検査 E13）

### 4.2 （参考）総務省の案内と杉並区の案内に、令和8年改正の基礎控除の差の加算は書かれていない

§2.2・§4.1 のどちらも、控除限度額を「課税総所得金額等の 5%」とだけ書いている。法令（［法令］§3.2）と施行通知（§2.1）には加算がある。

## 5. 分からなかったこと

1. 「家屋敷」の定義を示した国（総務省・旧自治省）の文書。取扱通知（市町村税・道府県税）にはない。取扱通知（道府県税）の「独立性」の 1 回は不動産取得税（増築・改築）の文脈（p.144。検査 C05）。
2. 単身赴任者の配偶者が住所地として課税されているとき家屋敷課税をしない、という熊本市の条件（§3.2）が、ほかの団体でも使われるか。集めた3団体のうち、この条件を書くのは熊本市だけ。
3. 子が一人暮らしをする住宅（親が借りる・所有する）が親の「家屋敷」に当たるか。3団体の案内のどれも書いていない。
4. 総務省・自治体の案内のうち、令和8年改正の基礎控除の差の加算を説明したもの。総務省の施行通知（§2.1）以外には見つけていない。
5. 配当割額等の控除不足額の還付について、自治体の案内は集めていない（取扱通知 25の2 だけ）。
