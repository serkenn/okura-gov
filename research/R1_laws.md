# R1 法令の調査

## 目的

判定コア（OpenFisca 上の自作パッケージ）に書くべき、法令上の要件・計算式・基準額を一次情報で確定させる。
あわせて、法令の変更を毎日監視するための情報源を決める（D9）。

## 対象範囲（最初の段階）

扶養されている子供（主に16〜22歳くらい）に関係するものを優先する。

1. **所得税**
   - 所得の種類と、それぞれの所得の計算方法：給与所得、事業所得、雑所得（業務に係るもの・その他）、一時所得
   - 合計所得金額、総所得金額等の定義
   - 扶養親族・控除対象扶養親族・特定扶養親族の定義、所得要件、年齢要件、判定の時点（12月31日の現況など）
   - 特定親族特別控除（令和7年度の税制改正で新設とされる）の要件と控除額の段階
   - 基礎控除、給与所得控除の改正内容（令和7年分・令和8年分での違い）
   - 医療費控除（通常のものと、セルフメディケーション税制）：対象者、対象になる医療費、補填額の扱い、生計を一にする親族の分
   - 青色申告・白色申告の事業専従者と、扶養親族になれない条件
   - 勤労学生控除
2. **住民税（地方税法）**：扶養の判定は所得税と同じか、違う点は何か。非課税限度額
3. **社会保険**：健康保険法の被扶養者の定義（法律で決まっている部分と、通知に委ねている部分の境目。通知の側は R3 で扱う）。国民年金の第3号被保険者
4. **年齢の数え方**：年齢計算ニ関スル法律など（何歳になるのはいつか）
5. **記録の保存**：電子帳簿保存法のうち、個人（事業所得・雑所得のある子供）に関係する部分。記録層の設計に影響する

## 調べ方

- 一次情報：e-Gov 法令検索、e-Gov 法令API、財務省「税制改正の解説」、税制改正大綱、国税庁の改正に関する資料
- 年度ごとに、改正前と改正後を表にする。施行日と「令和X年分から適用」を区別する
- 条番号は原文で確認したものだけを書く（前のセッションでは条番号を検証していない）

## 監視の情報源（D9 用）

次の点を確かめる。

- e-Gov 法令API（Version 2）で、更新・改正された法令の一覧や改正履歴を取れるか。取れるなら、どのエンドポイントで、更新の頻度は
- 国税庁の新着情報に、RSS などの機械で読める形式があるか
- 官報（インターネット版官報）を監視する必要があるか
- 税制改正の流れ（大綱は12月 → 法案 → 3月末ごろ成立 → 施行）のうち、どの段階で issue を作るべきか

## 成果物

`AGENTS.md` のドキュメント規約に従う（title1 は `R1-laws` を推奨）。

- `docs/public-sources/`：要件・計算式・基準額の一覧（出典URL、取得日、適用年度つき）、令和7年分と令和8年分の差分、監視に使えそうな情報源の公開仕様
- `docs/measurements/`：監視用の API などを実際に叩いて確かめた結果（スクリプトは `scripts/`、出力は `scripts/results/`）

## 確認が必要な、記憶ベースの主張（HANDOFF §6）

- 扶養親族の所得要件：合計所得金額 48万円 → 58万円以下
- 給与所得控除の最低保障額：55万円 → 65万円
- 特定親族特別控除：19〜22歳が対象。給与収入にして 123万円・150万円・188万円 などの境目があるとされる
- これらがいつ（令和7年分から？）適用されるか
