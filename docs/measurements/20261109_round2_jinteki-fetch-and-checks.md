## 4. 所得税と住民税の政令・省令の文言の比較（`checks.md` §2）

方法：各条の号（「一　…」の行）を取り出し、(a) 法令番号の括弧（「（昭和二十四年法律第二百八十三号）」など）、(b) 見出しを引く括弧（「（障害者及び特別障害者の範囲）」「（定義）」など）を消し、(c) 次の書き方の違いを同じ文字列にそろえてから号ごとに比べた（`R2X_jinteki_check.py` の `unify()`）。

- 所令「市町村長又は特別区の区長」／地令「市町村長」 → 「市町村長」にそろえた（地令第1条が市町村に関する規定を特別区に準用し「市町村長」を「特別区長」と読み替えるので、実質の違いではない。［PS］§2.2）
- 所令が知的障害者更生相談所・精神保健福祉センターを括弧書きで定義し、地令が法律名つきで直接書く違い
- 所令「次項第六号において「市町村長等」という。」／地令「第七条の十五の七第六号において…」、所令「前項第N号に掲げる者」／地令「第七条第N号に掲げる者」
- 所令「国内」「国外」／地令「法の施行地内」「法の施行地外」、所令「前各号に掲げる者のほか」／地令「前各号に掲げる者を除くほか」、読点の有無（「滅失し、若しくは」）

結果：

| 比較 | 号の数 | 正規化後に号ごとに一致 |
|---|---|---|
| 障害者の範囲 所令10①（2026-12-31）vs 地令7（2027-01-01） | 7 | 一致 |
| 特別障害者の範囲 所令10② vs 地令7の15の7 | 6 | 一致 |
| 寡婦の範囲 所令11 vs 地令46の2 | 5 | 一致 |
| 寡婦の事実婚 所規1の3 vs 地規1の9の7 | 2 | 一致（(a)(b) の正規化だけ） |
| ひとり親の事実婚 所規1の4 vs 地規1の9の8 | 2 | 一致（同上） |

読み取り：(c) でそろえた違いは、法令の書き方の違いで要件の違いではないと読んだ（I。どの違いを「書き方」とみなしたかは上に全部書いた。「特別区の区長」は地令第1条の読替えによる）。

## 5. 給与収入 6,777,778円と寡婦・ひとり親の 500万円（`checks.md` §3）

国税庁の年末調整のしかた（令和7年分 p.15・令和8年分 p.13）の注「給与所得だけの場合は、本年中の給与の収入金額が6,777,778円以下であれば、合計所得金額が500万円以下」を、所得税法第28条第3項の「六百六十万円を超え八百五十万円以下である場合」の号の式（令和7年分の版 asof 2025-12-31 では**第4号**、令和8年分の版では第3号。`checks.md` の見出しの「第3号」は令和8年分の版の号番号。既存の取得 `scripts/results/R1_egov_articles/shotoku_2025-12-31.txt`・`shotoku_2026-12-01.txt`。両版とも「百七十六万円と当該収入金額から六百六十万円を控除した金額の百分の十に相当する金額との合計額」）で計算した（分数で正確に）。

| 給与収入 | 給与所得（端数そのまま） | 500万円以下（端数そのまま） | 500万円以下（1円未満切捨て） |
|---|---|---|---|
| 6,777,777 | 4,999,999.3 | はい | はい |
| 6,777,778 | 5,000,000.2 | **いいえ** | はい |
| 6,777,779 | 5,000,001.1 | いいえ | いいえ |

→ 国税庁の 6,777,778円は、給与所得の1円未満を切り捨てた場合に一致する（両版で同じ）。第28条第3項に端数の定めはない。既存 `docs/hypotheses/20261109_impl-prep_kyuyo-hypotheses.md` H6（660万円以上の給与所得の1円未満は切り捨てる。根拠は別表第五の備考と国税庁の 665万5,556円）と同じ向きの結果。
