## HS1 「配偶者」は制度ごとに別の概念として持ち、婚姻に関する事実は日付つきの事実として記録する

- 内容：
  1. 概念辞書に、少なくとも次の4つを別の ID で置く (I)：`所得税.配偶者`（民法上の配偶者。事実婚を含まない）、`住民税.配偶者`、`健保.配偶者`（事実婚を含む）、`国年.配偶者`（事実婚を含む）。
  2. 中間表現の事実（D3・D5）として、人の組ごとに次を日付つきで持つ (I)：
     - 婚姻の届出による婚姻の開始日（民法第739条第1項：婚姻は届出によって効力を生ずる）
     - 離婚の日、配偶者の死亡の日（人の死亡日として持つ）
     - 生存配偶者の姻族関係終了の意思表示の日（民法第728条第2項。扶養親族の判定に効く）
  3. 事実婚は **人の判断（D4）** とする (I)。判断の材料として、住民票の続柄の記載（「未届の夫」「未届の妻」など）、戸籍、同居の事実を証憑として参照できるようにする。
  4. `住民税.配偶者` は当面 `所得税.配偶者` と同じ（民法上の配偶者）として扱い、結果に「出典未確認」の印を付ける (I)。
- 根拠：
  - 所得税は民法上の配偶者（所基通2-46、［TA1191QA］Q1「事実婚の相手方は…配偶者控除の対象とはなりません」）［PS-SP］§1.1・§1.8、［CON］§3.1。
  - 健保法第3条第7項第1号・国年法第5条第7項は事実婚を含む［PS-SP］§4・§5.1。日本年金機構は内縁関係の確認に両人の戸籍謄（抄）本と被保険者の世帯全員の住民票を求める［PS-SP］§4。
  - 住民税の「配偶者」の範囲を明示した規定・資料は見つからなかった［PS-SP］§6-4。
  - 寡婦・ひとり親の判定で住民票の続柄を使う規定がある（所規1の3・1の4）［CON］§3.1。

## HS2 所得税の配偶者控除・配偶者特別控除は、すべて法令の条文で決まる。コアに置き、注入データは要らない

- 規則の構造（コア）(F)：
  1. 同一生計配偶者：民法上の配偶者 ∧ 生計を一にする ∧ 青色事業専従者等でない ∧ 配偶者の合計所得金額 ≤ 上限（令和7年分 58万円、令和8年分 62万円）。
  2. 控除対象配偶者：同一生計配偶者 ∧ 本人の合計所得金額 ≤ 1,000万円。老人控除対象配偶者：さらに 70歳以上。
  3. 配偶者控除（第83条）：本人の合計所得金額の3段階 × 一般／老人。
  4. 配偶者特別控除（第83条の2）：生計を一にする配偶者 ∧ 青色事業専従者等でない ∧ 配偶者の合計所得金額 ≤ 133万円 ∧ 控除対象配偶者でない ∧ 本人 ≤ 1,000万円 ∧ 第2項の除外に当たらない。額は第1号イ〜ハと第2号・第3号の割合。
  5. 判定の時点は所法第85条第3項（HS3）。
- パラメータ（施行日・適用年分つき。D9・D13）(F)：
  - `同一生計配偶者.所得上限`：令和6年分まで 48万円、令和7年分 58万円（令和7年法律第13号、2025-12-01 施行、令和7年分以後）、令和8年分 62万円（令和8年法律第12号、2026-12-01 施行、令和8年分以後）［PS-SP］§1.1・§1.5。
  - 第83条・第83条の2 の金額と段階（38万・26万・13万、48万・32万・16万、900万・950万・1,000万、95万・130万・133万、93万1円、5万円・3万円、3分の2・3分の1、1万円未満切上げ）は令和6年分〜令和8年分で同じ文言［M-SP］§2.1。
  - 源泉控除対象配偶者（本人 900万円以下・配偶者 95万円以下）は月々の源泉徴収の区分にだけ使う［PS-SP］§1.1・§1.7。
- 端数処理（D13 の名前つき関数）(I)：
  - `第83条の2.超過額の切下げ(超過額)`：「5万円の整数倍−3万円」のうち超過額以下で最大のもの（等しければそれ自体）。
  - `第83条の2.割合と切上げ(額, 分子, 分母)`：整数の分数で計算し、1万円未満を切り上げ。
  - どちらも条文で一意に決まる。［M-SP］§3 で1円刻みに計算した区間が国税庁 No.1195 の表と全行一致した (F)。**一次情報で決まらない端数処理はない。**
- 実装の注意 (I)：
  - 第83条の2 に下限の数字は書かれていない。「控除対象配偶者に該当しない」を条件として書き、下限は導かれる形にする（下限の数字をパラメータとして別に持たない）。これで、同一生計配偶者の上限が変わっても第83条の2 を直さずに済む［PS-SP］§1.3。
  - 性質のテスト（D15④）：本人 ≤ 1,000万円・専従者でない・生計一のとき、配偶者の合計所得金額 0〜133万円の全域で、配偶者控除と配偶者特別控除のどちらか一方だけが適用され、額は配偶者の所得について増えない（単調非増加）。
- 入力として必要な事実：
  - 両者の所得の明細（合計所得金額はコアが計算する。非課税の給付（求職者給付・出産手当金・育児休業給付金など）は含めない［PS-SP］§1.8 Q4〜Q6）。確定申告をしないことを選んだ利子・配当等も除く［PS-SP］§1.6（［TA1190］）。
  - 生年月日（70歳の判定）。
  - 専従者：その年に、本人又は本人と生計を一にする居住者の青色事業専従者として給与を受けたか、白色の事業専従者に当たるか［PS-SP］§1.8（所基通2-48、［SG-0311］）。
  - 配偶者が非居住者か（親族関係書類・送金関係書類の有無）［PS-SP］§1.8 Q7。
- 人の判断（D4）：生計を一にするか（所基通2-47 の評価を含む）［CON］§4.1。どちらが誰を申告書に記載するか（HS5）。

## HS3 判定の時点は「12月31日（死亡はその時）」。年の途中の婚姻は年間の合計所得金額で判定し、離婚した元配偶者は対象にならない

- 内容：
  1. (F) 所得税の配偶者の該当性は、その年12月31日の現況、配偶者が既に死亡していれば死亡の時の現況（所法第85条第3項）。住民税は前年12月31日（前年の中途の死亡はその時）（地法第314条の2第8項）［PS-SP］§2.1・§2.2。
  2. (F) 配偶者が年の中途で死亡：死亡時の現況。配偶者の所得は1月1日から死亡日まで。月割はしない［PS-SP］§1.8（［TA1191QA］Q2）。死別した年は配偶者控除と寡婦・ひとり親控除を併用できる（所基通80-1・81-1、［SG-0310］）。
  3. (F) 納税者本人が年の中途で死亡：本人の死亡時の現況。配偶者の所得は1月1日〜12月31日の見積り（所基通85-1、［TA1191QA］Q3）。
  4. (I) **年の中途で婚姻**：12月31日に配偶者であれば、配偶者の合計所得金額は**その年の全体**（婚姻前の期間を含む）で判定する。根拠は、合計所得金額が年分の金額として定義され（所法2①三十イ（２））、期間を区切る規定が死亡の場合（第85条第3項ただし書）にしかないこと［PS-SP］§2.1。**国税庁がこれを明示した資料は見つからなかった**［PS-SP］§6-1 ので、結果に「解釈（国税庁の明示なし）」の印を付ける。
  5. (I) **年の中途で離婚**：12月31日に配偶者でないので、配偶者控除・配偶者特別控除の対象にならない。元配偶者は民法上の親族でもなくなるので、扶養親族にもならない（離婚で婚姻が解消し、姻族関係も終了する：民法第728条第1項［PS-SP］§2.1）。国税庁の明示は見つからなかった［PS-SP］§6-2。
  6. (F) 死亡と再婚が同じ年：対象は一人に限る（所令220、住民税は地令7の16・48の7⑤）［PS-SP］§2.1・§2.2。既存の仮説（所属の割当てで配偶者の候補を2人まで持つ）に従う。
- 入力として必要な事実：人の死亡日、出国日（居住者でなくなる日）、婚姻・離婚の日（HS1）。
- 未確定の点 (I)：住民税（地令7の16）には所令220 第2項・第3項に当たる規定が見つからなかった［PS-SP］§2.2・§6-10。住民税で「死亡した配偶者・再婚した配偶者」が他の納税義務者の扶養親族にもなる場合の扱いは、一般の所属の規定（地令46の3〜46の5［JUMIN］§4.2）で解くと仮定する。

## HS4 住民税の配偶者控除・配偶者特別控除・調整控除も条文で決まる。所得税とは相互適用の除外の範囲と額が違う

- 規則の構造（コア）(F)：
  - 定義は地法第292条第1項第7号・第8号（前年の合計所得金額）。年度＝所得の年分＋1［PS-SP］§3.1。
  - 配偶者控除 33万・22万・11万（老人 38万・26万・13万）。配偶者特別控除は配偶者の前年の合計所得金額 100万円以下で 33万円（本人 900万円以下）、100万円超は所得税の第83条の2 と同じ式。割合と1万円未満切上げも同じ［PS-SP］§3.2、［M-SP］§3.2。
  - 道府県民税（第34条）と市町村民税（第314条の2）で額は同じ［M-SP］§3.2。
  - **相互適用の除外**：令和8年度分から、配偶者が納税義務者について**配偶者控除（前号）又は配偶者特別控除**の適用を受けている場合は、配偶者特別控除を適用しない。所得税（第83条の2第2項第1号）は配偶者特別控除どうしだけを除外している［PS-SP］§1.4・§3.2。
  - 調整控除（第314条の6・第37条）の人的控除の差：控除対象配偶者 5万円（本人 900万円超950万円以下 4万円、950万円超 2万円）、老人控除対象配偶者 10万円（6万円・3万円）。表の（７）（配偶者特別控除の配偶者のうち前年の合計所得金額 55万円未満）5万円・3万円など。率は市町村民税 100分の3（指定都市 100分の4）、道府県民税 100分の2（指定都市 100分の1）［PS-SP］§3.3。
- パラメータ（年度・施行日つき）(F)：同一生計配偶者の上限 令和7年度分まで 48万円、令和8年度分 58万円（令和7年法律第7号、2026-01-01 施行、令和8年度以後）、令和9年度分 62万円（令和8年法律第2号、2027-01-01 施行、令和9年度以後）。相互適用の除外の文言の変化も令和8年度分から［PS-SP］§3.4、［M-SP］§2.2。
- コアと注入データの境目 (I)：
  - 配偶者控除・配偶者特別控除・調整控除の表と率はコア（法律で全国一律）。
  - **納税義務者の住所が指定都市か**は、市町村についての事実（1月1日の住所の市町村の属性）として注入データにする。注入されていなければ、調整控除の道府県民税・市町村民税の内訳は「未確定」、合計（100分の5）は決まる（D19 の「取りうる範囲で評価」）。
- 端数処理：所得税と同じ（HS2）。条文で一意に決まる。
- 入力として必要な事実：所得税と同じ（前年の分）。住民税では申告・報告書の種類で所属を決める書類が違う（給与支払報告書・申告書・申請書）［JUMIN］§4.2。

## HS5 「誰が誰について何を受けるか」は申告書等の記載の事実（判断）として入力で受け、コアは整合を検査する

- 内容 (I)：
  1. 配偶者控除・配偶者特別控除の相互の関係（所法83の2②一、地法314の2①十の二の括弧書き）と、配偶者が他の人の扶養親族・特定親族とされる場合の所属（所令218・218の2、地令46の3・46の4）は、**申告書等にどう記載したか**で決まる［PS-SP］§1.4・§2.1・§2.2、［MISC］§3。
  2. コアが「AがBについて配偶者特別控除を受けるか」を、「BがAについて受けるか」から逆算すると循環する。そこで、各人・各年分の「申告書等の記載」（確定申告書・扶養控除等申告書・配偶者控除等申告書・給与支払報告書などに誰をどの区分で記載したか、提出日）を **判断台帳の選択（D4・D12）／提出後は事実** として入力で受け、コアはその組合せが法令上許されるかを検査する（許されない組合せは理由つきで拒否する。決まらないときは所令218②・地令46の3②の既定に従う）。
  3. 所法83の2②二・三（源泉控除対象配偶者として月々の源泉徴収を受けている配偶者）のために、配偶者の「扶養控除等申告書に源泉控除対象配偶者を記載し、甲欄で源泉徴収を受けたか」「年末調整を受けたか」「確定申告書を提出したか・決定を受けたか」を事実として持つ［PS-SP］§1.4。
- 根拠：［PS-SP］§1.4（第83条の2第2項）、§1.6（申告書の注意事項「あなたの配偶者が、あなた以外の所得者の扶養親族若しくは特定親族とされる場合…配偶者（特別）控除の適用を受けることができません」）、［MISC］§3（所令218〜220）。

## HS6 健康保険の被扶養者としての配偶者：法律の構造はコア、収入の基準は「国の通知」のパラメータ、保険者ごとの運用は注入データ

- 規則の構造 (F)：
  - 健保法第3条第7項第1号：配偶者（事実婚を含む）は「主としてその被保険者により生計を維持するもの」であればよく、同一の世帯は要件でない。国内居住要件（例外あり）［PS-SP］§4、［CON］§4.3。
  - 生計維持の基準（昭和52年通知）：年間収入 130万円未満（60歳以上・障害者 180万円未満）かつ、同一世帯なら被保険者の年間収入の2分の1未満（例外的に、被保険者の年間収入を上回らず生計維持の中心的役割を果たしていると認められる場合）、別世帯なら援助額より少ない［PS-SP］§4、［PS-K］。
  - 19歳以上23歳未満の150万円は配偶者に適用しない［SH］§1.2。
  - 認定日以後の「今後1年間の見込み」で判定、令和8年4月1日以後の認定日は労働契約による判定もある［PS-K］§1.1・§5.1。
- コアと注入データの境目 (I)：
  - 法律の構造（続柄、事実婚、同一世帯が要件か、国内居住）＝コア。
  - 130万・180万・2分の1・援助額の比較＝国の通知で決まる共通部分。コアのパラメータとして持つが、出典の種類を「通知」と記録する（法令ではない）。
  - 保険者ごとの運用（事業収入から差し引く経費の範囲、確認書類、検認の時期など）＝保険者ごとの注入データ（D19）［PS-K］§1.3。
- 入力として必要な事実・判断：
  - 事実婚に当たるか（D4）、同居・別居（事実）、配偶者の今後1年の年間収入の見込み（D4。見込みの印を結果まで伝える：D19）、被保険者の年間収入の見込み（D4）、被保険者からの援助（送金の事実）、60歳以上か・障害の程度（事実）、配偶者自身が被用者保険の被保険者か（事実。被保険者なら被扶養者にならない［PS-K］§4.2）、後期高齢者医療の被保険者か。
  - 婚姻・離婚・死亡の日（HS1）。削除の事由に「離婚」「婚姻等により他の被保険者に扶養されるようになったとき」がある［PS-SP］§2.3。
- 境目の注意 (I)：税は「以下」（58万円以下・133万円以下）、健保は「未満」（130万円未満）。比較演算子をパラメータに含めて持つ。

## HS7 第3号被保険者の判定は「健保の被扶養者の判定」を再利用し、国民年金法の要件（年齢・第2号の配偶者・国内居住・適用除外）と日単位の資格期間をコアで足す

- 規則の構造 (F)：
  - 国年法第7条第1項第3号：第2号被保険者（厚生年金保険の被保険者）の配偶者（事実婚を含む：第5条第7項）で、主として第2号被保険者の収入により生計を維持するもの（被扶養配偶者）のうち20歳以上60歳未満。国内居住（国年則第1条の3 の5類型の例外）。第2号被保険者である者・国年則第1条の2 の者（特定活動の在留資格の外国籍の者）を除く［PS-SP］§5.1。
  - 生計維持の認定は、健保法・各共済組合法の被扶養者の認定の取扱いを勘案して日本年金機構が行う（国年令第4条）。認定には行政手続法第3章（第12条・第14条を除く）を適用しない（国年法第7条第3項）［PS-SP］§5.1。
  - 現在の収入の基準：130万円未満（健保の認定の取扱いを勘案）。厚労省年金局の資料は昭和52年通知（平成5年3月5日最終改正）を「具体的な通知」として添付し、平成5年4月以降130万円で変わっていないと説明する。日本年金機構は「年収が130万円未満であり、かつ配偶者の年収の2分の1未満」と書く［PS-SP］§5.2。
  - 第3号固有の認定基準として昭和61年3月31日 庁保発第13号（厚生大臣の「被扶養配偶者の認定基準」）があるが、データベースの本文は制定時の90万円のままで、現在の金額の根拠には使えない［PS-SP］§5.2・§6-5。
  - 被保険者の資格の取得・喪失は日で定まる（国年法第8条第5号「被扶養配偶者となつたとき」はその日に取得。第9条は「該当するに至つた日の翌日」に喪失が原則で、第6号「被扶養配偶者でなくなつたとき」は翌日、第3号「六十歳に達したとき」〜第5号は本文の括弧書きにより「その日」（第4号は厚生年金保険法に基づく老齢給付等を受けることができる者となつたときに限る））。ただし国内に住む20歳以上60歳未満の人の第1号⇔第3号は資格の取得・喪失ではなく種別の変更になる。種別の変更があった月は変更後の種別の月とみなし、同じ月に2回以上変わればその月は最後の種別の月とみなす（国年法第11条の2）。種別の変更が生じる日を直接定める条文は未確認［PS-SP］§2.3・§6-12。届出は14日以内、事業主（共済組合員の配偶者は共済組合等）を経由［PS-SP］§2.3。
  - 65歳以上で老齢・退職の給付の受給権がある厚生年金保険の被保険者は、第2号被保険者に当たらない（国年法 原始附則第3条。給付の範囲は厚生年金保険法附則第4条の3第1項の政令）。したがってその配偶者は第3号にならない（日本年金機構の案内では第1号へ切り替え）［PS-SP］§5.1・§5.2。案内の「70歳未満」の部分の根拠の条文と、政令の中身は未確認［PS-SP］§6-7。
- コアと注入データの境目 (I)：
  - 年齢・国内居住・適用除外・第2号の配偶者であること・資格期間の日付計算＝コア（法令）。
  - 生計維持の判定＝HS6 の「国の通知で決まる共通部分」と同じ関数を、**保険者の注入データを使わずに**呼ぶ（認定するのは保険者ではなく日本年金機構なので）。保険者ごとの注入データで健保の結果が変わる場合は、健保と第3号の結果が食い違いうることを結果に示す（推測は inferences の IS7）。
  - 「65歳以上で老齢・退職の給付の受給権がある厚生年金保険の被保険者は第2号被保険者でない」は、出典を国年法附則第3条（法令）としてコアに置く。給付の範囲（政令）と「70歳未満」の部分は「条文未確認」の印つき。入力の事実として、配偶者（厚生年金保険の被保険者）の老齢・退職の給付の受給権の有無と取得日が要る。
- 入力として必要な事実・判断：HS6 のもの＋配偶者（第2号）の厚生年金保険の資格（取得日・喪失日）と生年月日、本人の生年月日（20歳・60歳の到達日）、住所（国内か、海外特例の類型）、国籍と在留資格（適用除外の判定）、日本年金機構の認定の通知の日（国年則第14条の2。判定と「認定された事実」を分ける）。
- 端数・日付の扱い (I)：「20歳に達したとき」「60歳に達したとき」は年齢計算ニ関スル法律と民法第143条により誕生日の前日に達する（［CON］§2.2 の年齢の数え方）。税の「12月31日の現況」とは別の関数にする。コアの出力は「第3号の要件を満たす区間（日付の区間）」を基本とする。月単位の被保険者期間への当てはめの規則は国年法第11条の2（変更があった月は変更後の種別、同じ月に2回以上なら最後の種別）にあるので、別の関数として置ける。ただし種別の変更が生じる日を直接定める条文は未確認なので、区間の境目を変更の日とみなして月に当てはめた結果には印「条文未確認（変更の日）」を付ける。
