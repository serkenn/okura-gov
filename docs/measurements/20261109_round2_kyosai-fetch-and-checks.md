## 0. 安全の扱い

- ダウンロードしたものは取得ごとに新しい空のディレクトリ `.work/downloads/<YYYYMMDD-HHMMSS>_R2X_kyosai_<set>/` に置いた（e-Gov は `.work/downloads/<ts>_R2X_kyosai_egov/`）。その中でインタプリタやツールを実行していない。HTML から抽出したテキストとリンクは別のディレクトリ `.work/text/<ts>_R2X_kyosai_<set>/` に書いた。
- `R2X_kyosai_checks.py` はダウンロードしたファイルを読まず、`scripts/results/R2X_kyosai_egov/articles/*.txt`（`R2X_kyosai_egov.py` が JSON から作ったテキスト）だけを読む。
- PDF は Read ツールのページ指定で描画して読んだ（ファイルを実行するツールは使っていない）。
- リクエストの間は 1.5 秒あけた。User-Agent は `okura-gov-research/0.1`。個人の情報は送っていない。官報は取得していない。
- Web 検索（URL を見つけるため）に送った語は、制度名・条文の語だけで、家族の情報は含まない。
