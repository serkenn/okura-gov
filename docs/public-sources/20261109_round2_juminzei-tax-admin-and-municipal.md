## 1. 総務省「地方税法の施行に関する取扱いについて（市町村税関係）」改正後全文（平成22年4月1日総税市第16号。令和8年4月1日総税市第25号までの改正を反映。「技術的助言」という位置づけは PDF の読んだ頁では確認できなかった）

読んだ頁：p.2-3（目次）、p.33-38、p.40-51、p.57-60。第2章第2節「第4 税率及び税額の計算」は p.42 から。

- 19の2（p.41-42）：地震保険料控除の経過措置（平成18年改正法附則第11条）。前年中に支払った地震保険料等の契約がすべて地震保険料なら 1/2（最高 2万5千円）、
  すべて平成18年12月31日までに締結した長期損害保険契約等なら改正前の第314条の2第1項第5号の3 による控除（最高 1万円）、両方あれば合わせて最高 2万5千円。
- 21（p.42）：特別障害者のうち「重度の知的障害者」は知能指数おおむね 35 以下で常時の介護を要する程度の者。21の2：前年中に非居住者であった期間がある者も所得控除の範囲は変わらない。
- 22（p.42）：個人の均等割は、法第311条で軽減する場合のほか、**不均一の課税は原則として適当でない**。道府県民税の個人の均等割には法第311条に当たる規定がないので、
  法第323条で市町村民税の均等割を減免して法第45条で道府県民税も減免される場合を除き、法第311条の例による軽減はできない。
- 23（p.42）：**所得割の税率は比例税率**でなければならない（所得金額を区分して区分ごとに異なる税率を定めることはできない）。（法314の3）
- 24（p.42-43）：寄附金税額控除の要件（［法令］§8.1 と同じ内容）。(3)〜(7) の寄附金は市町村の条例で定めるものに限る。
- 24の3（p.44-46）：(1) 特例控除対象寄附金かどうかは、寄附金を支出した時に受領した都道府県等が指定されているかで判定する。指定を取り消された日以後の寄附金は対象にならない。
  (2) 共同募金会・日本赤十字社は賦課期日現在の住所所在の都道府県内のものに限る。(3) 金銭以外の財産による寄附は取得費等の必要経費相当額。
  (4) 平成26年度〜令和20年度分は附則第5条の6 の読替え。p.45-46 の破線の枠（「※令和10年1月1日から適用」）は、令和30年度まで・令和31年度以後の読替え（附則第5条の6第3項・第4項）に書き換えた文を載せる。
- 24の4・24の5（p.46）：寄附金税額控除だけを受ける申告の様式（施行規則第5号の5の2様式）、条例指定の NPO 法人への寄附金は確定申告書などを出している者も別に申告書が必要（第5号の5の3様式）。
- 24の6（p.47-48）：申告特例（ワンストップ）。(1) 申告特例対象寄附者は、所得税の確定申告の義務がない（または第121条の適用を受ける）見込みで、住民税の申告も寄附金税額控除以外に要しない見込みの者。
  (4) 同一年に同一の地方団体へ複数回寄附するときは寄附ごとに求める（同一団体は 1 と数える）。(8) 翌年度分の住民税の申告書・確定申告書を出したら、申告特例の求めと通知はなかったものとみなす。
  (9) 申告特例通知書を送付した都道府県知事等の数が **5 を超えたら**、全部なかったものとみなす。（法附則7⑧⑨⑬）
- 25（p.49）：外国税額控除。市町村民税の控除限度額は国税の控除限度額の **100分の18**（指定都市 **100分の24**）。
- 26（p.50-51）：調整控除。(1) 合計課税所得金額は課税総所得金額・課税退職所得金額・課税山林所得金額の合計で、分離課税の所得（上場株式等の配当・譲渡、土地等の事業所得、長期・短期譲渡、
  一般株式等の譲渡、先物取引の雑所得など）を含まない。(2) **調整控除の額は、他の税額控除に先立ち、税率適用後の所得割の額から控除する**。
- 28（p.51）：住宅借入金等特別税額控除。(1) 居住年が **平成21年から令和12年まで** の者が対象（通知の文は令和8年改正を反映）。(2) 所得税の住宅借入金等特別税額控除額は措法第41条の3の2 を適用しないで計算する。
  (3) 前年分の所得税額は住宅借入金等特別税額控除を行う前の所得税額。(4) 市町村は給与支払報告書等の記載で控除額の算出に必要な情報を把握する。
- 28の3（p.51）：前年中に非居住者であった期間がある者も、税額控除の範囲は変わらない。
- 32（p.57）：賦課期日（1月1日）の現況で納税義務の有無を認定する（［既存］と同じ）。
- 33（p.57）：個人の市町村民税を賦課徴収するときは、個人の道府県民税と森林環境税を併せて賦課し、徴収しなければならない。
- 35（p.58）：納付額は、市町村民税・道府県民税・森林環境税の額で按分して、それぞれ納付があったものとして扱う（いずれか一の税だけの徴収はできない）。

## 2. 自治体の計算例（令和8年度分）

### 2.1 名古屋市「市民税・県民税の計算例」（更新日 2026-04-01）

- URL：https://www.city.nagoya.jp/kurashi/zeikin/1037356/1011880/1011883/1011891.html （SHA-256 `e31ea03689c320af2f9e829cffa1f474d6c7fe091481184adf3a7ebf4e9027a5`）
- 指定都市。家族構成：夫婦と子3人（19歳・16歳・12歳）、妻と子は所得なし。給与収入 5,505,000円、社会保険料 825,600円、旧契約の一般生命保険料 80,000円。
- 給与所得 3,963,200円、所得控除の合計 2,400,600円（社保 825,600、生命保険 35,000、配偶者 330,000、扶養 780,000（19歳 45万・16歳 33万・12歳 0）、基礎 430,000）。
- 課税総所得金額 1,562,600円 → **1,562,000円（1,000円未満切捨）**。
- 市民税所得割 1,562,000×**7.7%**＝120,274円、県民税所得割 ×2%＝31,240円。
- 調整控除：人的控除差 配偶者 5万・特定扶養 18万・一般扶養 5万・基礎 5万＝33万円、合計課税所得 200万円以下なので 33万円×4%＝13,200円（市）、×1%＝3,300円（県）。
- 市民税額＝120,274−13,200＋均等割 **2,800円**＝109,874円 → **109,800円（100円未満切捨）**。県民税額＝31,240−3,300＋均等割 **1,500円**＝29,440円 → 29,400円。
- 合計 139,200円＋森林環境税 1,000円＝140,200円。「市民税額は、**名古屋市市民税減税を適用した税率**によって計算しています」。
- 読み取れること（E）：標準税率（指定都市 8%・均等割 3,000円）より **低い** 市民税の税率・均等割の例。県民税の均等割は標準（1,000円）より高い。調整控除の率は 4%・1% のまま。

### 2.2 横浜市「令和８年度市民税・県民税・森林環境税の計算（例）」（最終更新日 2026-04-01）

- URL：https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/zeikin/y-shizei/kojin-shiminzei-kenminzei/kojin-shiminzei-shosai/kojinkeisan.html
  （SHA-256 `4333d084b74e43c55a6e984cce8a287ba33249fea6291a1e0b81db3056ab66c9`）
- 指定都市。夫婦（一方は無収入）、子2人（17歳・13歳）、給与収入 5,500,000円、社会保険料 394,800円、一般生命保険料（新契約）90,000円、地震保険料 20,000円。
- 給与所得 3,960,000円、所得控除の合計 1,522,800円（社保 394,800、生命保険 28,000（限度額）、地震保険 10,000、配偶者 330,000、扶養 330,000、基礎 430,000）。
- 課税標準額 2,437,200円 → 2,437,000円（千円未満切捨）。市民税算出所得割 ×8%＝194,960円。県民税算出所得割 ×**2.025%**＝49,349.25円 → **49,349円（1円未満切捨）**。
- 調整控除：合計課税所得が 200万円超、人的控除差 15万円 − 43.7万円 ＜ 5万円 なので 5万円×4%＝2,000円（市）、×1%＝500円（県）。
- 控除後市民税所得割 192,960円 → 192,900円、控除後県民税所得割 48,849円 → 48,800円（百円未満切捨）。
- 均等割 3,900円（市民税）＋1,300円（県民税）、森林環境税 1,000円。令和8年度の税額 247,900円。
- 読み取れること（E）：市民税の均等割（3,900円）・県民税の所得割（2.025%）と均等割（1,300円）が標準と違う。算出所得割の **1円未満を切り捨てる** 扱い。
  所得割（控除後）を百円未満切捨てしてから均等割を足している。

## 4. 分からなかったこと

- 超過課税・減税の **税率の値** を全国分まとめた一次資料（総務省の資料は団体名と規模だけ）。各団体の条例を見る必要がある。
- 1円未満の扱い（算出所得割・税額控除）を定めた通知の文言。取扱通知の読んだ頁にはなかった。自治体の案内には「算出所得割を1円未満切捨て」（横浜市）、
  「配当控除を1円に切り上げ」（中央区）の例があるだけ。
- 配当控除・住宅借入金等特別税額控除・寄附金税額控除の順序を定めた法令・通知の文言（中央区の案内だけ。取扱通知には調整控除を先にすることだけがある）。
