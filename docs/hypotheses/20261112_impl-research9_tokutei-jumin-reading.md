## H1 「前年分の所得税につき納税義務を負わない」は一次情報で1つに決まらない（読みの候補を残す）

- 地方税法・同施行令・同施行規則に定義がない（［PS9］§2.1、［M9］検証 A4・A7）。総務省の取扱通知・改正の説明は見つからなかった（［PS9］§2.3）。
- 手がかり（どれも決め手にならない）：
  - 国税通則法第15条第1項の「納税義務」は「国税を納付する義務」、所得税は暦年の終了の時に成立する（［PS9］§2.2）。源泉徴収による所得税の義務は支払者の「徴収して国に納付する義務」なので、
    給与から源泉徴収されたかどうかは本人の「所得税につき納税義務」の有無を決めない。本人の前年分の所得税の額（年税額）が0 かどうかで読むのが文言に沿う。
  - 所得税法第120条第1項は、確定申告の義務を「所得税の額の合計額が**配当控除の額を超える**とき」とする（配当控除だけを引いて比べ、住宅借入金等特別控除などのほかの税額控除は引かない）。
    「納税義務を負わない」を確定申告の義務の有無の言い換えと読むなら、この基準（算出税額 ≦ 配当控除）になる。
  - 第313条第3項（青色事業専従者）は「前年分の所得税につき納税義務を負わないと認められたこと」を、所得税の書類を出さなかった理由に挙げる（［PS9］§2.1）。所得税の申告をしない人を指す用法と読める。
- したがって、判定コアの読みの候補（［H8］H10：税額控除の後の額が0／算出税額が0）は一次情報で断定に変えられない。第120条第1項の基準（算出税額が配当控除の額以下）は
  第3の候補になりうる（税額控除の後が0 と算出税額が0 の間にある：配当控除だけで0 になる人は前者で「負わない」、後者で「負う」、第3の候補で「負わない」。
  住宅借入金等特別控除で0 になる人は前者で「負わない」、後の2つで「負う」）。D22 S1（支えが同程度なら両方で評価）に従い、候補を足すかはユーザー・判定コアの担当が決める。
- **2026-11-12 の9回目（追記）**：ユーザーの判断（一次情報で決まらない読みは、ありうる候補を全部で評価する。D21 R6）で、判定コアの読みの候補を3つにした
  （税額控除の後の額が0／算出税額が0／算出税額が配当控除の額以下）。3つ目の候補の根拠は第120条第1項の本文の「所得税の額の合計額が配当控除の額を超えるとき」
  （［PS9］§2.2。令和7年分・令和8年分の両版にある文言）。この候補に入れていないもの（どちらも第120条第1項に付いているが、ここでは入れない）：
  - 同項のかっこ書き（控除しきれない外国税額控除・源泉徴収税額・予納税額がある場合を除く：［PS-ZG］`docs/public-sources/20261109_impl-prep_zeigaku-tax-calc.md` §5.1）。
    源泉徴収税額の多寡で決まる除外で、上の国税通則法第15条の手がかり（源泉徴収は本人の納税義務の有無を決めない：［PS9］§2.2）と合わない。
  - 措法41の2の2第6項第2号の読替え（年末調整で控除された住宅借入金等特別控除の額を「配当控除の額」に加える：［JJ］`docs/public-sources/20261111_impl-research3_joto-junjo-laws-and-nta.md` §4）。
    入れると、年末調整の住宅借入金等特別控除で0 になる人は3つ目の候補でも「負わない」になる（1つ目の候補と同じ結論）。入れるかは未決（ユーザーに確認）。
    → **2026-11-12 の10回目（追記）**：ユーザーの指示（D21 R6：ありうる読みを全部評価する）で、3つ目の候補はそのままにし、この読替えを含めた変形を4つ目の候補として足した（juminzei README の JM-41。判定コアは4つの候補の全部で評価し、結論が分かれれば未確定）。

## H2 地方税法施行規則第1条の12 の書類は、判定コアでは「住民税の申告書の記載の選択」に含めてよい

- 第313条第11項・第32条第11項の「総務省令で定める必要な書類」は、所令167の4 の事項を記載した特定支出に関する明細書と、所令167の5 の支出を証する書類（［PS9］§3）。
  所法57の2③ と違い、給与等の支払者・キャリアコンサルタントの証明書は列挙されていない（ただし特定支出の範囲〔所法57の2②〕は証明を要件に含むので、証明のない支出は特定支出に当たらない：［PS8］§1）。
- 判定コアが持つのは「記載して提出するか」の選択（選択.住民税の申告 の specific_expense_deduction）だけで、書類の有無は事実として持たない。
  所法57の2③ の添付と同じ扱い（選択に含める）でよい。値の計算は変わらない。

## H3 第一表の給与の「区分」：㋔（G13）は所得金額調整控除、⑥（G16）は特定支出控除

- 手引き 3-2_06 の原文：㋔欄の区分は所得金額調整控除（Step3 の (1) なら 1、(2) なら 2、両方なら 3）、⑥欄の区分は特定支出控除を受ける場合だけ明細書の区分番号（［PS9］§4.1）。
  e-Tax の KOA020 23.0 でも、収入金額等の給与の区分が 1〜3、所得金額等の給与の区分が 1〜511（［PS9］§4.2）。明細書も「所得金額等」欄の給与の区分に書くとする（［PS9］§4.3）。
- 既存の記録（output-forms-and-specs §2.5）と、それに基づく様式の対応表（KOA020-01 の G13＝特定支出控除、G16＝所得金額調整控除）は**逆**。
  欄コードの位置（㋔の区分 G13・⑥の区分 G16）は既存の記録のとおりとして、G13 に所得金額調整控除の 1・2・3、G16 に特定支出の区分の合計を写すのが原文に合う。
- Step3 の (1) は租税特別措置法第41条の3の11第1項、(2) は同第2項に当たる（手引きの文言の要件と同じ。条の対応は既存の［GAPS］`docs/public-sources/20261109_round2_gaps-sources.md` §3.1）。

## H4 ⑥（G16）に書く「区分番号」は、明細書 ⑫「適用を受ける特定支出の区分の合計」

- 明細書の各区分の番号は 2 のべき（通勤費 1・転居費 2・研修費 4・資格取得費 8・帰宅旅費 16・図書費 32・衣服費 64・交際費等 128・職務上の旅費 256）で、
  KOB070 の ⑫「適用を受ける特定支出の区分の合計」の範囲は 0〜511（＝9区分の全部の和）、KOA020 の ⑥ の区分の範囲は 1〜511（［PS9］§4.3・§5.2）。
  したがって ⑥ の区分に書く値は、適用を受ける区分の番号の和（どの区分の組み合わせかを1つの数で表す）。
- 「適用を受ける」区分は、明細書の各区分の差引金額 Ⓒ（Ⓐ−Ⓑ）が正の区分と読む（⑪ の合計に入る区分。勤務必要経費は図書・衣服・交際を別々の区分として数える）。
  差引金額が0 の区分を数えるかの明文は見つからなかった（［PS9］§7）。

## H5 第二表「特例適用条文等」には「所法57の2」と ⑪ 特定支出の合計額を書く

- 明細書の注記：「上記⑪の金額を申告書第二表の「特例適用条文等」欄に書きます。記載例：特例適用条文等　所法５７の２　XXX,XXX円」（［PS9］§6）。金額は ⑪ 特定支出の合計額（⑰ 特定支出控除の金額ではない）。
- e-Tax の「特例適用条文等」は文字の1欄（ABF00000）なので、ほかの特例（措法27 など）と同じ欄に並べて書く。並べ方（区切り）の定めは見つからなかった。
- 特定支出控除を受けるとき（所法57の2③ の記載をし、⑰ が正）だけ書く。⑰ が0（⑪ が給与所得控除額の2分の1 以下）のときは「適用はありません」（明細書の注記：［PS8］§7.2）なので書かない。
