## 1. 家屋敷課税（F）

### 1.1 納税義務者と課税の形（第294条第1項（第24条第1項））

- 第294条第1項柱書：「市町村民税は、第一号の者に対しては均等割額及び所得割額の合算額により、…**第二号及び第四号の者に対しては均等割額により**、…課する。」（検査 K01）
  - 第1号「市町村内に住所を有する個人」。
  - **第2号「市町村内に事務所、事業所又は家屋敷を有する個人で当該市町村内に住所を有しない者」**（検査 K02）。
  - → 第2号の者には **均等割だけ** が課され、所得割は課されない。
- 第24条第1項柱書（道府県民税）：「…第二号及び第四号に掲げる者に対しては均等割額により…」（検査 K06・B10）。
  第2号「道府県内に事務所、事業所又は家屋敷を有する個人で **当該事務所、事業所又は家屋敷を有する市町村内に** 住所を有しない者」（検査 K07）。
- 第24条第7項：「第一項第二号に掲げる者については、**市町村民税を均等割により課する市町村ごとに一の納税義務** があるものとして道府県民税を課する。」（検査 K08）
  → 同じ道府県の中でも、家屋敷のある市町村ごとに道府県民税の均等割が課される。
- 版：第294条・第24条は asof 2026-04-01 の版で文言が変わったが、変わったのは公益法人等の列挙（マンション建替組合→マンション再生組合など）だけ
  （`scripts/results/R3X_juminzei-extra_laws/diff_chiho_2026-01-01_vs_2026-04-01.md`）。家屋敷課税に関わる文言は 2025-01-01〜2028-01-01 の6版で同じ（検査 K01〜K08 が全版で OK）。

### 1.2 判定の時点

- 第318条：「個人の市町村民税の賦課期日は、当該年度の初日の属する年の一月一日とする。」第39条（道府県民税）も同じ（検査 K09・K10）。
- 第317条の2第8項：市町村長は、必要があると認める場合には、条例で定めるところにより、第294条第1項第2号の者に「**賦課期日現在において有する** 事務所、事業所又は家屋敷の所在その他必要な事項」を申告させることができる（検査 K18・L2）。
- → 令和8年度分は 2026-01-01、令和9年度分は 2027-01-01 の現況で、住所と家屋敷の有無を見る。

### 1.3 住所の意味（第294条第2項〜第4項）

- 第2項：第1項第1号の「市町村内に住所を有する個人」とは、住民基本台帳法の適用を受ける者については、**当該市町村の住民基本台帳に記録されている者** をいう（検査 K03）。
- 第3項：住民基本台帳に記録されていない個人が当該市町村内に住所を有する者である場合、記録されている者とみなして課することができる（検査 K04）。
- 第4項：第3項で課された者には、その者が記録されている住民基本台帳の市町村は課することができない（検査 K05）。

### 1.4 指定都市の区・特別区（第737条第1項）

「道府県民税、市町村民税及び固定資産税に関する規定の都及び…指定都市…に対する準用及び適用については、**特別区並びに指定都市の区及び総合区の区域は、一の市の区域とみなし**…」（検査 K21・L1）。
→ 指定都市では、住所のある区と別の区に家屋敷があれば、その区について第294条第1項第2号が当てはまる（市の案内の読みは［行政］§3.2）。

### 1.5 非課税（第295条（第24条の5））

- 第295条第1項：市町村は、第1号（生活保護法の生活扶助を受けている者）・第2号（障害者、未成年者、寡婦又はひとり親で前年の合計所得金額が135万円を超えない者）に
  当たる者には市町村民税を課することができない。**ただし、この法律の施行地に住所を有しない者については、この限りでない。**（検査 K11〜K13）
- 第295条第3項：「市町村は、**この法律の施行地に住所を有する者で均等割のみを課すべきもの** のうち、前年の合計所得金額が政令で定める基準に従い当該市町村の条例で定める金額以下である者に対しては、
  均等割を課することができない。」（検査 K14・L4）。政令の基準は施行令第47条の3（［住民PS］§13 が引く既存の調査 `docs/public-sources/20261109_impl-prep_juminzei-hikazei-fuyo-shinkoku.md` §1。この調査では取り直していない）。
- 第295条には「第二百九十四条第一項第二号」を名指しして除く文言がない（検査 K15）。
- 第24条の5第1項（道府県民税）も同じ形でただし書がある（検査 K17）。第3項：第295条第3項で市町村民税の均等割を課することができない者には、道府県民税の均等割も課することができない（検査 K16）。

### 1.6 手続

- 第300条第1項（納税管理人）：「市町村民税の納税義務者は、納税義務を負う市町村内に **住所、居所、事務所、事業所又は寮等を有しない場合** においては、…納税管理人を定めて…」（検査 K20）。
  列挙に「家屋敷」はない（検査 B08）。第2項：徴収の確保に支障がないことの認定を受けたときは定めることを要しない。
- 第320条（普通徴収の納期）：「六月、八月、十月及び一月中（**当該個人の市町村民税額が均等割額に相当する金額以下である場合にあつては、六月中**）において、当該市町村の条例で定める。」（検査 K19）
- 第41条第1項：個人の道府県民税の賦課徴収は、市町村が市町村民税の賦課徴収（均等割の税率の軽減を除く）の例により、市町村民税と併せて行う（検査 K22）。
  ほかに、第41条第3項（還付加算金・延滞金などの計算）、第17条の2（過誤納金の充当）、第17条の4第6項（還付加算金）、第739条の2（納税通知書等の様式）、第739条の5（徴収・滞納処分の特例）が
  「第二百九十四条第一項第二号に掲げる者に対して課する均等割」を名指しして、住所地の課税と分けて扱っている
  （`scripts/results/R3X_juminzei-extra_laws/hits_chiho_2026-11-09.json` の該当箇所。読んだのはその文の前後だけで、検査はしていない）。
- 第319条第2項：市町村は、個人の市町村民税を賦課徴収する場合、当該個人の道府県民税及び森林環境税を併せて賦課徴収する（検査 K24）。

### 1.7 均等割の額・森林環境税

- 第310条：個人の均等割の標準税率は **3,000円**（検査 K23）。道府県民税は第38条で **1,000円**（［住民PS］§13。この調査では取り直していない）。超過課税は注入するデータ。
- 森林環境税：森林環境税及び森林環境譲与税に関する法律第3条は「この法律の施行地に **住所を有する個人**」に課する（［住民PS］§14）。事務所・家屋敷だけを有する者は対象外。

### 1.8 「家屋敷」の定義

- 地方税法・施行令・施行規則の本則と原始附則に、「家屋敷とは」「家屋敷をいう」という定義の文言は **ない**（検査 checks2 §4、［実測］§4.1）。
- 地方税法で「家屋敷」を含む条は、第20条の3（道府県税の賦課徴収を市町村に処理させる場合）、第20条の4（徴収の嘱託）、第24条、第294条、第317条の2 だけ（asof 2026-11-09・2027-01-01）。
  施行令・施行規則（asof 2026-11-09）には 0（［実測］§4.1）。
- → 何が「家屋敷」に当たるかは、法令の文言からは決まらない。行政の通知・自治体の案内の書き方は［行政］§1・§3。

## 2. 配当割額・株式等譲渡所得割額の控除（F）

### 2.1 第314条の9（第37条の4）

- 第314条の9第1項：所得割の納税義務者が、**第313条第13項に規定する確定申告書に記載した** 特定配当等に係る所得の金額の計算の基礎となつた特定配当等の額について配当割額を課された場合、
  又は同条第15項に規定する確定申告書に記載した特定株式等譲渡所得金額…について株式等譲渡所得割額を課された場合には、当該配当割額又は株式等譲渡所得割額に **五分の三** を乗じて得た金額を、
  その者の **第314条の3 及び前三条の規定を適用した場合の所得割の額** から控除する（検査 D01・D02）。
- 第2項：控除することができなかった金額があるときは、市町村は、政令で定めるところにより、**その控除することができなかつた金額を還付しなければならない**（検査 D03）。
  この場合、確定申告書に係る年の末日の属する年度の翌年度分の個人の道府県民税・個人の市町村民税・森林環境税、又は未納の地方団体の徴収金・森林環境税に係る徴収金（「市町村徴収金」）があるときは、
  納税義務者は還付をすべき金額（市町村徴収金の額が限度）により市町村徴収金を納付・納入することを委託したものとみなす（検査 D04・D05）。
- 第3項：第37条の4 で控除されるべき額で道府県民税の所得割から控除できなかった金額は、第1項の控除できなかった金額とみなして第2項を適用する（**道府県民税の分も市町村が還付・充当する**）（検査 D06）。
- 第37条の4：道府県民税は **五分の二** を、第35条及び前三条を適用した場合の所得割の額から控除する（検査 D07）。第37条の4 に第2項（還付の定め）はない（検査 D08）。
- 第314条の9・第37条の4 に指定都市の区分（4/5・1/5 のような読替え）はない（検査 D09・D10）。指定都市でも 3/5・2/5。
- 版：第314条の9・第37条の4 は 2025-01-01〜2028-01-01 の6版で同じ（［実測］§3.2 の表）。

### 2.2 配当割・株式等譲渡所得割と、総所得金額からの除外

- 第71条の27第1項：配当割の課税標準は、支払を受けるべき特定配当等の額（検査 B09）。第71条の28：配当割の税率は **百分の五**（検査 D11）。第71条の49：株式等譲渡所得割の税率は **百分の五**（検査 D12）。
- 第71条の31第1項：特定配当等の支払を受けるべき日現在において道府県内に住所を有する個人に対して特定配当等の支払をする者（上場株式等の配当等などは、その支払を取り扱う者）を特別徴収義務者とする（検査 B09b）。
- 第313条第12項〜第15項（asof 2026-11-09）：
  - 第12項「特定配当等（**第二十三条第一項第十五号ロに掲げるものを除く。** 以下この項において同じ。）に係る所得を有する者に係る総所得金額は、当該特定配当等に係る所得の金額を除外して算定するものとする。」（検査 D16）
    asof 2026-01-01 以前の版は括弧書きがない（検査 D15）。
  - 第13項：前項は、前年分の所得税に係る第317条の3第1項に規定する **確定申告書に特定配当等に係る所得の明細に関する事項その他総務省令で定める事項の記載があるとき** は、当該特定配当等に係る所得の金額については適用しない（検査 D13）。
  - 第14項・第15項：特定株式等譲渡所得金額について同じ形（検査 D14）。
- 施行規則第1条の12の2第1項（第313条第13項の総務省令で定める事項）：第1号「法第三十七条の四及び第三百十四条の九第一項の規定により所得割額から控除する配当割額」。
  第2項：第1号の事項は、第2条の3第2項の **確定申告書に付記しなければならない事項** とする（検査 D24・D25）。第1条の12の3 は株式等譲渡所得割額について同じ（検査 D26）。

### 2.3 控除不足額の充当と還付（施行令第48条の9の3〜第48条の9の5）

- 第48条の9の3第1項：市町村長は、控除不足額がある場合には、確定申告書に係る年の末日の属する年度の翌年度分の個人の道府県民税・市町村民税・森林環境税の
  **賦課決定（第321条の2第1項の追徴に係るものを除く。）後、納税通知書を発する前に**、還付をすべき金額によりこれらを納付・納入する（検査 D20・D21）。
  第3項：なお残る金額は、①同じ年度分の追徴、②その他の未納の徴収金の順に充てる。
- 第48条の9の4第1項：それでも残る部分は還付する（検査 D22）。
- 第48条の9の5第1項：納付・納入・還付をする金額に、控除不足額が確定した日の翌日からの日数に応じ **年七・三パーセント** の割合の金額を加算する。
