## IKY1 別居の曾祖父母は、健保では範囲内、共済では範囲外

- 前提：HKY3（続柄 × 同一世帯の要否を制度ごとの表で持つ）。
- 場面：被保険者・組合員 P の曾祖母 G が別居、P が仕送り。G は後期高齢者医療の被保険者でないと仮定する（実際の曾祖父母はほぼ75歳以上で後期高齢者医療の被保険者になり、どちらの制度でも除外される。**この場面は範囲の表の単体テスト専用**）。
- 推測：
  - 健保：G は第1号の「直系尊属」→ 同一世帯の要件なし → 範囲内（その先は収入・援助の比較）。
  - 共済（国・地方・私学）：G はイにない → ロ（同一世帯が要件）→ 別居なので**範囲外**。理由に「国共済法第2条第1項第2号ロ（同一の世帯に属する三親等内の親族）」を出す。
- 検証の方法：(1) コアの単体テスト（範囲の表）。(2) 法改正の監視で、健保法第3条第7項・国共済法第2条・地共済法第2条の文言が変わったら `scripts/R2X_kyosai_checks.py` の C1 を再実行し、表を作り直す。(3) 組合の案内の親族図（KEISATSU「同居を必要とする親族では…曾祖父母、曾孫…」）と一致することは確認済み［KY］§1.2。
- 注：現実の曾祖父母はほぼ後期高齢者医療の被保険者で、どちらの制度でも除外される。範囲の表が制度で違うことのテストとしてだけ使う。

## IKY2 単身赴任：同じ家族でも、国家公務員共済と協会けんぽで「必要な入力」が変わる

- 前提：HKY4（同一の世帯：共済は定義から導く、健保は保険者データ）、HKY5（規則の型 T1〜T3）。
- 場面：組合員・被保険者 P（年間収入の見込み 600万円）が転勤で市B に単身で住み、配偶者 S（パート、今後1年の見込み 110万円、60歳未満）と子 C は市A の自宅に残る。P は S の口座に生活費を入れているが、送金の記録は取っていない。判定日 2026-11-09。
- 推測：
  - 国家公務員共済（運用方針5）：別居の理由＝組合員の転勤、「一時的」（D4 判断）があれば、S は同一の世帯に当たる。T1：110万 < 130万。T2（組合のデータがなければ「あり／なし」の両方）：110万 < 600万 × 1/2 = 300万。どちらでも可 → **被扶養者の要件を満たす目安**。送金の記録は不要。「一時的」の判断がなければ「同一世帯の判断が必要」で止まる。
  - 協会けんぽ（K-FAQ 16・19：単身赴任・海外赴任は別居として仕送りを確認）：保険者データで「転勤の別居＝別居」とすれば、S は別世帯 → T3：110万 < 援助額 が要る → 送金（事実）がないので**「援助額の事実が必要」で未確定**。保険者データがなければ、同居扱い（可）と別居扱い（援助額不明で判定不能）で結論が分かれる → **未確定**（D19）。
- 検証の方法：(1) 同じ中間表現に保険者データだけを替えて2回評価する場面テスト（D15 ③）。(2) 協会けんぽ・日本年金機構が単身赴任を同一世帯に準じて扱う一次情報があるかを再調査する（[SA2] §5-1）。見つかれば保険者データを直す。

## IKY3 収入に波があるパート：窓の規則で取消の候補日が変わる

- 前提：HKY6（見込みと実績の窓の2本立て）、HKY13（月の数え方）。
- 場面：配偶者 S（130万円の基準、月額基準 108,334円）の給与（支給月で数える）：2026年1〜9月 各90,000円、10〜12月 各120,000円（残業）、2027年1月以降 各90,000円。給与以外の収入なし。2026年中の合計 1,170,000円。
- 計算：任意の連続12か月の最大は 1,170,000円（`python -I` で全窓を計算）。10〜12月は3か月連続で 108,334円以上。連続3か月の**平均**は、9〜11月（(90,000＋120,000＋120,000)÷3＝110,000円）で初めて 108,334円以上になる（8〜10月は 100,000円）（検証の実測 `docs/measurements/20261109_round2_kyosai-verification.md` §5）。
- 推測（保険者データごとの取消の候補日）：
  | 規則（資料） | 結果 |
  |---|---|
  | 3か月連続で月額基準以上 → 翌月初日（OITA-TEBIKI） | 2027-01-01 が取消の候補日 |
  | 4か月連続 → 4か月目の初日、任意の12か月で130万円超 → 超えた月の初日（KOURITU-HIRO） | 候補日なし（継続） |
  | 連続3か月の平均が月額基準以上 → 恒常的、ただし今後1年が基準額以上にならないことが明らかなら除く（FUKUOKA-KIJUN） | 「明らか」の D4 判断があれば継続。なければ取消。条件を最初に満たす窓は 2026年9〜11月（平均 110,000円）。取消日は資料の表で「月額基準額以上となった月の翌月初日」で、どの月を指すかが決まらないので、候補日は 2026-10-01（窓の最初の月＝9月）、2026-11-01（月額が初めて基準以上になった月＝10月）、2026-12-01（窓の最後の月＝11月）の3つ |
  | 労働契約による判定で、残業が契約に明記されない臨時収入（KOURITU-480 本部Q&A 5） | 継続 |
  | データなし | 上の結論が分かれるので**未確定**。分かれた規則の一覧を返す |
- 変形：同じ給与の並びで、S ではなく 20歳の子 C（150万円の基準、月額基準 125,000円）なら、120,000円 < 125,000円なのでどの規則でも候補日なし（継続）。→ 年齢による基準の違いが窓の規則にも効くことのテスト。
- 変形2：10月以降ずっと 120,000円が続くと、任意の12か月の窓は 2026年6月〜2027年5月で 1,320,000円になり 130万円を超える（`python -I` で計算）。KOURITU-HIRO の規則では、まず「月額108,334円以上が4か月連続」（2026年10月〜2027年1月）で 4か月目の初日 2027-01-01 が候補日になり、12か月の累計による 2027-05-01 はその後になる。
- 検証の方法：(1) 規則の型ごとの単体テスト。(2) 支給月と勤務月のどちらで数えるか、窓に認定日前の月を含めるかを、組合の案内・問い合わせ窓口の公表 Q&A で再調査する（[KY] §8 には未記載。HKY13）。

## IKY4 事業収入のある子：所得税の事業所得と、被扶養者の事業収入は大きく違い、費目1つで結論が変わる

- 前提：HKY7（費目つきの明細を共有、引ける費目は保険者データ）、HKY8（150万円の年齢）、HKY13（ちょうど基準額）。
- 場面：子 C（その年の12月31日現在21歳、150万円の基準）の令和7年分の事業（青色申告）：売上 2,000,000円、売上原価（仕入）500,000円、通信費 100,000円、旅費交通費 200,000円、減価償却費 150,000円、広告宣伝費 100,000円、青色申告特別控除 650,000円。他の収入なし。
- 計算：所得税の事業所得 = 2,000,000 − 1,050,000 − 650,000 = **300,000円**。
- 推測（被扶養者の事業収入）：
  | 保険者データ | 引く費目 | 事業収入 | 150万円の基準 |
  |---|---|---|---|
  | MIYAGI の表（通信費○、旅費・減価償却・広告・青色×） | 売上原価、通信費 | 1,400,000円 | 可（< 150万） |
  | FUKUOKA-KIJUN の表（通信費は事業分と家計分が明確に区分されている場合のみ） | 区分あり：売上原価、通信費／区分なし：売上原価 | 1,400,000円／**1,500,000円** | 可／**不可**（運用方針は「年額150万円以上」で不可） |
  | 協会けんぽ（K-LEAF の例示に通信費がない） | 売上原価（通信費は未定義の費目） | 1,400,000〜1,500,000円 | **未確定** |
  | データなし | — | — | 未確定 |
- 同じ C が24歳（130万円の基準）なら、どのデータでも不可（1,400,000円 ≥ 130万円）。
- 見込みの時点：FUKUOKA-KIJUN の規則なら、令和7年分の確定申告で基準以上になった場合の取消の候補日は 2026-03-15（確定申告の受付締切日）。
- 検証の方法：(1) 費目の認否表を保険者データとして与えた単体テスト。(2) 青色申告特別控除・減価償却費を引かないことは複数の資料で一致（[KY] §6.3）するので、データなしでも「引かない」を層 B 相当として扱えるかを、厚労省・財務省・総務省の一次情報で再調査する（見つからなければデータの側に残す）。

## IKY5 別居の親への仕送り：規則の型で結論が逆になる

- 前提：HKY5（型 T3〜T6）。
- 場面：P の母 M（65歳、180万円の基準）が別居。M の収入は公的年金 月80,000円（年960,000円）。P の送金 月50,000円（年600,000円、振込）。他に援助する人はいない。P の年間収入 600万円。
- 計算：T4 の割合 = 600,000 /（960,000 + 600,000）= 5/13 ≒ 0.385（`python -I` で確認）。
- 推測：
  | 型（資料） | 判定 |
  |---|---|
  | T1 収入 < 180万 | 可 |
  | T3 援助額 > 本人の収入（健保 S52、MIYAGI の労働契約の節） | **不可**（600,000 < 960,000） |
  | T4 送金 ≥ 全収入の1/3（MONKA、OITA-TEBIKI、KOURITU-REI-F） | 可（5/13 ≥ 1/3） |
  | T5 本人月収 < 10万なら送金 ≥ 5万（MIYAGI 基準-10）、本人収入＋送金 ≤ 組合員の収入 | 可（50,000 ≥ 50,000、1,560,000 ≤ 6,000,000） |
  | T6 送金 ≥ 本人収入 かつ ≥ 年65万（FUKUOKA-KIJUN） | **不可** |
  | データなし | **未確定** |
- 変形：送金が手渡しなら、FUKUOKA-KIJUN・OITA-TEBIKI のデータでは送金に数えない（不可）。健保の H30QA-N Q21 の書き方では合理的なら認めうる。
- 検証の方法：型ごとの単体テストと、保険者データを替えた場面テスト。MIYAGI の「月額 5万円以上」は「以上」なので、送金がちょうど 50,000円で可になることを境目のテストにする。

## IKY6 別居の学生の子：書類の省略と、比較の要否が別の問題として残る

- 前提：HKY11、HKY5。
- 場面：子 C（20歳、全日制の大学生、150万円の基準）が市C で一人暮らし。アルバイト 年1,000,000円。P の仕送り 月30,000円（年360,000円）。
- 推測：
  - 範囲：子は同一世帯の要件なし → 範囲内。T1：1,000,000 < 1,500,000 → 可。
  - 別世帯の比較を当てると、T3（援助額 > 本人収入）は 360,000 < 1,000,000 で**不可**、T4 は 360/1360 ≒ 0.26 < 1/3 で不可、T6 も不可。
  - 一方、学生は仕送りの書類が不要（健保 H30QA-H Q18、FUKUOKA-KIJUN）、別居の届出で継続（MIYAGI）とする資料がある。「比較をしない」と明記した資料は見つかっていない［SA2］§3。
  - → 保険者データに「学生の子の別世帯：比較しない」があれば**可**、「比較する」なら不可、データがなければ**未確定**。
- 検証の方法：協会けんぽ・日本年金機構・各共済組合の公表資料で、別居の学生の子に援助額との比較を当てるかを明記したものを再調査する。見つかったら、層 B（国の通知）か層 C（保険者データ）かを決める。

## IKY7 共済の「30日以内」：届出がちょうど30日目・31日目のとき

- 前提：HKY9。
- 場面：組合員 P の子が 2026-05-01 に出生。被扶養者の申告を組合が受理した日が (a) 2026-05-30、(b) 2026-05-31、(c) 2026-06-01。
- 推測：
  | 受理日 | 初日を数えない（5/2 を1日目） | 初日を数える（5/1 を1日目） |
  |---|---|---|
  | (a) 5/30 | 29日目 → 認定日 5/1 | 30日目 → 5/1 |
  | (b) 5/31 | 30日目 → 5/1 | 31日目 → **5/31（受理日）** |
  | (c) 6/1 | 31日目 → **6/1（受理日）** | 32日目 → 6/1 |
  - (b) だけ数え方で結論が変わる。コアは数え方を名前つき関数にし、(b) で「出典未確認」の印を付ける。
- 検証の方法：(1) 国共済法・地共済法に期間の計算の特則があるかを e-Gov で走査し、なければ民法の期間の規定（第138条〜第143条）の適用を、組合・財務省の一次情報（期間の数え方を例示した案内）で確かめる。(2) 確かめられたら関数を1つにして印を外す。

## IKY8 19歳以上23歳未満の150万円：生年月日と適用開始日の境目

- 前提：HKY8。
- 推測（実測 C4 の範囲から）：
  - 2007-01-01 生まれ：2025-12-31 に19歳（1月1日生まれは前日に加齢）→ 令和7年の認定は150万円。2007-01-02 生まれ：2025年は18歳 → 130万円、2026年から150万円。
  - 2003-01-02 生まれ：2025-12-31 に22歳 → 150万円。2003-01-01 生まれ：2025-12-31 に23歳 → 130万円。
  - 認定日 2025-09-30 以前は130万円（地方・私学・健保）。国家公務員共済は適用開始日の一次情報がないので、認定日 2025-10-01 前後の判定に「未確定（国家公務員共済の150万円の適用日が未確認）」の注記を付ける。
- 検証の方法：(1) `scripts/R2X_kyosai_checks.py` の C4 を年を変えて回帰テストにする。(2) 財務省の運用方針の改正通達（150万円を入れたもの）を再調査し、適用日が分かればパラメータを確定する（[KY] §8-2）。

## IKY9 住民税：単身赴任の納税義務者と、配偶者と同居する老親

- 前提：HKY12。
- 場面：P は2026年4月に転勤し、住民票を市B に移した。配偶者 S、子 C（17歳、生計を一にする）、P の母 M（72歳、P の直系尊属、生計を一にする、合計所得金額は扶養親族の上限以下）は市A で同居。2027-01-01（令和9年度分の賦課期日）も同じ状態。
- 推測：
  - P の令和9年度分の住民税は市B が課す（第294条第1項第1号・第2項、第318条）。S・C・M の自分の住民税（非課税の判定を含む）は市A が課し、均等割の非課税の条例の額・級地は市A のデータで引く。
  - P の扶養控除：C・M が市A に住むことは控除の妨げにならない（第292条第1項第9号に住所の要件なし）。M は老人扶養親族で、**P の配偶者 S と同居を常況**としているので、第314条の2第4項の「同居直系尊属」に当たり、控除額は45万円（同居でなければ38万円）。
  - 変形：P が住民票を移さずに市B で生活している場合、コアは住民票の市A を使い、「第294条第3項（実際の住所の市町村が課税しうる）・取扱通知 6(1)（家族と離れて勤務する者の住所は実情で認定）」の注記を出す。
- 検証の方法：(1) 所得税の同居老親等（措置法第41条の16 など）の要件の文言を e-Gov で取得し、「居住者又はその配偶者」との同居で足りるかを確かめる（本調査では未確認）。(2) 住民税の結果は、作成コーナーでは照合できない（住民税の税額は市町村が計算する）ので、総務省・市町村の公表した計算例と照合する方法を探す。

## IKY10 国家公務員の海外赴任と家族の同行：所得税・住民税・被扶養者で「住所」の扱いが3通り

- 前提：HKY12（公務員の国内住所のみなしと、被扶養者の国内居住要件の例外）。
- 場面：国家公務員 P が2026年4月から海外の在外公館に赴任し、配偶者 S と子 C も同行。2027-01-01 時点も国外。
- 推測：
  - 所得税（令和8年分）：P は国内に住所を有するものとみなされ（所得税法第3条第1項）、居住者として計算される。S・C は国外に住むので、扶養控除などでは国外居住親族の扱いになる（D18。本調査の範囲外）。
  - 住民税（令和9年度分）：所得税法第3条第1項は住民税に適用されない（取扱通知 6(5)）。P・S・C は2027-01-01 に国内の市町村に住所を有しなければ、住所による市町村民税は課されない（家屋敷等による均等割は別：HKY12）。
  - 被扶養者（国家公務員共済）：S・C は国内に住所を有しないが、「外国に赴任する組合員に同行する者」（国共済則第2条の5第2項第2号）として国内居住の例外に当たる → 範囲内（収入などの判定は通常どおり）。
- 検証の方法：(1) 所得税法第3条第1項の「政令で定める者」（除かれる者）を e-Gov の施行令で確認する。(2) 国外居住親族の扶養控除の要件（書類を含む）は別の調査（D18）で確かめ、この場面に足す。
