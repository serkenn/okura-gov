# rules/tax：税額・申告の要否・期限

所得控除の合計 → 課税所得（千円未満切捨て）→ 税額（超過累進・上場株式等の分離課税）→ 配当控除・税額控除 → 基準所得税額 → 復興特別所得税 →
源泉徴収税額・予定納税額の精算（百円未満切捨て）→ 申告の要否・期限。

このディレクトリだけで規則を足す（packages/core/README.md §10）。共有のファイルは触らない。登録は rules/__init__.py の1行だけ。

## 3. 対象外の一覧（2026-11-11。D24③。2026-11-12 に (c) を全部片づけた）

分類：(a) 範囲の外（SCOPE §4・D20）、(b) ユーザーが後の段とした（D21 R3・D22 S12・S19 など）、(c) 範囲内なのに未対応。
(c) のうち、語彙はあり記録を直せば決まるもの（欄の書き忘れ・重複・矛盾）は「c-入力」（理由の文に、どの記録・欄を入れれば決まるかを書く）、
判定コアの整数（int32）の上限は「c-限界」（共有の制約）、上流のモジュールの対象外に従うものは「上流」と書く。

## 4. 決まらないこと・読み

- 源泉徴収税額は所得税と復興特別所得税の合計で精算し、第120条第1項かっこ書きの「控除しきれない」も合計で比べる（法令の読み。zeigaku の仮説 H7）。
- 税額控除の限度：手引き 3-4_36（㊷）の順に、前に残った税額を限度に控除する（控除の合計で税額を限度。各控除の限度の条文は docs で読んでいない。読みの印つき）。政党等寄附金特別控除の税額の25%の限度は other_deductions の担当。
  ㉞（事業所得等の特例に係る税額控除）・㊴〜㊶（住宅耐震改修特別控除等）は外部で計算した額（計算明細書・付表の額。個々の限度は外部の計算に含まれる）を受け取る（2026-11-12）。
  これらの控除が第120条第1項の申告の要否（「配当控除の額」を超えるか）の比較に入るかの読替えの規定は docs で読んでいない（どれも確定申告で受ける控除なので、比較は今のまま）。
  住民税の住宅借入金等特別税額控除の「前年分の所得税の額」（地方税法附則第5条の4第5項第2号）は措法第41条の19の2〜第41条の19の4 などを適用しない額で、
  ㉞ の控除は列挙にない（`docs/public-sources/20261109_round3_juminzei-extra-law-text.md` §3.2）。juminzei の担当への申し送り：`住民税.前年分の所得税の額` に ㉞ を引くか確かめる。
- 第121条：「全部が源泉徴収の対象か」は記録の源泉徴収税額の欄の有無で読む。基通121−5(1)(3)（家事使用人のみの支払者・国外の支払）と令第262条の2（同族会社の役員等が支払者から利子・対価を受ける）は salary_payment の欄で判定し、欄がなければ当たらないものとする（法令の読み。§3 の TX-25）。「給与所得及び退職所得以外の所得金額」（基通121−6）は合計所得金額から給与所得（調整控除を足し戻す）・退職所得を引き、青色申告特別控除を足し戻す。
- 申告の種類の「第124条」：確定申告書を提出した記録がその年分にあるか（問いの提出日で確かめる）で「提出しないで」を判定する。出国（第126条・第127条）は 判断.住所の所在 の foreign の開始日で、納税管理人の届出がその日までにあれば出国でない。
- `heirship` の `when.on` を「相続の開始があったことを知った日」として読む（VOC F-R07 の中身。`vocabulary.py` の題には書かれていない。根拠に読みの印）。
- 休日の根拠の種類：春分日・秋分日は暦要項（官報は取得していない）。列挙に当てはまる種類がないので「告示」＋「原文未確認」にした。
- 仮に置いた種類（`事実.年末調整の住宅借入金等特別控除`・語彙にない `選択.所得控除の順序`）は 2026-11-12 に中間表現の語彙に置き換えた（源泉徴収票の `housing_loan_credit`、選択 `選択.所得控除の順序`）。
- 未払の給与の分かれ目（TX-02）・相続人ごとの期限（TX-14）・清算人が確定した日（TX-13）・暦要項（TX-23）は、入力の `missing` の分かれ目（outcomes は空）で依存する値を未確定にする（other_deductions の timing_split と同じ形）。
  候補の値を全部計算して比べるのは TX-14（相続人ごとの期限を inputs.py で求め、同じなら断定）と TX-02 の (a) が0と言える場合だけ。

## 5. 申告の範囲

金額の概念は「申告の欄」「申告の範囲」を両方 true にした（2026-11-11）。上流（控除・源泉徴収など）が対象外の人は、その人・年分の申告用の値が全部止まる（`build_filing`：申告書が完成しないため）。
真偽・日付の概念（提出義務・還付申告・申告期限）は欄に写す金額でないので false のまま。様式の欄の対応表ができたら見直す。
