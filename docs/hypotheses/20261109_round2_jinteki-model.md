## H1 障害者・特別障害者の区分は、記録した「根拠」からコアが対応表で決める

- 内容：事実台帳には「障害の根拠」（手帳・判定・認定）を種類・等級・日付つきで記録し、障害者／特別障害者／該当なしの区分はコアが法令の対応表で決める。人が「障害者控除の区分」を直接入力する形にはしない。
- 対応表（コアに置く。所得税と住民税で同じ表を使う）：

| 根拠の種類（記録） | 障害者 | 特別障害者 | 条文 |
|---|---|---|---|
| 身体障害者手帳（級別） | 手帳に障害の記載がある（1〜6級） | 1級・2級 | 所令10①三・②三、地令7三・7の15の7三 |
| 精神障害者保健福祉手帳（障害等級） | 交付を受けている（1〜3級） | 1級 | 所令10①二・②二 ほか |
| 知的障害の判定（児童相談所・知的障害者更生相談所・精神保健福祉センター・精神保健指定医） | 知的障害者と判定 | 重度と判定 | 所令10①一・②一 ほか |
| 戦傷病者手帳（障害の程度） | 交付を受けている | 特別項症〜第三項症 | 所令10①四・②四 ほか |
| 原爆被爆者の厚生労働大臣の認定 | — | 全員 | 所令10①五・②五 ほか |
| 常に就床を要し複雑な介護を要する（判断。6か月以上：所基通2-39） | — | 全員 | 所令10①六・②五 ほか |
| 事理を弁識する能力を欠く常況（判断） | — | 全員 | 所令10①一・②一 ほか |
| 65歳以上で市町村長等の認定（認定書の区分） | 障害者に準ずる | 特別障害者に準ずる | 所令10①七・②六、地令7七・7の15の7六 |

- 複数の根拠があるときは重い方をとる（同じ人が手帳と認定を両方持つことはある：I）。
- 根拠：［PS］§1.5・§2.2・§3、［M］§4（所令10 と地令7・7の15の7 は号ごとに同じ文言。文字の違いは「特別区の区長」の有無などの書き方だけで、特別区は地令第1条の準用・読替えで「特別区長」になるので要件は同じ：［PS］§2.2）。
- **要介護認定はこの表に入れない。** 事実台帳に要介護度を記録してもよいが、コアは障害者の判定に使わない。障害者に当たるのは市町村長等の「認定書」がある場合だけ（［PS］§1.8 No.1185、§1.9 の2つの事務連絡）。要介護度から認定書の有無を推定しない。
- 7級（手帳が交付されない）は、65歳以上の認定がなければ障害者に当たらない（［PS］§1.8 No.1160 Q&A Q1）。
- 判断（D4）に当たるもの：
  - 「常に就床を要し複雑な介護を要する」「事理を弁識する能力を欠く常況」：根拠の書類（市町村の認定書、医師の診断書など）への参照つきの判断として受ける。
  - **療育手帳の表示が「重度」に当たるか**：法令の要件は「判定により重度の知的障害者とされた」こと（所令10②一）で、療育手帳は法令に出てこない。手帳の表示（A・マルA・A2・B など）と名称は自治体で違う（［PS］§1.8 No.1160 Q&A Q2、令和8年分 年末調整のしかた）。表示と重度の対応はコアに持たず、「重度と判定された」という判断を、手帳の表示・交付自治体を根拠として受ける。住民税の取扱通知の「知能指数おおむね35以下で常時の介護を要する」（［PS］§2.5）は判断の参考情報にとどめる。
- 境目：対応表（法令）はコア。自治体ごとの療育手帳の表示の意味はコアに持たない（判断で受ける）。注入データにする案も考えられるが、法令の要件は「判定」であって自治体の表示の規則ではないので、判断の方が筋がよい（I）。

## H2 判定の時点は制度ごとに違う。根拠の事実は「区間」で持ち、時点で切り出す

- 内容：手帳・認定・同居・婚姻・住民票の続柄は、始まりと終わりの日付をもつ区間の事実として記録し、コアが制度ごとの判定時点で切り出す。

| 判定 | 時点 | 根拠 |
|---|---|---|
| 所得税：本人が障害者・特別障害者・寡婦・ひとり親か | その年12月31日（年の中途で死亡・出国したときはその時） | 所法85①［PS］§1.3 |
| 所得税：同一生計配偶者・扶養親族が障害者・特別障害者・同居特別障害者か | その年12月31日（既に死亡していれば死亡時） | 所法85② |
| 所得税：ひとり親の子（政令で定める子）か | 12月31日。子が既に死亡していれば死亡時 | 所法85①ただし書 |
| 住民税の控除：同上 | 前年12月31日（前年の中途で死亡したときは死亡時） | 地法314の2⑧［PS］§2.3 |
| 住民税の非課税（地法295①二）：障害者・寡婦・ひとり親か | **法令に定めがない**。取扱通知は「賦課期日（1月1日）の現況」 | ［PS］§2.4、［住民税］§3 |
| 健保の被扶養者：障害者（180万円）か | 通知に定めがない | ［PS］§4.1 |

- 住民税の非課税の提案：前年12月31日と1月1日の両方で区分を求め、同じなら確定、違えば「未確定（判定時点が法令で決まらない）」と返す。市町村がどちらの日で判定するかを注入データで渡されたら、それに従う（D19 の「注入されていなければ取りうる範囲で評価し、決まらなければ未確定」）。
- 過去の年分にさかのぼらない：手帳の交付日より前の12月31日には「交付を受けている」に当たらない（［PS］§1.8 質疑応答 05/31）。例外は H3 の通達による取扱いだけ。
- 精神障害者保健福祉手帳は2年ごとに認定を受ける（精神法45④［PS］§3）。有効期間の終わりの日も記録する。12月31日が有効期間の外で更新の申請中という場合の扱いは一次情報がない（［PS］§6 の3）→ コアは「判断を求める」と返して止める。

## H3 手帳の申請中・認定の申請中（所基通2-38、質疑応答 05/63）は「通達による取扱い」の印をつける

- 内容：身体障害者手帳・戦傷病者手帳を申請中（又は交付のための医師の診断書を持つ）で、12月31日の現況で明らかに手帳の程度の障害がある人は、障害者（明らかに1・2級の程度なら特別障害者）として扱う。65歳以上の市町村長等の認定についても、12月31日に認定を受けられる程度の障害があり申告時に申請中なら適用してよい（質疑応答）。結果には「法令の文言ではなく通達・質疑応答による」と印をつける。
- 入力の事実：手帳の申請日（又は診断書の発行日）、**申告書等の提出日**（2-38(1) は「提出する時において」申請中であることを要件にする）、手帳の交付日（後日わかったもの）。
- 判断（D4）：「12月31日の現況で明らかに手帳に記載される程度の障害がある」（と、1・2級の程度か）。
- 範囲：2-38 は身体障害者手帳・戦傷病者手帳だけを書いている。精神障害者保健福祉手帳・知的障害の判定について同じ扱いをする一次情報はない（［PS］§1.7、§6 の2）→ コアは対象外として「判断を求める」と返す。住民税に同じ取扱いがあるかも見つかっていない（［PS］§2.5）→ 住民税側では印をつけたうえで「未確定」を返す案（I）。
- 根拠：［PS］§1.7 2-38、§1.8 No.1186・質疑応答 05/63・年末調整のしかた（注意事項）。

## H4 障害者控除の額と、誰が控除するか

- 額（コアのパラメータ。F）：

| 区分 | 所得税（令和7年分・令和8年分） | 住民税（令和8年度分・令和9年度分） |
|---|---|---|
| 本人・親族が障害者 | 27万円 | 26万円 |
| 本人・親族が特別障害者 | 40万円 | 30万円 |
| 同一生計配偶者・扶養親族が同居特別障害者 | 75万円（40万円に代えて） | 53万円（30万円に代えて） |

  根拠：［PS］§1.2・§2.3、［M］§3。令和9年分・令和10年度分も同額（2026-11-09 時点の条文）。
- 誰が控除するか：本人の分は本人。親族の分は、その人を**同一生計配偶者又は扶養親族**とする居住者（納税義務者）。扶養親族には16歳未満も含む（［PS］§1.2）。
  - 扶養親族・同一生計配偶者が2人以上の居住者に当たるときの所属は、既存の所属の解き方（所法85④⑥・所令218・219、住民税は地法292②〜④・地令46の3〜46の5）の結果をそのまま使う。障害者控除だけ別の人に付けることはしない。根拠は、所法85⑥ により扶養親族（16歳未満を含む）が一の居住者の扶養親族にのみ該当するとみなされ、所法79② の「居住者の…扶養親族」がその一人の居住者だけになること（［PS］§1.3）。所基通79-1（［PS］§1.7）は控除対象配偶者・控除対象扶養親族についての通達で、16歳未満の扶養親族には文言上は及ばない。
  - 配偶者が同一生計配偶者でない（合計所得金額が 58万円／62万円を超える）ときは、他方の配偶者は障害者控除を受けない。その配偶者は自分の申告で本人分を受ける（所法79①②の読み取り：I）。
  - 年の中途で死亡した居住者の扶養親族等は、相続人等も重ねて控除できる（所基通79-2）。
- 同居特別障害者の入力の事実：12月31日に、居住者・その配偶者・居住者と生計を一にするその他の親族のいずれかと**同居を常況**としているか。病気の治療のための入院は同居に当たり、老人ホーム等への入所は当たらない（［PS］§1.8 質疑応答 05/32。同居老親等についての回答で、No.1160 から関連事例として張られている）。入院と施設入所を区別して記録する。「同居を常況」は判断（D4）。
- 端数処理：なし（額は万円単位の定額）。

## H5 寡婦・ひとり親は所得税と住民税で同じ構造。違うのは「前年」と判定時点と額だけ

- 判定の順序（コア）：先にひとり親を判定し、当たらなければ寡婦を判定する（寡婦は「ひとり親に該当しないもの」［PS］§1.1）。
- ひとり親（所法2①三十一、地法292①十二）：
  1. 現に婚姻をしていない（未婚・離婚・死別を問わない）、又は配偶者の生死が明らかでない（所令11 の5つの事由の配偶者）
  2. 生計を一にする子（**年齢の制限なし**［PS］§1.8 No.1171 Q&A Q2）で、総所得金額等が 58万円以下（令和7年分・令和8年度分）／62万円以下（令和8年分・令和9年度分）で、**他の者の同一生計配偶者又は扶養親族とされていない**子がいる
  3. 本人の合計所得金額が 500万円以下（住民税は前年の合計所得金額）
  4. 事実婚の相手として省令で定める者がいない＝住民票の世帯主との続柄に「未届の夫」「未届の妻」等の記載がない
- 寡婦（所法2①三十、地法292①十一）：「夫と」離婚・死別・夫の生死不明の者（＝妻だった者）で、本人の合計所得金額 500万円以下、事実婚の記載がない。離婚の場合は**扶養親族を有すること**も要件。
  - 「扶養親族を有する」は所属の結果に従う（所法85⑥の適用があればその人の扶養親族とされた者に限る：所基通2-40）。青色事業専従者は扶養親族でないので数えない（［PS］§1.8 No.1170 Q&A）。
- 入力として必要な事実（事実台帳）：民法上の婚姻の履歴（婚姻日・離婚日・配偶者の死亡日）、配偶者の生死不明の事由と起算日（所令11 の各号）、本人が「妻」だったか（寡婦の判定に使う）、親子関係、生計を一にすること（既存）、住民票の「世帯主か」「世帯主との続柄」の区間、子の死亡日、申告書等で子が誰の扶養親族・同一生計配偶者とされているか（所属の表：既存）。子と本人の所得はコアが計算する。
- 判断（D4）に当たるもの：生計を一にすること（既存）。所属の表は申告書等の記載という事実だが、記載がない場合の決め方は既存の仮説による。
- 事実婚は住民票の記載だけで判定する（所規1の3・1の4、地規1の9の7・1の9の8［PS］§1.6・§2.2、取扱通知 2の2［PS］§2.5）。住民票に記載のない事実婚を判断で入れる口はコアに作らない（法令の文言どおり：I）。
- 住民税の非課税だけの特例（取扱通知 第1の3［PS］§2.5、E）：寡婦の扶養親族が他の納税義務者の扶養親族とされていても、寡婦がその扶養費の一部を負担していれば「扶養親族を有する」として扱う。→ 判断（D4）「扶養費の一部を負担している」を受け、**非課税の判定でだけ**使う（所得税・住民税の寡婦控除には使わない）。結果に「通知による取扱い」の印をつける。
- 取扱通知 第1の1 ただし書（太平洋戦争の元陸海軍の者と内縁関係にあった者を寡婦とする）は対象外として拒否する（I：現代の家庭で起こらない）。
- 額（コアのパラメータ。F）：寡婦 所得税27万円・住民税26万円。ひとり親 所得税35万円（令和7年分・令和8年分）→38万円（令和9年分から）、住民税30万円（令和8年度分・令和9年度分）→33万円（令和10年度分から）。根拠：［PS］§1.2・§1.4・§2.3、［M］§3。

## H6 住民税の非課税（障害者・寡婦・ひとり親の 135万円）は法律の値で、コアに置く

- 内容：地法295①二「障害者、未成年者、寡婦又はひとり親（これらの者の前年の合計所得金額が百三十五万円を超える場合を除く。）」は、均等割・所得割の両方（分離課税の所得割を除く）を課さない。135万円は法律に書かれているので、級地・条例で変わる均等割の非課税（地法295③）と違い、注入データにしない（［PS］§2.4、［住民税］§1〜§2）。
- 定義は §2.1 の地法292①十〜十二（所得税と同じ文言で「前年」）。特別障害者かどうかは非課税に関係しない。
- 比較：「百三十五万円を超える場合を除く」→ 前年の合計所得金額 ≤ 1,350,000 円なら非課税（境目の 1,350,000 円ちょうどは非課税）。
- **障害年金は合計所得金額に入らない**：国年法25条・厚年法41条②の公課の禁止（［PS］§5）。障害年金を受けている障害者は、障害年金の額にかかわらず、ほかの所得の合計所得金額で 135万円を判定する（I）。一方、健保の被扶養者の年間収入には障害年金を入れる（H7）。
- 判定時点は H2（未確定を返しうる）。
- 未成年者の 135万円（既存）と同じ規則の中で、「障害者・寡婦・ひとり親・未成年者のどれか1つに当たる」を判定する。どれに当たったかを根拠として結果に出す。

## H7 健保の被扶養者の 180万円（障害者）は通知の値。障害の程度は「障害年金の障害等級」の物差しで、手帳の等級からは決まらない

- 内容：180万円は法令ではなく通知（昭和52年通知とその改正、令和7年の労働契約の通知）による（［PS］§4.1）。コアには「通知の値」として出典つきで置き、結果の根拠に「通知」と出す。
- 物差しの違い：通知の要件は「概ね厚生年金保険法による障害厚生年金の受給要件に該当する程度の障害者」。障害厚生年金の障害等級は1〜3級（厚年法47②・厚年令3の8・別表第一、1・2級は国年令別表）で、**障害者手帳の等級（身体1〜7級、精神1〜3級）とは別の法令・別の表**（［PS］§4.2）。手帳の等級から「程度」を機械的に決めない。
- 提案する入力と判定：
  1. 障害年金（障害厚生年金 1〜3級、障害基礎年金 1・2級）を受けている事実があれば「程度に該当」とする（I：通知の物差しそのものに当たる最も直接の事実。ただし通知は受給を要件にしていない）。
  2. 保険者が 180万円の基準で認定した（又は「程度に該当する」と判断した）事実があれば、それに従う（保険者の判断は事実として記録する）。
  3. それ以外（手帳だけ、年金なし）は、保険者ごとの注入データ（例：「身体障害者手帳のX級以上を該当とみなす」「診断書で判断」）があればそれに従い、なければ 130万円（又は 19〜22歳の 150万円）と 180万円の両方で評価し、結論が同じなら確定、違えば「未確定（障害の程度の基準が保険者の運用で決まる）」と返す（D19）。
- 判定時点：通知に定めがない（［PS］§4.1・§6 の5）→ 判定日（認定日・確認日）の現況で見る（I）。
- 年間収入には障害年金・遺族年金など非課税の収入も入れる（［健保］§1、［PS］§4.3）。税の合計所得金額とは逆（H6）。
- 共済組合の同じ基準は別のトピックで扱う。根拠が通知（保険者の運用）である点は同じ構造になると予想する（I）。

## H10 境目と端数処理

- 額はすべて万円単位の定額で、端数処理は生じない。
- 比較の向き：寡婦・ひとり親の合計所得金額「五百万円以下」、ひとり親の子「…以下」は含む。住民税の非課税「百三十五万円を超える場合を除く」は 135万円ちょうどを含む。健保の「180万円未満」は含まない。所令10①七の「年齢六十五歳以上」は12月31日の年齢（年齢の数え方は既存の規則）。
- 合計所得金額 500万円の境目では、給与所得の1円未満の扱いで結論が変わる（給与収入 6,777,778円：端数そのままなら 5,000,000.2円で超える、切り捨てなら 500万円ちょうどで以下。［M］§5）。既存の名前つきの端数関数（給与所得の1円未満切捨て）を共有し、別の扱いを作らない。
- 65歳以上の認定の生年月日の目安（E）：令和7年分は昭和36年1月1日以前生まれ、令和8年分は昭和37年1月1日以前生まれ（［PS］§1.8 年末調整のしかた）。コアは生年月日と12月31日から計算し、この表は照合（テスト）に使う。
