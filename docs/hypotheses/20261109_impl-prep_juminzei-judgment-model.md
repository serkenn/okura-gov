## H1 住民税は「年度」で判定し、所得の年・法令の版・所得税法令の版を年度から決める

- 内容：住民税の判定関数は「年度 N」を受け取り、次を固定の規則で決める。
  1. 所得の年＝N の前年（令和8年度 → 令和7年、令和9年度 → 令和8年）。
  2. 地方税法・施行令・施行規則の版＝~~**賦課期日（N年度の初日の属する年の1月1日）**に施行されている版~~
     （検証で訂正）**改正法の附則が「N年度分」に適用するとした規定を含む版**。賦課期日の版とは限らない。令和8年法律第2号は 2026-04-01 施行で、附則第11条第1項が
     「別段の定めがあるものを除き…令和八年度以後の年度分の個人の市町村民税について適用」とするので、1月1日より後に施行された改正もその年度分に効く［PS］§0 の追記。
     実装では、条ごとに「適用年度」を附則から取り、パラメータを年度で引く。扶養・非課税・申告の条については、令和8年度分は asof 2026-01-01 と 2026-11-09 で文言が同じ（［M］§3.1、§7 の追記）。
  3. 所得の計算に使う所得税法令の版＝**前年分の所得税に適用されたもの**（令和9年度分なら令和8年分の所得税法・措法）。
- 根拠：法第292条第1項第7号（前年の定義）、第318条（賦課期日1月1日）、第292条第5項（所得税法令は前年の所得について適用されたもの）、第313条第2項（所得税法令の計算の例）［PS］§7。
  改正法の附則が「令和八年度以後の年度分」「令和九年度以後の年度分」から適用すると書く［R1地方］§2。
  扶養親族 58万円の改正は 2026-01-01、62万円の改正は 2027-01-01 の版で入っている［M］§3.2。
- 確からしさ：1 と 3 は高い（条文の組み合わせ）。2 は検証で元の形が反証された（上の訂正）。3 のうち措法第29条の4（給与所得控除 74万円）が住民税に及ぶことは条文に明記がなく、
  行政・国会の資料だけ［PS］§7、［M］§3.4。令和9年度分の値は 2026-11-09 時点で成立している改正までのもので、2027年の改正で変わりうる［PS］§0 の追記。

## H2 非課税の判定は「全部非課税（法295①）→ 所得割 → 均等割」の順に、使う所得の種類を変えて行う

- 内容：
  1. 法第295条第1項：生活扶助、または障害者・未成年者・寡婦・ひとり親で**前年の合計所得金額**が135万円以下 → 均等割・所得割とも課さない
     （検証で訂正：元は「（分離課税に係る所得割は別）」。条文の括弧書きは「第二号に該当する者にあつては…分離課税に係る所得割…を除く」で、除外は第2号（障害者・未成年者・寡婦・ひとり親）だけ。
     第1号（生活扶助）の者には分離課税に係る所得割も課さない。その判定の時点は退職手当等の支払を受けるべき日の属する年の1月1日（第295条第2項）［PS］§3.1）。
  2. 所得割：法附則第3条の3第4項。**総所得金額等**（第313条で算定した総所得金額・退職所得金額・山林所得金額の合計＝繰越控除の後）が
     35万円×（同一生計配偶者＋扶養親族〔16歳未満を含む〕＋1）＋10万円（＋配偶者・扶養がいれば32万円）以下 → 所得割を課さない。
     （検証で追記：数える扶養親族は「年齢十六歳未満の者及び…控除対象扶養親族に限る」。非居住者の扶養親族の一部は数えない［PS］§1.4 の追記。均等割の 3 も同じ）
     所得控除の結果、所得割額が出ない場合も所得割はかからない（これは税額の計算の結果）。
  3. 均等割：法第295条第3項。所得割を課さない者（「均等割のみを課すべきもの」）のうち、**前年の合計所得金額**が条例の額以下 → 均等割も課さない。
     条例の額は施行令第47条の3 の基準（基本額≤35万円×級地の率、10万円、加算額≤21万円×級地の率）。
- 根拠：［PS］§1〜§3、［M］§5.1。均等割の境目は所得割の境目以下になる（加算額 21万円 ≤ 32万円、級地の率 ≤ 1.0）［PS］§1.4・§2.1 から。
- 帰結：判定コアは同じ年について「合計所得金額」と「総所得金額等」の2つを別々に出す必要がある（繰越控除がなければ同じ値）。

## H3 住民税の判定には2つの時点がいる：前年12月31日と、賦課期日の1月1日

- 内容：
  - 前年12月31日の現況：扶養親族・特定親族・特定扶養親族（19歳以上23歳未満）・勤労学生・障害者などに当たるか（控除の判定。法第314条の2第8項）、
    均等割の非課税の基準の級地区分（施行令第47条の3 第2号・第3号、施行規則第9条の21）。
  - 1月1日の現況：住所（どの市町村が課税するか。第294条第2項・第318条）、生活扶助、**未成年者かどうか**（取扱通知 32、自治体の案内）、
    給与支払者から1月1日現在で給与を受けているか（申告の要否、所属の決め方。法第317条の2第1項ただし書、施行令第46条の3第1項）。
- 根拠：［PS］§1.2、§1.3、§3、§5、§6.1。
- 確からしさ：前年12月31日の部分は条文。未成年者の1月1日は、法令の文言ではなく賦課期日の規定と取扱通知（技術的助言）・自治体の案内による（中）。
  **非課税の判定で数える扶養親族の人数・年齢（16歳未満を含む）の時点は、条文で確認できていない**［PS］§9。
- 年齢の数え方：年齢計算ニ関スル法律・民法第143条［R1年齢］§3。自治体の案内は令和5年度（賦課期日 2023-01-01）の未成年者を「平成17年1月3日以降に生まれた方」とする［PS］§3.2。
  これは「誕生日の前日の終わりに年をとる」読みで、1月2日生まれの人は1月1日の時点で一つ年をとっている扱いになる。

## H4 住民税の扶養の所属（U6）は、所得税と同じ「記載で決まる」形だが、決まらないときの規則が違う

- 内容：
  - 1人が2人以上の納税義務者の扶養親族・特定親族に当たるとき、いずれか1人の扶養親族・特定親族とみなす（法第292条第4項）。
    どちらかは、申告書（法317条の2①の申告義務がある者）または給与支払報告書・公的年金等支払報告書（給与所得等以外の所得を有しなかつた者）の記載、
    その者が出した申請書があれば申請書の記載による（施行令第46条の5第1項）。
  - 決まらないとき（重複記載など）：前年の総所得金額等が最も大きい納税義務者（施行令第46条の5第2項）。
    配偶者が同一生計配偶者か他の人の扶養親族か、生計を一にする配偶者か他の人の特定親族かで決まらないときは、夫又は妻の側（施行令第46条の3第2項、第46条の4第2項）。
  - ~~所得税の確定申告書は住民税の申告書とみなされる（法第317条の3）ので、確定申告書の扶養の記載が住民税の所属にもなる。~~
    （検証で訂正）所得税の確定申告書は住民税の申告書とみなされる（法第317条の3）。ただし施行令第46条の5第1項は所属を決める書類を人の区分で分けるので、文言どおりに読むと、
    確定申告書の扶養の記載が住民税の所属を決めるのは**法第317条の2第1項の申告義務者**（給与・公的年金等以外の所得がある人など）の場合。
    **給与所得等以外の所得を有しなかつた者**（1月1日現在で報告書の提出義務者から給与・公的年金等を受け、前年に他の所得がない人）は、確定申告をしても
    給与支払報告書・公的年金等支払報告書（申請書を出せば申請書）の記載による［PS］§4.2 の訂正。市町村の実務は確かめていない（未決 JU6）。
- 根拠：［PS］§4、［M］§3.2。所得税の規則（所令219）は［R4概念］。
- 帰結：
  - 「誰の扶養にするか」は人の判断・提出した書類の記載という**事実**として持ち（D4・D12）、判定コアは記載を受け取って所属を決め、記載がないか重複するときだけ規則で決める。
  - 規則の部分は所得税（所令219②）と住民税（施行令46の5②）で別の関数にする。住民税の規則は「総所得金額等が最大」だけで、所得税の「既に申告書等で扶養としている居住者」の段がない。
  - 2026-01-01 より前の版（令和7年度分まで）は特定親族がない形で、令和7年度分は対象外（D14）なので実装しなくてよい。

## H5 申告の要否は「確定申告の有無」「1月1日現在の給与・公的年金の支払者」「前年の所得の種類」「受けたい控除」「市町村の条例」で決まる

- 内容（判定表）：
  1. 前年分の所得税の確定申告書を出した（出す）→ 住民税の申告書を出したものとみなす（法317の3①）。
  2. 1月1日現在で給与支払報告書（または公的年金等支払報告書）を出す義務がある者から給与（公的年金等）を受けていて、前年に給与所得（公的年金等に係る所得）以外の所得がない
     → 不要。ただし医療費控除・雑損控除・純損失等の控除・寄附金税額控除を受けたいなら必要（法317の2①ただし書・③）。公的年金のみの者は、一定の控除を受けたいなら必要。
  3. 市町村の条例で定める「所得割の納税義務を負わないと認められる者」→ 不要（例：札幌市は前年の合計所得金額が「第28条の３第15号アに定める基礎控除額」以下の者、専従者、
     賦課期日に生活扶助を受けている者）。（検証で訂正：元は「基礎控除額 43万円以下」。現行の札幌市税条例では第28条の３第15号アは特定親族特別控除（45万円）で、
     基礎控除額は第16号ア（43万円）。引用と語が食い違っており、額は確かめられない［PS］§6.2。未決 JU7）
  4. それ以外（前年に事業所得・雑所得がある、年の途中で給与の支払者を辞めて1月1日には受けていない、など）→ 3月15日までに申告が必要（法317の2①）。
- 根拠：［PS］§6。
- 帰結：
  - 所得税の確定申告が不要でも、住民税の申告が不要とは限らない（2・3 に当たらなければ必要）。
  - 3 は市町村ごとに違うので、判定コアは「条例の免除に当たるか」を市町村の条例のパラメータで判定するか、「条例による」として未決を返す。
  - 申告の要否の判定には、中間表現に「1月1日現在で給与（公的年金等）を受けている支払者があるか」「その支払者は給与支払報告書の提出義務者か（源泉徴収義務者か）」が要る。

## H6 均等割の非課税の額は市町村ごとのパラメータで、既定値は政令の基準×級地

- 内容：均等割の非課税の基本額・加算額は条例で定める（法295③、施行令47の3）。判定コアのパラメータは「市町村（または級地）→ 基本額・加算額」とし、根拠として条例の条番号・取得日・URL を持つ。
  条例を確認していない市町村は、級地ごとの政令基準の上限（35万/21万、31.5万/18.9万、28万/16.8万）を既定値にし、結果に「既定値を使った」と書く。
- 根拠：［PS］§1.2〜§1.6（札幌市は上限どおり 35万円・21万円）、［M］§5.4（柏市＝2級地の公表値が 31.5万円・18.9万円で計算した値と一致）。
- 確からしさ：中。全国の条例が上限どおりかは確認していない。級地区分（どの市町村が何級地か）の一次情報（生活保護の告示）は取得していない［PS］§9。
- 所得割の非課税（35万円・10万円・32万円）は法律に直接書かれ、市町村・級地で変わらない［PS］§2.1。

## H7 令和8年度分・令和9年度分で、非課税の境目（所得の額）は同じで、変わるのは所得の計算と扶養の要件

- 内容：
  - 同じ：法第295条（135万円）、施行令第47条の3・施行規則第9条の21（均等割）、法附則第3条の3（所得割）、扶養控除・特定扶養・特定親族特別控除・勤労学生控除・基礎控除の額。
  - 変わる：扶養親族・同一生計配偶者の所得要件（58万円 → 62万円）、特定親族の下限（58万円超 → 62万円超）、勤労学生の所得要件（85万円 → 89万円。所得税法の前年分の文言による）、
    給与所得の計算（令和9年度分は措法第29条の4 で 69万1千円以上220万円未満の給与所得が変わる）。
  - 令和10年度分：ひとり親控除 30万円 → 33万円（asof 2028-01-01 の版）。
  - （検証で追記）所得税の側：扶養親族の所得要件（所得税法第2条第1項第34号）は令和8年分から 62万円、勤労学生は令和8年分から 89万円（令和8年法律第12号附則第2条）。
    給与所得（第28条）の改正も令和8年分から（同附則第3条）。したがって所得の年で見れば、所得税（令和8年分）と住民税（令和9年度分）の扶養親族の要件は同じ 62万円［PS］§5 の追記。
- 根拠：［M］§3.1・§3.2・§5.3、［PS］§5。
