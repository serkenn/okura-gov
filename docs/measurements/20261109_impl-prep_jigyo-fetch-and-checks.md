### 4.1 C9：タックスアンサー No.1810 の注記と条文の値

- 条文から読んだ値：扶養親族の合計所得金額要件 令和7年分 580,000、令和8年分 620,000（R1 の `scripts/results/R1_egov_articles/shotoku_2025-12-31.txt`・`shotoku_2026-12-01.txt` 第2条第1項第34号）。家内労働者等の特例額 令和7年分 650,000、令和8年分 690,000（C1）。
- 家内労働者等の特例の対象となる所得しかない人の、総収入金額の上限：
  - 扶養親族に当たる上限（特例額＋所得要件）：令和7年分 **1,230,000**、令和8年分 **1,310,000**
  - 本人に所得税がかからない上限（特例額＋TA が書く基礎控除額）：令和7年分 1,600,000、令和8年分 1,730,000
- TA No.1810 の本文（`scripts/results/IMPL_jigyo_nta/ta_index/ta_1810.txt`）：
  - 令和8年分：「173万円以下の場合は、総所得金額が基礎控除額の104万円以下」「131万円以下の場合は、扶養者の所得税額の計算上、配偶者控除あるいは扶養控除の対象」→ 計算と一致。
  - 令和7年分：「その年の総収入金額が160万円以下の場合は、合計所得金額が基礎控除額の95万円以下となりますので、本人に所得税は課されず、また、扶養者の所得税額の計算上、配偶者控除あるいは扶養控除の対象となります。」→ **扶養の部分は条文からの計算（123万円）と一致しない**（160万円は「本人に所得税がかからない」上限と一致）。

### 4.2 C10：措令18の2② の配分と国税庁の計算書の配分

- 比べたもの：
  - 措令18の2②（2025-12-31 版）の文言どおり：F＝特例額−給与の調整、雑所得の分＝F のうち事業所得の実額の必要経費に達するまでの部分以外の部分、事業所得の分＝事業所得の実額の必要経費（雑所得の総収入金額が雑所得の分に満たないときは、その不足分を加える）。それぞれ総収入金額が限度（措法27 後段）。
  - 国税庁「家内労働者等の事業所得等の所得計算の特例の適用を受ける場合の必要経費の額の計算書【令和７年分以降用】」（`.work/downloads/20261109-150217_IMPL_jigyo_nta_forms/kanai_keisansho_r07.pdf`）の ⑤＝65万円−②−④、⑥＝65万円−③−④、⑦＝①と⑥の少ない方（③がないか③≦⑤）、⑧＝②（③＞⑤）、⑨＝③と⑤の少ない方。④は「給与所得の収入金額」。
- 総当たり：事業所得の総収入金額 0〜100万円、実額経費 0〜70万円、雑所得の総収入金額 0〜100万円（いずれも5万円刻み）、雑所得の実額経費 0〜30万円（10万円刻み）、給与収入 0／30万／60万円、特例額 65万円。給与の調整は両方とも「給与収入（特例額を上限）」で揃え、配分の違いだけを見た。特例の要件（実額経費の合計が F 未満）を満たす組だけ比べた。ほかに、事業所得・雑所得の総収入金額がともに 0 の組（180 組）と、事業所得の総収入金額が 0 で事業所得の実額経費が正の組（`IMPL_jigyo_checks.py` の `if R_biz == 0 and E_biz > 0: continue`。特例の要件を満たすものは 960 組で、うち 632 組では2つの書き方が食い違う。どれも事業所得が赤字の組）も比べていない（2026-11-09 独立検証で追記。`scripts/results/IMPL_jigyo_verify/check.json` の `calc.C10`）。
- 結果：比べた 24,120 組のうち 21,524 組が一致、2,596 組が不一致。**不一致はすべて事業所得の実額経費が事業所得の総収入金額を超える組（事業所得が赤字）**。例：事業収入 5万・事業経費 10万・雑収入 30万・給与 30万 → 措令の文言どおりでは事業分 5万（総収入金額が限度）、計算書では ⑧＝10万。
- 計算書の書き方（`kanai_kakikata_r07.pdf`）は「事業所得が赤字となる方…は、税務署におたずねください」と書いている（公開資料の情報 §2.4）。
