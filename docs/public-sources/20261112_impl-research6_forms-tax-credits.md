## 1. 手順4 の欄の並び（[IDX]）

目次の「手順4 税金の計算をする」の並び：㉛㉜ 課税される所得金額・税額 → ㉝ 配当控除 → ㉞「㉞」（区分） → ㉟（特定増改築等）住宅借入金等特別控除 →
㊱㊲㊳ 政党等寄附金等特別控除 → ㊴㊵㊶ 住宅耐震改修特別控除等 → ㊷ 差引所得税額 → ㊸ 災害減免額 → ㊹ 再差引所得税額（基準所得税額） → ㊺ 復興特別所得税額 → …

## 2. ㉞（区分）：事業所得等の特例に係る税額控除（[T29]）

原文（第一表）：

> ㉞欄 … 事業を営む方が、中小企業者が機械等を取得した場合の所得税額の特別控除など、事業所得等の特例に係る税額控除の適用を受ける場合には、
> 左側空欄に「投資税額等」、「区分」の□に「１」と記入し、控除額を記入します。

第二表：「特例適用条文等」欄 … 該当条文を記入します。

- ㉞ の欄名は様式では空欄（「（　　）」）で、事業所得等の特例に係る税額控除のときに「投資税額等」と書く。欄コードは G68、区分は G22
  （`docs/public-sources/20261109_round2_yoshiki-forms-r07.md` の第一表の表）。
- 区分の番号は **「1」だけ** が書かれている。ほかの番号・ほかの控除に ㉞ を使う書き方は、このページにない（分からなかった）。
- 控除の対象の制度は「中小企業者が機械等を取得した場合の所得税額の特別控除など」とだけあり、制度の一覧・条番号・限度はこのページにない（読んでいない）。

## 3. ㊴〜㊶ 住宅耐震改修特別控除等（[T32]）

控除の概要（原文の要約）：

- 住宅耐震改修特別控除：家屋の耐震改修をした場合で一定の要件を満たすときの控除。
- 住宅特定改修特別税額控除：家屋のバリアフリー改修工事や省エネ改修工事、多世帯同居改修工事等、耐久性向上改修工事等、子育て対応改修工事等をした場合で一定の要件を満たすときの控除。
- 認定住宅等新築等特別税額控除：認定住宅等の新築や新築の認定住宅の購入をした場合で一定の要件を満たすときの控除。

申告書の書き方（第一表。原文）：

> ㊴から㊶欄…住宅耐震改修特別控除の場合は、「区分」の□に「1」と記入し、『住宅耐震改修特別控除額・住宅特定改修特別税額控除額の計算明細書』で計算した金額を転記します。
> 住宅特定改修特別税額控除の場合は、「区分」の□に「2」と記入し、『住宅耐震改修特別控除額・住宅特定改修特別税額控除額の計算明細書』で計算した金額を転記します。
> 認定住宅等新築等特別税額控除の場合は、「区分」の□に「3」と記入し、『認定住宅等新築等特別税額控除額の計算明細書』で計算した金額を転記します。
> 複数の控除がある場合は、「区分」の□に「4」と記入し、控除額の合計額を記入します。

| 区分 | 控除 | 額 |
|---|---|---|
| 1 | 住宅耐震改修特別控除 | 計算明細書で計算した金額 |
| 2 | 住宅特定改修特別税額控除 | 計算明細書で計算した金額 |
| 3 | 認定住宅等新築等特別税額控除 | 計算明細書で計算した金額 |
| 4 | 複数の控除がある場合 | 控除額の合計額 |

- 第二表：子育て対応改修工事等に係る住宅特定改修特別税額控除を受ける方の記入方法は「（特定増改築等）住宅借入金等特別控除」（[T30]）を参照、とある。
- 額は計算明細書で計算した金額の「転記」。計算明細書の中身（各控除の限度・税額による上限の有無）は読んでいない。
- 各控除の条番号はこのページにない。地方税法附則第5条の4第5項第2号の原文の要約（`docs/public-sources/20261109_round3_juminzei-extra-law-text.md` §3.2）に
  「措法…第41条の19の2〜第41条の19の4」が列挙されているが、どの条がどの控除かはこの作業で原文を確かめていない。

## 4. ㊷ 差引所得税額：控除の順序と赤字（[T36]）

原文：

> ㊷欄 … ㉜欄の金額から、㉝欄、㉞欄、㉟欄、㊱〜㊳欄、㊴〜㊶欄の金額を差し引いた金額（赤字の場合は「0」）を記入します。

- 差し引く順：㉜（税額）から ㉝ 配当控除 → ㉞ → ㉟ 住宅借入金等特別控除 → ㊱〜㊳ 政党等寄附金等特別控除 → ㊴〜㊶ 住宅耐震改修特別控除等。
- 限度：差し引いた結果が赤字なら「0」。個々の控除ごとの限度（前に残った税額を超える分の扱い）は書かれていない。どの控除も 0 以上なので、
  「前に残った税額を限度に順に差し引く」と「全部を差し引いて赤字なら 0」は ㊷ の値が同じ（判定コアの読み：`rules/tax/calc.py` の `deduct_credits`）。
- ㊸ 災害減免額を引いた ㊹ が再差引所得税額（基準所得税額）（[IDX]）。災害減免は後の段（HANDOFF D21 R3）なので、判定コアでは ㊷＝㊹。

## 5. ㉟ 住宅借入金等特別控除の区分（[T30]。参考）

> ㉟欄 … 『（特定増改築等）住宅借入金等特別控除額の計算明細書』で計算した金額を転記します。
> ※ 「区分1」の□は、東日本大震災の被災者の方が、住宅の再取得等に係る住宅借入金等特別控除の控除額の特例の適用を受ける場合、「7」を記入します。
> ※ 給与所得者が、既に年末調整でこの控除の適用を受けている場合には、源泉徴収票の「住宅借入金等特別控除の額」欄の額（摘要欄の「住宅借入金等特別控除可能額」欄に
> 金額が記載されている場合はその額）を㉟欄に転記し、「区分2」の□に「1」を記入します。

㉟ の区分1・区分2（G23・G24）は、この作業では写していない（対応表では「事実」のまま）。

## 6. 分からなかったこと

- 事業所得等の特例に係る税額控除の制度の一覧・条番号・限度（[T29] は「中小企業者が機械等を取得した場合の所得税額の特別控除など」だけ）。
- 住宅耐震改修特別控除等の各控除の条番号と限度（計算明細書・「受けられる方へ」の PDF は取得していない）。
- これらの控除が所得税法第120条第1項の申告の要否の比較（配当控除の額を超えるか）に入るか（読替えの規定を読んでいない）。
