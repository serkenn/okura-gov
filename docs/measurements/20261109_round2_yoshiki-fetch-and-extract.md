- 作成日：2026-11-09

### 3.2 青色申告決算書（一般用）の欄コードと科目の対応の確かめ方（F）

- `scripts/results/R2X_yoshiki_rowmap/aoiro_ippan_10_rowmap.tsv` の候補を、`aoiro_ippan_10_text.tsv` の文字と座標（同じ y で並ぶ「行番号・科目名・欄コード」）を目で追って確かめた。
- 1ページ（損益計算書）：欄コード G01〜G45 は、x≈136・400・667 に印字された行番号 1〜45 と同じ高さ（|dy|≦0.6）にあり、G番号と行番号が一致する（G01＝1 … G45＝45）。科目名は同じ高さの左（x≈44〜110、309、588）。2行に分かれた科目名（売上（収入）金額（雑収入を含む）、期首商品（製品）棚卸高 など）は行番号の上下 10pt 以内。
