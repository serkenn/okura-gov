## I1 青色申告特別控除（令和7年分・令和8年分）：申告の方法・時期・帳簿で額が変わる

- 前提：［H］H3・H5。
- 場面と期待値（控除前の所得の金額。不動産所得は事業的規模と明記したもの以外は事業的規模でない）：

| 例 | 条件 | 期待値 |
|---|---|---|
| T1 | 事業所得300万円、正規の簿記、期限内に e-Tax | 650,000（事業所得から） |
| T2 | 事業所得40万円、同 | 400,000（黒字の合計が上限） |
| T3 | 事業所得200万円、不動産所得（事業的規模）▲50万円、e-Tax | 650,000（赤字の不動産所得は合計に入れず、全額を事業所得から） |
| T4 | 事業所得300万円、正規の簿記、書面で期限内（決算書を添付、控除を記載） | 550,000 |
| T5 | 同、書面で期限後 | 100,000 |
| T6 | 事業所得300万円、簡易帳簿 | 100,000 |
| T7 | 事業所得300万円、現金主義 | 100,000 |
| T8 | 不動産所得（事業的規模でない）80万円だけ、正規の簿記、e-Tax | 100,000 |
| T9 | 不動産所得（事業的規模でない）30万円＋事業所得20万円、e-Tax | 500,000（不動産から300,000、事業から200,000） |
| T10 | 事業所得▲100万円だけ | 0 |
| T11 | T1 で、仕訳帳・総勘定元帳を年の途中から電子保存し、書面で期限内 | 550,000（最初の記録段階から一貫していないので④一に当たらない） |
| T12 | T1 で、優良な電子帳簿（電帳規5⑤）・適用届出書を翌年3月15日までに提出、書面で期限内 | 650,000 |

- 性質（④）：同じ記録で、「期限内 e-Tax」→「書面で期限内」→「期限後」の順に控除額は増えない（65万→55万→10万）。控除額は黒字の合計を超えない。赤字の所得から控除しない。
- 検証方法：
  - ①②：上の表を単体テストにする。令和7年分と令和8年分で同じ値になること（措法25の2・措規9の6 が同文）。
  - ⑤：令和7年分の作成コーナーで、架空の青色申告決算書（一般用）を作り、T1・T3・T9 の入力で「青色申告特別控除額」が期待値になるかを見る（e-Tax で提出しない作り方でも、作成コーナーが控除額をどう扱うかを記録する）。T8・T9 は事業的規模の扱いで結果が分かれるので、作成コーナーの画面の問い（事業的規模か）を記録する。
  - 国税庁の資料：令和7年分青色申告決算書（一般用）の書き方（037.pdf）の記載例（Read ツールで画像の一部を見た限り、事業所得の記載例で「青色申告特別控除額」550,000）。書き方の本文を読めていないので、読める形で取り直して照合する。

## I3 申告の計画に依存する結果の印

- 前提：［H］H3（申告の計画は判断として受け、結果に条件を付ける）。
- 期待値：T1 の入力で、申告の計画が「e-Tax・期限内」のとき、結果は 650,000 と条件「確定申告期限までに e-Tax で、貸借対照表・損益計算書等とともに送信した場合に限る（措法25の2④二）」。計画を「書面・期限内」に変えた別シナリオでは 550,000。実際の提出の事実が「期限後」で入ると 100,000 に変わる。
- 検証方法：①：同じ中間表現で、計画の判断だけを変えた複数シナリオ（D19）の一括評価が、上の3つの値と条件の印を返すこと。④：実際の提出の事実が入ったら、計画の判断より事実が優先されること。

## I4 青色事業専従者と扶養：学生の子・働いている子

- 前提：［H］H6。
- 場面（架空）：親Aが青色で事業所得、親Bと子は親Aと生計を一にする。
  - S-a：子（20歳、学生でない、他に職業なし）が親Aの事業に1年を通じて専ら従事し、届出書（月10万円、年120万円）どおり支払を受けた。期待値：親Aの必要経費に1,200,000（相当と判断された場合）。子の給与所得の収入金額 1,200,000。子は親A・親Bの扶養親族・特定親族（所法84の2）・源泉控除対象親族のどれにもならない（合計所得金額にかかわらず）。
  - S-b：S-a で給与が年60万円。期待値：子の合計所得金額が扶養の所得の要件を満たす額（給与所得控除の後で0になる場合を含む）でも、子は青色事業専従者として給与の支払を受けているので、親A・親Bの扶養親族にならない。親Aの必要経費 600,000。
  - S-c：子が昼間の大学生で、夏休みなどに親Aの事業を手伝い、給与を受けた。期待値：学生である期間は専ら従事する期間に含まれない（所令165②一。夜間の授業で昼間の事業に従事するなどの例外は判断）ので、通常は専従者に当たらない。当たらなければ、その給与は所法56 により親Aの必要経費にならず、子の給与所得にもならない。子は（所得の要件を満たせば）扶養親族のまま。
  - S-d：子（15歳になる年）の年齢：2010-12-31・2011-01-01 生まれは2025年12月31日に15歳以上、2011-01-02 生まれは15歳未満（専従者になれない）。
- 検証方法：③：場面のテストにする。S-b は「青色事業専従者の除外が所得の要件より先」であることの性質のテスト（④）。⑤：作成コーナー（令和7年分）で、事業主の決算書の専従者給与と、別人の申告での扶養の入力ができるか（作成コーナーは人ごとに申告を作るので、除外は利用者の入力に依存するはず）を確かめ、結果を記録する。S-c は所令165②一の括弧（夜間・常時修学しない等）の判断の入力で結論が変わることを単体テストにする。

## I5 専従の期間（6月超・2分の1）

- 前提：［H］H6（期間の数え方は出典未確認の名前つき関数）。
- 期待値：
  - 1年を通じて営む事業で、親族が1月1日〜7月10日に専ら従事（6か月と10日）：6月を超える → 専従者。
  - 1月1日〜6月30日（ちょうど6か月）：「六月をこえる」に当たらない → 専従者でない。数え方（日単位・月単位）で境目が動くので、この例は「出典未確認」の印つきの結果にする。
  - 7月1日に開業した事業で、親族が9月1日〜12月31日に専ら従事（4か月）：青色の場合は従事できる期間（6か月）の2分の1（3か月）を超える → 専従者（所令165①ただし書）。白色の事業専従者控除では本文（6月超）だけなので当たらない。
- 検証方法：②④：境目の前後（6か月ちょうど、6か月と1日）のテスト。数え方を示す国税庁の資料（質疑応答事例「年の中途で事業に従事した親族に係る青色事業専従者給与」など、TA No.2075 から張られたもの）を取得して照合する。

## I6 承認の時期と期限

- 前提：［H］H1・H10。
- 期待値（休日の調整は、その日が休日の場合だけ翌日にずらす）：
  - 2026年3月10日に申請（令和8年分から）、通知なし → 2026年12月31日に承認があったものとみなす。令和8年分は青色。
  - 2026年3月1日に開業し、5月1日に申請（初日不算入なら期限は5月1日）→ 期限内。初日を算入する読みでは期限は4月30日で期限後。結果に「期限の計算：初日不算入」の印。
  - 2026年11月15日に開業し、2027年1月10日に申請 → 期限内（開業から2月以内）。みなし承認の日は2027年2月15日、令和8年分から青色。
  - 2025年分を取りやめる届出：期限は2026年3月15日（旧所法151①「その年の翌年三月十五日」。2026年3月15日は日曜日なので通則法10② により翌日）。2026年分を取りやめる届出：その年分の確定申告期限（2027年3月15日）。
  - 取りやめ届出の日から1年以内の申請：コアは承認を予測せず「却下されうる」の印。承認の通知の事実が入れば青色。
- 検証方法：①②：期限の関数の単体テスト（休日の一覧はパラメータ）。2026年3月15日が日曜日であることは暦で確かめる（祝日の一覧の出典は別に用意する）。⑤ は使えない（作成コーナーは承認の手続を扱わない）。手続の案内（A1-8）の「その事業開始等の日から2月以内」の例示を国税庁の質疑応答などで探し、初日の扱いを確かめる。

## I7 純損失の繰越控除

- 前提：［H］H8。
- 期待値（青色で毎年申告、総所得金額は繰越控除前）：
  - C1：2025年の純損失100万円、2026年・2027年の総所得金額各60万円 → 2026年に60万円、2027年に40万円を控除（2027年の控除後20万円）。
  - C2：2025年の純損失100万円、2026年・2027年は0、2028年20万円、2029年200万円 → 2028年に20万円控除。2029年は2025年分を控除できない（前年以前3年内でない）。残り80万円は使えずに消える。
  - C3：2025年・2026年の純損失各50万円、2027年の総所得金額70万円 → 古い2025年分50万円、次に2026年分20万円。2026年分の残り30万円は2028・2029年に繰り越す。
  - C4：C1 で2025年が白色（変動所得・被災事業用資産の損失なし）→ 繰越しなし。
  - C5：C1 で2026年分の確定申告書を出していない → 2027年に2025年分を控除できない（連続して申告していない）。
- 検証方法：①②④（繰越しの合計は生じた純損失を超えない、古い順）。⑤：作成コーナー（令和7年分）の損失申告（第四表）に架空の前年以前の純損失を入れ、翌年に繰り越す額の欄を照合する。

## I8 純損失の繰戻し還付

- 前提：［H］H9。
- 期待値（前年の課税総所得金額だけ、税額控除なし、平均課税なし）：
  - K1：前年300万円、繰り戻す純損失100万円 → 前年の税 202,500、繰戻し後 102,500、還付 100,000。
  - K2：前年150万円、純損失300万円（全部を繰り戻す）→ 75,000 → 0、還付 75,000。残りの150万円分は繰り戻しても税が減らないので、繰越しに回すのが有利（一部だけ繰り戻せる：記載要領）。
  - K3：K1 で前年の税額控除後の所得税額が5万円 → 還付は 50,000（所法140② の限度。税額控除後の額で比べる：所基通140・141−2）。
  - 前年分の復興特別所得税は還付されない（［H］H9）。その税率（令和7年分・令和8年分は基準所得税額の2.1%）は既存の仮説 `docs/hypotheses/20261109_impl-prep_zeigaku-calc-model.md` H1 の段8 による。
- シナリオ比較（D19）：K2 で「全部を繰り戻す」と「150万円だけ繰り戻し、残り150万円を繰り越す」を並べて評価できること。
- 検証方法：①：税額の計算は ［H］H10 の `繰戻し_税額`（所法89 の超過累進に、1,000円未満・100円未満の切捨て）で行う。⑤：作成コーナーに繰戻し還付請求書の作成機能があるかを確かめ、あれば K1 の数字で照合する（ないなら、還付請求書の様式の計算の順（⑦〜㉒）どおりに手計算した結果を期待値の出典にする）。

## I10 記録層の事実の検査

- 前提：［H］H12、H1〜H3。
- 期待値：青色の年分で、(a) 承認の事実がない、(b) 帳簿の方式の宣言がない、(c) 申告の計画も実際の提出の事実もない、のどれかなら、コアは「未確定」と理由を返し、黙って10万円や白色にしない。(a) だけがない場合は青色の規定を適用しない（白色として計算する）のではなく、「承認の有無が不明」と返す。
- 検証方法：①：中間表現の検査のテスト（欠けた事実ごとに、返る理由が違うこと）。
