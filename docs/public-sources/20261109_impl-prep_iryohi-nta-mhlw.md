## 1. 所得税基本通達 73−1〜73−10 [通達]

原文（通達73。73−8〜73−10 の「補塡」の「塡」の字はページ上で画像（alt=ほてん）。ここでは「補塡」と書く）：

| 項 | 見出し | 原文の要点 |
|---|---|---|
| 73−1 | （生計を一にする親族に係る医療費） | 「自己と生計を一にする配偶者その他の親族に係る医療費」とは、**医療費を支出すべき事由が生じた時又は現実に医療費を支払った時の現況**において居住者と生計を一にし、かつ、親族である者に係る医療費をいう |
| 73−2 | （支払った医療費の意義） | 「その年中に支払った当該医療費」とは、その年中に**現実に支払った**医療費をいうのであるから、未払となっている医療費は現実に支払われるまでは控除の対象とならない |
| 73−3 | （控除の対象となる医療費の範囲） | 医師、歯科医師、令第207条第4号の施術者又は同条第6号の助産師（「医師等」）による診療、治療、施術又は分べんの介助（「診療等」）を受けるため**直接必要な費用**は医療費に含まれる：(1) 医師等による診療等を受けるための**通院費**若しくは医師等の**送迎費**、入院若しくは入所の対価として支払う**部屋代、食事代**等の費用又は**医療用器具等**の購入、賃借若しくは使用のための費用で、**通常必要なもの** (2) 自己の日常最低限の用をたすために供される**義手、義足、松葉づえ、補聴器、義歯等**の購入のための費用 (3) 身体障害者福祉法第38条、知的障害者福祉法第27条若しくは児童福祉法第56条又はこれらに類する法律の規定により都道府県知事又は市町村長に納付する費用のうち、医師等による診療等の費用に相当するもの並びに(1)及び(2)の費用に相当するもの |
| 73−4 | （健康診断及び美容整形手術のための費用） | いわゆる**人間ドックその他の健康診断**のための費用及び容姿を美化し、又は容ぼうを変えるなどのための費用は、医療費に該当しない。ただし、**健康診断により重大な疾病が発見され、かつ、当該診断に引き続きその疾病の治療をした場合**には、当該健康診断のための費用も医療費に該当する |
| 73−5 | （医薬品の購入の対価） | 令第207条第2号の医薬品とは医薬品医療機器等法第2条第1項の医薬品をいうが、同項の医薬品に該当するものであっても、**疾病の予防又は健康増進のために供されるもの**の購入の対価は、医療費に該当しない |
| 73−6 | （保健師等以外の者から受ける療養上の世話） | 令第207条第5号の「保健師、看護師又は准看護師による療養上の世話」は、これらの者が保健師助産師看護師法の業務として行う療養上の世話をいうが、これらの者以外の者で**療養上の世話を受けるために特に依頼したもの**から受ける療養上の世話も含まれる |
| 73−7 | （助産師による分べんの介助） | 令第207条第6号の「助産師による分べんの介助」には、助産師が行う保健師助産師看護師法第3条の妊婦、じょく婦又は新生児の**保健指導**も含まれる |
| 73−8 | （医療費を補塡する保険金等） | 法第73条第1項かっこ内の「保険金、損害賠償金その他これらに類するもの」（「医療費を補塡する保険金等」）には次のようなものがある：(1) 社会保険又は共済に関する法律その他の法令の規定に基づき支給を受ける給付金のうち、健康保険法第87条第2項（療養費）、第97条第1項（移送費）、第101条（出産育児一時金）、第110条（家族療養費）、第112条第1項（家族移送費）、第114条（家族出産育児一時金）、第115条第1項（高額療養費）又は第115条の2第1項（高額介護合算療養費）の規定により支給を受ける給付金のように医療費の支出の事由を給付原因として支給を受けるもの (2) 損害保険契約又は生命保険契約（これらに類する共済契約を含む）に基づき医療費の補塡を目的として支払を受ける傷害費用保険金、医療保険金又は入院費給付金等 (3) 医療費の補塡を目的として支払を受ける損害賠償金 (4) その他の法令の規定に基づかない任意の互助組織から医療費の補塡を目的として支払を受ける給付金 |
| 73−9 | （医療費を補塡する保険金等に当たらないもの） | (1) 死亡したこと、重度障害の状態となったこと、療養のため労務に服することができなくなったことなどに基因して支払を受ける保険金、損害賠償金等 (2) 健康保険法第99条第1項（傷病手当金）又は第102条（出産手当金）の規定により支給を受ける傷病手当金又は出産手当金その他これらに類するもの (3) 使用者その他の者から支払を受ける見舞金等（73−8の(4)に該当するものを除く） |
| 73−10 | （医療費を補塡する保険金等の見込控除） | 医療費を補塡する保険金等の額が医療費を支払った年分の**確定申告書を提出する時までに確定していない場合**には、当該保険金等の**見込額**に基づいて同項の規定を適用する。この場合において、後日、当該保険金等の確定額と当該見込額とが異なることとなったときは、**遡及してその医療費控除額を訂正**する |

（通達の健康保険法の条番号は、通達の原文に書かれたものをそのまま写した。健康保険法の条文では確かめていない。→ 独立検証で、健康保険法の現行版（e-Gov、asof 2026-11-09）の条の見出し・項と照合し、通達の引用と合うことを確かめた。実測 `docs/measurements/20261109_impl-prep_iryohi-verification.md` の V-NM-4。）

## 2. 「総所得金額等」と控除額の計算欄

### 2.1 国税庁の用語集「総所得金額等」 [TA]（用語）

原文：「次の（1）と（2）の合計額に、退職所得金額（※1）、山林所得金額を加算した金額（※2）です。（※1）退職所得金額は、確定申告が不要な場合でも計算に当たって加算する必要があります。（※2）申告分離課税の所得がある場合には、それらの所得金額（長（短）期譲渡所得については特別控除前の金額）の合計額を加算した金額です。（1）事業所得、不動産所得、給与所得、総合課税の利子所得・配当所得・短期譲渡所得および雑所得の合計額（損益通算後の金額）（2）総合課税の長期譲渡所得と一時所得の合計額（損益通算後の金額）の２分の１の金額　ただし、次の繰越控除を受けている場合は、その**適用後**の金額をいいます。純損失や雑損失の繰越控除／居住用財産の買換え等の場合の譲渡損失の繰越控除／特定居住用財産の譲渡損失の繰越控除／上場株式等に係る譲渡損失の繰越控除／特定投資株式に係る譲渡損失の繰越控除／先物取引の差金等決済に係る損失の繰越控除」

- 同じ用語集の「合計所得金額」は、同じ（1）（2）と退職所得金額・山林所得金額・申告分離課税の所得の合計で、繰越控除は「その**適用前**の金額」。違いは繰越控除の扱いだけ。
- TA1120・TA1131 の本文の「総所得金額等」は、この用語集にリンクしている（[MEAS] §2 のリンクの記録）。

### 2.2 控除額の計算欄 [様式]（手引3-3_24、様式ref1）

## 3. 医療費控除の対象となる医療費 [TA]（TA1122）と、明細書の「医療費の区分」

TA1122 の一覧（原文の項目。かっこ内は TA の注記の要点）：

1. 医師または歯科医師による診療または治療の対価（健康診断の費用や医師等に対する謝礼金などは原則として含まれない）
2. 治療または療養に必要な医薬品の購入の対価（風邪薬は医療費、ビタミン剤などの予防・健康増進のための医薬品は医療費にならない）。（注）特定一般用医薬品等の購入費は、一定の取組を行っているときに、通常の医療費控除との選択でセルフメディケーション税制の対象
3. 病院、診療所、介護老人保健施設、介護医療院、指定介護療養型医療施設、指定介護老人福祉施設、指定地域密着型介護老人福祉施設または助産所へ収容されるための人的役務の提供の対価
4. あん摩マッサージ指圧師、はり師、きゅう師、柔道整復師による施術の対価（疲れを癒す、体調を整えるといった治療に直接関係のないものは含まれない）
5. 保健師、看護師、准看護師または特に依頼した人による療養上の世話の対価（家政婦に病人の付添いを頼んだ場合を含む。心付けは除く。家族や親類縁者に付添料の名目で支払っても対象にならない）
6. 助産師による分べんの介助の対価
7. 介護福祉士等による一定の喀痰吸引および経管栄養の対価
8. 介護保険等制度で提供された一定の施設・居宅サービスの自己負担額
9. 医師等による診療、治療、施術または分べんの介助を受けるために直接必要なもの：(1) 通院費、医師等の送迎費、入院の際の部屋代や食事代、コルセットなどの医療用器具等の購入代や賃借料で通常必要なもの（（注1）公共交通機関が利用できない場合を除き、タクシー代は含まれない（注2）自家用車のガソリン代や駐車場の料金は含まれない） (2) 義手、義足、松葉杖、補聴器、義歯、眼鏡などの購入費用 (3) 身体障害者福祉法、知的障害者福祉法などにより都道府県や市町村に納付する費用のうち診療等の費用相当分など (4) 傷病によりおおむね6か月以上寝たきりで医師の治療を受けている場合のおむつ代（医師が発行した「おむつ使用証明書」が必要。要介護認定を受けている一定の人は市町村長等の確認書等で代えられる）
10. 日本骨髄バンクに支払う骨髄移植のあっせんに係る患者負担金
11. 日本臓器移植ネットワークに支払う臓器移植のあっせんに係る患者負担金
12. 高齢者の医療の確保に関する法律に規定する特定保健指導（一定の積極的支援によるものに限る）のうち一定の基準に該当する者が支払う自己負担金

明細書・医療費集計フォームの「医療費の区分」は4つ：**診療・治療／医薬品購入／介護保険サービス／その他の医療費**（様式ref1、[MEAS] §4）。記載要領：「医療費の内容として該当するものを全てチェックします」「『□その他の医療費』欄は、例えば、通院費、医療用器具の購入（いずれも通常必要なものに限ります。）などがある場合にチェックします」「通院費の支払先が乗り継ぎ等により複数ある場合には、記入例のようにまとめて記入しても差し支えありません」（手引6_01）。

証明書類が必要な費用（様式ref1-ki・手引008 の「添付又は提示が必要な書類」。画像から読んだもの）：寝たきりの人のおむつ代→医師が発行した「おむつ使用証明書」／温泉利用型健康増進施設の利用料金→温泉療養証明書／指定運動療法施設の利用料金→運動療法実施証明書／ストマ用装具の購入費用→ストマ用装具使用証明書／B型肝炎患者の介護に当たる同居の親族が受けるワクチンの接種費用→医師の診断書／白内障等の治療に必要な眼鏡の購入費用→処方箋／市町村又は認定民間事業者による在宅療養の介護費用→在宅介護費用証明書。「これらの書類に記載された①証明年月日、②証明書の名称及び③証明者の名称（医療機関名等）を明細書の適宜の欄又は欄外余白などに記載することで、添付又は提示を省略しても差し支えありません。この場合、添付等を省略した証明書などは、確定申告期限等から5年間ご自宅等で保管する必要があります。」

## 4. 補塡の扱い [TA][QA][様式]

| TA1120 | 「保険金などで補てんされる金額は、その給付の目的となった医療費の金額を限度として差し引きますので、引ききれない金額が生じた場合であっても他の医療費からは差し引きません。」例：生命保険契約などで支給される入院費給付金、健康保険などで支給される高額療養費・家族療養費・出産育児一時金など |

## 6. セルフメディケーション税制 [TA][厚労]

### 6.1 要件と選択（TA1129・TA1131・特集セルフ）

- 「セルフメディケーション税制は医療費控除の特例であり、通常の医療費控除との選択適用となります。…この特例の適用を受ける場合は、通常の医療費控除を併せて受けることはできません。また、これらのいずれかの適用を選択した後、**更正の請求や修正申告によりこの選択を変更することはできません**。」（TA1129）
- 「セルフメディケーション税制の適用を受ける場合には、この特例の対象となる特定一般用医薬品等購入費以外の医療費の額が通常の医療費控除の適用下限額（10万円と総所得金額等の5パーセント相当額のいずれか低い方の金額）を超える場合であっても、通常の医療費控除を併せて受けることはできません。」（TA1131）
- 控除額：「実際に支払った特定一般用医薬品等購入費の合計額（保険金などで補填される部分を除きます。）から12,000円を差し引いた金額（最高88,000円）」「一定の取組（人間ドックなど）に要した費用は、セルフメディケーション税制による医療費控除の対象となりません。」（TA1129）
- 「申告される方が『一定の取組』を行っている必要があります（申告される方と生計を一にする配偶者その他の親族の方が『一定の取組』を行っている必要はありません。）」（TA1129・TA1133）。厚労QA Q16「申請者の子どもが受けた予防接種は『一定の取組』に該当しません」。
- 特集セルフ（注）：「セルフメディケーション税制の対象となる医薬品の購入費用であるもののうち、それが治療や療養に必要な医薬品の購入の対価であるものについては、通常の医療費控除を受けることを選択した場合の控除の対象となる医療費にも該当します。」
- 提出書類（TA1129）：「令和3年分以後のセルフメディケーション税制の適用に関する事項を記載した確定申告書を令和4年1月1日以後に提出する場合は」セルフメディケーション税制の明細書を添付。取組を行ったことを明らかにする書類は「確定申告書への添付または提示は不要ですが、確定申告期限等から5年を経過する日までの間、税務署から提示または提出を求める場合があります。」領収書も同じく5年間提示・提出を求める場合がある。
- 根拠（TA1129 の原文）：「所法73、120、所令262、措法41の17、措令26の27の3、措規19の10の2の2、平28厚生労働省告示第178号、第181号、平成29年改正法附則58、令和3年改正措法附則38」。

| QA05/82「姉の子供の医療費を支払った場合」 | 姉の子供は3親等の血族で親族（民法第725条：6親等内の血族、配偶者、3親等内の姻族）。生計を一にするなど他の要件を満たせば対象 |
| QA05/57「死亡した父親の医療費」 | 父の死亡後に相続人である長男が支払った入院加療期間の医療費は、被相続人の準確定申告では控除できない（被相続人が支払ったことにならない）。「医療費を支出すべき事由が生じた時、**すなわち、その医療費の請求の基となった治療等を被相続人である父親が受けた時**に、長男と父親が生計を一にしていたのであれば、その医療費は、相続人である長男の医療費控除の対象となります。」 |
| 厚労QA Q13「同一世帯の中に、従来の医療費控除により申告する人と、この税制により申告する人がいて構いませんか」 | 「同一世帯であっても、それぞれの方が自己の負担した対象医療費について所得控除を申告することができます。なお、**同一の医療費について重複して控除を受けることはできません**。」 |

- 「同じ医療費を2人で控除できない」ことを**国税庁が直接書いた原文（通達・TA・質疑応答事例）は、今回取得した範囲では見つからなかった**。厚生労働省の Q&A（Q13）には書かれている。国税庁の資料は、どれも「実際に支払った者」の控除の対象とする書き方（上の表）。
- 1件の医療費を2人で分けて支払った場合の扱いを書いた国税庁の資料は見つからなかった。

## 8. 年分への帰属と、医療費に当たるか（質疑応答事例）[QA]

いずれも「令和7年8月1日現在の法令・通達等に基づいて作成」。

| 事例 | 原文の要点 |
|---|---|
| QA05/24 未払の医療費 | 昨年治療を終えた50万円のうち昨年支払った30万円は昨年分、今年支払った20万円は本年分 |
| QA05/81 借入金で支払った医療費 | 借入金で支払った年分の医療費控除の対象（未払ではない） |
| QA05/86 入院時に病院へ支払った保証金 | 12月に支払った保証金10万円が翌年1月の退院時に入院費用に充当された場合、「入院費用に充当された年分の医療費控除の対象」（＝翌年分） |
| QA05/72 特定健康診査と特定保健指導が年をまたがって行われた場合 | 昨年12月に支払った特定健康診査の自己負担額は、本年に基準該当で特定保健指導（積極的支援）を受けた結果、医療費に該当するものとして扱われ、**昨年分**の医療費控除の対象（支払った年）。特定健康診査に代えて人間ドックを受けた場合も同様。厚生労働省は領収書に所定事項（特定健康診査の実施機関・医師名、基準該当の判定、特定保健指導の実施年度、自己負担額など）を記載するよう周知 |
| QA05/09 人間ドックの費用 | 対象外。ただし重大な疾病が発見され引き続き治療を行った場合は対象（通達73−4） |
| QA05/12 かぜ薬の購入費用 | 医師の処方や指示がなくても、かぜの治療のために使用した一般的な医薬品の購入費用は対象 |
| QA05/39 漢方薬やビタミン剤の購入費用 | 医薬品であることに加え、治療又は療養に必要なものであることが必要 |
| QA05/21 病院に収容されるためのタクシー代 | 突然の陣痛でタクシーで入院した場合は対象。一般にはタクシー代の全額が対象ではないが、病状からみて急を要する場合や電車・バス等が利用できない場合は全額が対象 |
| QA05/50 自家用車で通院する場合のガソリン代等 | 対象外。通院費は「電車賃やバス賃などのように人的役務の提供の対価として支出されるもの」 |
| QA05/20 患者の世話のための家族の交通費 | 子供の通院に親が付き添う場合など、患者を一人で通院させることが危険な場合は付添人の交通費も対象。入院中の子供の世話のための親の交通費は対象外 |
| QA05/16 差額ベッド料 | 自己の都合により個室を使用する場合の差額ベッド料は対象外 |
| QA05/18 入院患者の食事代 | 病院に支払う食事代は入院の対価で、通常必要なものは対象。出前・外食・おやつ代は対象外 |
| QA05/53 眼鏡の購入費用 | 一般的な近視・遠視の矯正は対象外。医師の治療等を受けるため直接必要なもの（例：白内障の患者の視機能回復、医師の指示による子供の視力の発育のための眼鏡）は対象 |
| QA05/54 寝たきりの者のおむつ代 | 「おむつ使用証明書」で医師による治療を受けるため直接必要な費用であることが明らかにされたものは対象（おおむね6か月以上寝たきりで医師の治療を受けている者） |
| QA05/42 親族に支払う療養上の世話の費用 | 入院中の親の付添いをした子に支払う謝礼は対象外（「特に依頼した者」は原則として家政婦等人的役務の提供を業とする者） |

- 質疑応答事例（所得税）の目次 https://www.nta.go.jp/law/shitsugi/shotoku/01.htm （LM 2025-12-03、SHA-256 先頭16桁 265c6c375a970b70）の「医療費控除」の節には **59件**（目次の通し番号 6〜64。1〜5 は前の節「雑損控除」）。（独立検証で訂正：もとは「64件（目次の番号）」と書いていたが、64 は通し番号の最後の番号で、件数ではない。実測 `docs/measurements/20261109_impl-prep_iryohi-verification.md` の V-NM-1。）上の表と §4・§7 で取り上げた以外の事例（歯列矯正、不妊治療、出産関係、介護サービス、寝具・氷枕、帰宅旅費、転地療養など）は本文を読んでいない。

## 9. 分からなかったこと

- **5%の円未満の端数の扱い**：様式（E 欄「D×0.05（赤字のときは0円）」）、手引き、TA に書かれていない。法令にもない（[LAW] §6）。作成コーナーの計算はサーバー側で行われ（`docs/measurements/20261109_sakusei-corner_client-analysis.md` §5）、ブラウザからは確かめられない。
- **同じ医療費を2人で控除できないこと**を国税庁が直接書いた原文（§7）。1件を2人で分けて支払った場合の扱い。
- クレジットカード・口座振替・家族の共有口座から支払った場合の「支払った者」と「支払日」を書いた国税庁の資料は、今回取得した範囲では見つからなかった（質疑応答事例の医療費控除の目次にも該当する題名がない）。
- 告示181 の第2号（予防接種）の文言が、TA1133 の記載（インフルエンザに関する特定感染症予防指針）から現行（急性呼吸器感染症に関する特定感染症予防指針）に変わった時期と、令和7年分・令和8年分のどちらから適用されるか。告示の改正文そのものは取得していない。
- 令和3年厚生労働省告示第252号（経過措置の末日）は、厚生労働省の事務連絡に引用された文言で確かめただけで、告示の原文（官報）は取得していない（官報は自動取得しない約束）。
- ~~セルフメディケーション税制の明細書の記載要領（017-ki.pdf）の本文（文字が表示されず読めなかった）。~~ → 独立検証で読めた（§5.4、実測 `docs/measurements/20261109_impl-prep_iryohi-verification.md` の V-NM-3）。
