## 5. e-Tax の仕様書本体（CAB）を取得しなかった理由（判断の記録）

1. 規約：仕様書ダウンロードコーナーの「e-Tax等仕様公開に当たっての注意事項」を原文で確認した（public-sources §8.1）。リバースエンジニアリングの禁止や利用目的の制限はなく、規約上の支障は見つからなかった。
2. 技術：配布は CAB 形式（F：一覧ページの文言）。Python 標準ライブラリに CAB の展開機能はない。展開には `expand.exe`（Windows 付属）などの外部ツールを信頼できないファイルに使う必要がある。ツールの安全性（CAB 内のファイル名にパスが含まれる場合の扱いなど）を確かめていないので、ユーザーのグローバル指示（ツールは使う前に安全性を確認）に従い、今回は使わなかった。
3. 時期：令和8年分（令和9年1月受付開始）の確定版と XML スキーマは 2026-11-25 に掲載予定（F）。今取得できるのはドラフト版。
4. 必要性：出力層の最小の形の仮説（`docs/hypotheses/20261109_impl-prep_output-minimal-layer.md`）では e-Tax の XML を作らない。

## 6. 限界

- 第一表・第二表の欄コードは画像からの転記。原本との突き合わせは、実装でこの一覧を使う前に、もう一度行う必要がある。（2026-11-09 独立検証：別の検証者が 01.pdf の画像と全部突き合わせ、欄番号・欄コード・単位の印字は一致した。欄名の「住所」2か所だけを「納税地」に訂正。様式ID の `K` の次の文字は画像では 0 か O か区別できない）
