# R3 推測：D9 の監視の組み方と、記録層・判定コアへの影響

- 作成日：2026-11-09
- 前提とする仮説：`docs/hypotheses/20261109_R3-tsutatsu_record-facts-and-monitoring.md`（以下 H1〜H3）

## I1 毎日の監視は「一覧ページの条件付き GET → 抽出テキストの差分」で足りる（H3 から）

推測の内容：
- 監視対象（1日1回）：
  1. 厚労省 法令等データベース「登載準備中の新着通知」（iframe の newindex.html。URL は公開資料 `docs/public-sources/20261109_R3-tsutatsu_monitoring-sources.md` §1.2）（保険局・年金局の節）
  2. 厚労省 新着情報の RSS（URL は公開資料 `docs/public-sources/20261109_R3-tsutatsu_monitoring-sources.md` §1.1）（報道発表・審議会資料。制度改正の予告を拾う）
  3. 国税庁 新着情報、所得税基本通達の一部改正通達の一覧、源泉徴収義務者向けの新着・税制改正（URL は公開資料 `docs/public-sources/20261109_R3-tsutatsu_monitoring-sources.md` §2）
  4. 日本年金機構 新着情報一覧（URL は公開資料 `docs/public-sources/20261109_R3-tsutatsu_monitoring-sources.md` §3）
  5. 判定に使う TA（1120、1177、1180、1500 など）と通達のページ（2−47、35−2、45−1・2、73−1〜10 のページ）
  6. （任意）e-Gov パブリックコメント RSS（URL は公開資料 `docs/public-sources/20261109_R3-tsutatsu_monitoring-sources.md` §5）
- 1回の監視で約10〜15リクエスト。304 が大半なら、取得量はほぼヘッダだけになる。
- 200 が返ったら、本文から抽出したテキスト（画像の alt を含む）を前回と比べ、変化があれば issue を作る。国税庁はソフト404を返すので、タイトルに「指定されたページを表示できませんでした」が出たら「削除・移動」として issue にする。
- 厚労省の RSS の利用条件（再配布の禁止）があるので、公開リポジトリの issue にはフィードの本文を転載せず、タイトルと URL の参照にとどめるのが無難。

検証方法：
- `scripts/R3_monitor_probe.py` を2週間、1日1回実行し、各候補について「304 の割合」「200 だったときに抽出テキストが実際に変わった割合（偽陽性率）」「検知した変化のうち税・社会保険の扶養に関係したもの」を記録する。抽出テキストの比較機能は probe にまだないので、追加して実測する。
- 2週間の間に厚労省の通知のデータベース定期更新（毎月）が1回入るはずなので、「登載準備中」から項目が消えることを観測し、消えた通知が `t_doc` で引けることを確認する。

## I2 Last-Modified だけで変化を判定すると偽陽性が多い（H3 から）

推測の内容：TA 8件の Last-Modified が同じ時刻（2026-09-09 01:00 前後）にそろっていたのは、サイト全体の再生成などによるもので、本文は変わっていない可能性が高い。

検証方法：次に Last-Modified が変わったときに、前回保存した HTML から抽出したテキストと新しいものを比べる。一致すれば推測どおり。

## I3 被扶養者の判定は、中間表現に「見込み・契約」の事実を入れないと書けない（H1・H2 から）

推測の内容：
- 中間表現（D5）は入出金の集計値だけでなく、「労働契約の内容（時給、所定時間・日数、手当の額、契約期間）」「今後1年間の収入見込み（人が入力）」「認定日」を持つ必要がある。これは D3 の「事実だけ」に反しない（契約書・労働条件通知書は事実の記録）が、見込み額は人の判断（D4）として扱うのが妥当。
- 判定コアのパラメータは、税は「年分」、被扶養者は「認定日」をキーにする必要がある。

検証方法：
- 厚労省 Q&A の例（19〜23歳 Q&A の Q4「N年10月に19歳」、労働契約 Q&A の Q2・Q4・Q9）と国税庁 Q&A の例（令和8年分 Q1−3「11月30日以前に最後の給与」）をテストケースに書き起こし、中間表現のスキーマ案でこれらを表現できるかを確かめる（スキーマ案を作る段階で実施）。

## I4 国税庁の改正は施行の数か月前に公表されるので、毎日の監視で十分間に合う（H3 から）

推測の内容：令和8年度改正の Q&A は令和8年5月、施行は令和8年12月1日。令和7年度改正の Q&A は令和7年5月30日、施行は令和7年12月1日。厚労省の150万円の通知は令和7年7月4日発出で10月1日適用、労働契約の通知は令和7年10月1日発出で令和8年4月1日適用。いずれも3か月以上の余裕がある。

検証方法：今後の改正について、通知・Q&A の公表日（監視で検知した日）と適用日の差を記録し続ける。3か月を切る例が出たら監視の頻度や手順を見直す。
