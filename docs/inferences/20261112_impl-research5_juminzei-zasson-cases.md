# impl-research5 推測：住民税の雑損失の繰越控除の計算例（ユニットテストの期待値）

前提の仮説：`docs/hypotheses/20261112_impl-research5_juminzei-zasson-and-46-5.md` H1・H2（条文は ［PS］ `docs/public-sources/20261112_impl-research5_juminzei-zasson-and-46-5.md` §1）。

| 例 | 計算 | 結果 |
|---|---|---|
| J1 分離課税に係る退職所得なし：総所得 300,000・退職所得金額 100,000、雑損失 800,000 | 総所得金額 → 退職所得金額（施行令第48条の3第1項第2号ホ） | 控除 400,000（所得税と同じ） |
| J2 分離課税に係る退職所得 100,000（前年の所得に入らない）：総所得 300,000、雑損失 800,000 | 総所得金額だけから | 控除 300,000、500,000 は翌年度以後に残る（所得税は 400,000 を控除） |
| J3 総所得 0・上場配当 1,000,000・上場譲渡 1,000,000、雑損失 1,500,000 | 総所得 → 上場配当 → 上場譲渡（H1） | 上場配当 0・上場譲渡 500,000 |
| J4 総所得 600,000・退職 200,000、純損失 1,000,000、雑損失 300,000 | 純損失が先に全部を使う | 雑損失の控除 0 |
| J5 J4 で純損失 500,000 | 総所得の残り 100,000・退職 200,000 | 雑損失の控除 300,000 |
| J6 令和9年度分：令和8年度の記録に 2025年の損失 300,000・2024年の損失 100,000 | 前年前3年内（2023〜2025年）。2024年の損失は令和7年度・令和8年度の申告書（確定申告書を含む）が要る | 400,000 |
| J7 令和9年度分：2023年の損失で、令和6年度・令和7年度の申告書の記録がない | 連続して提出しているときに限る（第313条第9項） | 繰越なし（入力の不足）。2023年分・2024年分の確定申告書があれば 300,000 |

検証の方法：ユニットテスト `packages/core/tests/test_juminzei_zasson.py`。J2 の住民税の繰越の残り（500,000）は市町村の税額決定通知書・住民税の申告書の記載と照らす
（様式の欄の有無は ［PS］§3 で未確認）。
