# 仮説（impl-research joto-junjo）：分離課税と所得控除・雑損失の控除の順序のモデル

- 作成：2026-11-11。根拠：［PS-JJ］`docs/public-sources/20261111_impl-research_joto-junjo-laws.md`、［M-2C］`docs/measurements/20261111_impl-research_phase2c-fetch-and-checks.md`、［M-V］`docs/measurements/20261111_impl-research_phase2c-verification.md`、［PS-K］`docs/public-sources/20261109_round2b_kabu-law-and-nta.md`。
- 対象：総合課税と、上場株式等の配当（申告分離）、一般株式等・上場株式等の譲渡。土地建物等の譲渡・先物・山林は対象外（D20）。

## H1 控除の順序（所得控除・雑損失の繰越控除）

控除すべき金額は次の順で引く。雑損失の繰越控除が先、所得控除（雑損控除を先に。所法87①）が後。

1. 純損失の繰越控除：総合課税の総所得金額にだけ（所法70 は措法8の4③三・37の10⑥五の読替えの対象外。［PS-JJ］§1・§2）。所令201 の順序で山林、退職へ流れる（対象外の分は別）。
2. 雑損失の繰越控除：所令204①二 を読替えたもの。`総所得金額 → 上場株式等に係る配当所得等の金額 → 上場株式等に係る譲渡所得等の金額 → （一般株式等に係る譲渡所得等）→ 山林所得 → 退職所得`（措令4の2⑨、25の8⑯、25の11の2⑳）。
3. 所得控除：所法87② を読替えたもの。`総所得金額 → 配当 → 譲渡 → 山林 → 退職` の順に引くと仮定する。

根拠：［PS-JJ］§1・§2。

## H2 複数の読替えが同時にある場合の順序の扱い

- 法令は読替えを別々に書いているので、同時に適用されるときの前後の順序は明文がない（［PS-JJ］§4）。措令25の11の2⑳の表（損益通算・繰越控除の適用があるとき）は `総所得金額、上場株式等に係る配当所得等の金額、上場株式等に係る譲渡所得等の金額` の順。第三表の行の順は 株式等の譲渡（81）→ 配当（82）。
- 提案：雑損失の繰越控除には⑳の順を使い、所得控除も同じ順に揃える（根拠の種類：「法令の読み」。支えが同程度なら両方で評価する D22 S1 には当たらないと判断する。第三表の行の順は順序の説明ではないため）。結果が1,000円未満の切捨ての差だけで変わるときは、D22 S3 に従い金額を幅で返す。
- 配当と譲渡は税率が同じ（15%。［PS-K］）なので、順序で変わるのは千円未満の切捨て（行ごと）の影響だけになる見込み（計算の確かめは推測の文書）。

## H3 所法120 の読替え（申告書の記載事項）

- 所法120 の「総所得金額」「課税総所得金額」「第三章（税額の計算）」は、措令4の2⑧・25の8⑮・25の9⑬ により分離の所得を含める読みで使う。実装では「確定申告の要否・記載事項の判定」で、総所得金額の代わりに読替え後の合計を使う。根拠：［PS-JJ］§2。
- 適用後の金額：上場株式等の配当所得等の金額・譲渡所得等の金額は、損益通算・繰越控除の適用がある場合はその適用後（措令25の11の2⑰⑱）。根拠：［PS-JJ］§2.3。
- 所法121 の読替え（課税総所得金額に分離分を含める）：［PS-JJ］§2.1、`docs/hypotheses/20261111_impl-research_121-model.md`。
