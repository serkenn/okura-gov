## 6. 作業中に気づいたこと

1. 国保令第29条の7・地法第703条の4は、令和8年度の改正で**項番号が繰り下がった**（減額賦課 第5項→第6項、擬制世帯主 第28項→第38項）。条・項番号を根拠として持つときは、版（年度）とセットにしないと取り違える。
2. Bash の `grep -E` で `[二七]` のような複数バイト文字の文字クラスが一致しなかった（Git Bash の環境）。値の取り出しは Python の正規表現で行った（`scripts/R2X_kokuho_values.py`）。
3. 国保税の 65歳以上の公的年金の 15万円の特例は地令ではなく**地法の附則（第35条の5）**、125万円の読み替えは**地令の附則（第18条の8）**にある。料では両方とも国保令の附則第5条。料と税で置き場所が違う。
4. 軽減の判定で「給与所得を有する者」の数に入る収入の要件（給与等の収入金額55万円超）は、令和7年分以後の給与所得控除の最低額（65万円）の引上げの後の版（2026-04-01・2026-11-09）でも 55万円のままだった。
