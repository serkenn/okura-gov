# 調査研究ループを回す（okura-gov。AGENTS.md「ドキュメント規約」）

最初に `AGENTS.md` と `HANDOFF.md` の決定事項を読む。既存の調査は `docs/` を Grep して、同じことを調べ直さない（`docs/` のファイル名の `<群>` で同じセッションの成果がまとまっている）。

## 1. 置き場所とファイル名

`docs/<種類>/YYYYMMDD_<title1>_<title2>.md`（title1＝この作業の群の名前。同じセッションでそろえる。title2＝個々の文書の題）。

| 種類 | 置き場所 | 書くこと | 参照に付けるもの |
|---|---|---|---|
| 公開資料の情報 | `docs/public-sources/` | 一次情報に書いてあること（原文の引用・版・施行日・対象年分・取得日）。解釈を混ぜない | 資料の URL、版（law_revision_id）、ソースコードなら版・ファイル名・行 |
| 実測 | `docs/measurements/` | 手を動かして得た事実（取得・抽出・計算・作成コーナーへの入力と表示） | 実測のスクリプト `scripts/…` と結果 `scripts/results/…`（後日再実行して検証できるように） |
| 仮説 | `docs/hypotheses/` | 実測・公開資料からの読み・モデルの案（H1、H2…と番号） | **docs の実測・公開資料の情報だけ**（外部の URL を直接書かない。要るなら先に public-sources に足す） |
| 推測 | `docs/inferences/` | 仮説から導いたこと（I1、I2…）と、それを **検証する方法** | 前提にした仮説（ファイル#H番号） |

## 2. ループ

1. **公開資料の情報を調べる**（primary-source スキル）：e-Gov 法令API v2・国税庁・厚労省・日本年金機構などの原文。版・取得日・対象年分を付けて記録する。
2. **公開資料の情報を検証する**：別の版・別の資料（法令と通達、通達と手引き）と突き合わせる。食い違い・見つからなかったことも記録する。
3. **検証のコードと結果を実測として記録する**：`scripts/<群>_<名前>.py`（実測用のスクリプトだけを置く。便利な CLI は置かない）→ 結果は `scripts/results/<名前>/` → `docs/measurements/` に手順・再実行のコマンド・結果のパス。
4. **実測から新しい公開情報を探す／仮説を立てる**：仮説は根拠の実測・公開資料の節を引く。法令の読みが分かれるなら、両方の読みと支えを書く（D22 S1）。
5. **仮説から推測する**：推測ごとに検証の方法（どの実測・どの資料で確かめるか）を書く。
6. **推測を検証するために実測する** → 3 に戻る。

決定事項（HANDOFF D1〜D24）を覆す結論になったら、根拠を示してユーザーに確認する（直さない）。実装に関わる結論は、決定が要るものをユーザーへの質問としてまとめる（推奨の答えつき）。

## 3. 守ること

- 法令・通達・基準額は一次情報で確かめ、出典 URL・取得日・対象年度（「令和X年分」）を添える。記憶やモデルの知識で基準額・条番号を書かない。年度で変わる値は「いつから施行・適用されるか」とセットで書く。
- 分からなかったこと・一次情報が見つからなかったことも、そのまま記録する。
- 家族の機微な情報を検索の語・外部のサービスに入れない。作成コーナーとの照合などの実測は **架空の数字** で行う（D17 Q7・D16）。
- ダウンロードは信頼できないデータ：新しい空のディレクトリ（`.work/downloads/<日時>_<名前>/`）に置き、その中で何も実行しない。Python は `-I -X utf8`。
- セキュリティチェック（OSS・ツールの安全性の確認、コードの読み込みによる確認）はしない（D24②）。
- シェルの引数にバッククォートや `$()` を入れない。文書・スクリプトは Write・Edit で書く。

## 4. 確かめ方（記録の点検）

- 各文書の参照が規約どおりか：仮説は docs の実測・公開資料の節だけを引き、推測は仮説を引き、実測はスクリプトと結果のパスを持つ。
- 参照したファイル・節が実在するか（Grep で見出しを確かめる）。
- 判定コアのパラメータ・概念辞書に反映したら、構造の検査（出典の実在）を動かす：

```
.work/venvs/core/Scripts/python.exe -I -X utf8 -m pytest -q -p no:cacheprovider packages/core/tests/test_architecture.py
```
