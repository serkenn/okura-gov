## 3. 反証の探索

| 主張 | 探したもの | 結果 |
|---|---|---|
| 給与の年分は 36−9 の日（支給日）で決まり、支払日ではない | 36−9 のページで「支給を受けた日」を原則とする書き方（定めがない場合の補充としてだけ出てくることの確認）、質疑応答事例で「支払日の属する年」とする書き方 | 見つからない。「支給を受けた日」が出てくるのは (1) と (4) で支給日が定められていない場合だけ |
| 死亡後に支給期の到来する給与は所得税を課さない（相続財産） | 3−33 が「退職手当金等に該当する」としていないか、9−17 の要件の書き方 | 3−33 は「退職手当金等には該当しないで、本来の相続財産に属する」。9−17 は「相続税の課税価格計算の基礎に算入されるもの」の条件付き。質疑応答事例2件は条件を付けずに書く（［PS-KJ］§3）。食い違いではないが、条件の当てはめは確かめられていない（下の §4） |
| 未払の給与もその年分の収入（源泉徴収票の支払金額に内書き） | 手引 令和7年分 PDF（目視、PDF 4頁）と令和8年分 HTML | 両方とも「支払の確定した給与等の総額」「未払額を内書き」。令和8年分の PDF（`tebiki2026_all`）は PDF 4頁が別の内容（提出範囲の改正）で、「支払金額」欄の頁は探していない |
| 36−9 の内容が令和7年分・令和8年分の間に変わっていない | 36−9 の改正の注記（昭63・平19 の改正の記載だけ）、ページの Last-Modified 2025-11-25 | 令和以後の改正の注記はない。ただしページの Last-Modified より前の版を取っていないので、2025-11-25 の更新で 36−9 が変わったかは確認できなかった（変わったとしても取得した文が令和7年分の申告の時点の通達） |

## 4. 確認できなかったこと

1. 支給日が死亡の日と同じ日の扱い（［PS-KJ］§4-1）。取り直した一次情報のどれにも書かれていない。
2. 9−17 の「相続税の課税価格計算の基礎に算入されるもの」に、相続税がかからない（基礎控除以下）場合も含まれるか。相続税法の課税価格の条文は取得していない。
3. 未払のまま支払われなくなった給与、未払の給与の源泉徴収税額の年分（［PS-KJ］§4-4、［H-KJ］UJ3・UJ4）。
4. 令和8年分の法定調書の手引 PDF の「支払金額」欄の頁（HTML 版で代えた）。
