## 1. 均等割の非課税の基準（調べること1）

### 1.1 法律（F）

- 地方税法第295条第3項：「市町村は、この法律の施行地に住所を有する者で均等割のみを課すべきもののうち、前年の合計所得金額が
  **政令で定める基準に従い当該市町村の条例で定める金額以下**である者に対しては、均等割を課することができない。」
- 道府県民税：地方税法第24条の5第3項：「道府県は、第二百九十五条第三項の規定により個人の市町村民税の均等割を課することが
  できないこととされる者に対しては、当該均等割と併せて賦課徴収すべき個人の道府県民税の均等割を課することができない。」
  → 道府県民税の均等割は、市町村の判定に従う。

### 1.2 政令（F）：地方税法施行令第47条の3（見出し「法第二百九十五条第三項の政令で定める基準」）

> 一　法第二百九十五条第三項の市町村の条例で定める金額は、当該条例で**基本額**として定める一定金額に、同項に規定する法の施行地に住所を
> 有する者の同一生計配偶者及び扶養親族（**年齢十六歳未満の者及び法第三百十四条の二第一項第十一号に規定する控除対象扶養親族に限る**。
> 以下この号において同じ。）の数に一を加えた数を乗じて得た金額に、**十万円を加算**した金額（その者が同一生計配偶者又は扶養親族を
> 有する場合には、当該金額に当該条例で**加算額**として定める一定金額を加算した金額）とするものとすること。
> 二　前号の基本額として定める一定金額は、**三十五万円を超えない範囲内**において、三十五万円に、生活保護法第八条第一項の規定により
> 厚生労働大臣が定める保護の基準における地域の**級地区分（前年の十二月三十一日における地域の級地区分とする。）**ごとに、総務省令で
> 定める世帯につき前年において同法第十一条第一項第一号から第三号までに掲げる扶助に要した費用として算定される金額を勘案して
> 総務省令で定める率で、当該市町村が同日において該当した当該地域の級地区分に係るものを乗じて得た金額を**参酌して定める**ものとすること。
> 三　第一号の加算額として定める一定金額は、**二十一万円を超えない範囲**において、二十一万円に、前号に規定する総務省令で定める率で
> 当該市町村が前年の十二月三十一日において該当した同号に規定する地域の級地区分に係るものを乗じて得た金額を参酌して定めるものとすること。

### 1.3 省令（F）：地方税法施行規則第9条の21

- 第1項：令第47条の3第2号の「総務省令で定める世帯」は、夫・妻・子2人の世帯、借家に居住、収入のない世帯。
- 第2項：「総務省令で定める率」は、級地区分（前年の12月31日における級地区分）に応じ、**一級地 1.0、二級地 0.9、三級地 0.8**。

## 2. 所得割の非課税（調べること2）

### 2.1 法律（F）：地方税法附則第3条の3（見出し「個人の道府県民税及び市町村民税の所得割の非課税の範囲等」）

- 第4項（市町村民税）：「市町村は、**当分の間**、市町村民税の所得割を課すべき者のうち、その者の前年の所得について第三百十三条の規定により
  算定した**総所得金額、退職所得金額及び山林所得金額の合計額**が、**三十五万円**にその者の同一生計配偶者及び扶養親族（年齢十六歳未満の者及び
  第三百十四条の二第一項第十一号に規定する控除対象扶養親族に限る。以下この項及び次項において同じ。）の数に一を加えた数を乗じて得た金額に
  **十万円**を加算した金額（その者が同一生計配偶者又は扶養親族を有する場合には、当該金額に**三十二万円**を加算した金額）以下である者に対しては、
  第二百九十四条第一項の規定にかかわらず、市町村民税の所得割（分離課税に係る所得割を除く。）を課することができない。」
- 第1項：道府県民税の所得割について同じ形（第32条で算定した額、第34条第1項第11号の控除対象扶養親族）。
- 第2項・第5項：上限をわずかに超える人の所得割額を減らす調整（式は条文どおり。ここでは値を取り出していない）。
- **級地による違いはない**（35万円・10万円・32万円は法律に直接書かれている）。条例に委ねる規定もない。
- 判定に使う金額は「総所得金額等」（第313条で算定した額＝純損失・雑損失の繰越控除の後）で、均等割の非課税・第295条の「合計所得金額」
  （第292条第1項第13号：第313条第8項・第9項の控除**前**）と違う。
- 版：asof 2025-12-31 から 2028-01-01 まで、金額の文言は同じ。変わったのは引用する附則の条番号だけ［実測］§3。
- 札幌市税条例 附則第3条の3 も同じ値（35万円、10万円、32万円）を書いている（F、§1.6 の URL）。
- E：総務省「地方税法の施行に関する取扱いについて（市町村税関係）」（§8.2）第2章第1節第1 の4 が同じ内容を述べる（p.30-31）。

## 3. 未成年者の 135万円と、判定の時点・成年年齢（調べること3）

### 3.1 法律（F）

- 地方税法第295条第1項：「市町村は、次の各号のいずれかに該当する者に対しては市町村民税（第二号に該当する者にあつては、第三百二十八条の規定により
  課する所得割（以下「分離課税に係る所得割」という。）を除く。）を課することができない。ただし、この法律の施行地に住所を有しない者については、この限りでない。」
  - 第1号：生活保護法の規定による生活扶助を受けている者
  - 第2号：**障害者、未成年者、寡婦又はひとり親（これらの者の前年の合計所得金額が百三十五万円を超える場合を除く。）**
- 第295条第2項：判定の時点を定めているのは「分離課税に係る所得割につき前項第一号（生活扶助）」の場合だけ（退職手当等の支払を受けるべき日の属する年の1月1日の現況）。
  **第1項第2号（未成年者など）の判定の時点を直接定めた文言は、第295条にはない**。
- 第318条：「個人の市町村民税の**賦課期日は、当該年度の初日の属する年の一月一日**とする。」
- 地方税法の本則と原始附則（asof 2026-11-09）で「未成年者」は第24条の5 と第295条にしか出てこない（ほかは「未成年者口座」など）。
  **「未成年者」の定義規定は地方税法にない**［実測］§3.3。
- 民法第4条（成年）：「年齢十八歳をもって、成年とする。」（asof 2026-11-09）
  - 平成30年法律第59号 附則第1条：「この法律は、平成三十四年四月一日から施行する。」（＝2022-04-01）。附則第2条第2項：施行の際に18歳以上20歳未満の者は施行日に成年に達する。
- 年齢の数え方は年齢計算ニ関スル法律と民法第143条（既存：`docs/public-sources/20261109_R1-laws_social-insurance-age-records.md` §3）。

### 3.3 分からなかったこと

- 未成年者の判定時点が1月1日であることを**法令の文言で**直接定めた規定は見つからなかった（第318条の賦課期日と取扱通知 32 による）。
- 令和8年度分・令和9年度分について「〇年1月3日以降生まれ」と明示した自治体の資料は取得していない（令和5年度の例だけ）。

## 4. 1人が2人以上の納税義務者の扶養親族等に当たる場合の所属（調べること4、R4 の U6）

### 4.1 法律（F）：地方税法第292条第2項〜第4項（asof 2026-01-01 以後）

- 第2項：納税義務者の配偶者が、その納税義務者の同一生計配偶者に当たり、かつ他の納税義務者の扶養親族にも当たる場合は、「政令で定めるところにより、
  これらのうちいずれか一にのみ該当するものとみなす。」
- 第3項：納税義務者の配偶者が、第314条の2第1項第10号の2 の「生計を一にする配偶者」に当たり、かつ他の納税義務者の**特定親族**にも当たる場合も同じ。
- 第4項：「二以上の市町村民税の納税義務者の扶養親族又は特定親族に該当する者がある場合には、その者は、政令で定めるところにより、これらの納税義務者の
  うちいずれか一の納税義務者の扶養親族又は特定親族にのみ該当するものとみなす。」
- 道府県民税は第23条第2項〜第4項に同じ形の規定がある（施行令第7条の3の3〜第7条の3の5 が対応）。
- 版の違い：asof 2025-12-31 では第3項がなく、旧第3項（いまの第4項）は「扶養親族」だけだった。**特定親族を加えた形は 2026-01-01 から**（令和8年度分から）。

### 4.2 政令（F）：地方税法施行令第46条の3〜第46条の5（asof 2026-01-01 以後）

- 第46条の5（見出し「二以上の納税義務者がある場合の扶養親族及び特定親族の所属」）第1項：いずれの納税義務者の扶養親族又は特定親族とするかは、
  - 法第317条の2第1項の**申告書を提出する義務を有する者**：当該申告書
  - **給与所得等以外の所得を有しなかつた者**（第46条の3第1項の定義：給与支払報告書・公的年金等支払報告書を出す義務がある者から1月1日現在で
    給与・公的年金等を受けていて、前年に給与所得以外または公的年金等に係る所得以外の所得がなかった者）：**給与支払報告書又は公的年金等支払報告書**
  に記載されたところによる。ただし、給与所得等以外の所得を有しなかつた者が、総務省令で定めるところにより、自己の扶養親族又は特定親族とする者の氏名など
  を記載した**申請書**を賦課期日現在の住所所在地の市町村長に提出したときは、当該申請書に記載されたところによる。
- 第46条の5第2項：同一人が2人以上の納税義務者の扶養親族・特定親族として申告書・報告書・申請書に記載されたとき、その他第1項で決まらないときは、
  「当該二以上の納税義務者のうち**前年の法第三百十三条第一項の総所得金額、退職所得金額及び山林所得金額の合計額が最も大きいもの**の扶養親族又は特定親族とする。」
- 第46条の3：配偶者が同一生計配偶者か他の人の扶養親族か → 決まらないときは「その夫又は妻である市町村民税の納税義務者の同一生計配偶者とする。」
- 第46条の4：配偶者が生計を一にする配偶者（特別控除対象配偶者）か他の人の特定親族か → 決まらないときは夫又は妻の特別控除対象配偶者とする。
- 版：asof 2025-12-31 では第46条の4 が「扶養親族の所属」（いまの第46条の5 の前身。特定親族なし）。2026-01-01 から 3条の形［実測］§3。
- 所得税（所令219）との違い：所得税は、決まらないときにまず「既に申告書等で扶養としている居住者」、次に所得最大の居住者

  住民税の申告書の記載とみなされる（同条第2項）。
  - （検証で訂正）元の記述「したがって所得税の確定申告書での扶養の記載は、住民税の第46条の5第1項の「申告書」として働く」は広すぎる。
    第46条の5第1項は、所属を決める書類を**人の区分で**分けている：「法第三百十七条の二第一項の申告書を提出する義務を有する者」は申告書、
    「給与所得等以外の所得を有しなかつた者」（第46条の3第1項の定義：1月1日現在で報告書の提出義務者から給与・公的年金等を受け、前年に給与所得以外・公的年金等に係る所得以外の

    市町村の実務は確認していない**。判定の仮説としては H4 で扱う）。
- 札幌市税条例 第30条第7項（F）：給与・公的年金等の受給者で第30条第1項第1号に当たる者は、給与支払報告書等に記載された扶養控除と異なる控除を
  受けようとする場合、3月15日までに申請書を出せる。

## 6. 住民税の申告が必要な場合・不要な場合（調べること6）

### 6.1 法律・政令（F）

- 地方税法第317条の2第1項本文：第294条第1項第1号の者（市町村内に住所を有する個人）は、**3月15日まで**に、前年の総所得金額等、専従者給与、
  純損失・雑損失、各種の所得控除、寄附金税額控除、扶養親族などを記載した申告書を、**賦課期日現在の住所所在地の市町村長**に提出しなければならない。
- 同項ただし書（申告が要らない者）：
  1. 給与支払報告書・公的年金等支払報告書を出す義務がある者から**1月1日現在において**給与又は公的年金等の支払を受けている者で、**前年中に給与所得以外の所得
     又は公的年金等に係る所得以外の所得を有しなかつたもの**（ただし公的年金等に係る所得以外の所得がなかった者で、社会保険料控除（政令で定めるものを除く）・
     小規模企業共済等掛金控除・生命保険料控除・地震保険料控除・勤労学生控除・配偶者特別控除（一部）・扶養控除（第314条の2第4項の同居老親等の分）・
     特定親族特別控除（85万円以下の特定親族の分を除く）や、これらと併せて雑損控除・医療費控除・純損失等の控除・寄附金税額控除を受けようとする者は除く）
  2. 「**所得割の納税義務を負わないと認められる者のうち当該市町村の条例で定めるもの**」
- 第317条の2第2項：給与支払報告書・公的年金等支払報告書が1月31日までに出されなかった場合、市町村長は1の者を指定して申告書を出させることができる。

  3月15日までに、これらの控除に関する事項を記載した申告書を出さなければならない。

- 第317条の3第1項：前年分の所得税につき**確定申告書を提出した場合**（政令で定める場合を除く）には、当該確定申告書が提出された日に第317条の2第1項〜第4項の
  **申告書が提出されたものとみなす**（同日前に住民税の申告書を出していればその限りでない）。第2項：確定申告書の記載事項（総務省令で定める事項を除く）が住民税の申告書の記載とみなされる。
