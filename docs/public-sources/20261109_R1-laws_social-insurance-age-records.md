## 1. 健康保険の被扶養者：法律で決まっている部分と、委ねている部分

### 法律（健康保険法第3条第7項）で決まっていること

- 「被扶養者」とは、次に掲げる者で、**日本国内に住所を有するもの**又は外国において留学をする学生その他の日本国内に住所を有しないが渡航目的その他の事情を考慮して日本国内に生活の基礎があると認められるものとして**厚生労働省令で定めるもの**。ただし、後期高齢者医療の被保険者等その他**厚生労働省令で定める者**は除く。
  - 第1号：被保険者の直系尊属、配偶者（事実婚を含む）、子、孫及び兄弟姉妹であって、**主としてその被保険者により生計を維持するもの**（同居は要件ではない）
  - 第2号：三親等内の親族で第1号以外のもの：**同一の世帯に属し**、かつ主として生計を維持するもの
  - 第3号・第4号：事実婚の配偶者の父母・子（同一世帯、生計維持）
- 2025-12-31 時点と 2026-11-09 時点で第3条第7項の文言は同じ（差分なし）。

### 省令（健康保険法施行規則）で決まっていること

- 第37条の2：法第3条第7項本文の「厚生労働省令で定めるもの」（国内居住要件の例外）＝ 外国で留学をする学生、外国に赴任する被保険者に同行する者、観光・保養・ボランティア等就労以外の目的で一時的に海外に渡航する者 など5号。
- 第38条：被扶養者届（5日以内。被扶養者の職業、**収入**、住所、氏名、生年月日、続柄などを記載）。

### 金額の基準は法令の本文にない（実測で確認）

`scripts/R1_kenpo_amount_scan.py` で、健康保険法・同施行令・同施行規則・国民年金法・同施行令・同施行規則の本文（本則と附則のすべての文）を検索した結果：
「百三十万」「百五十万」「百八十万」「百六万」はどの法令にも**0件**。「生計を維持」は健康保険法第3条第7項など、国民年金法第7条などに出てくるが、金額は書かれていない。

→ **「主としてその被保険者により生計を維持する」の認定基準（年収130万円未満など、19歳以上23歳未満の150万円未満を含む）は、法律・政令・省令の本文には書かれていない**。どの文書（通知など）で決まっているかは R3 の担当。HANDOFF §6 の「健康保険の被扶養者の基準（130万円など）が、法律ではなく通知で決まっている」は、少なくとも「法令の本文にはない」ところまでは正しい。19歳以上23歳未満150万円の時期（2025年10月とされる）と文書の種類は、R1 では確認していない（R3）。

## 2. 国民年金の第3号被保険者

- 国民年金法第7条第1項第3号：第2号被保険者の**配偶者**（国内居住、または省令で定める海外居住者）であって、**主として第二号被保険者の収入により生計を維持するもの**（20歳以上60歳未満。第8条以下で資格取得の時期等）。
- 第7条第2項：「主として第二号被保険者の収入により生計を維持することの認定に関し必要な事項は、政令で定める。」
- 国民年金法施行令第4条：その認定は、健康保険法・国家公務員共済組合法・地方公務員等共済組合法・私立学校教職員共済法における**被扶養者の認定の取扱いを勘案して日本年金機構が行う**。
- 第3号は配偶者だけが対象。扶養されている子供には直接関係しない（子供は20歳から第1号被保険者。学生納付特例は国民年金法第90条の3。本文は取得済み `kokunen_2026-11-09.txt` だが内容は未整理）。

## 3. 年齢の数え方

- 年齢計算ニ関スル法律（明治35年法律第50号）。条番号のない3項からなる（e-Gov の XML では Paragraph Num 1〜3）。
  - 第1項：「年齢ハ出生ノ日ヨリ之ヲ起算ス」
  - 第2項：「民法第百四十三条ノ規定ハ年齢ノ計算ニ之ヲ準用ス」
  - 第3項：明治6年第36号布告の廃止
- 民法第143条第1項：週・月・年によって期間を定めたときは暦に従って計算する。第2項：週・月・年の初めから期間を起算しないときは、期間は**最後の週・月・年においてその起算日に応当する日の前日に満了**する（応当日がないときはその月の末日）。
- 民法第140条（初日不算入）は、年齢計算ニ関スル法律第1項が「出生ノ日ヨリ起算」と定めているので、年齢には適用されない、と読める（この読みは仮説。`docs/hypotheses/20261109_R1-laws_hypotheses.md` H1）。
- 税法の判定の時点：所得税法第85条第3項（その年12月31日の現況）、第57条第7項（専従者の15歳未満の判定も12月31日の現況）。住民税は地方税法第314条の2第8項（前年12月31日の現況）。

## 4. 記録の保存（電帳法）のうち、個人（事業所得・雑所得のある子供）に関係する部分

- 電帳法第2条：定義。第2号「国税関係帳簿書類」、第4号「保存義務者」（国税に関する法律の規定により国税関係帳簿書類の保存をしなければならないこととされている者）、第5号「電子取引」（取引情報の授受を電磁的方式により行う取引）。
- 電帳法第4条：国税関係帳簿・書類を電磁的記録で保存できる（任意。財務省令＝施行規則第2条で要件）。
- 電帳法第7条：「所得税（源泉徴収に係る所得税を除く。）及び法人税に係る保存義務者は、電子取引を行った場合には、財務省令で定めるところにより、当該電子取引の取引情報に係る電磁的記録を**保存しなければならない**。」（義務）
- 施行規則第4条第1項：電子取引データの保存の要件（タイムスタンプ、訂正削除の記録が残るシステム、訂正削除防止の事務処理規程のいずれか、など）。検索機能の要件は、**基準期間（個人は前々年）の売上高が5,000万円以下**の事業者などで、税務職員の求めに応じてデータを提示・提出できる場合は不要とする趣旨の規定がある（第4条第1項中。全文の要件の組合せは未整理）。第2項：「事業者」に個人事業者（業務を行う個人）を含み、個人の判定期間はその年1月1日〜12月31日。第3項：相当の理由がある場合の猶予（出力書面の提示等）。
- 「保存義務者」に当たるかは所得税法側で決まる：
  - 所得税法第148条：青色申告者の帳簿書類。
  - 所得税法第232条第1項：不動産・事業・山林所得を生ずべき業務を行う白色の者の帳簿の備付け・記録。第2項：**雑所得を生ずべき業務**を行う者で前々年の業務収入が300万円超の者は、総収入金額・必要経費に関する書類を保存。
- 記録層の設計への含意（事実の整理のみ）：子供が事業所得や業務に係る雑所得を持ち、取引情報を電子で受け取った場合（ネットでの売上明細、電子の領収書など）、第7条の保存の対象になり得る。どの範囲が対象になるかの通達・Q&A は R3。
