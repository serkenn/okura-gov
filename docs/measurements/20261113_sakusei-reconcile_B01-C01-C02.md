## 4. 操作で分かったこと（スキルに反映した）

- **作成コーナーは、ブラウザの標準のダイアログ（confirm・alert）を出す場面がある**（決算書作成の印刷の画面で「次へ進む」、決算書の「表示・印刷」など）。出ると、ブラウザのツールの操作も JS も止まる（タブを閉じるしかない。C01 は2回、C02・B01 は各1回、やり直した・観測を画面に切り替えた）。
  クリックの前に、そのページで `window.confirm=()=>true; window.alert=()=>{};` を実行しておくと、そのページ自身のダイアログは止まらない。次のページの読み込み時に出るもの・別の枠（iframe）から出るものは防げない。
- 決算書作成の中の「決算書等表示・印刷」は押さない（ダイアログで止まる）。所得税の申告書の PDF には決算書・収支内訳書は入らない（提出書類の案内に別に書かれる）ので、決算書の値は入力画面・所得金額の確認の画面で読む。
- 申告書の PDF の「申告書等を表示・印刷する」は、1回目のクリック（ページの移動の直後）は効かず、2回目で落ちることが多い。2回目でも落ちず、そのあと JS が止まったら、ダイアログが出ている。
- 「作成開始」のあとの「自動再生中」（案内の動き）は 30秒〜2分かかることがある。終わるまで待つ。
- 画面で読んだ値は円で表示される。単位のある欄（基礎控除・課税される所得金額・第3期分の税額など）は、欄に書く形（値 ÷ 単位）に直して記入表に書いた。
