# R1 推測：判定コアのパラメータと監視の設計への当てはめ

- 作成日：2026-11-09
- 種別：仮説をもとにした推測
- 前提の仮説：`docs/hypotheses/20261109_R1-laws_hypotheses.md` の H1〜H5

## I1 OpenFisca のパラメータは「年分の1月1日」で切り替える（前提：H2）

- 推測：扶養親族の所得要件は `2024-01-01: 480000`、`2025-01-01: 580000`、`2026-01-01: 620000` のように、年分の1月1日の日付で持てば、年分の判定が正しくなる。基礎控除の加算（措法第41条の16の2）、給与所得控除の最低額（措法第29条の4、令和8・9年のみ）も同じ扱い。措法第29条の4は令和10年分で効力がなくなる（条文が「令和八年又は令和九年において」）ので、`2028-01-01` に所得税法本則の値へ戻す必要がある。
- 源泉徴収の計算を扱う場合は、別の日付の軸（支払日）を持つパラメータが必要になる。
- 検証方法：`docs/measurements/20261109_R1-laws_article-extraction.md` §4 の照合表（国税庁資料の給与収入の境目）をテストケースにし、年分ごとに OpenFisca で計算させて一致を確かめる（例：令和8年分は措法第29条の4第2項の式が直接決まるので、給与収入 1,360,000円 → 扶養親族に該当、1,360,001円 → 非該当。令和7年分の 1,230,000円付近は、所得税法別表第五の刻みで給与所得が決まるため、別表第五を確認してから境目のテストケースを決める）。

## I2 1月1日生まれの子の年齢区分（前提：H1）

- 推測：H1 により、平成19年（2007年）1月1日生まれの子は 2025-12-31 の終了時に19歳になる。国税庁が「12月31日の現況」にこれを含める扱いなら、令和7年分では19歳（特定扶養親族・特定親族の年齢範囲）に入る。
- 判定コアには、生年月日と判定日から年齢を出す関数を1か所だけ作り、「誕生日の前日の終了で加算」と「判定日の終了時点を含むか」を明示的な引数にしておく。
- 検証方法：国税庁の年末調整の資料（R3 で取得するもの）にある「特定扶養親族＝平成X年1月2日から平成Y年1月1日までに生まれた人」のような生年月日の範囲と、関数の結果を照合する。

## I3 監視ジョブの形（前提：H3、H4）

- 推測：毎日1回、次を行えば、法令本文の変更から issue を作れる。
  1. 監視対象の法令ID一覧（所得税法 340AC0000000033、同施行令 340CO0000000096、同施行規則 340M50000040011、租税特別措置法 332AC0000000026、同施行令・施行規則、地方税法 325AC0000000226、同施行令、健康保険法 211AC0000000070、同施行令・施行規則、国民年金法・同施行令、電子帳簿保存法・同施行規則、年齢計算ニ関スル法律、民法）について `/law_revisions/{id}?updated_from=<前回確認日>` を問い合わせる（法令あたり1リクエスト、1.5秒間隔で約30秒）。
  2. 新しい `law_revision_id` があれば、その版と直前の版の本文（`/law_data/{revision_id}`）を取り、監視対象の条（パラメータの出典の条）の差分を取る。差分があれば issue を作る。issue には施行日、`current_revision_status`、改正法の附則のうち適用関係の部分を貼る。
  3. 一括ダウンロードの日次 CSV（ZIP の中の CSV だけを読む）で、監視対象外の法令に「所得税」「扶養」などを含む新規・改正がないかを見る（ZIP が大きい日があるので、必要なら週1回）。
  4. 施行日が「令和九十九年」などの仮の値の行は「施行日未定」として扱う。
- issue の「影響する層」（D9）の初期値：所得税法・措置法・地方税法の改正 → 判定コア（パラメータ・計算式）。定義（第2条）の改正 → 中間表現にも影響の可能性あり、と書く。
- 検証方法：令和9年度の税制改正（大綱は 2026年12月、改正法の公布は 2027年3月末の見込み）でこのジョブを動かし、①公布日と、日次 CSV・`/law_revisions` に版が初めて現れた日の差（登録の遅れ）、②監視対象の条の差分が正しく取れたか、を記録する。遅れが長ければ（例えば数週間）、公布直後の検知のために財務省・国税庁のページの変化の監視を追加する。

## I4 被扶養者（社会保険）の判定コアの分け方（前提：H5）

- 推測：社会保険の被扶養者の判定は、①法令（健康保険法第3条第7項）由来の構造部分（続柄・同一世帯・国内居住）と、②通知由来の収入基準（年齢・障害の有無などで変わる額）を別のモジュール・パラメータ群に分けると、通知の変更（法令API で検知できない）と法令の変更を別々に監視・修正できる。
- 検証方法：R3 の成果（通知の名称・日付・基準額）が出たら、通知の改正履歴（過去の基準額の変更）を当てはめ、②だけの変更で済むことを確かめる。
