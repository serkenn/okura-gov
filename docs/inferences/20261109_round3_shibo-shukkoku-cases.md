## SI1 令和8年分の死亡の申告は、2026-11-30 に出すか 2026-12-01 に出すかで、基礎控除と扶養の判定が変わる

- 前提：SH7、SH4-7。
- 推測（2026年に本人が死亡。本人の合計所得金額 200万円。死亡の時に見積もった親族の合計所得金額 60万円）：

| 提出日 | 基礎控除 | 親族は扶養親族か | 判定コアが出すもの |
|---|---|---|---|
| 2026-11-30 以前 | 88万円（58万＋30万） | 当たらない（上限 58万円） | (a) この値（申告書に書く値）、(b) 改正後の値（基礎控除 104万円、扶養親族に当たる）、(c) 更正の請求の期間 2026-12-01〜2031-12-01 |
| 2026-12-01 以後 | 104万円（62万＋42万） | 当たる（上限 62万円） | 改正後の値だけ |
| 入力なし | (a)(b) の両方。(a) に印「条件つき（提出日）」 | — | — |

  扶養の判定の値には SH4 の印「法令が求める見積り」も付く。合計所得金額 100万円・400万円・500万円の差は［M］§5.7（9万円・36万円・4万円）。
- 検証の方法：
  1. ②年分の境目のテスト：提出日 2026-11-30 と 2026-12-01、2025-11-30 と 2025-12-01 の組で、基礎控除と扶養の判定が上の表のとおり切り替わること。期待値の出典は［PS］§7.2・§7.4。
  2. 2026-12-01 以後に e-Gov 法令API で asof 2026-12-01 の所法・措法を取り直し、状態が施行済みに変わっても第2条・第86条・第41条の16の2 の本文が［M］§3.2 と同じであることを確かめる（施行前の版の取り違えがないか）。
  3. ⑤ の代わり：令和8年分の作成コーナーが公開されたら（時期は未確認）、通常の確定申告として合計所得金額 200万円の架空の数字を入れ、基礎控除が 104万円になることを観察する（版の値だけの照合。D16）。
  4. 様式の欄：2026年12月に出す令和8年分の死亡の申告で、欄値表の「雑損控除」欄に改正後の基礎控除額（雑損控除があれば合計）が入り、「基礎控除」欄が 0 になること（［R8Q&A］Q6−2 の e-Tax ソフトの入力方法との照合）。

## SI2 年齢の境をまたぐ親族は、死亡した本人の申告と、同じ年の相続人の申告で区分が変わる

| 1956-10-01 | 69歳：老人扶養親族でない（一般の控除対象扶養親族） | 70歳：老人扶養親族 |

## SI3 死亡の時の見積りは、後で親族に所得が生じても変わらない（〈i-SPO〉IS8 の具体化）

- 前提：SH4。
- 推測（本人が 2026-06-30 に死亡、2026-12-01 以後に申告。相続人が死亡の時の配偶者の合計所得金額を 50万円と見積もった。配偶者はその後 12月までに合計所得金額 120万円になった）：
  1. 本人の申告：配偶者は同一生計配偶者（上限 62万円以下）。値に印「法令が求める見積り」。欄値表は止めない。
  2. 配偶者の実績が後で記録されても、本人の申告の結果は変わらない。基準時点（6/30）までの実績が見積りを超えていなければ「食い違い」も付けない。
  3. 配偶者自身の申告と、相続人など他の居住者の12月31日の判定は、実績の 120万円で行う。
- 検証の方法：
  1. ①単体テスト：見積りを固定して、親族の実績の取引を後から足しても本人の年分の出力（欄値表を含む）がバイト単位で変わらないこと（D13 の決定性）と、印の付き方。
  2. 設計のレビュー：〈OUT〉の印の表（「法令が求める見積り」は申告用の値を止めない）と SH4 が食い違わないこと。
  3. 根拠の文（TA1191 の Q&A Q3：［PS-SP］§1.8）との対応を、結果の根拠の欄に書けること。

## SI4 見積りが入力されていないときは、親族の所得の種類と実績で「断定」か「未確定」かが分かれる

- 前提：SH4-6（D21 R6）。
- 推測：
  1. 親族の所得が給与だけで、死亡の時までの給与だけで給与所得の金額が上限（令和8年分・12月1日以後の提出なら 62万円）を超えている → 「扶養親族に当たらない」と断定。根拠に「見積りなし、基準時点までの実績で上限を超えた」と書く。
  2. 親族に事業所得がある、又は死亡の時までの実績が上限以下 → 「未確定（判断）」と、`見積り.親族の合計所得金額` を入力すれば決まること、境目の値（62万円、提出日によっては 58万円）を返す。
- 検証の方法：④性質のテスト：(1) の場合に、年の残りの給与を任意に増やした見積りを与えても結論が変わらないこと。(2) の場合に、上限の上と下の見積りを与えると結論が分かれること（＝未確定が正しいこと）。給与所得の金額の計算は既存の給与所得の規則（このトピックの外）を使う。

## SI5 相続人の繰戻し還付：同じ年に所法141①と141④がある場合

- 前提：SH9。
- 推測（［M］§5.6：2026年9月に死亡。2026年の純損失 100万円、2025年の純損失 60万円（2025年分では繰り越した）、2024年分の課税総所得金額 500万円。いずれの年も青色申告書を期限内に提出）：
  1. 所法141①（2026年の純損失 → 2025年分）：2025年分の課税総所得金額が 0 なので還付 0。
  2. 所法141④（2025年の純損失 → 2024年分）：所得税 572,500円 → 452,500円 で還付 120,000円。請求の期限は 2026年分の確定申告期限（＝相続人が知った日から4月の期限。SH5）。
  3. 2026年の純損失 100万円は「消滅（相続人に引き継がない）」と理由（所基通70−15）。
  4. 2026年分の申告が期限後なら、所法141① は使えない（③。やむを得ない事情の認定は税務署長なので「条件つき」）。所法141④ の請求が期限を過ぎれば使えない。
  5. 還付の相続人別の額は、相続人の選択がなければ相続分で按分した候補に印「出典未確認」（SH6-6）。
- 検証の方法：
  1. ①単体テスト：純損失の金額の繰戻しによる所得税の還付請求書の記載要領の欄の式（［PS-AO］§5.3）で同じ例を手で計算し、一致すること。
  2. ③場面のテスト：死亡日を 2026-01-10（所法124 で 2025年分を相続人が出す：所基通140・141−1 の経路）と 2026-09-15（所法125）にした2つの場面を足し、使える経路がそれぞれ違うこと。
  3. 次の公開資料の調査：相続人が提出する還付請求書の記載要領（相続人別の額の書き方）を国税庁の様式の一覧から探す。

## SI8 出国：納税管理人の届出の有無で、申告の種類と対象の範囲が変わる

- 前提：SH8、SH0-4、SH5。
- 推測：
  1. 納税管理人を届け出ずに 2026-08-31 に国外に住所を移した人：所法127 の申告。所得は 1/1〜8/31、判定は 8/31、期限は出国の時。出国の時までに出せば、2026-11-30 以前の提出なので SI1 の (a)(b)(c) を出す。国外転出時課税の判断がなければ「未確定（一次情報）」。
  2. 届け出てから移った人：出国に当たらない。その年に非居住者の期間があるので、2026年分は「対象外」（所法102・所令258 の計算と所法165・166 を取得していない）。
  3. 出国して同じ年に戻った人：その年に非居住者の期間があるので「対象外」。
- 検証の方法：
  1. ③場面のテスト：上の3つの場面で、申告の種類と「対象外」の理由が出ること。
  2. 次の公開資料の調査：所法165・166 と所令の該当条を取得し、非居住者の期間のある年分のうち、国内源泉所得がない場合などで対象に入れられる範囲があるかを調べる（D20 の範囲を変えるならユーザーに確認）。

## SI9 雑損失の繰越控除：死亡の年分で使い、残りは消える

- 前提：SH10。
- 推測（［M］§4 [7]：2026年に死亡。2023年の雑損失の残り 50万円、2025年 30万円。2026年分の総所得金額 30万円、退職所得金額 10万円。白色申告）：
  2026年分の死亡の申告で 2023年分から総所得金額 30万円・退職所得金額 10万円を控除。残りの 2023年 10万円と 2025年 30万円は「消滅」と印「出典未確認（読み）」。白色でも使える。合計所得金額（扶養の判定に使う値）は控除の前の 40万円のまま。
- 検証の方法：
  1. ①単体テスト：所令204① の順序（古い年から、総所得 → 山林 → 退職）と、合計所得金額が繰越控除で変わらないこと。
  2. 次の公開資料の調査：国税庁の質疑応答事例などで、死亡した人の雑損失の繰越控除の残りを相続人が使えないことの明示を探す。見つかれば印を外す。

## SI10 住民税：死亡した人には翌年度以後の住民税を計算しない

- 前提：SH11。
- 推測：2026年に死亡した人について、令和9年度分の住民税を問われたら「課税されない（1月1日に住所を有する個人でない）」と返し、所得割・均等割を計算しない。相続人の令和9年度分の住民税で、死亡した親族の扶養の判定は死亡の時（［PS-SP］§2.2）。令和8年度分（既に課された年度）は計算を変えない。
- 検証の方法：①単体テスト。地法294①・318 の文言（［PS］§10）を期待値の出典にする。出国した人の翌年度は、住民票の記録（事実）を変えて結果が切り替わることを確かめる。

## SI11 法令の版を年分だけで引くと、施行日の前に出す死亡・出国の申告で誤る

- 前提：SH7-4。
- 推測：パラメータを「年分 → 値」だけで引く実装は、2026-11-20 に出す令和8年分の死亡の申告で、基礎控除を 104万円（改正後）とし、申告書に書くべき 88万円（その日の法令）と違う値を出す。親族の扶養の判定も逆になりうる（SI1）。
- 検証の方法：②年分の境目のテストに、提出日の鍵を含む組（2025-11-30／2025-12-01、2026-11-30／2026-12-01）を必ず入れる。法令の変更の監視（D9）で、施行日が年の途中（12月1日など）の改正を検知したときは、死亡・出国の申告の提出日の鍵を足す作業を issue の「影響する層」に書く。
