# 推測（impl-research joto-junjo）：分離課税の所得控除の順序が税額に与える差の大きさと検証の方法

- 作成：2026-11-11。前提の仮説：`docs/hypotheses/20261111_impl-research_joto-junjo-model.md`（H1・H2）。

## I1 順序の違いの効果

- 総合課税の所得が 0 で、所得控除の残りが配当と譲渡（どちらも 15%）にまたがる場合、配当→譲渡の順でも譲渡→配当の順でも、課税所得の合計は同じ。税額は千円未満の切捨てが行ごとに行われる（通則法118①）ので、合計の差は 1,000円 × 15% ＝ 150 円の範囲に収まるはず。
- 例（架空）：控除の残り 200,500。配当 1,000,300、譲渡 2,000,400。
  - 配当→譲渡：配当 1,000,300−200,500＝799,800 → 799,000、譲渡 2,000,400 → 2,000,000 → 税額合計 (799,000＋2,000,000)×15%＝419,850。
  - 譲渡→配当：配当 1,000,300 → 1,000,000、譲渡 2,000,400−200,500＝1,799,900 → 1,799,000 → 税額合計 (1,000,000＋1,799,000)×15%＝419,850（この例では同額）。
  - 切捨ての端数の出方で最大 150 円程度の差になりうる。
- 検証の方法：作成コーナーで分離の配当と譲渡に所得控除の残りがまたがる架空の数字を入れて、第三表の 81・82 の行に控除がどう配分されるかを観察する（D15 ⑤、D16 の範囲）。順序が H1 と違えば、仮説 H2 を見直し、結果は幅で返す（D22 S3）。

## I2 雑損失の繰越控除

- 総合 0・配当 100万・譲渡 100万・雑損失 150万の場合、所令204①二の読替え（⑳の表）に従えば配当→譲渡の順で控除する。税額の合計は同じ。検証は作成コーナーの「雑損失の繰越し」で第四表の各行の金額を観察する。
