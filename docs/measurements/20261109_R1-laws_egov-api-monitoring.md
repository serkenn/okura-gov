# R1 実測：e-Gov 法令API v2 などで法令の変更を検知できるか

- 実施日：2026-11-09（JST）
- 種別：実測
- 環境：Windows 11、Python 3.11.9（標準ライブラリのみ）、`python -I` で実行。User-Agent `okura-gov-research/0.1`、リクエスト間隔 1.5 秒。
- ダウンロードしたファイルは `.work/downloads/<ts>_<name>/`（git 管理外）に置いた。

## 再実行の方法

```
python -I scripts/R1_egov_spec.py         # 仕様（OpenAPI）の取得
python -I scripts/R1_egov_revisions.py    # 改正履歴・updated_from・amendment_law_id・一括ダウンロード
python -I scripts/R1_monitor_sources.py   # 各省庁サイトの RSS の有無、sitemap、税制改正ページ
```

結果：
- `scripts/results/R1_egov_spec/fetch_log.json`
- `scripts/results/R1_egov_revisions/summary.json`、`revisions.md`、`revisions_<law_id>.json`、`bulk_updated_<日付>_<CSV名>.txt`
- `scripts/results/R1_monitor_sources/summary.json`

後日再実行すると、`updated` や現行の版が変わっているはず。値が変わること自体は異常ではない。

観察（`revisions.md`）：

- **未施行の改正も入っている**（`current_revision_status: UnEnforced`）。例：所得税法の `340AC0000000033_20261201_508AC0000000012`（令和8年法律第12号、施行 2026-12-01）、`..._20270101_508AC0000000012`、`..._20280101_508AC0000000012`、`..._20300619_507AC0000000074`。
- 1つの改正法令が、施行日ごとに別の版（revision）として登録される。令和8年法律第12号は所得税法について 2026-04-01、2026-12-01、2027-01-01、2027-07-22、2028-01-01 の版がある。
- 未施行の版の本文も `/law_data/{law_id}?asof=<未来の日付>` で取得できた（`docs/measurements/20261109_R1-laws_article-extraction.md`）。
- `updated` は最後に更新された日時で、初めて登録された日時ではない。例：所得税法の `..._20260401_508AC0000000012`（2026-04-01 施行）の `updated` は 2026-09-08T11:20:43。登録の遅れ（公布から e-Gov に載るまでの日数）は、この値からは測れない。
- 施行日が決まっていない改正には `amendment_scheduled_enforcement_date` と `amendment_enforcement_comment`（例「公布の日から起算して三年を超えない範囲内において政令で定める日」）が入る（健康保険法の令和8年法律第51号の版など）。

## 3. データの更新日での絞り込み（updated_from）

`/law_revisions/{law_id}?updated_from=2026-10-01`：

| 法令 | 返った版 |
|---|---|
| 所得税法 | 2件：`..._20261001_507AC0000000070`（updated 2026-10-01T03:03:11）、`..._20260812_508AC0000000064`（updated 2026-10-01T03:03:11） |
| 健康保険法 | 複数件（未施行の 2029-10-01、2029-06-24、2028-12-11、2028-06-04 などの版。updated は 2026-10-09） |
| 年齢計算ニ関スル法律 | 0件 |

→ **法令IDごとに `updated_from=<前回確認日>` で問い合わせれば、更新された版だけが返る**。新しい版が加わると、隣の既存の版の `updated` も同時刻に変わることがある（所得税法の例）。

`/laws?updated_from=2026-10-01&limit=5`：HTTP 200、`total_count` 9,568。パラメータなしの `/laws?limit=1` も 9,568。→ **`/laws` は `updated_from` を無視する**（仕様にもない）。法令IDを指定せずに「更新された法令の一覧」を API で取る方法は、仕様と実測の範囲では見つからなかった。

## 4. 改正法令から被改正法令を引く（amendment_law_id）

- `/laws?amendment_law_id=507AC0000000013`（令和7年法律第13号）：HTTP 200、`total_count` 20。租税特別措置法、国税徴収法、国税通則法、所得税法、法人税法、印紙税法、登録免許税法、消費税法、電子帳簿保存法など。各法令の `revision_info` はその法令の現時点の最新の版（例：所得税法は施行日 2026-10-01 の版）を示す。
- 改正法令そのもの：`/laws?law_id=507AC0000000013` は0件、`/law_data/507AC0000000013` は 404（`{"code":"404004","message":"指定のパラメータで取得できる法令本文ファイルは存在しません。"}`）。
  → **一部改正法の本文（改正規定）は API で取得できない**。改正法の附則（施行期日・経過措置）は、被改正法令の本文の中に `SupplProvision`（`AmendLawNum` 属性つき）として収録されており、そこから読める（所得税法の本文で令和7年法律第13号・令和8年法律第12号の附則を読めた）。

## 5. 一括ダウンロードの更新法令データ（file_section=3）

| update_date | 結果 |
|---|---|
| 20261108（日曜） | HTTP 500（HTML のエラーページ） |
| 20261101 | 200、ZIP 6,394,729 バイト、41 エントリ。CSV `R081101.csv`（ヘッダ＋20行） |
| 20260801 | 200、ZIP 2,077,693 バイト、39 エントリ。CSV `R080801.csv`（ヘッダ＋19行） |
| 20250401 | 200、ZIP 44,781,349 バイト、939 エントリ。CSV `R070401.csv`（ヘッダ＋469行） |

（最初の実行では 20261001：17,774,280 バイト・685 エントリ、20260401：75,849,167 バイト・1,087 エントリ。）

- ZIP には「法令ごとの XML」と「その日の更新一覧の CSV」が入っている。CSV は UTF-8（BOM つき）で、列は
  `法令種別,法令番号,法令名,法令名読み,旧法令名,公布日,改正法令名,改正法令番号,改正法令公布日,施行日,施行日備考,法令ID,本文URL,未施行`。
  例：`法律,昭和三十二年法律第二十六号,租税特別措置法,…,所得税法等の一部を改正する法律,令和七年法律第十三号,令和七年三月三十一日,令和八年十一月一日,,332AC0000000026,https://laws.e-gov.go.jp/law/332AC0000000026/20261101_507AC0000000013,`
- 仕様の「取得範囲は過去３ヶ月」に反して、1年7か月前（20250401）も取得できた。今後もできるとは限らない。
- ZIP の大きさは日によって大きく違う（2MB〜76MB）。毎日の監視で ZIP を落とすと重い。
- **施行日が「令和九十九年十二月三十一日」などの値**の行がある（R070401.csv の消費税法・法人税法・印紙税法など、未施行欄が○）。施行日未定の改正に仮の日付を入れていると読める（推測。仕様で未確認）。監視側で、施行日を実在の日付として扱うと誤る。
- 登録の遅れの手がかり：R070401.csv（2025-04-01 の更新分）には、2025-03-31 公布の令和7年法律第13号による改正が 41 行ある（電子帳簿保存法、消費税法、法人税法、国税通則法など）。一方、所得税法の令和7年法律第13号の版はこの日の CSV には入っていなかった。所得税法の版がいつ登録されたかは測っていない。

## 7. まとめ（実測で言えること）

1. e-Gov 法令API v2 は、**法令IDを決めておけば**、`/law_revisions/{id}?updated_from=<日付>` で新しく登録・更新された版（未施行を含む）を毎日取れる。
2. 法令IDを決めずに「更新された法令の全体」を知るには、一括ダウンロードの日次 CSV（file_section=3）が使える。API には同等の機能が見つからなかった。
3. 改正法そのものの本文は取れない。施行期日・適用関係は、被改正法令の本文に収録された改正法の附則から読める。
4. 国税庁・財務省・官報には機械で読める新着フィードが見つからなかった。官報は robots.txt で巡回が禁止されている。
