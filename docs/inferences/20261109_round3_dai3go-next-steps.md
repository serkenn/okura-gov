# 推測：第3号被保険者の収入基準の根拠についての仮説から導いたことと、その検証方法（第3ラウンド dai3go）

## ID1 平成5年3月15日 庁保発第5号の本文には、［S61］の別添の「一二○万円」を「一三○万円」に改める文がある（前提：HD1）

- 推測：HD1 が正しければ、第5号は［S61］の別添「被扶養配偶者の認定基準」の 一イ・一ロ・二 の金額（その時点の値。平成4年1月からの健保の値に合わせていれば120万円）を130万円に改め、障害者の金額も改める文を持つ。宛先は都道府県知事、発出者は社会保険庁年金保険部長（［S61］と同じ）で、平成5年4月1日からの適用を定める。
- 検証方法：
  1. 厚生労働省（年金局）又は日本年金機構に対し、行政文書「平成5年3月15日 庁保発第5号」の開示を請求する（情報公開請求。本プロジェクトの自動の取得の範囲外。ユーザーの判断が要る）。
  2. 社会保険庁の通知を収めた冊子（平成5年以降の版）を、国立国会図書館などで探し、［S61］の注記（改正の履歴）と改正後の本文を見る。
  3. 社会保険審査会の裁決のうち、第3号被保険者（国民年金の「（国）」の事案）を扱う他の裁決を、掲載の一覧から網羅的に集め、［S61］の引用の「最終改正」の表記がすべて同じかを数える（`scripts/R3X_dai3go_fetch.py` に set を足し、`scripts/R3X_dai3go_checks2.py` の N4 と同じ検査をかける）。→ 2026-11-11 の検証で、公開の一覧（裁決年 平成28・29年〜令和7年）にある第3号の事案は令和元年（国）第263号の1件だけだった（`docs/measurements/20261109_round3_dai3go-verification.md` #100）。公開の一覧からはこの方法を実行できない。
- 否定される場合：本文が見つかり、金額の改正を含まない（HD1 の (b)）、又は番号・日付が違う（HD1 の (a)）。複数の裁決で最終改正の表記が食い違う場合は、(a) の可能性が上がる。

## ID2 ［S61］には平成5年より前の改正（昭和62年・平成元年・平成4年）があり、それらもデータベースに収録されていない（前提：HD1・HD2）

- 推測：［S61］の金額が健保と同じ経緯（［KT2］p.5 の62年5月 100万円、元年5月 110万円、4年1月 120万円）をたどったなら、昭和62年・平成元年・平成3〜4年に「庁保発」の改正の通知がある。訂正前の HD2（収録されていない改正は本文に反映されない）からは「それらはデータベースに無い」と予想したが、訂正後の HD2 からはそう予想できない。データベースにあるかどうかは、下の方法で確かめる問いとして残す。
- 検証方法：厚労省 法令等データベースの情報詳細検索で、各年（昭和62年、平成元年、平成3年、平成4年）の種別「庁保発」の番号を1から順に指定して件名を列挙し（種別だけの検索はエラーになるため。1件 1.5 秒、各年 30 番程度）、件名に「被扶養配偶者」を含むものがあるかを見る。
- 否定される場合：その中に「国民年金法における被扶養配偶者の認定基準の一部改正」のような件名の通知があり、本文が［S61］の金額を改めている（その場合、データベースは改正の通知を収録しながら［S61］の本文に反映していないことになる）。
- 注（2026-11-11 の検証）：HD2 は「改正の通知が収録されていないから本文が古い」という推論を取り下げた。平成5年の庁保発は第5号のほかに第1・2・4・10・12号も0件で（`docs/measurements/20261109_round3_dai3go-verification.md` #98）、番号の列挙で件名が見つからなくても、改正が無かったことの手がかりにはならない。

## ID3 ライブラリの第3号の判定（令和7年分・令和8年分）は、健保（配偶者）の判定と同じ境目で結論が変わる（前提：HD3・HD4）

- 推測：年間収入の見込みが 1,299,999円 なら（他の要件を満たすとき）第3号に該当し、1,300,000円 なら該当しない。同一世帯で第2号被保険者の年間収入の2分の1ちょうどなら原則の要件を満たさず、補足の要件（第2号の年間収入を上回らず、生計維持の中心的役割）の判断が要る。健保の被扶養者として認定されていても、年間収入の見込みが130万円以上なら、［S61］の基準では該当しない（［S61-U］の「１」の推定とは食い違う。結果に食い違いを示す）。
- 検証方法：D15 の②（年分ごとの法令の境目のテスト）に、上の境目のケースを期待値つきで入れる。期待値の出典は HD3 の3つ（法令・通知〔原文未確認の印〕・年金局の説明）。機構の案内（第2ラウンドの［N-YOGO］［N-FAQ］の文言）と結論が合うことを確かめる。
- 否定される場合：機構・年金局の一次情報で、第3号の境目が健保と違う（例えば「以下」）ことが示される。

## ID4 第3号の収入の基準が変わるときは、データベースの［S61］の本文よりも先に、年金局・機構の案内の文言が変わる（前提：HD2・HD5）

- 推測：HD2 のとおりデータベースが改正の通知を反映しない場合があるので、毎日の監視（D9）で［S61］の本文だけを見ていると変更を見落とす。機構の案内（「年収が130万円未満」の文）と、健保の［S52］（データベースで改正後の文を表示する）の変更は検知できる。
- 検証方法：監視の対象に、(1) データベースの［S52］・［S61］・［S61-U］の本文のハッシュ、(2) 機構の第3号・被扶養者の案内の頁の該当の文、(3) データベースの新着の通知の件名に「被扶養」を含むもの、を入れる。過去の変更（令和7年10月の19歳以上23歳未満の150万円、令和8年4月の労働契約による判定）で、(1)〜(3) のどれが先に変わったかを、取得済みの資料の日付（通知の発出日、案内の頁の Last-Modified）で並べて確かめる。
- 否定される場合：［S61］の本文がデータベース上で改正後の金額に更新される（その場合は HD2 の前提が変わる）。

## ID5 平成15年3月24日 庁文発第798号は、［S61］の別添の金額を改める通知ではない（前提：HD5）

- 推測：この通知は、［S61］の金額ではなく、認定の事務（年間収入の見方や届出の扱いなど）に関するもの。
- 検証方法：ID1 の 1・2 と同じ手段で本文を得る。データベースの平成15年の「庁文発」を番号で列挙する（798号の前後）ことでは本文は得られない（798号は0件だった）。
- 否定される場合：本文が［S61］の別添の金額を改めている。その場合、HD1 の「最終改正」の記載（平成5年）は、裁決の時点（令和2年）でも誤りだったことになり、ID1 の検証の優先度が上がる。
