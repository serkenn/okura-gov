## 1. 原文の要点（「寄附金税額控除」の項）

- 原文：「A 都道府県・市区町村に対する寄附金（ふるさと納税等）や、B あなたの令和8年1月1日現在における住所地の共同募金会と日本赤十字社支部に対する寄附金、
  C あなたの令和8年1月1日現在における住所地の都道府県が条例で指定した寄附金、D あなたの令和8年1月1日現在における住所地の市区町村が条例で指定した寄附金について、
  それぞれの合計寄附金額を記入します。」
- 注意書き（原文の要点）：
  - ワンストップ特例を申請していても、確定申告を行うとその申請は無効になる。確定申告を行う場合は、特例申請をした分も含めて寄附金の金額を記入する。
  - 「都道府県・市区町村に対する寄附金のうち、寄附日においてふるさと納税に係る総務大臣の指定を受けていない地方公共団体に対するものは特例控除の対象となりませんので、
    『共同募金、日赤その他の寄附』欄へ記入してください。」
  - 災害義援金として日本赤十字社や中央共同募金会等の募金団体に寄附したもので、最終的に被災地方団体や義援金配分委員会等に拠出されるものは、
    地方団体に対する寄附金として扱い、「都道府県、市区町村への寄附（特例控除対象）」欄に記入する。
  - 「C・D について、都道府県・市区町村の両方が指定した寄附金がある場合は、両方の欄に記入してください。」どの団体が条例で指定されているかは、
    住所地の都道府県・市区町村に問い合わせる。
  - 認定NPO法人等以外の NPO 法人等への寄附金のうち住所地の都道府県・市区町村が条例で指定したものは、所得税の寄附金控除の対象にならないが、
    個人住民税の寄附金税額控除を受けられる。この場合は別途、市区町村への申告が必要。

## 2. 記載例（原文の表）

| 寄附先 | 金額 | 記入する欄 |
|---|---|---|
| ①●●県（ふるさと納税） | 80,000円 | a「都道府県、市区町村への寄附（特例控除対象）」 |
| ②□□市（ふるさと納税） | 40,000円 | a |
| ③住所地の日本赤十字社支部 | 90,000円 | b「共同募金、日赤その他の寄附」 |
| ④住所地の都道府県共同募金会（社会福祉法人） | 20,000円 | b |
| ⑤社会福祉法人（住所地の都道府県が条例で指定） | 55,000円 | c「都道府県条例指定寄附」 |
| ⑥認定NPO法人（住所地の都道府県・市区町村ともに条例で指定） | 15,000円 | c と d「市区町村条例指定寄附」 |

- 欄の額：a ＝ ①＋② ＝ 120,000円、b ＝ ③＋④ ＝ 110,000円、c ＝ ⑤＋⑥ ＝ 70,000円、d ＝ ⑥ ＝ 15,000円。
- 原文の注：「ふるさと納税に係る総務大臣の指定がない地方公共団体への寄附（特例控除対象以外）については、A ではなく B に記入します。」
  「⑥の寄附金の額が『都道府県』及び『市区町村』の両方の欄に含まれることから、①から⑥の合計額と a から d の合計額は同じになりません。」

## 3. 分からなかったこと・判定コアで区別できないこと

- 手引きは欄と地方税法の各号（第314条の7第1項第1号〜第4号・第37条の2第1項）の対応を条番号では書いていない。A は第1号（特例控除対象寄附金：第2項の総務大臣の指定）、
  B は第2号（共同募金会・日本赤十字社）と指定のない第1号、C・D は第3号・第4号（条例で定めるもの）と読める（条文は
  `docs/public-sources/20261109_round2_juminzei-tax-law-text.md` §8.1、`docs/public-sources/20261112_impl-research4_juminzei-kifu-laws-and-kokuji.md` §1、
  `docs/public-sources/20261111_impl-research3_juminzei-laws-and-soumu.md` §1）。
- 災害義援金（日本赤十字社・共同募金会を通じて被災地方団体等に拠出されるもの）を A に書く扱いの根拠の条文・通知は、この手引きのページにはない。
  中間表現の donation に、義援金として地方団体に拠出されるかを表す語彙はない（2026-11-12 時点）。判定コアは寄附先の種類（recipient_type）で第1号か第2号かを決める。
- 令和8年分の手引きは未公表（2026-11-12 時点）。
