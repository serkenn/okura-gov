# 推測：消費税の課税事業者・経理方式が、家族の判定に与える影響の場面と期待値（第2ラウンド追加分 invoice）

- 作成日：2026-11-09
- 種別：推測。前提にした仮説：`docs/hypotheses/20261109_round2b_invoice-model.md`（以下 H1〜H9）。
- 数値の例は架空。消費税等の額は「外部で計算した値」の代わりに置いた値で、消費税の計算として正しいかは検証していない（D20）。例の算術は `scripts/R2B_invoice_examples.py`（結果 `scripts/results/R2B_invoice_examples/results.md`）で再現できる。

## I1 登録した最初の年は、税込経理の原則だと消費税等の分だけ所得が大きく出て、扶養の要件の境目をまたぎうる（H3・H5）

- 場面：令和7年1月1日から登録した子（白色、事業所得だけ、令和6年は免税）。令和7年の税込売上 660,000、税込経費 77,000。令和7年分の消費税等（外部の値）12,000 を令和8年3月に申告。
- 期待値（H3 の計上の年の規則による）：

| 計算 | 令和7年分の事業所得（＝合計所得金額） | 令和7年分の扶養親族の要件（58万円以下。H5 の出典） |
|---|---|---|
| 税込・原則（申告書を出した年に計上） | 583,000 | 満たさない |
| 税込・未払金に計上（納税者の選択） | 571,000 | 満たす |
| 税抜 | 571,000 | 満たす |
| 登録しなかった場合（免税・税込） | 583,000 | 満たさない |

- 含意：
  1. 子の「未払金に計上するか」の選択（H3 の 4）が、**親の扶養控除**の可否を変える（人をまたぐ依存。H5 の 1）。ライブラリは選択を入力として受け、選ばない。シナリオ比較（D19）では両方を評価できる。
  2. 原則の計算では、令和7年分の 12,000 は令和8年分の必要経費になる（令和8年分の事業所得を 12,000 下げる）。
  3. 同じずれが、令和8年度の住民税（令和7年の所得）の扶養・非課税の判定に、そのまま伝わる（H5 の表）。
- 検証の方法：
  - 算術：`scripts/R2B_invoice_examples.py` の `threshold_I1`（再実行で同じ値が出ること）。
  - 法令の当てはめ：作成コーナー（令和7年分）で、収支内訳書の租税公課に令和7年分の消費税等を入れた場合と入れない場合の事業所得を出し、ライブラリの2通りの値と一致することを確かめる（D15 ⑤）。どちらの入れ方も許されることの根拠は経理通達 7 の本文とただし書（仮説 H3 の出典）。
  - D15 ② の境目のテストに、この組（583,000／571,000 と 580,000）を期待値として入れる。

## I2 税抜経理を選んでも、資産の無い家族の事業なら、所得は「税込・未払金計上」と同じで、経理方式の違いは計上の年だけに出る（H4）

- 期待値：資産（減価償却資産・棚卸資産・繰延資産）が無い年分では、税抜経理の事業所得等 ＝ 税込の売上 − 税込の経費 − その年を課税期間とする年税額。仮払消費税等を経過措置の 80％・70％ で区分しても、全額で区分しても、区分しなくても同じ。
- 含意：ライブラリは税抜経理の人にも、取引ごとの消費税の分解を求めずに済む。税抜経理で要る追加の事実は、資産ごとの税抜の取得価額と、課税期間の年税額だけ。
- 検証の方法：
  - 算術：`scripts/R2B_invoice_examples.py` の性質テスト（乱数 2,000 組で不一致 0）と `partial_karibarai`。
  - 家事関連費の按分を含む場合（按分を税込の額にかけるか、税抜の額にかけて仮払を事業分だけにするか）でも同じになるかは、まだ式に入れていない。按分の取引を含む性質テストを足して確かめる。
  - 作成コーナーの青色申告決算書（又は収支内訳書）に、同じ取引を税抜で入れた場合と税込で入れた場合の所得が一致するか（作成コーナーに経理方式を選ぶ欄があるかも含めて）確かめる。

## I3 税抜経理では、10万円前後の資産の「少額の減価償却資産」の判定が、相手方の登録の有無と取引の日（2026-10-01 の 80％→70％）で変わる（H4・H6）

- 場面と期待値（税抜経理、一般課税で 1の2 を選ばない人。取得価額＝税込×(1 − 10/110×控除割合)）：

| 税込 | 相手方・日付 | 税抜の取得価額 | 10万円未満か |
|---|---|---|---|
| 107,000 | 登録事業者 | 97,273 | はい |
| 107,000 | 登録なし・2026-09-30 まで（80％） | 99,218〜99,219 | はい |
| 107,000 | 登録なし・2026-10-01 以後（70％） | 100,191 | いいえ（一括償却資産などの対象） |
| 108,900 | 登録事業者、又は2割特例の年に 1の2 を選んだ場合 | 99,000 | はい |
| 108,900 | 登録なし（80％・70％とも） | 100,980／101,970 | いいえ |
| どちらも | 税込経理 | 税込の額 | いいえ |
| どちらも | 税抜経理で、登録なしの相手からの取引の仮払消費税等を区分しなかった場合（令和3年改正の経過的取扱い(3)。H4 の 4） | 税込の額 | いいえ |

- 注（独立検証で追加）：上の「登録なし」の行は仮払消費税等を区分した場合の値。区分しなければ取得価額は税込の額になる（H4 の 4、H6 の「使い方」）。

- 含意：令和8年分の中で、同じ値段の同じ相手からの買い物でも、9月と10月で判定が変わる。ライブラリは資産ごとの税抜の取得価額を外部の値として受け（H4 の 4）、H6 の率の表で範囲を検査する。
- 検証の方法：
  - 法人税の「令和3年改正消費税経理通達関係Q&A」の全文（問2 以後。今回は問1 しか読んでいない）に、経過措置の期間の仮払消費税等と取得価額の数値例があるか読み、同じ計算になるか確かめる（所得税の経理通達も「同様の改正の趣旨」とされている）。
  - 1円未満の端数（切捨て・四捨五入）で結論が変わらないことは `scripts/R2B_invoice_examples.py` の `shogaku_I3` で確かめた（境目から十分離れている例だけ）。境目に近い額では端数の選択（名前つきの関数。H7）が結論を変えうるので、境目のテストを別に足す。
  - 税務署（電話相談）に、2割特例の年に 1の2 を選んだ個人の資産の取得価額が 110分の10 で計算されることを確認する。

## I4 健保の被扶養者の判定は、事業収入に消費税等を含めるかで結論が変わりうるので、保険者のデータが無ければ「未確定」になる（H5 の 2）

- 場面：登録している子の今後1年の事業収入の見込み（判断台帳）が、税込 1,320,000（税抜 1,200,000）、保険者が差し引きを認める経費は 0。保険者の基準額 B を 1,300,000 未満とする（例。年齢による別の基準は H5 の出典の範囲）。
- 期待値：保険者のデータが「含める」→ 1,320,000 で基準を満たさない。「含めない」→ 1,200,000 で満たす。データが無い → 両方を評価して結論が違うので「未確定（保険者の消費税の扱いが未確認）」。消費税等の納付額は、保険者のデータで差し引くと明示されない限り差し引かない。
- 検証の方法：協会けんぽ・健保組合・共済組合（家族が加入している保険者）の被扶養者の案内・Q&A を、消費税・税込・税抜の語で探す。見つからなければ保険者に問い合わせ、回答を出典つきのデータとして注入する（D19）。

## I5 消費税等の予納・中間納付は、税込経理では「申告書の提出（みなし提出）の年」に必要経費になり、払った日の年ではない（H3 の 3）

- 場面：令和8年分の消費税等を令和8年10月に予納し、令和9年3月に確定申告書を出した。別の人は令和8年8月に中間申告書を出した（又は出さず、期限に提出があったものとみなされた）。
- 期待値：予納の額は、未払金に計上しなければ令和9年分の必要経費（申告書の提出の年）。中間申告の額は令和8年分の必要経費（中間申告書の提出又はみなし提出の年）。
- 検証の方法：予納と必要経費の年について書いた国税庁の資料（タックスアンサー・質疑応答事例）を探す。見つからなければ税務署に確認する。経理通達 7 の「納税申告書に記載された税額については当該納税申告書が提出された日の属する年」の文言の当てはめ（仮説 H3 の出典）が、予納に例外を置いていないことを根拠にしている。

## I6 年の途中で登録した年に税抜経理を選んだ人は、当面「未対応」になる（H2 の 3・H8 の 1）

- 場面：令和8年7月1日に登録した子（それまで免税）。
- 期待値：税込経理なら通常どおり計算できる（登録の前後で計算は変わらない。消費税等の申告書の事実だけが増える）。税抜経理を選んだと入力されたら「未対応（登録の前の免税の期間の取引の扱いが一次情報で確認できない）」を返す。
- 検証の方法：国税庁のインボイス制度Q&A（全文）と、所得税の経理通達・タックスアンサーに、年の途中で登録した個人の経理処理の記述があるか探す。あれば規則を足して「未対応」を外す。

## I7 経理通達が R8改正（3割特例・7・5・3割控除）に追いついていないので、令和9年分以後の税抜経理には監視が要る（H6）

- 期待値：令和7年分・令和8年分（取引は 2026-12-31 まで）の計算には影響しない。令和9年分・令和10年分の3割特例の年に 1の2 を使えるか、令和11年10月以後の 50％・30％ の期間の仮払消費税等の額は、経理通達の改正で示されると予想する。
- 検証の方法：経理通達のページ（公開資料の情報 §0.2 の URL）の Last-Modified と冒頭の改正の表示を、法令の変更の監視（D9）の対象に加える。改正が出たら H6 の表に施行日つきで足す。

## I8 消費税の課税事業者になった家族がいると、所得税・住民税・国保は同じ事業所得等の値で連動して動くが、健保だけは別の値で動く（H5）

- 期待値：経理方式・計上の年の選択を変えると、所得税（本人と、本人を扶養に入れる家族）、翌年度の住民税、翌年度の国保の所得割が、同じ差額で動く。健保の被扶養者の判定は、所得税の経理方式と無関係に、保険者の運用（事業収入の範囲、消費税の扱い）で決まる。
- 検証の方法：S1〜S8 の場面（`docs/inferences/20261109_R4-modeling_scenarios.md`）のうち事業収入のある場面に「登録あり・税込原則」「登録あり・未払金計上」「登録なし」の3通りを足し、判定コアの依存グラフ（SCOPE §6 の 6）で、経理方式の判断から各判定への依存の経路が H5 の表のとおりになることを機械的に確かめる。
