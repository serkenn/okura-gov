# 公的年金等の雑所得：仮説から導いた場面ごとの推測と検証方法

- 種別：推測（inferences）。作成日：2026-11-09。
- 前提の仮説：`docs/hypotheses/20261109_round2b_nenkin-model.md`（以下 H1〜H10）。
- 金額の基準（H4・H8 が参照する公開資料の情報による）：所得税の扶養親族の合計所得金額 令和7年分 58万円以下・令和8年分 62万円以下、健保の被扶養者 130万円未満（60歳以上・障害者 180万円未満）、住民税の障害者・寡婦等の非課税 135万円（既存の住民税の調査の値で例示）。
- 場面はすべて架空・一般化したもの。
- 検証方法の記号：[単] 判定コアの単体・境目のテスト（D15①②）、[作成] 確定申告書等作成コーナーに架空の数字を入れた照合（令和7年分のみ。D15⑤・D16）、[問] 保険者・市町村・税務署への問い合わせ、[探] 一次情報の追加の探索。

## I1 65歳以上の親：税の扶養の境目は年金 172万円、健保は 180万円。この間の人は「税は扶養外、健保は被扶養者」

- 前提：H1・H2・H4。
- 場面：親 P（2026-12-31 に 70歳、子と同居、生計を一にする）。令和8年分の老齢基礎年金＋老齢厚生年金 175万円（国内の支払）。他の所得なし。
- 推測：
  - 所得税（令和8年分）：公的年金等控除 110万円 → 雑所得 65万円 → 合計所得金額 65万円 > 62万円 → 子の扶養親族（老人扶養親族）に当たらない。年金が 172万円以下なら当たる（境目の収入 ＝ 62万＋110万）。令和7年分なら境目は 168万円。
  - 健保：年間収入 175万円 < 180万円（60歳以上）→ 収入の要件は満たす（同居なら被保険者の収入の2分の1未満も必要。75歳以上なら後期高齢者医療の被保険者で被扶養者にならない）。
  - 所得税の申告：121③（175万円 ≤ 400万円、国内の年金だけ、他の所得 0）→ 申告不要。年金 175万円は 65歳以上の源泉徴収を要しない額（令和8年 205万円）より小さく源泉徴収されないが、121③ の「全部」から除かれるので妨げない（H6）。
  - 住民税：公的年金等だけの人として申告不要（受けたい控除がなければ）。所得の数え方は同じ 65万円（H4）。
- 検証：[単] 175万・172万・172万1円で扶養の判定が切り替わること、令和7年分は 168万円。[作成] 令和7年分で 65歳以上・公的年金等 168万円と 169万円を入れ、雑所得 58万円・59万円の表示を確かめる。

## I2 遺族年金＋老齢基礎年金：税では所得 0、健保では 180万円ちょうどで外れる

- 前提：H3・H4。
- 場面：Q（66歳、別居の子が仕送り）。遺族厚生年金 120万円、老齢基礎年金 60万円。他の収入なし。
- 推測：
  - 所得税：遺族厚生年金は非課税（厚年法41②）。課税の公的年金等 60万円 ≤ 110万円 → 雑所得 0 → 合計所得金額 0 → 扶養親族に当たりうる。
  - 健保：年間収入 ＝ 120万＋60万 ＝ 180万円。基準は「180万円未満」なので当たらない。
  - 住民税：合計所得金額 0。均等割の非課税の基準（条例の値）より小さい（I：基準は正の額）。
  - 所得税の申告：121③ を満たす（老齢基礎 60万円は源泉徴収を要しない額より小さい）。
- 検証：[単] 非課税の年金が合計所得金額に入らず、健保の年間収入に入ること。[問] 保険者に、年金を額面で数えるか、介護保険料などの天引き後で数えるか（H4 の未確定）。

## I3 所得税は申告不要でも、住民税の申告は要る

- 前提：H6・H7。
- 場面：R（68歳）。老齢年金 300万円（国内の支払、源泉徴収あり）。副業の業務に係る雑所得 15万円（収入 − 必要経費）。
- 推測：
  - 所得税：121③ の 1.（300万円 ≤ 400万円）・2.（全部源泉徴収）・3.（他の所得 15万円 ≤ 20万円）を満たす → 申告不要。ただし還付があるなら還付申告は選べる（H6 の選択）。
  - 合計所得金額：公的年金等の雑所得 190万円（300万 − 110万）＋ 15万円 ＝ 205万円（申告不要でも数える：H4）。家族の配偶者特別控除などの判定はこの値を使う。
  - 住民税：「公的年金等に係る所得以外の所得」が 15万円あるので、地法317の2①ただし書に当たらず、住民税の申告が要る（確定申告をすれば不要）。判定コアは「所得税：申告不要（121③）／住民税：申告が必要（317の2①）」と別々に返す。
- 検証：[単] 2つの要否が別々に出ること。[探] 国税庁 TA1600 注2 と同じ趣旨の市町村の案内。[問] 市町村の税務課（申告が要ることの確認）。

## I4 給与（年末調整あり）と年金の両方がある人は、121① と 121③ のどちらにも当たらないことが多い

- 前提：H6。
- 場面：S（2026-12-31 に 64歳）。勤務先で年末調整を受けた給与（給与所得 20万円超）と、特別支給の老齢厚生年金 100万円（65歳未満の源泉徴収を要しない額 155万円〔令和8年〕より小さく、源泉徴収なし）。
- 推測：
  - 121①：給与所得及び退職所得以外の所得金額 ＝ 公的年金等の雑所得 40万円（100万 − 60万）> 20万円 → 当たらない。
  - 121③：年金 100万円 ≤ 400万円、全部（203の7 のものを除く）源泉徴収 → 満たす。他の所得 ＝ 給与所得 > 20万円 → 当たらない。
  - → 申告不要に当たらない。年金に源泉徴収がないので、年金分の税は確定申告で納める形になる（第120条の申告義務の判定は税額の仮説）。所得金額調整控除の第2項（給与と公的年金等の両方）も働く（既存の gaps の仮説）。
- 検証：[作成] 令和7年分で、年末調整済みの給与と公的年金等 100万円（源泉徴収税額 0）を入れ、納める税額が出ること。[単] 121① と 121③ の両方の理由が結果に出ること。

## I5 外国の年金があると 121③ は使えない

- 前提：H3・H6・H9。
- 場面：T（67歳、居住者）。国内の老齢年金 200万円、外国の公的年金 30万円（国内での源泉徴収なし）。
- 推測：
  - 公的年金等の収入金額 230万円 → 雑所得 120万円（外国の年金も公的年金等：TA1600 の扱い〔E〕による）。
  - 121③ の 2. を満たさない（外国の年金は所法203の2 の対象外）→ 申告不要に当たらない（TA1600 注3 と同じ結論）。
  - 外国で税が差し引かれていれば、外国税額控除は対象外として返す（D20）。
- 検証：[探] 外国の年金が公的年金等に当たる条文の経路（所令72条3項などの取得）→ 検証で取得済み：所法35③三 → 所令82の2②一 → 所令72③九（H3）。[作成] 令和7年分で外国の年金の入力欄があるかと、申告の要否の表示。

## I6 端数処理で住民税の非課税（135万円）が変わる収入がある

- 前提：H8・H4。
- 場面：U（2026-12-31 に 62歳、寡婦）。令和8年分の公的年金等 2,166,667円（企業年金など）。他の所得なし。
- 推測：
  - 公的年金等の雑所得 ＝ 2,166,667 × 3/4 − 275,000 ＝ 1,350,000.25円（分数のまま）。
  - 令和9年度の住民税の非課税（寡婦で前年の合計所得金額 135万円以下）：分数のままなら 135万円を超えて課税、雑所得を円未満切り捨てにすれば 1,350,000円で非課税。→ 判定コアは「未確定（端数処理）」を返す（H8）。
  - 65歳以上なら 135万円の境目は収入 245万円（A − 110万円の帯）で端数が出ないので、この問題は起きない。扶養親族の 62万円の境目でも起きない（H8）。
- 検証：[作成] 令和7年分で 65歳未満・公的年金等 2,166,667円を入れ、表示される雑所得（1,350,000 か）を見る。作成コーナーの扱いは参考で、法令の根拠ではない（D15⑤）。[探] 申告書の様式・記載要領に端数の定めがあるか。[問] 市町村の課税での扱い。

## I7 1月1日生まれの境目

- 前提：H2・H1。
- 場面：令和8年分、公的年金等 150万円、他の所得なし。V は 1962-01-01 生まれ、W は 1962-01-02 生まれ。
- 推測：V は 2026-12-31 に 65歳 → 控除 110万円 → 雑所得 40万円 → 扶養親族に当たりうる。W は 64歳 → 控除 65万円（40万円＋(150万円−50万円)×25%。最低額 60万円より多い）→ 雑所得 85万円 → 当たらない。住民税（令和9年度）も、H2 の読み（前年12月31日の年齢）なら同じ年齢で同じ結果。ただし W（1月2日生まれ）は、地方公共団体の案内の「1月1日の現況」を1月1日の終了時の年齢と読むと 65歳になり、住民税だけ結果が変わりうる点そのもの（H2）。健保は 60歳以上の 180万円未満でどちらも収入の要件を満たす。
- 検証：[単] 生年月日 1961-12-31／1962-01-01／1962-01-02 の3点（[M] V6 と同じ点）。[作成] 令和7年分で 1961-01-01 生と 1961-01-02 生を入れ、公的年金等控除の違いを見る。[問] W の生年月日（1月2日生まれ）で、市町村の住民税の課税での年齢の扱い（H2）。

## I8 さかのぼって払われた年金が、過去の年分の扶養を変える

- 前提：H5・H4。
- 場面：X（66歳、子の扶養親族として令和8年分の申告済み）。令和8年分の老齢年金 150万円。2027年に、裁定の遅れで 2026年の各支給日に払われるはずだった分 30万円が一括で入金。
- 推測：
  - 所基通36−14 の注により、30万円は 2026年の各支給日の年分（令和8年分）に入る。令和8年分の公的年金等 180万円 → 雑所得 70万円 > 62万円 → X は令和8年分の子の扶養親族に当たらなくなる。
  - 判定コアは、令和8年分の結果が 2027年に記録された事実に依存したことを根拠に出し、令和8年分の再評価で扶養控除が外れることを示す（修正申告の要否は利用者の判断）。
  - 健保（2027年の認定）は「今後1年の見込み」で、過去分の一括入金をどう数えるかは一次情報がない。
- 検証：[単] 入金日と支給日が違う事実で、年分が支給日で決まること。[探] 国税庁の質疑応答事例・TA で、さかのぼって支払われた年金と扶養控除の関係を書いたもの。[問] 保険者（一括入金の扱い）。

## I9 未支給年金は受け取った遺族の一時所得

- 前提：H3。
- 場面：親が亡くなり、子 Y が自分の名で未支給の老齢年金 20万円を受け取る。Y にほかの一時所得はない。
- 推測：Y の一時所得の収入金額 20万円 − 特別控除 50万円 → 一時所得 0。Y の合計所得金額は増えない。亡くなった親の年分の公的年金等には入らない。
- 検証：[単] 一時所得の規則で、未支給年金を受け取った人の収入として数えること。[探] TA1605 の根拠（所基通34−2）の本文。
