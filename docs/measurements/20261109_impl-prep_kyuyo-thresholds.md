## 1. 方法

給与所得の関数 `kyuyo_shotoku(年分, 給与収入)`（`scripts/IMPL_kyuyo_thresholds.py`）：

1. 収入 6,600,000円以上：所得税法第28条第2項・第3項の式（年分に適用される版）。控除額を `Fraction` で計算し、給与所得の1円未満を切り捨てる。
2. 令和8年分・令和9年分で収入 691,000円以上 2,200,000円未満：措置法第29条の4第2項（asof 2026-12-01 の条文の5区分）。
3. それ以外（6,600,000円未満）：所得税法第28条第4項により別表第五。令和6年分は asof 2024-12-31、令和7年分は asof 2025-12-31、令和8年分・令和9年分は asof 2026-12-01 の版の機械抽出（`scripts/results/IMPL_kyuyo_beppyo5/beppyo5_<asof>.json`）。

比較用の `formula_only(年分, 給与収入)`：別表第五を使わず第28条第3項の式だけで求める（R1 の `scripts/R1_wage_thresholds.py` と同じ考え方。令和8・9年分は措置法第29条の4第1項の 74万円を含め、第2項の表は使わない。1円未満切捨て）。

境目：「給与所得 ≤ 所得要件」となる最大の給与収入を二分探索で求めた（関数が非減少であることは、全区分の境目とその1円前の値で確かめた：2024〜2028 の各年で単調性の違反 0 件）。住民税は、年度 N の所得割を N−1 年の所得で計算し、給与所得はその年分の所得税と同じ関数で求めた（この扱いの根拠は仮説の文書 H4）。
