# 仮説（impl-research 121）：所法121 の申告不要の判定に要る事実と規則

- 作成：2026-11-11。根拠：［PS-121］`docs/public-sources/20261111_impl-research_121-laws-and-nta.md`、［PS-JJ］`docs/public-sources/20261111_impl-research_joto-junjo-laws.md`、既存 ［PS-ZG］`docs/public-sources/20261109_impl-prep_zeigaku-tax-calc.md`。D14・D19・D21（準確定を含む）の範囲。

## H1 入力に要る事実

1. 給与：支払者ごとの給与等の金額（その年中に支払を受けるべきもの）。支払者の区分（主たる／従たる。第195条の扶養控除等申告書の提出の有無）。
2. 源泉徴収の対象か：支払者ごとに第183条・第190条の規定による徴収をされた又はされるべきか。除外の事実：常時2人以下の家事使用人のみに給与等を支払う者（第184条。基通121−5(1)）、在日大公使館等（基通121−5(2)）、国外で支払（基通121−5(3)）のいずれかの支払者から受けているか。
3. 年末調整の有無と、同一時点で2以上の支払者から受けていないか（基通121−4 の「一の支払者」の判定）。
4. 給与所得及び退職所得以外の所得金額：利子・配当・不動産・事業・山林・譲渡・一時・雑の所得の金額の合計（所得金額で、収入金額ではない）。確定申告を要件とする特例を適用しないで計算（基通121−6）。除くもの（TA1900）：申告不要を選択した配当等・譲渡、源泉分離課税の利子等など。
5. ただし書（所令262の2）：同族会社の役員・親族などか、同社から給与等のほかに貸付金の利子・資産の対価を受けているか。
6. ロの判定：社会保険料・小規模企業共済等掛金・生命保険料・地震保険料・障害者・寡婦・ひとり親・勤労学生・配偶者・配偶者特別・扶養・特定親族特別の各控除の額。
7. 第2項（退職）・第3項（公的年金等：収入400万円以下、全部源泉徴収〔第203条の7 の除外あり〕、公的年金等に係る雑所得以外の所得金額20万円以下）。

根拠：［PS-121］§1〜§4、［PS-ZG］§5.2。

## H2 判定（純粋関数の案）

- `申告不要(第1項)`＝給与あり、かつ給与等の合計≤2,000万、かつただし書に当たらない、かつ（第1号 または 第2号）。第1号：一の支払者（基通121−4）かつ全部が徴収された又はされるべき、かつ「その他の所得≤20万」。第2号：二以上かつ全部が徴収された又はされるべき、かつ（イ：従たる給与等＋その他の所得≤20万 または ロ：給与等≤150万＋控除合計 かつ その他の所得≤20万）。
- 課税総所得金額の読替え：分離課税の配当・譲渡がある場合、第121条第1項・第3項の「課税総所得金額」に上場株式等に係る課税配当所得等の金額などを含める（措令4の2⑧、25の8⑮。［PS-JJ］§2）。
- 第121条に該当しても申告はでき、申告書の扱いは基通121−1（［PS-ZG］§4.2）。還付の申告は別途（第122条）。

## H3 記録しておくこと

- 住民税の申告の要否は別の判定（`docs/public-sources/20261109_impl-prep_juminzei-hikazei-fuyo-shinkoku.md`）。結果は「申告不要」と「住民税の申告の要否」を別の項目にする。
- 給与以外の所得の見込みの扱いは D19。「その他の所得≤20万」に近い入力は「境目の説明」を出す。
