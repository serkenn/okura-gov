1. 調整控除・寄附金税額控除・住宅借入金等特別税額控除・配当控除・所得割の税率の条文は、令和8年度分と令和9年度分で計算に関わる文言が同じ。違いは、①基礎控除の差の加算（2026-04-01 から、令和8年度分にも適用）、
   ②特例控除の定額上限（令和10年度分から）、③住宅借入金等の居住年の延長（2026-01-01 以後の居住）、④所得控除の所得要件（58万→62万）。
2. 自治体の計算例 2 件（標準と違う税率・均等割を含む）は、条文の読みに注入値を与えるだけで再現できた。
3. 1円未満の扱いを定めた法令の文言は見つからず、扱いを変えると 20,000 件中 15〜225 件で年税額が 100〜200円変わった。

5. e-Gov API は HTTP 200 で JSON でない本文を返すことがある。

## 5. 限界

- 計算例との照合は 2 件（どちらも給与所得者・指定都市・令和8年度）。令和9年度分、指定都市以外、寄附金・住宅借入金等・配当控除を含む自治体の計算例とは照合していない。
- `compute()` は配当控除・外国税額控除・配当割額等の控除・分離課税・雑損控除などを実装していない。所得控除の内訳は計算例に出てくるものだけ。
- `compute()` は附則第3条の3第5項の B・C に、申告特例控除（附則第7条の2）を引いた後の所得割の額を使っている。条文の B・C（同項第2号・第3号）は第314条の3、第314条の6〜第314条の8、
  附則第5条第3項・第5条の4第5項・第5条の5第2項（道府県民税は対応する条）を適用した額で、附則第7条の2 を含まない。§3.7 の計算例・仮の例と §3.8 の 20,000 件の数字には影響しなかった
  （B・C を条文どおりにした再計算：`docs/measurements/20261109_round2_juminzei-tax-verification.md` の E9）。
- 1円未満の感度は仮の入力の分布に依存する（現実の分布ではない）。
