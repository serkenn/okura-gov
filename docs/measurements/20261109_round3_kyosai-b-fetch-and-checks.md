## 1. 安全の扱い

- 取得したものは set ごとに新しい空のディレクトリ `.work/downloads/<YYYYMMDD-HHMMSS>_R3X_kyosai-b_<set>/` に置いた。HTML から抽出したテキストとリンクは別のディレクトリ `.work/text/<ts>_R3X_kyosai-b_<set>/` に書いた。ダウンロード先の中でインタプリタやツールを実行していない。
- `R3X_kyosai-b_pdftext.py` はリポジトリのルートで実行し、PDF のパスを引数で受けて読むだけ。zlib の展開に上限（64 MiB）をつけた。AES は FIPS-197 の試験ベクタで自己検査した（`summary.json`：`aes_selftest_fips197` の `C.1_AES128`・`C.3_AES256` がともに true）。
- `R3X_kyosai-b_checks.py` は、上の2つが書いたテキスト（`scripts/results/R3X_kyosai-b_pdftext/`、`.work/text/*_R3X_kyosai-b_kokka_pcm/`・`*_kokka_b/`）だけを読む。PDF そのものは読まない。
- 縦書き・回転した頁は、Claude Code の Read ツールの頁指定で描画して読み、テキスト化の結果と照合した（§3.3、§3.5）。Read ツールはファイルを実行しない。
- リクエストの間は 1.5 秒あけた。User-Agent は `okura-gov-research/0.1`。個人の情報は送っていない。官報は取得していない。Web 検索に送った語は通知の番号と制度名だけ。
