### 検証方法

1. 判定コアの単体テスト（D15 ①）：上の入力を中間表現の JSON で書き、段ごとの期待値（給与所得 660,000、控除合計 1,310,000、課税総所得金額 0、精算 −40,000、申告要否「義務なし・還付申告できる」、根拠の条）を確かめる。期待値のコメントに上の表の出典を書く。
2. 境目のテスト（D15 ②）：給与収入を 1,630,000円（給与所得 890,000 → 勤労学生に当たる）と 1,631,000円（891,000 → 当たらない）にして、勤労学生の該当だけが変わり、課税総所得金額は0のままであること（H5）。
3. 作成コーナー（D15 ⑤）：令和8年分の作成コーナーが公開されたら、ユーザーが架空の値（給与 1,400,000、源泉徴収税額 40,000、勤労学生「大学」）を入れ、「還付される税金」40,000円と「課税される所得金額」0円を記録する。公開前は Z1-R7 で代える。
4. 反証になる結果：課税総所得金額が0にならない、還付額が40,000円でない、申告要否が「義務あり」になる。

## Z3 源泉徴収がない場合（令和8年分）：申告義務ありの例

### 入力（Z2 との差）

- 給与は年末調整を受けており、源泉徴収票の源泉徴収税額は 0円（例：勤務先に扶養控除等申告書を出していた）。報酬からの源泉徴収もなし（源泉徴収の対象でない取引）。源泉徴収税額の合計 0円。

### 推測（期待値）

| 段 | 期待値 | 計算 | 出典 |
|---|---|---|---|
| 課税総所得金額・税額 | Z2 と同じ（120,000円、6,000円、126円、合計 6,126円） | — | — |
| 精算 | **納付 6,100円** | 6,126 − 0 ＝ 6,126 → 所得税と復興特別所得税の合計で百円未満切捨て | [PS-ZG] §3.1（復興法24②）、§3.3（手引き ㊿） |
| 申告要否 | **義務あり** | A 真、B 偽（控除しきれない源泉徴収税額・予納税額なし）、C1 偽（給与以外の所得 500,000 > 200,000） | [PS-ZG] §5.1、§5.2、H4 |
| 期限 | 第三期：2027-02-16〜2027-03-15（2027-03-15 は月曜） | 所法120① | [PS-ZG] §5.1、[M-ZG] §6 |

- 補足（予定納税の見込み）：翌年（令和9年分）の予定納税基準額は、前年分（令和8年分）の課税総所得金額に係る税額を**雑所得の金額がなかったものとみなして**計算する（所法104①一）。雑所得を除くと課税総所得金額は 660,000 − 1,040,000 → 0 なので、予定納税は生じないはず（H8）。一般に、給与と雑所得だけの子供で予定納税基準額が15万円以上になるのは、事業所得などで課税総所得金額が数百万円規模になる場合に限られると見込む（未検証。税額15万円には、5%・10% の税率で課税総所得金額がおよそ247万5千円必要という算術による）。
- 検証方法：単体テスト（義務あり・納付 6,100・根拠の条）。境目のテスト：雑所得を 200,000円にすると C1 が真になる（Z3-S）、200,001円で偽になるが、税額は0のままなので義務はない（次節）。

## Z3-S 雑所得20万円（令和8年分）

- 推測：給与所得660,000＋雑所得200,000＝860,000 ≤ 890,000 なので勤労学生に当たり（雑所得は自己の勤労によるもの）、控除合計 1,310,000 で課税総所得金額は0。A が偽なので義務なし。源泉徴収税額が0なので還付もなし（[M-ZG] §6 の Z3-small 行（この文書の Z3-S と同じ入力）。表の「納付 0」は申告しても納める額がないという意味）。
- 推測の延長：令和8年分で、給与1か所（全部源泉徴収）の子供が「給与以外の所得20万円以下」（C1）に当たるとき、税額が出るのは給与所得が 841,000円以上（給与収入およそ 1,581,000円以上）の場合だけ（841,000 + 200,000 − 1,040,000 ＝ 1,000）。それ未満なら C1 の判定を待たずに A が偽になる。
- 検証方法：性質のテスト。給与収入と雑所得を格子状に動かし、「A が偽なら C の結果によらず義務なし」「C1 が真なら A によらず義務なし」の両方を確かめる。
