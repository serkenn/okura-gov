## 6. 実測として言えること（要約）

1. 第124条〜第127条は「死亡又は出国の場合の確定申告」の款で、確定申告書の定義（所法2①三十七）に含まれる（§3.3・T01）。したがって純損失・雑損失の繰越控除（所法70・71 の「確定申告書を提出する居住者」）の条文の文言は、死亡・出国の申告書にもかかる。
2. 所法125① の期限は、記載要領の例と一致する読みA（知った日の翌日を起算日とする4月の期間の満了日）で計算でき、通則法10② で休日の翌日に繰り下がる。出国の時の期限は繰り下がらない（T15）。
3. 期限の計算は、春分日・秋分日・建国記念の日の日付と「その他一般の休日」の範囲を取得していないため、2月・3月・9月と1月2日・3日にかかる場合は決まらない（§4 [3]、§5.4）。〔検証で追記：この前提の下での結果。一次情報を入れると決まる：§7 の注記〕
4. 所法125②・127②（還付等を受けるための申告）の項には期限の文言がない（T04・T05）。
5. 判定の時点の語は、出国（127①②）は申告の条文に「その時の現況により」と書かれ、死亡（125）の条文には「現況」の語がなく、所法85① の括弧（「以下この条において同じ」）にある（T06・T07）。
6. 所法141 は死亡（第125条）の申告書だけを引き、出国（第127条）を引かない（T08）。所法71 には青色の要件がない（T10）。
7. 令和8年分の死亡・出国の申告書を 2026-11-30 以前に出すか 2026-12-01 以後に出すかで、e-Gov の上で使う所法86・2①三十四・措法41の16の2 の版が変わり、基礎控除と扶養親族の上限の値が変わる（§3.2・§5.7）。
8. 取得した国税庁の HTML で、死亡・出国に関する「見積り」は親族の合計所得金額（所基通85−1・TA2022・TA1920）と雑損控除の親族の所得（所基通72−4）の2か所だけ（§5.2）。

## 7. 分からなかったこと・やっていないこと

- 付表の書き方（f01.pdf）は暗号の鍵の検算に失敗し、付表（f01-yoshiki.pdf）は文字列を取り出せなかった。期限の例（6/20 → 10/20）を含むこの2つの PDF の文は、［PDF目視］だけが根拠（§5.3）。鍵の検算の失敗の原因は調べていない。
- 春分日・秋分日・建国記念の日の日付（祝日法2 の表の「春分日」「秋分日」「政令で定める日」）、通則法10② の「その他一般の休日」の範囲は取得していない。期限の関数はこれらにかかる日を「決まらない」とした。
  〔検証で追記：独立検証が建国記念の日の政令（2月11日）、国税通則法基本通達（徴収部関係）第10条関係4（1月2日・3日は「一般の休日」）、国立天文台の暦要項（2025〜2027年の春分日・秋分日）を取得した（［PS］§6.1）。これらを入れると、§4 [3]・§5.4 で「決まらない」とした期限はすべて決まる（例：知った日 2026-10-28 → 2027-03-01、2025-09-02 → 2026-01-05、2027-03-16 の死亡は前年分が期限後申告）。`docs/measurements/20261109_round3_shibo-shukkoku-verification.md` §3.5〕
- 3月の日をすべて決まらないとするなどの月の当て方（春分日を3月に置くこと）はスクリプトの前提で、一次情報で確かめていない。
- 附則の「同日から五年以内」の初日を算入するかは、国税庁の日付（2030-12-02・2031-12-01）では区別できなかった（§4 [4]）。
- 相続人の按分で切り捨てた差（100円・1円未満）をどう扱うか（誰かに寄せるのか、そのままか）を書いた資料は見つからなかった（計算は切り捨てたまま）。
- 民法第900条〜第903条（相続分）は取得していない。法定相続分の計算は実測していない。
- 作成コーナーは準確定申告書を作れない（［PS］§2.3 ［e-Tax準確定］）。D15⑤（作成コーナーとの照合）は、このトピックの計算には使えない。e-Tax ソフトは試していない（使う前にコードの確認が要る：AGENTS.md）。
