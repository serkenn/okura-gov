## H1 減価償却は「資産台帳（事実）＋判断（D4）＋年分のパラメータ」から決定的に計算でき、所得区分はコアが決める

- 根拠：減価償却資産は事業所得だけでなく雑所得を生ずべき業務の用に供される資産も含む（所法2①十九）［PS-G §1］。償却費は「その者が選定した償却の方法」（届出がなければ定額法）で、取得価額・耐用年数・償却率・月数から計算する（所法49①、所令120の2・123・125・126・129・131・132・134）［PS-G §2.1］。耐用年数と償却率は省令の別表で、令和7年分と令和8年分の版で別表に差分がない［M-G §4、§5.2］。措法28の2 は事業所得・不動産所得・山林所得の業務だけ、所法51① は事業、所法51④ は業務に係る雑所得で、所得区分によって使える規定が変わる［PS-G §3.2・§5.1］。
- 仮説：
  1. 記録層（D3・D11）は、資産ごとの**事実**（下の表の「事実」）を持ち、取引ID（取得の支払、付随費用、売却の入金、除却費用、保険金）で結ぶ。所得区分（事業か業務雑か）は判定コアが決める（HANDOFF §3。既存の仮説 `20261109_impl-prep_jigyo-calculation-model.md` H10 と同じ前提）ので、資産台帳には「どの業務に使うか（業務の識別子）」だけを持ち、「事業用資産か雑所得用資産か」は持たない。
  2. 判断台帳（D4・D12）は、法令が「選択」「見積り」「判定」を求めるものを持つ（下の表の「判断」）。
  3. 判定コアは、所得区分 → 資産ごとの扱い（H2）→ 年分の償却費・必要経費算入額（H3・H4）→ 処分（H6）→ 所得の金額 → 損益通算（H7）の順に計算する。

## H3 通常の償却（定額法）の式と、一次情報で決まらない端数

- 根拠：定額法は「取得価額 × 定額法償却率」（所令120の2①一イ(1)）、年の中途で業務の用に供した年は ×月数/12（月数は暦に従い1月未満は1月。所令132①一イ・②）、有形は取得価額−1円まで、無形は取得価額まで（所令134①二イ・ロ）［PS-G §2.1］。法定償却方法は定額法（所令125二イ）。償却率は別表第八で、99 行すべて「ceil(1000/耐用年数)/1000」と一致［M-G §5.2］。償却費の1円未満の端数の扱いは見つからなかった［PS-G §10］。
- 仮説：
  1. 年分 y の償却費 ＝ min( 取得価額 × 償却率(耐用年数) × 月数(y) / 12 ,  取得価額 − 残す額 − 前年までの償却費の累計 )、残す額 ＝ 1（有形）／0（無形）。月数(y) ＝ 業務の用に供した年は「供用した月から12月までの月数」、翌年以後は12（年の中途で私用に移した年は H6）。これは暦による数え方と 2025年・2026年の全日で一致した［M-G §5.4］。
  2. 償却率は「耐用年数 → 率」の表をパラメータに持ち（施行日つき、出典＝別表第八）、表の値を正とする。ceil(1000/n)/1000 の性質はパラメータの入力誤りを見つける検査（D15 ④ の性質のテスト）に使う。
  3. **端数**：「取得価額 × 率 × 月数/12」の1円未満は名前つきの関数 `償却費の端数` にし、候補は「切り捨て」「切り上げ」。値が決まるまで結果に「出典未確認」を付ける。どちらを既定にするかは作成コーナーとの照合で決める（推測 I2）。
  4. 定率法（届出が要る）、旧定額法・旧定率法（平成19年3月31日以前の取得）、特別償却は、当面「未対応」を返す（個人の法定償却方法が定額法で、家庭の事業でこれらが要る場面は少ないと見る。SCOPE §2 原則4）。
  5. 耐用年数は判断（D4）で別表の行の ID を受け、コアが「行 ID → 年数」の表（パラメータ）を引く。表は全行を持たず、使う行だけを出典（別表の名称・種類・構造又は用途・細目）つきで足していく（概念辞書と同じ追加の手順）。登録のない行 ID は「未対応」。

## H4 家事兼用の資産：償却費の全額を計算してから事業専用割合を掛ける。未償却残高をどちらで減らすかは決まっていない

- 根拠：家事関連費の規定は業務に係る雑所得にも及ぶ（所法45①一・所令96一）［PS-J §1］。収支内訳書の「減価償却費の計算」欄は「本年分の償却費合計」「事業専用割合」「本年分の必要経費算入額」「未償却残高（期末残高）」を別の欄として持つ［PS-G §4、PS-J §7.4］。所法38②一は、業務の用に供されていた期間について「必要経費に算入されるその資産の償却費の額の累積額」を取得費から控除し、二はそれ以外の期間の「減価の額」を控除する［PS-G §2.1］。家事兼用の資産の計算の順序・未償却残高の減らし方を明示した国税庁の文章は見つからなかった［PS-G §10］。
- 仮説：
  1. 必要経費算入額 ＝ 償却費（H3 の全額）× 事業専用割合。事業専用割合は整数の分数（SCOPE §8・§10 T2、D13）で判断台帳から受ける。掛けた後の1円未満は名前つきの関数 `事業専用割合後の端数`（候補：切り捨て・切り上げ）で、出典未確認の印を付ける。
  2. 未償却残高（翌年の上限の計算と、処分のときの未償却残額）の減らし方は2通りあり、どちらかを一次情報で決められていない：
     - 案A：償却費の全額で減らす（様式が「償却費合計」と「必要経費算入額」を分けていることと合う）。
     - 案B：必要経費に算入した額だけで減らし、家事分は所法38②二の「減価の額」の考え方で別に扱う。
     既定は案A とし、名前つきの規則 `家事兼用_未償却残高` にして「出典未確認」を付ける。作成コーナー（収支内訳書・決算書の減価償却の入力）で確かめる（推測 I4）。
  3. 少額（10万円）・一括（20万円）・措法28の2 の上限の判定は、事業専用割合を掛ける前の取得価額で行う（条文は資産の取得価額で判定すると書き、按分の規定を持たないため）。出典未確認の印を付ける。
  4. 少額・一括・措法28の2 で必要経費にする額にも事業専用割合を掛ける（所令96 が家事関連費一般に及ぶため）。出典未確認。
  5. 事業専用割合が年分ごとに変わる場合は、判断台帳の年分ごとの値を使う。

## H5 私用で持っていた資産を業務に使い始めた場合は、所令135・85 で「業務供用時の未償却残額」を作ってから定額法を続ける

- 根拠：所令135（業務の用に供した日に譲渡があったものとみなした所法38②の取得費を、同日の償却後の価額とする）、所令85（耐用年数×1.5（1年未満切捨て）、旧定額法に準じる、期間の年数は6月以上切上げ・6月未満切捨て）［PS-G §2.1］。質疑応答事例 04/17 は、平成18年取得の自宅を令和7年から貸付けに使う例で、非業務用期間の減価の額を「取得価額×90%×旧定額法償却率（33年 0.031）×18年」、業務供用後を旧定額法で計算する（同事例の注2「非業務用資産の減価の額の計算は、旧定額法による」）［PS-G §2.3］。別表第七の旧定額法償却率で事例の数字（15,066,000円）を再現できた［M-G §5.4 E9 検算］。
- 仮説：
  1. 業務供用時の未償却残額 ＝ 取得価額 − 減価の額、減価の額 ＝ 取得価額 × 0.9 × 旧定額法償却率(floor(法定耐用年数 × 1.5)) × 年数（6月以上切上げ）。0.9 は質疑応答事例の算式（旧定額法の残存価額10%）に従う。ただし減価の額は、所令85①後段により、同種の減価償却資産が所令134①一イ又はハに当たる場合はそこに定める金額（有形は取得価額の百分の九十五）を限度とする［PS-G §2.1］。この限度が平成19年4月1日以後に取得した資産に及ぶかは確かめていないので、名前つきの規則 `所令85_限度` にして「出典未確認」を付ける（私用の期間が短い E9・I5 では限度に届かない［M-GV §3.7］）。
  2. 平成19年4月1日以後に取得した資産は、業務供用後は**定額法**（取得価額 × 定額法償却率 × 月数/12）で、未償却残額が1円になるまで。質疑応答事例 04/17 の計算例は平成19年3月31日以前の取得なので業務供用後も旧定額法で、平成19年4月1日以後の取得の計算例は見ていない。ただし、同事例の末尾の注は平成19年4月1日以後に取得した建物は定額法によるとし、TA No.2109 は業務供用後の償却方法を取得年月日（転用した日ではない）で決めるとし、所令135 後段は取得価額と業務供用時の償却後の価額との差額を所令134 の適用上すでに必要経費に算入された償却費とみなす［PS-G §2.1・§2.3］。これらは「取得価額 × 定額法償却率で、累積（差額＋業務供用後の償却費）が取得価額−1円に達するまで」という読み方と合う。計算例での確認がないので「出典未確認」の印は残す（推測 I5 で作成コーナーと照合）。
  3. 年数の数え方（取得日から業務供用日までの満月数）と、年数の端数処理（所令85②）は名前つきの関数にする。日の端数の扱い（満月数を数えるときの日の切捨て）は条文に書かれておらず、計算例では切り捨てた［M-G §5.4 E9］。ただし「六月以上の端数は一年」の判定は、日の端数を切り捨てても変わらない（端数が6か月以上であることと、端数のうちの満月数が6以上であることは同じ）ので、結果に効く曖昧さは月末の応当日の扱いだけ［M-GV §6］。
  4. 記録層は、資産の取得日と、業務の用に供した日を別々に持つ（H1 の表）。取得が業務の開始より前なら、コアは H5 を使う。

## H6 処分（除却・譲渡・私用への転用）は、所得区分ごとに行き先が違う。業務に係る雑所得は所法51④の上限がある

- 根拠：所法49① は「その年十二月三十一日において有する減価償却資産」の償却費。所法51①（事業の用に供される固定資産の取りこわし・除却・滅失の損失は必要経費、譲渡に関連するものを除く）、所法51④（雑所得を生ずべき業務の用に供される資産の損失は、この項を適用しないで計算した雑所得の金額を限度）、所令142一（損失の基礎は所法38の取得費＝取得価額−償却費の累積額）［PS-G §5.1］。白色申告者の決算の手引き：除却等の年の償却費の計算は省略できる（30(4)）、譲渡の年の償却費は必要経費にしてもよい（30(3)）、売却代金は原則譲渡所得、少額・一括の資産（業務の性質上基本的に重要なものを除く）などは事業所得の収入（12）［PS-G §5］。所令81 の列挙に措法28の2 はない［M-G §5.1］。一括償却資産は除却・譲渡しても3年間1/3を続ける（所基通49−40の2）［PS-G §3.1］。所令132①二（年の中途で業務の用以外の用に供した場合は、1月1日からその日までの月数）［PS-G §2.1］。
- 仮説：
  1. 除却・取壊し・滅失（事業所得に区分された業務）：除却損 ＝ 処分の時の未償却残高 − 処分可能価額 + 取壊し費用等 − 保険金等（手引き ❺ の式）を必要経費に入れる。事業所得の損失を作りうるので、損益通算（H7）に流れる。
  2. 同（業務に係る雑所得に区分された業務）：同じ式の損失を、所法51④ によりその年の雑所得の金額（この損失を入れる前）を限度に必要経費に入れる。限度を超える部分は切り捨てる（繰り越さない）。
  3. 処分の年の償却費：既定は「計算する」（TA 2106・収支内訳書の書き方が、年の中途で取得・取壊し・譲渡した場合に月数で計算すると書くため）。手引き 30(4) の省略は判断（D4）で切り替える。省略しても所得の金額は変わらない：事業所得では必要経費の合計が同じ、業務に係る雑所得でも所法51④の上限の下で、0 未満を 0 とした雑所得の金額は 7,216 通りの総当たりで一致した［M-G §5.5］。違うのは収支内訳書の科目（減価償却費か、その他の経費の除却損か）の表示だけなので、判断は出力の層の表示に使う。
  4. 譲渡：少額・一括の資産で「業務の性質上基本的に重要なもの」でない（判断）ものの売却代金は、その業務の所得（事業所得又は雑所得）の総収入金額。それ以外の売却は譲渡所得（総合課税）で、SCOPE §5.2 の所得の列挙にない（HANDOFF D20 が対象外とするのは土地建物等の譲渡で、総合課税の譲渡所得の扱いは決まっていない）ので、当面「未対応」を返す。措法28の2 を適用した資産の売却も（所令81 の列挙にないので）譲渡所得として「未対応」に入る。
  5. 一括償却資産は、除却・譲渡しても残りの年の1/3を続け、除却損は出さない。少額の資産の除却は何もしない（取得の年に全額が必要経費のため）。
  6. 私用への転用（所令132①二）：その年の償却費は1月1日（又は業務供用日）から転用日までの月数。転用後の未償却残高は持ち続け、資産台帳上は「業務外」の状態にする。

## H7 損益通算は所令198 の順序の関数として、人・年分ごとに「所得区分ごとの所得の金額」から計算する。令和7年分と令和8年分で同じ順序を使う

- 根拠：所法69①（不動産・事業・山林・譲渡の損失だけ）、所法22②（一時所得と長期譲渡所得は損益通算の後に2分の1）、所令198（経常所得 → 譲渡（短期から）→ 一時 → 山林 → 退職、譲渡の損失は一時 → 経常 → 山林 → 退職、山林の損失は経常 → 譲渡 → 一時 → 退職）、所令199（変動・被災・その他の順）、所令201③（繰越控除は損益通算の後）、所法2①二十五（純損失）［PS-G §6・§7］。損失申告用の手引きの矢印の順序も同じ［PS-G §6.3］。所令198 第3号・第6号の「及び」→「又は」は令和8年政令第93号（2026-04-01 施行）で、経過措置の条は見つからなかった［PS-G §6.2、M-G §4.1］。雑所得・一時所得・給与所得・配当所得の損失は通算しない（TA 2250）［PS-G §6.3］。
- 仮説：
  1. 入力（コアの中で作る中間の値）：人・年分ごとに、経常所得の各金額（利子・配当・不動産・事業・給与・雑。雑所得は内部で通算した後、負なら 0）、譲渡所得（短期・長期。特別控除後）、一時所得（特別控除後。0以上）、山林・退職。損失は不動産・事業・山林・譲渡の金額が負のとき。
  2. 出力：損益通算後の各金額、総所得金額（経常＋短期譲渡＋（長期譲渡＋一時）×1/2）、**合計所得金額**（繰越控除の前。扶養・配偶者・各控除の所得要件に使う［R1 §4］）、純損失の金額とその内訳（変動所得の損失・被災事業用資産の損失・その他。所令199 の順で、その他から先に通算に使う）、申告書第四表「2 損益の通算」の欄（通算前・第1次・第2次・第3次通算後）に当たる中間値。
  3. 令和7年分と令和8年分で同じ順序の関数を使う。「及び」→「又は」は計算の順序を変えないと読む（どちらの文言も「順次控除する」で、第3号後段が短期譲渡を先にすると定めるため）。改正の趣旨を確かめるまで、関数の版の記録に「所令198 の文言が令和8年分で変わった（2026-04-01 施行）」を残す。
  4. 対象の範囲：HANDOFF D20・SCOPE §5.2 で不動産所得と退職所得は対象、山林所得は対象外。したがって「不動産所得・事業所得の損失 → 経常所得 →（譲渡所得）→ 一時所得 → 退職所得」の順（所令198一・三・五）と純損失の算出を実装し、山林所得がある入力は「対象外」を返す。総合課税の譲渡所得は SCOPE §5.2 の所得の列挙になく扱いが決まっていないので、その金額がある入力は当面「未対応」を返す。不動産所得の損失のうち、生じなかったものとみなされて通算できない部分（土地等を取得するための負債の利子に相当する部分、別荘等の貸付け、特定組合員の組合事業、国外中古建物の償却費相当部分）を除く処理が要る［PS-G §6.3（TA 2250 注4）］。その根拠条文（租税特別措置法の該当条）は本調査で取得していないので、実装の前に一次情報で確かめる。生活に通常必要でない資産の損失（所法69②）は「未対応」。
  5. 順序を無視した単純な合計とは結果が違う（例：事業 −500,000、給与 300,000、雑 100,000、一時 200,000 で、順序どおり 50,000、単純な合計 0）［M-G §5.4 E6］ので、D15 ② の境目のテストに入れる。
  6. 一時所得の 1/2 で生じる1円未満の端数は、所法22 に「端数」の語がない［PS-J §11］ので、名前つきの関数で扱う（既存の仮説 `20261109_impl-prep_jigyo-calculation-model.md` H6 と同じ扱い）。

## H8 純損失の繰越控除は「年をまたぐ依存」で、前年以前の申告の事実と青色の状態を入力に持つ。住民税は別に持つ

- 根拠：所法70①（青色の年の純損失を3年繰越）、②（青色でない年は変動所得の損失・被災事業用資産の損失だけ）、④（純損失が生じた年分の確定申告書を提出し、その後連続して提出している場合に限る）、所令201（古い年から、損益通算の後に控除）、所令199（変動・被災・その他の順）、所法2①二十三・所令7の2（変動所得＝漁獲・のり・養殖・原稿若しくは作曲の報酬・著作権の使用料）、所法140（繰戻し還付は青色）、合計所得金額は繰越控除の前［PS-G §7、R1 §4］。地方税法313②（総所得金額等は所得税法の計算の例）、⑧（青色の年の純損失は、住民税の申告を連続して出している場合に限り控除）、⑨（変動・被災）［PS-G §8］。
- 仮説：
  1. 前年以前3年の純損失は、記録から再計算せず、**その年分に提出した確定申告書（損失申告）の記載の事実**として入力に持つ（年分、純損失の金額とその内訳（変動・被災・その他）、青色か、提出日、前年以前に控除済みの額）。既存の仮説で前々年の収入を「確定した値の入力」として持つのと同じ考え（記録からの再計算は、当時の判断と版を再現できないため）。
  2. 連続して確定申告書を提出したかは「年分ごとの提出の事実」の列で持ち、コアが所法70④を判定する。欠けている年があれば繰越控除をしない。
  3. 白色の年の純損失は、変動所得（原稿・作曲の報酬、著作権の使用料など）と被災事業用資産の損失の部分だけ繰り越す。変動所得に当たるかは所得区分と同じく判定コアの判断で、材料は「支払の種類（原稿料・作曲料・著作権の使用料など）」の事実。
  4. 繰越控除は総所得金額などを減らすが、合計所得金額（扶養などの判定）は減らさない。コアは両方を出し、使う側（概念辞書の ID）を分ける。
  5. 住民税の純損失の繰越控除は、所得税と同じ純損失の金額を使うが、要件が住民税の申告の連続提出（青色の年は地方税法313⑧、白色の年の変動所得・被災事業用資産の損失は同⑨で、要件の始まりの年度が違う）なので、所得税とは別の状態（年度ごとの住民税の申告の事実）として持つ。
  6. 純損失の繰戻し還付（所法140）は前年分の税額の再計算を要するので、当面「未対応」（請求するかは本人の選択＝判断）。
  7. これは SCOPE §6 の5 の「年をまたぐ依存」に当たり、概念辞書に「所得税.純損失の繰越控除 ← 前3年の 所得税.純損失の金額（入力の事実）」と明記する。

## H9 健保・国保・住民税との境目：減価償却費は所得税の必要経費として計算し、別の制度が使うかは注入するデータで決める

- 根拠：協会けんぽの令和8年度リーフレットは、自営業者の収入から差し引けない経費の例に「減価償却費」を挙げ、船員保険の用語集も「控除できない例：減価償却費」とする［PS-K §1.2 の表「事業収入（自営業）」］。住民税の総所得金額等は所得税法の計算の例による（地方税法313②）［PS-G §8］。
- 仮説：
  1. 判定コアは、事業・業務の必要経費を「減価償却費（資産ごと）」「少額・一括・措法28の2 の必要経費算入額」「除却損」と、それ以外の経費に分けた明細で出す。所得税の計算はその合計を使う。
  2. 健保の被扶養者の「収入」の計算は、保険者ごとのデータ（D17・D19：出典つきの宣言的なデータ）で「どの経費の種類を差し引けるか」を指定する。協会けんぽは「減価償却費を差し引けない」をデータとして注入する。データがなければ、差し引く場合・差し引かない場合の両方で評価し、結論が分かれれば「未確定」を返す（D19）。
  3. 住民税（所得割の課税標準・非課税の判定）は、所得税と同じ減価償却費・損益通算の結果を使う（市町村ごとに変わる値はない）。違うのは純損失の繰越の要件（H8-5）だけ。
  4. 国民健康保険料の所得の算定が繰越控除の前後どちらの値を使うかは本調査で調べていない［PS-G §10］。コアは「損益通算後・繰越控除前」と「繰越控除後」の両方を出し、国保の側（注入するデータ）がどちらを使うかを宣言する形にしておく。
