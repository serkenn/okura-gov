# 推測：impl-research9 の仮説から出る判定コア・様式の対応表への影響と、確かめる方法

前提の仮説：`docs/hypotheses/20261112_impl-research9_tokutei-jumin-reading.md`（H1〜H5）。

## I1 地法313⑪ の「納税義務を負わない」（H1）

- 判定コアの読みの候補（税額控除の後の額が0／算出税額が0）は断定にできない。第3の候補（所法120① の基準：算出税額が配当控除の額以下）を足すと、
  配当控除だけで所得税が0 になる人の結論が候補の間で分かれうる（前の2つの候補では、配当控除で0 の人は「後が0」で負わない・「前が0」で負う）。
- 確かめ方：総務省の「地方税法の施行に関する取扱いについて（市町村税関係）」の現行の全文（総務省の通知の一覧ページか、地方税関係の法令集）で第313条第11項の記述を探す。
  見つかれば公開資料の情報に記録し、読みの候補を1つにする。

## I2 必要書類（H2）

- 判定コアの計算は変わらない。README・概念の注の「総務省令で定める必要な書類は docs にない」は、施行規則第1条の12（所令167の4 の明細書・所令167の5 の書類）に直せる。
- 確かめ方：不要（条文で決まる）。

## I3 様式の対応表 KOA020-01 の G13・G16（H3・H4）

- 今の対応表は G13 に特定支出控除、G16 に所得金額調整控除を写しているので、特定支出控除・所得金額調整控除のある人で欄が入れ替わる。直すと：
  - G13（㋔の区分）：所得金額調整控除の第1項だけ 1、第2項だけ 2、両方 3、なければ空欄。
  - G16（⑥の区分）：特定支出控除を受ける（適用の選択が真で、2分の1 を超える）とき、適用を受ける区分の番号の和（1〜511）。受けないときは空欄。
    判定コアの区分ごとの差引金額（通勤・旅費・転居・研修・資格・帰宅・図書・衣服・交際）が要る（今は合計額だけ）。
- 確かめ方：作成コーナー（令和7年分、架空の数字）で、所得金額調整控除の第2項だけがある人と、特定支出（通勤費と研修費など）のある人の第一表を作り、
  ㋔・⑥ の区分の印字を見る（例：通勤費＋研修費なら ⑥ の区分 5 になるはず）。

## I4 明細書 KOB070（H4）

- 欄の対応表を足すなら、様式ID KOB070（7.0）、⑪ BGL00000＝特定支出の額の合計額、⑫ BGM00000＝区分の合計、⑬ BGN00000＝給与等の収入金額、
  ⑭ BGO00000＝特定支出控除の前の給与所得の金額、⑮ BGP00000＝⑬−⑭、⑯ BGQ00000＝⑮×1/2、⑰ BGR00000＝⑪−⑯（赤字は0）、⑱ BGS00000＝⑬−⑮−⑰。
  紙の様式に欄コード（G01 など）の印字はないので、位置名と XML タグで鍵にすることになる（今の対応表は AI-OCR の欄コードを属性にしている）。
- ⑮ は ⑬−⑭（⑭ は別表第五の額）で、判定コアの給与所得控除額（第28条第3項の式）と数円〜数千円違いうる（impl-research8 I2）。⑱ も同じ。
- 確かめ方：作成コーナーで特定支出のある人の明細書を作り、⑫ と ⑮〜⑱ を判定コアの値と比べる。

## I5 第二表「特例適用条文等」（H5）

- 特定支出控除を受ける人の第二表の「特例適用条文等」に「所法57の2 XXX,XXX円」（XXX,XXX は特定支出の額の合計額）を出す。家内労働者等の特例（措法27）もある人は両方を並べる。
- 確かめ方：作成コーナーで特定支出控除を入れたときの第二表の印字を見る（区切りと数字の全角・半角）。
