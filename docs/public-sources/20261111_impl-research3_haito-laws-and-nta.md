## 1. 法令

- 所法24②：「配当所得の金額は、その年中の配当等の収入金額とする。ただし、株式その他配当所得を生ずべき元本を取得するために要した負債の利子（…）でその年中に支払うものがある場合は、当該収入金額から、その支払う負債の利子の額のうちその年においてその元本を有していた期間に対応する部分の金額として政令で定めるところにより計算した金額の合計額を控除した金額とする。」
- 所令59②：「…その年中に支払う同項に規定する負債の利子の額を十二で除し、これにその年において当該負債により取得した元本を有していた期間の月数を乗じて計算した金額とする。」③ 月数は暦に従い、1月に満たない端数は1月。
- 所法92①（配当控除）：剰余金の配当等（イ）と証券投資信託の収益の分配（ロ）の「配当所得」ごとに「当該配当所得の金額」に率を掛ける（第1号〜第3号。課税総所得金額1,000万円の境目）。**区分ごとの「配当所得の金額」を、所法24② の負債の利子の控除の後の金額からどう分けるかは書かれていない。**
- 措法9①：外国投資信託・国外私募公社債等運用投資信託・外国株価指数連動型特定株式投資信託・特定外貨建等証券投資信託・特定目的信託・特定目的会社・投資法人などの配当等に係る配当所得には所法92①を適用しない。②：その場合の所法92① の読替え（「及び租税特別措置法第九条第一項各号（配当控除の特例）に掲げる配当等に係るもの」を除く）。③：特定株式投資信託の収益の分配は剰余金の配当等の区分（10%）に読み替える。④：一般外貨建等証券投資信託の収益の分配は率を半分にする読替え。
- 措令4の4②：外貨建等証券投資信託・特定外貨建等証券投資信託の範囲（外貨建資産割合・非株式割合 50%・75%）。
- 措令に「配当控除」と「負債の利子」の配分を定める条は見つからなかった（`scripts/results/IMPL3_egov_fetch/haito/grep_sochirei_<asof>.txt`：「配当控除」を含む本則は第4条の4と試験研究等の税額控除の条だけ。所令の「配当控除」は第1条・第258条だけ）。

## 2. 通達・国税庁の説明

- 所基通24−5(1)：「株式等を取得するために要した負債の利子で、その年中における当該株式等の所有期間に対応して計算された金額は、当該負債によって取得した株式等の配当等からだけでなく、他の株式等の配当等からも控除できること。」(2) 処分した株式等の負債はその処分の時までの利子に限る。
- 所基通24−6：負債を株式等の譲渡の所得の株式等と配当の株式等とに区分することが困難なときの算式（配当所得の収入金額の比による按分）。**これは配当と株式等の譲渡の間の按分で、配当控除の区分の間の配分ではない。**
- 所基通24−7〜24−10：借換え、一部の譲渡（銘柄ごとの数の比）、買換え、月数按分（年の中途で取得・譲渡し、利子が1月1日〜12月31日の期間で計算されたときに限る）。
- TA1250（配当控除）：配当控除の計算のパターン1〜4。負債の利子の配分には触れていない。TA1330：配当所得の金額＝収入金額−株式などを取得するための借入金の利子（保有期間に対応する部分）。
- 「特定証券投資信託に係る配当控除額の計算書」の書き方（10-03-ki.pdf、取得 2026-11-11、Last-Modified 2026-06-30）：特定証券投資信託・特定外貨建等証券投資信託の定義と、計算の（1）〜（4）を「剰余金の配当等に係る配当所得の金額」「特定証券投資信託の収益の分配に係る配当所得の金額」で書く。**負債の利子の語はない**（`scripts/results/IMPL3_pdf_lines/hits.txt` に haito_keisansho_ki の「負債の利子」の当たりなし）。計算書の様式（10-03.pdf）は文字を取り出せなかった（文字の行 0。［M3-F］§6）。
- 確定申告の手引き（令和7年分）の総合課税の配当所得の計算欄（既存の取得 `scripts/results/IMPL2_phase2c_nta/tebiki_html/t3_2_05.txt`）：A 配当等の収入金額（合計）− B 負債の利子 ＝ C 配当所得の金額（赤字のときは0円）。配当控除の欄（`t3_4_28.txt`）は「配当所得の金額（※1）（配当控除の対象となるもの）」「※1 他の所得の赤字と損益通算する前の配当所得の金額です。」で、負債の利子の区分ごとの配分は書かれていない。

## 3. 分からなかったこと

- **配当控除の区分（剰余金の配当等／証券投資信託の収益の分配／一般外貨建等証券投資信託の収益の分配）が2つ以上あり負債の利子があるとき、負債の利子をどの区分の配当所得の金額から控除するかを定める一次情報は見つからなかった**（法令・所基通24関係・TA1250・TA1330・手引き・計算書の書き方）。読みの候補は ［H3］ H3。
- 計算書の様式（10-03.pdf）の欄の構成は、文字を取り出せず確かめていない。
