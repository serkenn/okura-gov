## 1. 条文

- 所法183①：「居住者に対し国内において第二十八条第一項（給与所得）に規定する給与等（…）の支払をする者は、**その支払の際**、その給与等について所得税を徴収し、その徴収の日の属する月の翌月十日までに、これを国に納付しなければならない。」②：法人の役員の賞与は、支払の確定した日から1年を経過した日までに支払がされない場合、その1年を経過した日に支払があったものとみなす（所基通183−1：「支払の確定した日（36−9に定める日）の属する年の翌年の応当日の翌日」）。
- 所法185①（賞与以外の給与等）：
  - 第1号（給与所得者の扶養控除等申告書を提出した居住者に、その提出の際に経由した支払者が支払う給与等）：その給与等の金額（ロ・ハ・ニ・ヘは2倍・3倍・月割額・日割額）と、申告書に記載された源泉控除対象配偶者及び**源泉控除対象親族**（R8。R7 の版は「控除対象扶養親族」）の有無・数に応じ、イ 毎月支給：別表第二の甲欄、ロ 毎半月：甲欄の1/2、ハ 毎旬：甲欄の1/3、ニ 月の整数倍の期間：甲欄×倍数、ホ 毎日：別表第三の甲欄、ヘ その他：別表第三の甲欄×支給日数。
  - 第2号（それ以外の給与等）：同じ区分で別表第二・第三の**乙欄**（従たる給与についての扶養控除等申告書があればその源泉控除対象配偶者・源泉控除対象親族の数に応じる）。
  - 第3号（日雇い等で政令で定めるもの）：別表第三の**丙欄**。
  - ②：月割額・日割額の意義などは政令で定める（政令〔所令〕の該当条は今回取得していない）。

## 3. 未払の給与との関係（条文から言えること）

- 所法183① の源泉徴収は「その支払の際」に行う。所法120①四の「源泉徴収をされた又はされるべき所得税の額」の「されるべき」額を、未払の給与についてどう扱うかを定める条文・通達は、今回の取得（所法183・185〜187・190、所基通183関係）には見つからなかった。
- 別表で「されるべき」額を計算するには、支給期（毎月・毎半月・毎旬・月の整数倍・毎日・その他）、扶養控除等申告書の提出の有無（甲・乙）、社会保険料等の額、扶養親族等の数（加算を含む）が要る（所法185①・別表の備考）。
