# rules/personal_deductions：人の区分と人的控除・扶養の割当て

登録済み。令和7年分・令和8年分の人の区分（その人だけで決まるもの）、扶養の割当て（所令218〜220）と扶養・配偶者などの判定、所得金額調整控除の第1項の「有する」、

### 4.1 段階評価の段（allocation.py。D23 K1）

| 段 | 読む値 | 書くもの |
|---|---|---|
| 所得金額調整控除の対象の親族等 | 判定用の合計所得金額・年齢・特別障害者か・給与等の収入金額 | `所得金額調整控除の対象の親族等を有するか`（措法41の3の11①。親族の組ごと。同じ子を夫婦の双方が有する：措通41の3の11−1。親族自身の第1項の控除の後の額で比べ、最小・最大の不動点が違えば読みの分かれ目） |
| 扶養の割当て | 合計所得金額・年齢・居住者か・総所得金額・退職所得金額・申告分離課税の上場株式等の所得・特別障害者か・障害者か | 扶養所属・法律婚のグループ、申告者・配偶者との関係の入力（親族か・子か・生計・同居・直系尊属・専従者・書類・送金・適用除外）、連鎖の扶養親族等か・申告者、死亡した申告者のための見積り、法律婚のグループ外の配偶者の材料 |
| 扶養の連鎖の合計 | 連鎖の人の1人分の額（扶養控除・特定親族特別控除・障害者控除）・扶養親族か・ひとり親の子か | 申告者の `連鎖の扶養親族の…の額`・`連鎖の扶養親族がいるか`・`連鎖のひとり親の子がいるか` |

- **所属の決め方**（所令218〜220、docs/public-sources/20261109_impl-prep_misc-age-kinship-attribution.md §3.2。仮説は misc H3・H4）：
  1. 配偶者の候補：判定の時に続いている婚姻（配偶者が既に死亡していればその死亡の時）。年の中途の死亡と再婚は所令220①：申告書等の記載（`entries` の spouse・`選択.配偶者の記載`）で一人、
     なければ `選択.配偶者の記載`（key `所令220:<人>`）の未入力として「死亡した配偶者・再婚した配偶者・どちらもしない」の候補で評価する。相手が別の人を選んだ側は、相手の所得が配偶者の上限の範囲なら配偶者の値を対象外にする。
  2. 扶養親族・特定親族になりうる組：親族（民法の親族：kinship.py。里子・養護受託老人を含む）・生計を一にする（`判断.生計を一にする`。未入力なら候補で評価）・専従者でない（所基通2−48）・合計所得金額が上限以下
     （又は特定親族の年齢と上限）・申告者が居住者。
  3. 配偶者が同一生計配偶者（又は配偶者特別控除の対象）にも当たるとき（所令218・218の2）：他の人だけが記載していればその人の扶養親族等、双方の記載・どちらもないときは配偶者。
  4. 記載の取り消し（所令218①・219① ただし書、所基通85−2。2026-11-11）：記載した人が後に提出した同じ区分の申告書等（記載の欄のあるもの）でその人を記載しなければ、前の記載は使わない（`_withdrawn`。法令の読み）。
  5. 年の中途の死亡と再婚（所令220②③。2026-11-11）：③ 死亡した配偶者が死亡の日までの申告書等で他の居住者の扶養親族とされていれば、再婚した配偶者を配偶者にする。② 一人を配偶者としたら、ほかの一人は他の居住者の扶養親族に当たらない。どちらも配偶者としないで二人とも他の居住者の扶養親族に当たりうるときは「一人に限り」をどちらにするかの定めがないので読みの分かれ目。相手が別の人を配偶者とした側（x→y、y→z）は法律婚のグループに入れないので、`グループ外の配偶者の…` の入力で同一生計配偶者・配偶者特別控除・老人・障害者控除を判定する（以前の PD-18）。
  6. 二以上の居住者の扶養親族等に当たるとき（所令219）：一人だけが記載していればその人、二人以上が記載していれば最も早い提出日の人（第2項第1号の「既に…記載により…としている」の読み）、
     それでも決まらなければ所得の合計額（総所得金額・退職所得金額・上場株式等の所得：措令4の2⑨・25の11の2⑳）が最も大きい人（第2号）。同額なら `選択.扶養の所属`（key `所属:<人>`）の
     未入力として候補で評価する（未確定と「何を入力すれば決まるか」）。記載は提出した書類（filed_document の entries。その年分の tax_year）が主で、同じ記載者・相手の書類がなければ選択を使う。
- **扶養の連鎖**（misc H5 の案A）：扶養親族等とされた人が自分も申告者なら、グループでは自分のインスタンスの申告者に置き、`連鎖の扶養親族等か` を真にする。その人の分の額は段 扶養の連鎖の合計 が
  申告者の入力に足す。相互の扶養（2人が互いに扶養親族）も同じ形で表す。
- **判断の1か所を置く親族の組**：直系の血族・法律婚の相手・里子などは常に、それ以外の親族（兄弟姉妹・おじおば・姻族など）は、組の判断・同じ世帯の住民票・
  申告書等の記載のどれかがあるときだけ `判断.生計を一にする` の1か所を置く（候補の直積の上限を超えて関係のない値まで未確定にしないため）。材料のない傍系の親族は扶養親族等の候補にしない
  （その組の判断を入力すれば候補になる）。`判断.同居を常況` は老人扶養親族の年齢以上・障害の根拠がある人の組だけ。
- **所得金額調整控除の第1項の「有する」**：第1段の値（第1項の控除の前の合計所得金額）から、親族自身の第1項の控除（親族も有するとき）を引いた額で比べる。人をまたいで互いに依存するので、全員「有しない」・全員「有する」から反復した最小・最大の不動点を求め、一致すればその値、違えば読みの分かれ目（一次情報。2026-11-11：以前の PD-15 の対象外）。
  給与等の収入金額が基準以下の人は親族の値を読まない（関係のない予測を伝えない）。
- **配偶者特別控除の適用除外**（所法83の2②）：夫婦の双方が互いに要件に当たるときは、申告書等の記載（又は選択）で一人に決まればそれ以外を除外し、決まらなければ対象外（入力を求める理由つき）。
  第2号（源泉控除対象配偶者として記載し、年末調整・確定申告がない）は扶養控除等申告書の記載と源泉徴収票の年末調整の欄で判定。
- **特定親族特別控除の適用除外**（所法84の2②、所令217の2）：第1号は割当てで特定親族が自分の特定親族を有するか、第2号・第3号（令和8年分以後）は扶養控除等申告書の記載と年末調整・確定申告の有無。

### 4.2 そのほか

- **寡婦**（所法2①三十の「夫」）：相手の法令上の性別（`legal_sex`。婚姻が終わった日の現況）が male の婚姻だけを `夫と離婚した…`・`夫と死別した…` の入力にする（female は当たらない）。
  性別の記録がない婚姻は当たりうるものとして入力し、寡婦に当たると判定された人だけ `寡婦に当たるか` を対象外にする（checks.py。性別は要件を狭める向きにだけ効くので、当たらない人は止めない。2026-11-11）。
- **住民票の事実婚の続柄**（所規1の3・1の4）：記載を確かめられない人（住民票の記録・続柄の記載がない）は、寡婦・ひとり親に当たると判定された人だけ、当たると判定した方の判定を
  対象外にする（checks.py。以前は婚姻をしている人など、記載によらず当たらない人まで入力で止めていた：2026-11-11 に直した）。
- **年の中途で死亡した人**の親族に関する控除の額：親族の合計所得金額を死亡の時の現況で見積もる（所基通85−1(2)）。`見積り.親族の合計所得金額`（person=親族、taxpayer=死亡した人）を
  段 扶養の割当て が読み（`relative_value`）、`扶養等の判定に使う合計所得金額` の入力にする（状態「見積り」：D21 R2。2026-11-11）。見積りのない親族（生計を一にしないと判断された人を除く）がいれば、死亡した人の親族に関する控除の額を、入力を求める理由つきで対象外（checks.py。判定の変数でなく額を止める）。ひとり親の子の総所得金額等（所令11の2②）は合計所得金額ではないので見積りにしない（法令の読み）。
- **居住者**：`abroad_stay`・`判断.住所の所在` を使うので `scope.residency_exclusions` は止まる。代わりに `inputs.py` が、国外の滞在があって判断がない・食い違う人と、
  年の途中で納税管理人の届出の後に国外へ移った人の値を範囲外にする（納税管理人の届出なしの出国は出国の時で判定する：PD-05、2026-11-12）。期間の重ならない国内・国外の判断（入国の年など）は判定の時の値で居住者かを決め（2026-11-11）、
  その人自身の所得控除の額は非居住者の期間の計算（所法102・165：非居住者本人の申告）として範囲外（checks.py）。
  非居住者の期間がある所得の記録のある親族の合計所得金額は、(a) 国内源泉所得だけ・(b) 全世界の所得 の読みで違いうる（impl-research3 H2。一次情報なし）。(a) の値を出す語彙がないので、
  その人を扶養親族等・配偶者として判定しうる人の関係の入力に読みの分かれ目（一次情報）を付けて未確定にする（`nonresident_income_splits`）。
  `判断.国内源泉所得の内訳`（2026-11-12）で国内源泉所得以外の所得が0なら、読みで値が分かれないので分かれ目にしない。
- **国外居住親族**（所法2①三十四の二ロ、SCOPE §5.1。2026-11-11 の結合のレビューで足した）：年分を通じて住所が国外で所得の記録がない人は、合計所得金額0として
  居住者の扶養親族等の判定に使う。その人自身の所得控除の額（ほかのモジュールの控除を含む）は checks.py が「範囲外」にする（非居住者本人の申告：D20）。
  書類（`所得税_国外居住親族の書類の要件を満たすか`）は、申告者が持つ親族関係書類と、その年の送金関係書類（38万円送金書類を含む）の両方（所令262④一：
  elderly-abroad-laws §3.2）。30歳以上70歳未満の非居住者は、区分ごとの書類（所令262④二：留学は第1号の書類と留学ビザ等書類、三：38万円以上は親族関係書類と
  その年の38万円送金書類。障害者は第1号）を `…留学の区分の書類の要件を満たすか`・`…38万円以上の区分の書類の要件を満たすか` に書き、式が区分の要件と合わせて判定する（2026-11-11）。
  非居住者には住民票がないので、事実婚の続柄を確かめられないことによる対象外（寡婦・ひとり親）は付けない（その人自身の控除は範囲外で止まる）。
- **親族の候補の集まり**：親子・婚姻などの記録で、その年分に生存していない人（死亡した配偶者・親）を通してもつなぐ（死亡した配偶者の父母は姻族のまま：民法728②）。
- **年齢**：判定の日の終了時の年齢。死亡の時の現況は、死亡の日の前日の終了時までに達した年齢（その日の終了時に加わる1歳を含めない。所法85③ ただし書の法令の読み：impl-research3 H6。2026-11-11）。

- **同居**：措法41の16（申告者又は配偶者）と所法79③（生計を一にする親族を含む）は範囲が違うので別の概念。

### 4.3 境目の説明（2026-11-12。D19、SCOPE §2-6、`boundaries.undeclared`）

- 主要な判定（扶養・特定親族・勤労学生・配偶者）と寡婦・ひとり親（本人と子）の所得の比較を、比べる量と基準の比較だけを持つ真偽の判定（`…要件`）に分け、
  判定の概念はそれを依存として読む（値は変えない）。基準が葉1つのパラメータのもの（年分の値はパラメータの日付で変わる）は `基準`。
  `所得税.扶養親族の所得要件` の比べる量を 所得税.扶養等の判定に使う合計所得金額 に直した（式と同じ額。年の中途で死亡した申告者の見積り）。
- 控除の額の段階（特定親族特別控除・配偶者特別控除〔配偶者の側〕・配偶者控除等〔本人の900万円・950万円・1,000万円〕・基礎控除〔本則と措法41の16の2 の区分〕）は、
  額が今の額のままである比べる量の上限（`…の段階の上限`。円）を基準の概念にして「上限以下か」の判定に付けた（`judgments.step_upper`・`tier_upper`。
  第2号・ロ の刻みの中は刻みごとの上限）。またぐと額が次の段階に変わる。
- `所得税.配偶者の合計所得金額` を出力にした（同一生計配偶者・配偶者特別控除の段階の比べる量）。
- 宣言しないもの：年齢だけで決まる判定（控除対象扶養親族・特定扶養親族・老人扶養親族・同居老親等・老人控除対象配偶者）。共有の仕組みは比べる量が円の概念だけで、
  これらの所得の境目は 所得税.扶養親族の所得要件・所得税.同一生計配偶者の所得要件 が説明する。国外居住親族の38万円（生活費等の支払の額）は事実の層の入力で出力がないので宣言していない。

## 5. 足し方の手順（要約）

1. 一次情報（docs/public-sources・docs/measurements）で条文・基準額・施行日を確かめる。記憶で値を書かない。
2. parameters/ に YAML（日付のキーは適用開始日、metadata に law・source_kind・reference・施行日）。
3. 変数を書く。変数名は concepts.yaml の約束どおり。式は同じ層か下の層の変数だけを引く。
4. `__init__.py` の MODULE に登録し、concepts.yaml の概念を `実装済み: true` にし、`未実装のとき` を消す。依存を宣言する。
5. テストは packages/core/tests/test_personal_deductions.py・test_allocation.py。`tests/test_architecture*.py` を通す。
