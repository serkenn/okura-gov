# rules/other_deductions：その他の所得控除と医療費の前処理

登録済み。雑損控除・医療費控除・セルフメディケーション税制・社会保険料・小規模企業共済等掛金・生命保険料・地震保険料・寄附金の控除、政党等寄附金特別控除等（税額控除）と、医療費の前処理を持つ。

このディレクトリだけで規則を足す（packages/core/README.md §10「規則モジュールの足し方」）。共有のファイル
（evaluate.py・situation.py・country/__init__.py・concepts/structure.yaml など）は触らない。登録は rules/__init__.py の1行だけ。

| ファイル | 中身 |
|---|---|
| `variables.py` | 入力変数（前処理の結果）と各控除の額の式 |
| `calc.py` | 式の純粋関数（段階の式・医療費・寄附金・生命保険料・地震保険料）。途中の値は Fraction |
| `inputs.py` | `build_inputs` と判断・選択の宣言（`DECISIONS`） |
| `medical.py` | 医療費の前処理（受診者の要件・範囲・補塡の限度とあん分・セルフメディケーション税制） |
| `insurance.py` | 社会保険料・掛金・生命保険料・地震保険料の前処理 |
| `donations.py` | 寄附の前処理（所得控除か税額控除かの選択を含む） |
| `casualty.py` | 雑損控除の前処理（損失の金額・災害関連支出）と、親族の資産の所属の段（所令205） |
| `life_special.py` | 年齢23歳未満の扶養親族を有するかを決める段階（措法41の15の5） |
| `checks.py` | 計算の後の対象外の検出（今はない。雑損の親族の所属は casualty.py の段に移した） |
| `kinship.py` | 親族の判定（民法725〜729。中間表現の親子・養子縁組・婚姻の記録から） |
| `facts.py` | 共通の道具（生計を一にするかの時点ごとの1か所・入力の積み上げ） |
| `basis.py` | 規則の根拠（`RULES`）と根拠のある切上げ（`HOKEN_CEIL`） |
| `parameters/所得税/` | 医療費控除・セルフメディケーション税制・生命保険料控除・地震保険料控除・寄附金控除・雑損控除・政党等寄附金特別控除等の基準額と率 |

## 4. 実装の決めごと（根拠は basis.py・concepts.yaml の注）

- 控除を受けるのは支払った人。親族は民法の親族と読む（法令の読み：kinship.py）。**関係の記録から親族と導けないときは、控除の対象から黙って外さず対象外にする**（記録の書き忘れと区別できない）。
- 医療費の生計の判定は受診時又は支払時（通達73−1）で、判断.生計を一にする を日ごとの1か所（key `支払者:受診者@日付`）で引く。personal_deductions の年分の1か所（`person:other_person`）とは別の問い。
- 社会保険料・地震保険料の生計の判定の時点は一次情報がないので、支払日と12月31日の両方を見て、違えば両方の読みで結論が分かれるので未確定にする
  （入力の `missing` に決める手段「一次情報」の分かれ目。D22 S1）。
- 給与から控除された社会保険料の年分は、控除が行われる給与の支払の日（`when.on`）の年。未払（`unpaid`）の給与からは数えない
  （第74条第1項「給与から控除される場合」・TA No.1130「差し引かれた金額」。支給日 `due_on` の年分にしないのは法令の読み）。
- 医療費の範囲：所令第207条各号に直接当たる種類は範囲に入るものとし（法令の読み）、目的・必要性で決まる種類（医薬品・健康診断・交通費・器具など）は 判断.医療費の範囲。未入力なら両方で評価する。
- 補塡：同じ対象の集合の給付は合計して限度を当てる。対象の集合が一部だけ重なるときは対象外。あん分（質疑応答事例 05/61）の1円未満は根拠のない端数として候補の全部で評価する（`RoundingSlotSpec(variable=None)`・`ctx.round_unfounded`）。
  受診者がその年分に生存していない（前年以前に死亡）ときは、受診した時の生計で判定する（質疑応答事例 05/57）。
- 医療費通知（2026-11-12。中間表現 `medical_expense_notice`：packages/ir/README.md §6.2。docs/public-sources/20261112_impl-research6_forms-iryohi-tsuchi.md）：
  記録の `payment_year` の年分に、受診者が支払者自身か生計を一にする親族（手引き ❶※2）の記録の ㋐−min(㋑, ㋐) を支払者の 補塡後の医療費の額 に足し、
  明細書の ❶ の3欄の概念（(1) notice_amount・㋐ paid_in_year・㋑ min(reimbursed, paid_in_year) の合計）を書く。㋑ の限度は記録ごと（ほかの医療費から差し引かない：
  手引き ❶(3)。記録ごとに当てるのは法令の読み）。生計の判定日は通知の対象の期間の終わりの日（when.to_on。受診者が死亡していれば死亡の日と早い方）で、
  判断.生計を一にする の日ごとの1か所（`支払者:受診者@日付`）を明細と共有する（通達73−1 の受診時の現況を通知の期間に当てる法令の読み：basis.MEDICAL_NOTICE_RULE）。
  親族の判定・死亡した受診者の扱いは明細と同じ（R_KIN_NOT_DERIVED・R_KIN_UNDECIDED・R_PATIENT_GONE）。医療費の範囲の判断は引かない（保険診療の自己負担額を所令207 の
  診療・治療の対価とする法令の読み）。**二重計上を防ぐ約束**：通知に載った支払は `medical_payment` に書かないか、書くなら `attributes.notice_id` に通知の記録の id を書く
  （その支払は明細から除く：手引き ❷「❶に記入したものについては、記入しないでください」）。notice_id の通知と支払者・受診者・年が違う（R_NOTICE_LINK）、
  通知に載った支払を対象にする補塡・見込額（R_NOTICE_REIMB）、㋐ が通知の額を超える（R_NOTICE_OVER）、期間の終わりの日がない（R_NOTICE_NO_END）は c-入力。
  notice_id を書かずに同じ支払を両方に書いた場合は、判定コアは区別できない（通知の行と領収書の対応は手引きに方法がない）。
- 端数：百分の五（医療費）・百分の四十（寄附金）は根拠がなく候補の全部で評価する（D22 S3）。生命保険料・地震保険料の区分ごとの式は、国税庁「年末調整のしかた」の切上げに従う（D21 R5：手引き。確定申告への当てはめと区分ごとに当てるのは法令の読み）。
- 根拠のない端数の候補は、端数が値を変えうる人がいるときだけ式で引く（引いたときだけ evaluate が分かれ目を開く。packages/core/README.md §5）。
- 保険（2026-11-12 に語彙を足してつないだ）：前納の期日 `prepaid_due_dates`（社会保険料：通達74・75−1(2) の按分と、選択 `選択.前納した社会保険料の控除の年分` で74・75−2 の全額。生命保険料・地震保険料：76−3(3)・77−7 の按分。按分の1円未満は根拠のない端数 `保険料の前納・居住割合のあん分の端数`）、附帯した契約 `attached_to_contract_id`（所法76⑩：附帯した日以後の支払から旧契約を新契約。通達76−1 の支払った時の現況：法令の読み）、支払の定め `benefit_payment_terms`（所令209①）、満期返戻金 `maturity_refund`・契約の変更の日 `contract_changes_on`（平成18年法律第10号附則第10条第2項・TA1145）、居住割合 `residential_ratio`（通達77−5 で按分、77−6 のおおむね90%以上は全額：法令の読み）。
- 新旧の選択（質疑応答事例 05/74〜05/76）は区分ごとに選べるが、中間表現の選択は人ごとに1つなので一般と個人年金の両方に当てる。
- `pension_payment`・`withholding_slip` は社会保険料の額を読むが、`record_kinds` に書かない（kyuyo・income_kinds が登録する）。公的年金（国民年金・厚生年金・共済年金）から差し引かれた額は受給者の支払として数える（TA No.1130・手引き p.15：zeigaku-tax-calc §7.2）。それ以外の年金から差し引かれた額は対象外。給与の源泉徴収票に社会保険料の欄があれば、その票が覆う支払者（票の支払者と includes_prior_payers）の明細の額の代わりに票の額を使う（D23 K4。2026-11-11 の結合のレビューで、以前の「源泉徴収票があれば対象外」を直した）。
- 寄附：国・地方公共団体と日本赤十字社（TA1150 の特定公益増進法人）は特定寄附金。共同募金会は受領証等の記載によらず特定寄附金（2026-11-12：社会福祉法人〔社会福祉法113②〕＝所令217①五 の特定公益増進法人、又は昭和40年大蔵省告示第154号第4号・第4号の2 の指定寄附金。どちらでも所法78② の特定寄附金で額は同じ。docs/public-sources/20261112_impl-research4_juminzei-kifu-laws-and-kokuji.md §2.1・§2.3、docs/hypotheses/20261112_impl-research4_all-model.md H11。根拠に法令の読みの印：特定公益増進法人の読みにかかる所法78②三 の業務関連の要件は、所法78② の本文を取り直していない留保）。other は受領証等の記載 `receipt_statement`（2026-11-12 に語彙に足した）で、指定寄附金・特定公益増進法人の業務・公益信託の信託事務に関連する旨なら特定寄附金（所法78②二〜四。令和8年4月1日前の公益信託は旧第3項の特定公益信託と読む：法令の読み）、「記載なし」は当たらない（法令の読み）、欄がないものは両方で評価（c-入力）。政党等（political_party を措法41の18①一・二の団体と読む）・認定NPO法人等・公益社団法人等（public_interest_corporation・school_corporation）は 選択.寄附金の控除の方式（種類ごとに全額どちらか。未入力なら全候補で評価）で、所得控除を選べば特定寄附金の額、税額控除を選べば税額控除の基礎。recipient_type の記載がなければ c-入力。令和8年分の「公職の候補者が特定政党支部に対してする寄附」の除外は `attributes.candidate_to_specified_party_branch`（語彙に足した。ない場合は当たらないものとする）。
- 税額控除の順序：公益→認定NPO→政党等（計算明細書の順）。25%の上限は税額控除の前の税額（算出税額）。40%の基礎の端数は式の中で有理数のまま百円未満切捨てに渡す（1円未満の端数の分かれ目は不要）。
- 雑損控除：保険金等はまず損害金額から（TA1110 注3）。直後の価額は語彙に足した `casualty.amounts.post_loss_value`（ない場合は対象外）。生活に通常必要でない資産は 判断.雑損の計算（未入力なら両方で評価）。
  事業用の資産（被災事業用資産）は第72条第1項のかっこ書きで対象から除く（損失は事業所得等の必要経費：income_kinds）。10分の1の1円未満は根拠のない端数（候補で評価）。
  原状回復の支出の割合（通達72−3）は 判断.雑損の計算 の restoration_portion の額を原状回復の支出として数える（法令の読み）。
- 雑損控除の親族の資産（所令205。段階評価の段 `雑損控除の資産の所属`：`StageSpec(run=None)`、build_inputs が `ctx.stage_value` で読む。D23 K1）：

## 5. 足し方の手順（要約）

1. 一次情報（docs/public-sources・docs/measurements）で条文・基準額・施行日を確かめる。記憶で値を書かない。
2. parameters/ に YAML（日付のキーは適用開始日、metadata に law・source_kind・reference・施行日）。表は data/（SOURCES.json に SHA-256）。
3. 変数（OpenFisca の Variable）を書く。変数名は concepts.yaml の約束どおり。式は同じ層か下の層の変数だけを引く。
4. `__init__.py` の MODULE（registry.RuleModule）に、変数・使う記録の種類・build_inputs・decisions・roundings・groups・checks・rules・basis を書く。
5. concepts.yaml の概念を `実装済み: true` にし、`未実装のとき` を消す。依存する概念・パラメータ・人／年をまたぐ依存・集約点を通らない依存を宣言する。
6. rules/__init__.py に1行を足す（未登録のとき）。
7. このディレクトリの外にテストを置くときは packages/core/tests/test_<名前>*.py。`tests/test_architecture*.py` を通す。
