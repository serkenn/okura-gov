## IG1 アフィリエイトの所得がある大学生：勤労学生の判定は判断（D4）で分かれ、所得税額は同じ（前提：HG1）

- 場面（令和8年分）：20歳の大学生（学校教育法第1条の学校）。アルバイトの給与収入 1,300,000、アフィリエイトの業務に係る雑所得 150,000（総収入 − 経費）。ほかの所得なし。
- 計算：
  - 給与所得：措法第29条の4第2項第2号（給与等の収入金額 74万1千円以上219万1千円未満は収入 − 74万円）で 1,300,000 − 740,000 = 560,000。
  - 合計所得金額 = 560,000 + 150,000 = 710,000（≦ 890,000）。
  - アフィリエイトを「勤労に基づく」と判断：給与所得等以外の所得 = 0（≦ 100,000）→ 勤労学生に当たる。
  - 「基づかない」と判断：給与所得等以外の所得 = 150,000（> 100,000）→ 当たらない。
  - 所得税：基礎控除 1,040,000（489万円以下）≧ 710,000 なので、どちらでも課税総所得金額 0・税額 0。**所得税額の結論は判断によらない**。
  - 変わるもの：申告書の勤労学生の記載と勤労学生控除額（27万円か0か）、住民税（令和9年度）の所得割の計算で差し引く勤労学生控除（26万円。地方税法第314条の2第1項第9号、範囲は所得税法の定義を準用）。所得割の課税標準が 260,000 違う。
- コアの期待される出力：判断が「未判断」なら、所得税額は 0 を返し、勤労学生の該当と、住民税の所得割に効く勤労学生控除は「未確定」とし、「アフィリエイトの雑所得が自己の勤労に基づくかの判断（D4）で分かれる」と説明する。
- 検証方法：
  1. 単体テスト（D15 ①）：上の3通り（基づく／基づかない／未判断）で、期待値どおりの結果と「未確定」の印が出るか。
  2. 作成コーナー（令和7年分、架空の数字）：給与収入 1,300,000（給与所得 650,000）と雑所得（業務）150,000 を入れ、勤労学生控除を選べるか、「勤労に基づく所得」かを利用者に尋ねる画面があるか、給与所得等以外の所得をどう数えるかを記録する。これは国税庁のシステムの運用の観察で、法令の解釈の一次情報ではない（反証になる結果：雑所得（業務）を自動的に「勤労に基づかない」として控除を拒む、または自動的に認める。どちらの場合も、その扱いを根拠つきで記録し、HG1 の既定を見直すかを検討する）。
  3. 住民税の所得割の部分は、住民税の担当の計算モデル（`docs/hypotheses/20261109_impl-prep_juminzei-judgment-model.md` 系統）と突き合わせる。

## IG2 TA No.1810 の令和7年分の（注）に従うと、扶養の判定を誤る場面（前提：HG2）

- 場面（令和7年分）：子の所得は家内労働者等の特例の対象となる業務委託の報酬（業務に係る雑所得）だけ。総収入 1,500,000、実額経費 100,000、給与なし。
- 計算：必要経費は特例の 650,000、合計所得金額 = 850,000。
  - TA の（注）の書き方（160万円以下なら扶養控除の対象）に従うと、扶養控除の対象になる。
  - 条文では 850,000 > 580,000 なので扶養親族に当たらない（HG2）。
    - 子が17歳：扶養控除なし、特定親族特別控除もない（19歳以上23歳未満だけ）。親の控除は 38万円（TA に従った場合）→ **0**。
    - 子が20歳：特定親族に当たり、特定親族特別控除（58万円超85万円以下は 63万円。既存の［PS-KY］の表）。控除額は特定扶養控除と同じ 63万円だが、控除の種類（申告書の欄）が違う。
  - さらに、親の給与等の収入金額が 850万円を超えるとき、子が扶養親族でないので、この子を理由とする所得金額調整控除はない（IG3 と同じ構造）。
- 既存の推測 `docs/inferences/20261109_impl-prep_jigyo-inferences.md` I1 は、同じ境目（1,230,000／1,230,001）を扱っている。本推測は、160万円の側の誤りが何に効くかを足したもの。
- 検証方法：
  1. 単体テスト（D15 ②）：総収入 1,230,000 → 扶養親族に当たる、1,230,001 → 当たらない（令和7年分）。1,310,000／1,310,001（令和8年分）。期待値の出典は条文（［M］C2）。
  2. 作成コーナー（令和7年分）：親の申告書で、17歳の子を合計所得金額 850,000 の扶養親族として入れようとしたとき、扶養控除が受けられないこと（入力の検査で止まる、または控除額 0）を確かめる。20歳の子なら特定親族特別控除 63万円になることを確かめる。
  3. TA No.1810 の（注）が直されるかを日々の監視（D9）で見る（本文の SHA-256 が 66d23053e2d026aa… から変わったら、（注）の文を読み直す）。直された文が 123万円を書けば、HG2 の内容1 を支える。

## IG3 所得金額調整控除の崖：子の合計所得金額が要件を1円超えると、親の控除が消える（前提：HG3）

- 場面A（令和7年分）：親A の給与等の収入金額 9,000,000、親B（Aの配偶者）9,500,000。生計を一にする20歳の子（合計所得金額 580,000 以下）。本人・家族に特別障害者はいない。
  - 子は両親それぞれの「年齢23歳未満の扶養親族」に当たる（措通41の3の11−1）。A：(9,000,000 − 8,500,000) × 10/100 = **50,000**、B：(9,500,000 − 8,500,000) × 10/100 = **100,000**。それぞれの給与所得の金額から控除し、合計所得金額も同じだけ下がる。
  - 子の合計所得金額が 580,001 になると、子は扶養親族でなく特定親族になる。A・B の所得金額調整控除はどちらも **0**（ほかに要件を満たす家族がいなければ）。親が受ける人的控除は特定扶養控除 63万円 → 特定親族特別控除 63万円で額は同じなので、所得金額調整控除の消滅だけが親の合計所得金額を A は 50,000、B は 100,000 押し上げる。
  - 16歳未満の子が別にいれば、その子が要件を満たすので消えない（扶養親族に年齢の下限がない）。
- 場面B（端数）：給与等の収入金額 8,500,001 → TA の切上げで 1、切捨てなら 0。8,500,005 → 1／0。8,500,010 → 1／1（［M］C3）。
- 場面C（令和8年分、第2項）：65歳以上の親C の給与等の収入金額 800,000、公的年金等に係る雑所得の金額 200,000。
  - 給与所得の金額は措法第29条の4第2項第2号で 800,000 − 740,000 = 60,000。措令第19条の4の2 により、第2項の「給与所得控除後の給与等の金額」はこの 60,000。
  - 所得金額調整控除 = min(60,000, 100,000) + min(200,000, 100,000) − 100,000 = **60,000**。給与所得の金額は 0、総所得金額 = 200,000。
- 検証方法：
  1. 単体テスト（D15 ②・④）：場面A の 580,000／580,001 の境目で両親の控除が 50,000・100,000 → 0 になること。性質のテスト：子の合計所得金額を上げると親の合計所得金額が下がることはない（単調性）。
  2. 作成コーナー（令和7年分）：給与等の収入金額 9,000,000、23歳未満の扶養親族1人で所得金額調整控除が 50,000 になるか。8,500,001 で 1 になるか（TA の切上げがシステムでも行われているか。反証になる結果：0 になる → 端数の関数の既定を見直し、出典を記録する）。
  3. 作成コーナー（令和8年分。2027年1月の提供後）：場面C の値。
  4. 年末調整の源泉徴収票（所規の様式）に記載される所得金額調整控除額の欄と、第1項だけが年末調整で扱われること（措法第41条の3の12）を、出力の整形のテストで確かめる。

## IG4 基礎控除の高い所得の境目（前提：HG4）

- 境目の期待値（令和7年分／令和8年分）：合計所得金額 23,500,000 → 580,000／620,000、23,500,001 → 480,000／480,000、24,000,000 → 480,000、24,000,001 → 320,000、24,500,000 → 320,000、24,500,001 → 160,000、25,000,000 → 160,000、25,000,001 → 0。
- 23,500,000 → 23,500,001 で、基礎控除は令和7年分 100,000、令和8年分 140,000 下がる。
- 給与だけの人で作るとき、給与等の収入金額 850万円超では所得金額調整控除の要件（特別障害者、23歳未満の扶養親族など）があると合計所得金額が表とずれる（国税庁の表の注記「特定支出控除や所得金額調整控除の適用がある場合には、表の金額とは異なります」［PS-KY］）。テストの場面は、その要件がない人で作る。
- 検証方法：単体テスト（D15 ②。期待値の出典は所得税法第86条第1項［M］C4）。作成コーナー（令和7年分）で、給与だけの人（所得金額調整控除の要件なし）の収入 25,450,000（給与所得控除 195万円で給与所得 23,500,000。既存の実測 `docs/measurements/20261109_impl-prep_kyuyo-thresholds.md` の表と同じ）と 25,450,001 を入れ、合計所得金額の表示と基礎控除が 580,000・480,000 になるかを見る。

## IG5 令和8年分の出力の根拠条文（前提：HG5）

- 令和8年分の収支内訳書（総収入金額及び必要経費の内容を記載した書類。白色申告の不動産所得・事業所得・山林所得は常に、業務に係る雑所得は前々年分のその業務の収入金額が1,000万円を超える場合に添付する）の根拠は、2027-01-01 以後の提出なら所得税法第120条第8項・所得税法施行規則第47条の3（第8項を引く版）。令和7年分（2026年に提出）は第6項。
- 令和8年分以後の確定申告書を 2027-01-01 以後に出すとき、社会保険料控除・小規模企業共済等掛金控除・生命保険料控除・地震保険料控除は、証明書類の添付・提示に代えて明細書を添付できる（所得税法第120条第6項）。出力の整形は、令和8年分からこの明細書の形を選べるようにする必要がある。
- 検証方法：
  1. 2027-01-01 以後に e-Gov 法令API で所得税法施行規則を asof その日で取り直し、`current_revision_status` が CurrentEnforced の版の第47条の3 が「第八項」を引くことを確かめる（`scripts/R2X_gaps_egov.py` の shotoku-ki のジョブの asof を変えて実行）。
  2. 国税庁の令和8年分の確定申告の様式・手引き（公開後）で、社会保険料控除等の明細書の様式と、収支内訳書の根拠の書き方を確かめる。
  3. 所得税法第122条第3項ほかの準用規定の 2027-01-01 版を取得し、第120条第8項を準用しているかを確かめる（本調査では未取得）。

## IG6 季節で波がある事業収入の子：見込みの作り方で健保の結論が逆になる（前提：HG6）

- 場面：20歳の子（被扶養者の候補、同一世帯）。認定日は 2025-10-01 以後で、19歳以上23歳未満の 150万円未満の要件。ハンドメイド品のネット販売の事業。健保の年間収入の計算（総収入 − 売上原価 − 社会通念上明らかに必要な経費。減価償却費は引かない）で、月ごとの額は 1〜9月 各 50,000、10〜12月 各 300,000。判定日は翌年1月中旬。
- 見込みの作り方ごとの値：
  - 直近12か月（前年の確定申告の値に相当）：9 × 50,000 + 3 × 300,000 = **1,350,000**（< 1,500,000 → 要件を満たす）。
  - 直近3か月の年換算（× 4）：900,000 × 4 = **3,600,000**（≧ 1,500,000 → 満たさない）。
  - 月額の連絡の基準（150万円 ÷ 12 = 125,000）を使う保険者なら、10〜12月の各月で基準を超える。
- 令和2年4月10日 事務連絡 記3 は、直近3か月の年換算で基準以上でも直ちに取り消さず、過去の課税証明書等と照らして総合的に判断するとしている。毎年同じ時期に繰り返す季節の波は「一時的」というより恒常的な収入の形なので、12か月の見方が自然と推測する（I。一次情報はこの線引きを書いていない）。
- コアの期待される出力：
  - D4 の見込みがない → 収入の要件は「未確定」。
  - D4 の見込み 1,350,000（作り方：直近12か月の実績、季節の型を当てはめた、材料は前年の確定申告書）→ 要件を満たす（「見込み」の印、作り方の記録を根拠に表示）。
  - 保険者の確認方法のデータ（例：直近3か月の収入証明を見る）が注入されていれば、目安 3,600,000 を見込みとは別の値として出し、「この保険者の確認方法では基準を超えて見える」と説明する。見込みの判定は置き換えない。
- 検証方法：
  1. 単体テスト（D15 ①・④）：コアが見込みを自分で計算しないこと（見込みがないと必ず未確定）、注入データがないと目安を出さないこと、注入データを足しても見込みによる判定が変わらないこと（性質のテスト）。
  2. 健保組合・協会けんぽの公表している確認方法を数件集め、注入データの形（時期、期間、連絡の基準、書類、経費の範囲）で表せるかを確かめる。季節の波の扱いを書いた保険者が見つかれば、公開資料の情報に記録し、HG6 の内容3 を見直す。
  3. 収入に波がある人の見込み方を定めた厚労省の通知・事務連絡を、日々の監視（D9）の対象（厚生労働省 法令等データベースの保険局保険課の事務連絡）で探す。見つかれば HG6 の反証になる。
