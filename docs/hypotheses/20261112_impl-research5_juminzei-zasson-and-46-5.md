# impl-research5 仮説：住民税の雑損失の繰越と、地令46の5 の書類の区分の読み

根拠の公開資料の情報：［PS］`docs/public-sources/20261112_impl-research5_juminzei-zasson-and-46-5.md`、照合の実測：［M］`docs/measurements/20261112_impl-research5_laws-fetch-and-checks.md`。

## H1 上場株式等の所得から雑損失を控除する順序

- 仮説：住民税の雑損失は、純損失の繰越控除の後の総所得金額、次に申告分離課税の上場株式等に係る配当所得等の金額、次に譲渡所得等の金額、次に退職所得金額から控除する。
- 根拠：施行令第48条の3第1項第2号ホは総所得金額 → 山林所得金額 → 退職所得金額（［PS］§1）。上場株式等の分離課税の所得は前年の所得の計算で所得税の計算の例による
  （第313条第2項）。施行令附則第18条の5 などは、上場株式等の譲渡損失の繰越控除の後に雑損失を控除すると書く（［PS］§1）。所得税の順（措令4の2⑨・25の11の2⑳：
  総所得金額 → 上場配当 → 上場譲渡 → 退職）は `docs/public-sources/20261111_impl-research3_joto-junjo-laws-and-nta.md` にある。
- 弱い点：住民税の附則の読替えの原文を確かめていない（［PS］§3）。住民税の所得割の率は区分の間で同じなので、順序で変わるのは区分ごとの課税標準の千円未満の
  切捨てと所得控除の当て先（separate.py）だけ。
- 実装：`rules/juminzei/calc.jumin_casualty_carryforward`、根拠 `basis.JUMIN_CASUALTY_ORDER`（法令の読み）。

## H2 住民税の繰越の記録がないときの額

- 仮説：前年度の住民税の繰り越す雑損失の金額の記録がないときは、所得税の繰り越された雑損失の金額（前年分の確定申告書の記載）を住民税の繰越の額とする。
  純損失（第313条第8項・第9項）も同じ（`resident_tax_net_loss_carryforward` がなければ所得税の繰り越された純損失の金額）。
- 根拠：雑損失の金額は住民税・所得税とも「雑損控除の基準を超える額」で、前年の所得が同じ（分離課税に係る退職所得・申告しない特定配当等がない）なら額は同じ
  （［PS］§1）。所得税の確定申告書は住民税の申告書とみなし、記載事項もみなす（第317条の3）。
- 弱い点：分離課税に係る退職所得のある年に生じた・控除した人は額が違いうる。その人は前年度の住民税の記録（`resident_tax_casualty_loss_carryforward`）を入力する。
- 実装：`住民税_繰り越された雑損失の金額`、根拠 `basis.JUMIN_CASUALTY_FALLBACK`（法令の読み）。

## H3 書類を人の区分で分ける読み（地令46の5①）

- 仮説：所属を決める書類は記載した人の区分で決まる。申告義務者（給与所得等以外の所得を有しなかった者でない人）は申告書（住民税の申告書・前年分の確定申告書）、
  給与所得等以外の所得を有しなかった者は給与支払報告書・公的年金等支払報告書（申請書を出せばその人の分は申請書）。給与所得等以外の所得を有しなかった者が医療費控除
  などのために出した確定申告書（第317条の2第3項の申告書とみなされる）の扶養の記載は、第46条の5第1項の書類にならない。
- 根拠：第46条の5第1項・第46条の3第1項の文言（［PS］§2。［M］§3 で原文と照合）。`docs/public-sources/20261109_impl-prep_juminzei-hikazei-fuyo-shinkoku.md` §4.2
  の検証の注（条文の組み合わせによる読み）。
- 区分の判定：1月1日現在の給与・公的年金等の支払者と支払報告書の提出義務は `jan1_payer_status`（年度ごと）、前年に給与所得以外（公的年金等に係る所得以外）の所得が
  ないかは所得の種類ごとの金額（分離課税に係る退職所得は数えない：第328条で他の所得と区分して課税する所得）。記録がなければ両方の区分で評価し、所属が分かれれば未確定。
- 申請書（第1項ただし書）は申請した人の給与支払報告書の記載を置き換える。ほかの人の報告書の記載は残り、2人以上なら第2項（以前の実装は、申請書があると他の人の記載を
  全部無視していた）。
- 弱い点：市町村の実務は確かめていない。第317条の2第2項の指定は語彙がない。
- 実装：`rules/juminzei/allocation.person_category`・`document_rows`、根拠 `basis.DOCUMENT_RULE`（法令の読み）。

## H4 給与支払報告書の記録がないときの扶養控除等申告書の記載

- 仮説：給与所得等以外の所得を有しなかった者で、給与支払報告書の記録がないときは、所得税の扶養控除等申告書（従たる給与・特定親族特別控除申告書を含む）の記載を
  給与支払報告書の記載とする。
- 根拠：給与所得者の扶養親族等申告書（地方税法第317条の3の2）は所得税法第194条の申告書を出す給与所得者が給与支払者を経由して出す（［PS］§2）。給与支払報告書は
  給与支払者が出す（第317条の6第1項）。
- 弱い点：2つの申告書を一の様式で出す取扱いと、報告書の記載がその申告書による根拠の原文は取得していない（［PS］§3）。
- 実装：`allocation.REPORT_SOURCE_DOCS`、根拠 `basis.REPORT_SOURCE_RULE`（法令の読み）。
