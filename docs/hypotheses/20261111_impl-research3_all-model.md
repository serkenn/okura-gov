## H1 旧定額法・旧定率法・定率法の償却費（IK-43・IK-65）

- 平成19年3月31日以前に取得：所令120① の区分で旧定額法・旧定率法（建物は平成10年3月31日以前の取得なら選択、以後は旧定額法）。［PS3-GK］§1。
  - 旧定額法の年額＝（取得価額 − 残存価額）× 別表第七の旧定額法の率。残存価額＝取得価額 × 別表第十一の残存割合（有形の多くは 10%、無形・ソフトウエア 0）（耐用年数省令4①・6①）。
  - 旧定率法の年額＝期首の未償却残高（取得価額 − 前年までの必要経費算入額の累積）× 別表第七の旧定率法の率。
  - 累積が取得価額の95%（所令134①一イ）に達するまでは各年の額を95% を超えない額に抑え、達した年の翌年分以後は（取得価額 − 95%相当額 − 1円）÷5 を毎年（累積が取得価額−1円を超えない額まで）。年の中途の業務の開始などは所令132 の月数按分（134③）。根拠：［PS3-GK］§3。
- 平成19年4月1日以後に取得の定率法：期首未償却残高×別表第九（平成24年3月31日以前）又は第十（以後）の償却率。その額が取得価額×保証率（償却保証額）に満たない最初の年からは、改定取得価額×改定償却率（所令120の2①一イ（2）・②）。累積の上限は取得価額−1円（134①二イ）。［PS3-GK］§2・§5。
- 率は**表の値をそのまま**持つ（式では再現できない：［M3-F］§3）。R7・R8 で表は同じ。
- 1円未満の端数：今回の取得で定めが見つからない（［PS3-GK］§6）。既存の端数の決定（D21 R5・D22 S3）に従う。

## H2 非居住者である親族の合計所得金額（PD-06）

- 一次情報で決まらない（［PS3-HK］§3）。読みの候補：
  - (a) 国内源泉所得だけ：非居住者の課税所得の範囲は国内源泉所得（所法7①三）で、課税標準は国内源泉所得について居住者の規定に準じて計算（所法165①）。
  - (b) 全世界の所得：合計所得金額は所法22（居住者の課税標準）の総所得金額等で定義され（所法2①三十ロ（2））、親族の居住・非居住を区別しない。
- 公式の説明はどちらもない（国税庁の Q&A 2種・TA1180・所基通165関係に記述なし。［M3-V］§2.3）→ D22 S1 の「支えが同程度」に当たる。**両方で評価し、扶養の判定が分かれれば未確定**（今の実装の扱いを続ける）。決めるのに要る入力：親族の所得のうち国内源泉所得の額と、それ以外の所得の額（円換算後）。

## H3 配当控除の区分が2つ以上で負債の利子があるとき（IK-98）

- 一次情報で決まらない（［PS3-HT］§3）。所法92① は区分ごとの「配当所得の金額」に率を掛けるが、所法24② の負債の利子の控除後の配当所得の金額を区分に分ける方法を書かない。
- 読みの候補：
  - (a) 元本に結びつける：負債の利子は「その元本を取得するために要した」もの（所法24②）なので、その負債で取得した元本の配当の区分から控除し、控除しきれない額は他の区分から控除する（所基通24−5(1)「他の株式等の配当等からも控除できる」）。他の区分から控除する順は決まらない。
  - (b) 収入金額の比で按分する（所基通24−6 が配当と株式等の譲渡の間で収入金額の比を使う例に倣う。ただし 24−6 は区分の間の配分の通達ではない）。
  - (c) 納税者が選ぶ（24−5(1) の「控除できる」を選択と読む）。
- 公式の説明がないので**全候補で評価し、配当控除の額が分かれれば未確定**（D22 S1。(c) は D22 S20 で全候補）。(a) は負債と元本の結びつき（どの負債でどの銘柄を取得したか）の入力が要る（IK-89 の語彙と同じ）。

## H4 所得控除・雑損失の控除を分離課税の所得に当てる順序（TX-19、OD-14）

- 所得税：**措通31・32共−4**（通達）の順。家族の範囲の所得に絞ると：総所得金額 → 上場株式等に係る配当所得等の金額 → 一般株式等に係る譲渡所得等の金額 → 上場株式等に係る譲渡所得等の金額 → 先物取引に係る雑所得等の金額 → 山林所得金額 → 退職所得金額（⑤〜⑪は適用税率の高いものから。上場配当・一般株式・上場株式の譲渡はいずれも 15%）。根拠：［PS3-JJ］§3。法令ではないので根拠の種類は「通達」。
- 同じ通達のただし書で、長期譲渡・上場配当・一般株式・上場株式・先物の**間**は納税者が異なる順序で控除して申告することを認める → **納税者の選択**（D22 S20：未入力なら通達の順を含む全候補で評価し、最適化しない）。税率が同じでも、区分ごとの課税所得の1,000円未満の切捨て（国税通則法118①の当て先は既存の決定）で税額が数円〜数百円違いうる。
- 所令205（雑損控除の対象となる親族の合計額）・所令204①二（雑損失の繰越控除）：措令4の2⑨・25の8⑯・25の11の2⑳ の表の行に第205条・第204条第1項第2号があり（R7・R8）、「総所得金額」に上場株式等の配当所得等・譲渡所得等（損益通算・繰越控除の後）を加えて読む（［PS3-JJ］§1・§2、［M3-V］V4）。→ OD-14 の分かれ目は読替えの表で決まる（含める）。

## H5 申告の要否と年末調整の住宅借入金等特別控除（TX-20）

- 所法120① の「配当控除の額」は、措法41の2の2⑥二で「配当控除の額と…第四十一条の二の二第一項…の規定により控除される金額との合計額」と読む（R7・R8。［PS3-JJ］§4、［M3-V］V4b）。→ **年末調整で措法41の2の2① により控除された額だけを加える**。確定申告で初めて措法41 の控除を受ける額は加えない（読替えがない）。
- 入力：給与所得の源泉徴収票の「住宅借入金等特別控除の額」（年末調整で控除した額）。これがあれば REASON_HOUSING の分かれ目は消える。

## H6 死亡の日が誕生日の前日の人の年齢（PD-01）

- 所法85③ ただし書「当該死亡の時の現況による」。年齢は年齢計算ニ関スル法律で出生の日から起算し民法143 を準用（［PS3-KM］§4、［PS-AGE］）→ 誕生日の前日の**終了**で1歳加わる。死亡の「時」はその日の途中の時点なので、**その日の終了で加わる1歳は含めない**（死亡の時の年齢は前日の終了までの満年齢）。
- 国税庁の説明はない（［PS3-KM］§4）。反対の一次情報もない → D22 S1 の「法令の読み」でこの読みを使い、根拠に「法令の読み」と記録する。

## H7 未払の給与の源泉徴収税額（TX-02）

- 所法183① の源泉徴収は「その支払の際」。所法120①四 の「源泉徴収をされるべき所得税の額」を、年末に未払の給与についてどう扱うかは一次情報で決まらない（［PS3-GS］§3）。
- 別表で額を出すこと自体は可能になった：支払日が令和7年中なら 2025-12-31 の版、令和8年中なら 2026-01-01 以後の版の別表第二〜第四（［M3-F］§4）。必要な入力：支給期の区分（毎月・毎半月・毎旬・月の整数倍・毎日・その他）、扶養控除等申告書の提出の有無と提出先、社会保険料等、扶養親族等の数と加算（本人・親族の障害者等）、賞与なら前月の給与。
- 読みの候補：(a) 未払の給与は申告の時点で「されるべき」額に入る（別表で計算）、(b) 支払の際に初めて源泉徴収義務が生じるので未払の分は入らない。支えが同程度 → 両方で評価し、精算額が分かれれば未確定（D22 S1）。

## H8 国民年金の一部免除・学生納付特例・納付猶予の135万円の経路（kokunen）

- 各条の第2号「前条第一項第二号**及び**第三号に該当するとき」（90の2①②③）、「第九十条第一項第二号及び第三号に該当するとき」（90の3①、平成16年法附則19②、平成26年法附則14①）（［PS3-KN］§1、［M3-V］V8b）。
- 読み：(a) 第2号（生活扶助以外の扶助等）**又は**第3号（障害者・寡婦・ひとり親で前年の所得135万円以下）のどちらかに当たればよい、(b) 両方に当たることを要する。日本年金機構の免除・納付猶予の説明は、全額免除〜納付猶予の所得の基準の表の後に「地方税法に定める障害者、寡婦またはひとり親の場合、基準額が変わります」と書く（［PS3-KN］§1）＝一部免除・納付猶予にも障害者等の基準があることを示す公式の説明 → D22 S1 により **(a)** を採り、根拠「法令の読み＋日本年金機構の説明」。
- 135万円の経路の「所得の額」は国年令6の11（法90①一・三の所得：控除前の総所得金額等＋分離課税の所得）。一部免除の第1号の所得（6の12：控除後）とは計算が違う。
- 納付猶予の第1号の額の政令は国年令にない（［M3-F］§7）。日本年金機構の「（扶養親族等の数+1）×35万円+32万円」を使い、根拠に「原文未確認（機構の説明）」の印。
- 学生等である期間は全額免除・一部免除・納付猶予の対象の期間から除かれ（90①・90の2・附則の各柱書）、学生納付特例（90の3）だけが当たる。
- 付加保険料（87の2）：月400円。法定免除・全額免除・学生納付特例・一部免除の者、国民年金基金の加入員は納付できない。産前産後（88の2）の期間は納付できる（2026-10-01 以後は 88の3 の育児期間も）。
- 産前産後（88の2）：出産予定月の前月（多胎は3月前）から翌々月まで、申請でなく法律上当然に納付を要しない（届出は事実）。88の3（育児期間、2026-10-01 施行）：88の2 の適用を受けた被保険者が子を養育する場合、出産予定日から3月を経過した日の属する月から12月を経過した日の属する月の前月まで。

## H9 国保（kokuho）

- **令和9年度の政令の値は未公布**（［PS3-KH］§1、［M3-V］§2.2）。令和9年度分の賦課限度額・軽減の基準のパラメータを持たない → 令和9年度の国保料（税）の計算は「未確定（政令の公布待ち）」。公布されたら施行日（例年4月1日）つきで足す（D9 の監視）。令和8年度の値は 67万・26万・17万・3万円、軽減 43万円＋10万円×(k−1)、31万円・57万円（［PS3-KH］§1）。
- 国保税の未就学児の均等割の減額（地法703の5②）は令和9年度分から「18歳に達する日以後の最初の3月31日以前」に拡大（法律）。割合の基準の政令（地令56の89）は未改正 → 令和9年度の国保税で6歳〜18歳の子がいる世帯は「未確定（政令待ち）」。国保料（国保法72の3の2・国保令29の7）も同じ。
- 年度の途中の資格の取得・喪失の月割り：法令に定めがない（［PS3-KH］§2）→ 条例の事項として注入点（今の README の扱いと同じ）。
- 産前産後：減額の対象（所得割額・均等割額のうち出産被保険者の分）と期間（出産予定月の前月〜翌々月、多胎は3月前から）は政令にある。「期間に係る額を基準として算定」の具体（月割りか）は条例 → 注入点。
- 特定世帯・特定継続世帯：政令の式で計算できる（按分の分母＝世帯数 − 特定世帯数×1/2 − 特定継続世帯数×1/4、その世帯の平等割＝イの額×1/2〔特定世帯〕・×3/4〔特定継続世帯〕。基礎賦課額・後期高齢者支援金等賦課額・子ども・子育て支援納付金賦課額。介護納付金賦課額にはない）。ただし按分の分母は市町村全体の世帯数で、注入データの平等割の額（条例の額）が既に按分の結果なら、世帯の側では「額×1/2・×3/4」だけを当てる（［PS3-KH］§4）。必要な事実：特定同一世帯所属者（国保法6八〔後期高齢者医療の被保険者になったこと〕で資格を喪失した者）と資格喪失日（特定月）、世帯に他の被保険者がいないこと。

## H10 住民税（juminzei）

- 特例控除対象寄附金：**支出した時に**受領した都道府県等が指定されているか（地法314の7⑨・37の2⑨）。指定は告示（地法314の7⑦）で、総務省がポータルに告示番号を掲載（［PS3-JM］§1.1）→ 注入点「ふるさと納税の指定（団体コード、指定の期間、出典の告示番号）」。未注入なら特例控除額を含むかで分かれれば未確定（今の扱い）。
- 条例で定める寄附金（314の7①三・四、37の2①三・四）：市町村・道府県ごとの条例 → 注入点（寄附先・寄附金の種類の一覧と出典の条例）。
- 附則5の5②：令和8年度・令和9年度分は FY8 の版の式（割合の最も低いもの×5分の3〔指定都市5分の4〕、所得割の額〔分離課税の所得割を含む〕の20%が上限）で計算できる（［PS3-JM］§2）。令和10年度分からの115万8千円の上限は範囲外（令和10年度）。
- 分離課税の所得への所得控除：314の2⑪ と附則33の2⑦三・35の2⑧三（35の2の2⑧で準用）の読替えで、総所得金額 → 上場配当 → 一般株式等の譲渡 → 上場株式等の譲渡 の各金額を「総所得金額、…」に加えて控除する。区分の間の順序を定める住民税の一次情報はない（［PS3-JM］§3）→ 所得税の措通31・32共−4 の順を候補の一つにし、全候補で評価（住民税の率は区分の間で同じ〔所得割 5%〕なので分かれるのは1,000円未満の切捨ての差だけ）。
- 団体コード：道府県の団体コード＝市町村コードの第1・2桁＋"000"＋検査数字（6・5・4・3・2、mod 11）。総務省の一覧表の全件で検査数字が合う（［M3-F］§5）→ 道府県の注入データの issuer.code に道府県コードを使える（市町村コードから計算できる）。
