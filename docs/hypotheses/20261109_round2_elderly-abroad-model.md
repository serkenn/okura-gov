## HE1 老人扶養親族と扶養控除の額（所得税）

- 構造（コア）：控除対象扶養親族のうち12月31日の現況で70歳以上 → 老人扶養親族 → 48万円。同居老親等に当たれば 58万円（48万円＋措法41の16 の10万円）［LW］§1・§2。
- 令和7年分・令和8年分で変わるのは扶養親族の所得要件（58万円→62万円）だけで、70歳・48万円・10万円は同じ［LW］§1.2、［MS］§3。パラメータは「老人扶養の年齢 70」「老人扶養の控除額 480000」「同居老親等の加算 100000」を年分の適用開始日つきで持ち、出典は所法84①と措法41の16①（版の law_revision_id つき）にする (I)。
- 年齢の計算は既存の関数（12月31日の終了時の年齢。1月1日生まれは前年の12月31日に加算）をそのまま使う［MISC］§1.3。
- 入力として要るもの：E1、E2（扶養親族であること：親族か）、生計を一にする（J4）、その親族の合計所得金額。
- **人をまたぐ依存**：老人扶養親族の合計所得金額は、多くの場合に公的年金等に係る雑所得を含む。公的年金等控除の計算は D20 で対象だが、本調査では条文を確認していない。国税庁の目安（公的年金等だけなら、令和7年分 168万円以下（65歳未満 118万円以下）、令和8年分 172万円以下（65歳未満 122万円以下）で合計所得金額が所得要件以下）は、公的年金等の計算を実装したときの境目のテストの期待値に使える［GD］§2.2 (I)。
- 端数：なし（円単位の定額）。

## HE2 同居老親等（措法41の16）と住民税の同居直系尊属（地法314の2④）

### HE2.1 要件を分けた形

措法41の16①・地法314の2④ の要件は次の4つの積で表せる［LW］§2.2・§5.1 (I)：

1. 老人扶養親族である（HE1。住民税は前年12月31日の現況の老人扶養親族）。
2. **居住者（納税義務者）又はその配偶者の直系尊属**である。E2 の辺から計算できる：居住者から親子の辺を上にたどれる人、または配偶者（その時点で婚姻関係にある人。所得税では法律婚だけ：［CON］§3.1）から上にたどれる人。
3. 居住者又はその配偶者の**いずれかとの**同居を常況としている（J2）。
4. 判定の時点：所得税は12月31日（死亡時は死亡の時）、住民税は前年12月31日［LW］§2.2・§5.1。

### HE2.2 「同居を常況」の判定：事実から候補を出し、判断で確定する

- 法令に定義がなく、国税庁の扱いは法令解釈通達ではなく、質疑応答事例・タックスアンサー・年末調整のしかたにある［LW］§2.3、［GD］§1.3。したがって判定コアは、事実（E3〜E5）から**候補**を出し、確定は判断（J2）で受け取る (I)。
- 候補を出す規則（国税庁の例示をそのまま規則にしたもの）［GD］§1.1 (I)：
  - 12月31日に同じ住居 → 同居の候補。
  - 同じ敷地の別棟で、日常生活を共にしている（判断） → 同居の候補。
  - 12月31日に入院中（治療のため）で、入院の前は同居 → 同居の候補（入院の長さは問わない）。
  - 12月31日に施設に入所中で、施設が「老人ホーム等」（J3） → 同居でない。
  - 居住者の転勤で別居（配偶者とも別居） → 同居でない。
- 規則の出典の種類を結果に出す：「法令（措法41の16①）」と「国税庁の取扱い（質疑応答事例・タックスアンサー）」を分けて根拠に書く（D13）(I)。
- 施設の種類が「入院」とも「老人ホーム等」とも決まらない（介護老人保健施設など）ときは、J3 の判断がなければ判定を止め、「判断が必要」と返す（SCOPE §2-4 の「黙って近似しない」）［GD］§6-1 (I)。
- **居住者が単身赴任で、配偶者が老親と同居している場合**：原文は「当該居住者又は当該配偶者のいずれかとの同居」なので、配偶者と同居していれば要件3を満たすと読める［LW］§2.1。国税庁の例示（3）「所得者が転勤したことに伴いその住所を変更したため、その老親等が所得者等と別居している場合……同居老親等に該当しません」は、「所得者等」（所得者又はその配偶者）と別居している場合を書いている［GD］§1.1。この読み（配偶者と同居なら該当）は原文の組み合わせで、国税庁の資料で明示したものは見つけていない (I)。推測 IE4 で検証方法を書く。

### HE2.3 住民税

- 住民税は同じ要件の構造で、額だけが違う：老人扶養 38万円、同居直系尊属 45万円［LW］§5.1。判定の時点は前年12月31日［LW］§5.1。
- 調整控除（地法314の6）の人的控除差は、老人扶養 10万円、同居直系尊属 13万円で、所得税と住民税の控除額の差と一致する［LW］§5.2、［MS］§3。判定コアでは、人的控除差の表を地法314の6 の表から直接パラメータにし、「所得税の額−住民税の額」で計算しない（一致は検査で確かめるだけ）(I)。
- これらの額は地方税法の本則の額で、市町村ごとの条例のデータではない。注入点は要らない。調整控除の率（市町村民税は100分の3、指定都市は100分の4。道府県民税は100分の2、指定都市は100分の1）の「指定都市か」は、住所の市町村の事実（E6）から決まる［LW］§5.2 (I)。調整控除は前年の合計所得金額が2,500万円以下の者に限る（地法314の6①・37①）［LW］§5.2。
- 「同居」の扱い（入院・老人ホーム）を住民税について書いた資料は探していない［LW］§7、［GD］§6-3。所得税と同じ候補の規則を使い、結果に「住民税についての出典未確認」の印を付ける (I)。

## HE3 国外居住親族：控除対象扶養親族の区分（所得税・住民税）

### HE3.1 区分の関数

- 入力：扶養親族であること（所得要件・生計を一にする）、12月31日（住民税は前年12月31日）に非居住者か（J1）、年齢（E1）、留学（E7）、障害者（E11）、その年（住民税は前年）の支払の合計が38万円以上か（HE3.2）［LW］§3.1・§5.1。
- 出力：所得税の申告書第二表の「国外居住」欄の区分と同じ形にすると、様式の欄の対応表（D19）とそのまま対応する：16歳未満＝5、16歳以上30歳未満又は70歳以上＝1、30歳以上70歳未満で留学＝2、障害者＝3、38万円以上＝4、それ以外＝5［GD］§3.2（手引き）(I)。
  - 複数に当たるときの数字の選び方（障害者を含めば3、留学と38万円の両方なら使う書類で2か4）は手引きの（注2）による［GD］§3.2。数字の選び方は欄の記入の約束で、控除の可否は変わらない（どの数字でも区分5でなければ控除対象）(I)。
- 区分は令和5年分以後で、令和7年分・令和8年分で同文［LW］§3.1。住民税（地法314の2①十一ロ）も同じ構造で、「その年」ではなく「前年において」の支払で判定し、留学は「この法律の施行地に住所及び居所を有しなくなつた者」と書く［LW］§5.1。所得税の判定の結果（その年分）を、翌年度の住民税の判定に**そのまま流用できる**（同じ年の同じ事実を見るため）(I)。

### HE3.2 「38万円以上」の判定

- 合計の対象：その年（暦年）に、居住者からその親族**各人へ**行った生活費又は教育費に充てるための支払［LW］§3.1・§3.2（所規47の2⑩）、［GD］§3.4（Q34：代表者にまとめた送金は代表者の分だけ）。
- 支払の日：為替取引は送金した日、クレジットカード等は利用日、電子決済手段は移転日（入金日・引落日ではない）［GD］§3.4（所基通2-50、Q7・Q42）。
- 円換算：原則は支払の日の電信売買相場の仲値。例外として現に支出した円の額、年間合計の一括換算（年最後の支払の日の仲値又は実際に適用された相場）［GD］§3.4。→ 方法は J5 の選択として受け取り、相場の値は E9 の事実（どの金融機関のどの日の仲値か）として受け取る。判定コアは為替相場のデータを持たない (I)。
- 手数料：金融機関の送金手数料は、38万円送金書類に手数料の額が記載されている場合に限り含めてよい［GD］§3.4（Q7）。→ E9 の「手数料の額」と「書類への記載の有無」で決める (I)。
- 手渡し：送金関係書類に当たらない［GD］§3.4（Q39）。E9 の方法が「手渡し」の支払は、38万円の合計にも送金関係書類にも数えない (I)。
- 端数：外貨×仲値で円未満が出たときの扱いは、資料に書かれていない。名前つきの関数（例 `fx_to_yen_floor`）にし、結果に「出典未確認」と出す。38万円の境目の近くで切り捨てと四捨五入で結論が変わるときは「未確定」と返す (I)。

### HE3.3 書類の要件

- 確定申告：所法120③二・三、所令262③④により、非居住者である親族の扶養控除・特定親族特別控除・配偶者控除・配偶者特別控除・障害者控除には、親族関係書類と生計を一にすることを明らかにする書類（送金関係書類）、30歳以上70歳未満（障害者を除く）は留学ビザ等書類又は38万円送金書類を、各人別に添付又は提示する。年末調整で控除された分や扶養控除等申告書で出した分は要らない［LW］§3.2。
- 書類がないときの効果：法令は「添付し、又は…提示しなければならない」と書き、国税庁は送金関係書類がなければ扶養控除等を適用できないとする（手渡しの例・年末調整の例）［LW］§3.2、［GD］§3.4（Q39・Q44）。→ 判定コアは、E10 に必要な書類の事実がない国外居住親族について、控除を適用せず、「不足している書類」を根拠に出す (I)。書類の事実が入力にない（記録されていない）ときは、書類があるとは仮定せず「書類の事実が未入力」として**未確定**と返す（SCOPE §2-4）(I)。
- 親族関係書類の組合せは、居住者から対象の親族までの続柄の経路（E2）の辺ごとに、親子関係・婚姻関係を証する書類が要る［GD］§3.5。→ 判定コアは E2 の経路から「必要な証明の辺」の一覧を出せる。書類の真正さや中身はコアでは判定しない（事実として受け取る）(I)。
- 書類は年分ごと：送金関係書類は「その年において」の支払を明らかにするもので、複数年分をまとめた送金は送金した年分だけ［GD］§3.4（Q36）。親族関係書類の発行日に法令の規定はない［GD］§3.5（Q18）(I)。
- 住民税の扶養控除・特定親族特別控除・障害者控除・配偶者（特別）控除の書類（地規2の2④⑤。2027-01-01 の版は⑤⑥）は、所得税の確定申告書・扶養控除等申告書などで出したものは不要［LW］§5.3。判定コアは「住民税で別に出す必要があるか」を、所得税で出した事実（E10）から決められる (I)。
- 住民税の非課税限度額：国外居住者である16歳未満の扶養親族・控除対象配偶者でない同一生計配偶者を数えると非課税限度額の制度の適用を受ける者は、それらの書類が要る［LW］§5.3、［GD］§3.2（手引き※2）。この書類（地規2の2⑥）は上と違い、所得税の確定申告書に添付しても足りない。確定申告書を出す者も3月15日までに市町村長に出す（地規2の3⑤⑥）［LW］§5.3。→ E10 の「誰に・いつ・どの申告書で」で、市町村長への提出・住民税の申告書等への添付を所得税の確定申告書への添付と区別する (I)。→ ［JZ］の非課税限度額の数え方の関数に、「国外居住者である16歳未満の扶養親族等は書類の事実がなければ数えない」という条件を足す (I)。

### HE3.4 「国外居住親族」の語の扱い

- 「国外居住親族」は所法194⑤で源泉徴収の申告書について定義された語で、確定申告の条文（所法120③）は「判定をする時の現況において非居住者である親族」と書く［LW］§3.2・§3.3。住民税の施行規則は「国外居住者」と呼ぶ［LW］§5.3。→ 概念辞書では、`所得税.非居住者である親族`（12月31日の現況）を中心に置き、源泉徴収の `所得税.国外居住親族`（申告書の提出日の現況：［GD］§3.3 Q4）と、住民税の `住民税.国外居住者`（前年12月31日）を別の ID にする。判定の時点が違うので、同じ人でも値が違いうる (I)。

## HE4 居住者・非居住者の判定（扶養の判定に使う分だけ）

- 本ライブラリは非居住者本人の申告をしない（D20）。家族の誰かが12月31日に非居住者なら、その人の所得税の計算は「対象外」と返し、その人が**他の家族の扶養親族として**どう扱われるかだけを計算する (I)。
- 非居住者かどうかは判断 J1 で受け取る。判定コアは、E7・E8・E12 の事実から次の**推定**を出して、判断の材料と根拠にする［LW］§4、［GD］§4 (I)：
  - 国外で継続して1年以上居住することを通常必要とする職業に就いた → 非居住者と推定（所令15①一）。その人と生計を一にし、その人が扶養する親族で国外に居住する者も非居住者と推定（所令15②）。
  - 留学：1年以上国外に居住することを通常必要とするものでなければ国外居住親族に当たらない（［QA-KG］Q16）。
  - 国内に住所を有する者の推定（所令14）、再入国の場合の居所（所基通2-2）、入国後1年（所基通2-3・2-4）。
  - 公務員（日本国籍）は国外にいても国内に住所を有するものとみなす（所法3①、所令13 の例外）。公務員本人だけで、同行する家族には及ばない（原文は「国家公務員又は地方公務員」と書く）(I)。
- 推定は覆されうるので、推定と判断 J1 が食い違うときは判断を使い、結果に「推定と異なる判断」と出す (I)。
- 年の途中の変化：扶養の判定は12月31日の現況で、年の途中で非居住者になった親族でも12月31日に非居住者なら国外居住親族として扱う［LW］§3.4。年の途中まで国内にいた期間の生活費の支払（送金でない手渡しなど）を、送金関係書類の要件との関係でどう扱うかを書いた資料は、本調査では見つからなかった（HE6 の U7、推測 IE10）(I)。

## HE5 健康保険の被扶養者：60歳以上・直系尊属・後期高齢者・国内居住要件

### HE5.1 年齢の区分

- 60歳以上は 180万円未満（障害厚生年金の受給要件に該当する程度の障害者も）、それ以外は 130万円未満（19歳以上23歳未満は既存のとおり 150万円未満）［GD］§5.1、［PS-K］§5.5。
- **60歳の判定の時点が一次情報にない**［GD］§5.1・§6-4。候補は「判定日（認定日）の年齢」と「判定日の属する年の12月31日の年齢」（19〜23歳と同じ扱い）の2つ (I)。→ パラメータ `健保.60歳の判定時点` を保険者ごとに注入する値にし（D19）、注入がないときは両方で評価して、結論が変われば「未確定」と返す (I)。
- 75歳以上（または65歳以上で障害の認定を受けた者）は後期高齢者医療の被保険者で、被扶養者にならない（健保法3⑦ただし書、高確法50）［LW］§6.1。判定コアは E13（後期高齢者医療の資格）を事実として受け取り、なければ E1 から「75歳到達で資格を得る見込み」を出す。資格の取得日の条文（高確法52 など）は取得していないので、到達日の扱いは「出典未確認」とする［LW］§7 (I)。

### HE5.2 続柄と同一の世帯

- 被保険者の父母・祖父母（直系尊属）は健保法3⑦一で、同一の世帯は要件でない。被保険者の配偶者の父母・祖父母は⑦二で、同一の世帯が要件［LW］§6.1、［GD］§5.2。→ 所得税の同居老親等（居住者**又は配偶者**の直系尊属）と、健保の⑦一（**被保険者の**直系尊属）は範囲が違う。同じ「祖父母との同居」の場面でも、配偶者の親は健保では同一世帯が必要になる (I)。
- 収入の基準の選び方（同一世帯なら2分の1未満、別世帯なら仕送り額より少ない）は S52 と既存［PS-K］のとおり。国外に住む家族は、別居なら「年間収入が仕送り額未満」、海外で同居なら「2分の1未満」［GD］§5.3（機構）。

### HE5.3 国内居住要件

- 原則：住民票が日本国内にあるか（E6）［GD］§5.3（R01 第1）。住民票が国内にあっても、明らかに日本での居住実態がない（海外で就労）と保険者が判断した場合は満たさない → これは保険者の判断で、判定コアは「住民票あり」を満たすとし、根拠に「保険者が居住実態で例外的に否定しうる」と出す (I)。
- 例外（健保則37の2 の5号）：第1〜4号は E7 の渡航目的の区分と書類で当てはめ、第5号は判断 J6［LW］§6.2、［GD］§5.3 (I)。例外の判定は**所得税の非居住者の判定と別**で、同じ人が「所得税では非居住者（国外居住親族）」かつ「健保では例外に当たり被扶養者」になりうる（例：1年以上の留学）(I)。
- 例外に当たっても、同一世帯の要件（⑦二）と生計維持の要件は別に要る（R01 Q4・Q5）［GD］§5.3。
- 国外の収入の見込み：ビザで就労の可否を見て見込む、就労できないビザなら就労の収入なし、渡航前の国内の所得証明で基準未満ならそれでよい（R01 Q2−2）［GD］§5.3。→ 判断 J7 の作り方の材料で、判定コアは見込みの値を受け取るだけ（D19）(I)。外貨の収入の円換算の方法は資料にない (I)。
