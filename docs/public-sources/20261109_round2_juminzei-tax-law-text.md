## 2. 所得割の課税標準（第313条（第32条））（F）

- 第1項：所得割の課税標準は、**前年の所得について算定した総所得金額、退職所得金額及び山林所得金額**。
- 第2項：これらは、法令に特別の定めがある場合を除き、**所得税法その他の所得税に関する法令の規定による**総所得金額等の **計算の例により** 算定する（所得税法第60条の2〜第60条の4 の例によらない）。
- 第3項〜第6項：青色事業専従者・事業専従者（住民税の事業専従者控除は配偶者 86万円、その他 50万円、と「所得÷(専従者数＋1)」の低い方）。白色の専従者控除は、
  住民税の申告書（第317条の2第1項）に記載がないと適用しない（申告義務がない場合などを除く）。15歳未満かどうかは前年12月31日の現況（第7項）。
- 第8項・第9項：純損失・雑損失の繰越控除は、住民税の申告書（第317条の2第1項又は第3項）を連続して提出している場合に限る。起点は項で違う。
  - 第8項（青色申告書を提出した年の純損失）：その年分の所得税の青色申告書の提出と、**「純損失の金額の生じた年の末日の属する年度の翌々年度以後の年度分」** について申告書を連続して提出していること。
  - 第9項（変動所得・被災事業用資産の損失に係る純損失、雑損失）：**「生じた年の末日の属する年度の翌年度」** の申告書を提出し、かつ、その後の年度分も連続して提出していること。
  ※所得税の確定申告書を出せば住民税の申告書を出したものとみなされる（第317条の3。［既存PS］§6）。
- 第11項：前年分の所得税の納税義務がない者の特定支出控除は、住民税の申告書で受ける。
- 第12項〜第15項：特定配当等・特定株式等譲渡所得金額は、前年分の所得税の確定申告書に記載がなければ総所得金額から除く（記載があれば含める）。
- 合計所得金額（第292条第1項第13号）は第313条第8項・第9項の控除**前**。上場株式等の配当所得等の分離課税（附則第33条の2第5項）があるときは、
  同条第7項第1号の読替えで、扶養・非課税（第292条第1項第7号〜第9号・第13号、第295条第1項第2号・第3項など）・調整控除（第314条の6）などに使う合計所得金額にその金額を含める。

## 4. 所得割の税率（第314条の3（第35条））と標準税率（F）

- 第314条の3第1項：所得割の額は、課税総所得金額・課税退職所得金額・課税山林所得金額の合計額に、**100分の6**（**指定都市**の区域内に住所を有する場合は **100分の8**）の
  **標準税率**によって定める率を乗じた金額。「当該定める率は、**一の率でなければならない**」。
- 第35条第1項（道府県民税）：**100分の4**（指定都市の区域内に住所を有する場合は **100分の2**）の標準税率によって定める率。「当該定める率は、**同一の標準税率ごとに一の率**でなければならない」。
- 第314条の3第2項（第35条第2項）：課税総所得金額等＝第314条の2（第34条）の控除後の前年の総所得金額等。
- 第1条第1項第5号：標準税率＝「地方団体が課税する場合に通常よるべき税率でその財政上その他の必要があると認める場合においては、**これによることを要しない税率**」で、
  地方交付税の基準財政収入額の算定に使う税率。
- 第310条・第38条・第314条の3・第35条（asof 4版）に、税率の上限を定める「超えることができない」の文言はない（［実測］§3.1 の C22）。
  地方税法の本則・原始附則の全文に「制限税率」という語はなかった（［実測］§3.4。上限は語ではなく「…を超えることができない」の形で書かれうるので、語がないことは上限がないことの証明にはならない。
  上限の有無は条ごとに文言で確かめた範囲だけを言える）。
- 指定都市＝地方自治法第252条の19第1項の市。指定の政令（asof 2026-11-09・2027-01-01、施行 2012-04-01 の版）は次の **20市**：大阪市、名古屋市、京都市、横浜市、神戸市、

- 第4条（非課税）：①生活保護法の生活扶助その他これに準ずるものとして政令で定める扶助を受けている者、②障害者・未成年者・寡婦・ひとり親で前年の合計所得金額 135万円以下、
  ③ **前年の合計所得金額が政令で定める金額以下** の者。
  - 施行令第1条：③の金額＝ 35万円 × 級地の率（前年12月31日の級地。施行規則の率）×（同一生計配偶者＋扶養親族〔16歳未満と控除対象扶養親族〕＋1）＋10万円（配偶者・扶養親族がいれば
    ＋21万円 × 級地の率）。**市町村の条例の額ではなく、政令の式で直接決まる**（施行令第1条に「条例」の語がない）。
  - 施行令の見出しには第4条第1項第1号（扶助）に当たる条が見当たらなかった（第1条は第4条第1項第3号、第5条〜第7条は第11条（免除）に関するもの）。
  - 地方税法第295条第3項（均等割の非課税）と違い、「均等割のみを課すべきもの」という限定がない。
- 第5条：税率 **1,000円**。第6条：賦課期日は当該年度の初日の属する年の1月1日。
- 第7条：賦課期日に住所を有する市町村が、個人の市町村民税の均等割の賦課徴収の例により、市町村民税・道府県民税の均等割と併せて賦課徴収する。
  ただし地方税法 **第311条（均等割の軽減）と第323条（減免）による例は除く**。
- 第11条：災害・生活扶助以外の扶助・失業等による免除（政令第5条〜第7条）。
- 附則第2条：第2章（森林環境税）は **令和6年度以後** の年度分に適用。

## 15. 端数処理（第20条の4の2、施行令第6条の17）（F）

- 第1項：地方税の **課税標準額** に **1,000円未満** の端数があるときは切り捨てる（政令で定める地方税を除く）。
- 第3項：地方税の **確定金額** に **100円未満** の端数があるときは切り捨てる（政令で定める地方税は 1円未満を切り捨てる）。
- 第8項：第2項、**第3項（確定金額の全額が100円未満のときに全額を切り捨てる部分に限る）** 及び前三項（第5項〜第7項。第4項（滞納処分費）は含まない）の適用では、個人の市町村民税、これと併せて徴収する個人の道府県民税、
  併せて賦課徴収する森林環境税を **それぞれ一の地方税とみなす**。
- 第6項：分割して納付する場合の 1,000円未満の端数は最初の納期限の分に合算（条例で別の定めができる。特別徴収の個人住民税・森林環境税は 100円）。
- 施行令第6条の17：第1項・第3項のただし書の「政令で定める地方税」は利子割・配当割・株式等譲渡所得割に係る道府県民税、たばこ税など。**個人の市町村民税（所得割・均等割）は含まれない**。
- 地方税法（本則・原始附則）と施行令の全文で「一円未満の端数」「これを切り上げ」などを探した（［実測］§3.4）。個人住民税の所得割の計算の途中（算出所得割、生命保険料控除、
  税額控除、附則第3条の3 の調整）の 1円未満を定めた文言は **見つからなかった**。見つかったのは、令和6年度分・令和7年度分の特別税額控除（附則第5条の8・第5条の12：1円未満切上げ）、
  配偶者特別控除の 2/3・1/3（1万円未満切上げ）、延滞金・還付加算金、特定寄附信託の利子（施行令附則第4条の8：1円未満切捨て）など。

## 16. 分からなかったこと・一次情報が見つからなかったこと

- 第20条の4の2第1項の「課税標準額」に当たる額。所得割の課税標準は第313条で「総所得金額、退職所得金額及び山林所得金額」（控除前）だが、自治体の計算例（［行政］§2）は
  控除後の課税総所得金額を 1,000円未満切捨てにしている。この扱いを定めた法令・通知の文言は見つけていない。
- 所得割の計算の途中の 1円未満の扱い（§15）。施行規則と取扱通知の全文は探していない（取扱通知は該当しそうな頁だけ読んだ：［行政］§1）。
- 配当控除・住宅借入金等特別税額控除・寄附金税額控除の互いの順序（法令の文言なし。§11）。
- 申告特例控除の区分の基準が負のときの扱い（§8.3）。
- 森林環境税法第4条第1項第1号の「政令で定める扶助」の中身（施行令の見出しに見当たらない）。
- 退職所得の分離課税の端数（1,000円・100円）の扱いと、退職所得の分離課税に超過課税が及ぶか（第328条の3 に「標準税率」の語がないことしか確かめていない）。
- 令和9年度分（賦課期日 2027-01-01）に、2027年に成立する改正が適用されるか（［既存PS］§9 と同じ）。
