## I1 令和7年分と令和8年分で結論が変わる：ひとり親の子の所得

- 前提：H5、H11。
- 場面：離婚して婚姻していない親X（住民票に「未届の夫／妻」の記載なし、合計所得金額 300万円）と、生計を一にする子Y（他の人の扶養親族とされていない）。子Yの総所得金額等が 60万円。
- 推測：
  - 令和7年分の所得税：子の要件（58万円以下）を満たさない → ひとり親に当たらない。離婚の寡婦（親Xが女性の場合）も、子Yは扶養親族（58万円以下）に当たらないので「扶養親族を有する」を満たさず、当たらない。→ 控除 0。
  - 令和8年分の所得税：子の要件（62万円以下）を満たす → ひとり親 35万円。
  - 住民税：令和8年度分（令和7年の所得）は 0、令和9年度分（令和8年の所得）はひとり親 30万円。
- 検証：[単] 所令11の2②・地令46の2の2② の版ごとの値で境目（58万／58万1円、62万／62万1円）のテストを作る。[作成] 令和7年分で子の所得 58万円と 58万1円を入れて、ひとり親控除の有無を確かめる（令和8年分は作成コーナーの公開後）。

## I2 障害者控除は扶養の所属についていく（分けられない）

- 前提：H4。
- 場面：祖父母Gと親Pが同じ家計で、障害者手帳3級の子C（16歳未満、所得なし）。Cを祖父母Gの扶養親族として扶養控除等申告書に書いた。
- 推測：Cの障害者控除（27万円）はGが受ける。PはCについて障害者控除を受けられない（H4：扶養親族は所属の結果、一の居住者の扶養親族にのみ該当するとみなされる。16歳未満で扶養控除がなくても、扶養親族の所属は申告書等の記載で決まる。所基通79-1 は控除対象扶養親族についての通達で、16歳未満のCには文言上は及ばないが、結論は同じ向き）。住民税も同じ所属（地法292④・地令46の5）でGに 26万円。
- 検証：[単] 所属の表を入力にして、障害者控除が所属の先に付くことのテスト。[作成] は1人ずつの申告なので、Gの申告に入れて控除が出ることだけ確かめられる（Pの側で出ないことは作成コーナーでは確かめられない）。[問] 16歳未満の扶養親族の所属の変更（所基通85-2）の手続を税務署に確認。

## I3 同居特別障害者：入院中と施設入所で額が変わる

- 前提：H4、H8。
- 場面：精神障害者保健福祉手帳1級の親M（Kの扶養親族、合計所得金額 0）。
  - (a) 12月31日に病気の治療で長期入院中（入院前はKと同居）
  - (b) 12月31日に施設に入所中
- 推測：(a) 同居特別障害者 → 所得税 75万円、住民税 53万円。(b) 同居に当たらない → 特別障害者 40万円・30万円。Mが70歳以上なら老人扶養親族の扶養控除も別に受ける（扶養控除の同居老親等の判定にも同じ同居の事実を使う）。
- 検証：[探] 「入院は同居」の質疑応答は同居老親等（措法41の16）についてのもの。障害者控除の同居（所法79③）に同じ扱いをすることを書いた国税庁の原文を探す（No.1160 から関連事例として張られていることだけは確認済み）。[作成] 同居特別障害者の選択肢で 75万円が出ること。

## I4 要介護認定だけでは障害者にならない。65歳以上の認定書があれば当たる

- 前提：H1、H3。
- 場面：要介護3の親O（70歳）。(a) 市町村長等の障害者控除対象者認定書なし。(b) 「特別障害者に準ずる」認定書あり（有効期間内）。(c) 認定書なし、12月31日時点で申請中、申告時も申請中。
- 推測：(a) 障害者に当たらない（コアは要介護度を使わない）。(b) 特別障害者 → 扶養親族で同居なら 75万円。(c) 所得税は質疑応答 05/63 により「申請中で、12月31日に認定を受けられる程度」なら適用してよい → 判断（認定を受けられる程度か）を受けて特別障害者／障害者とし、「通達・質疑応答による」の印。住民税は同じ取扱いの一次情報がない → 未確定（H3）。
- 検証：[問] 市Aの障害者控除対象者認定の基準と、申請中の住民税の扱いを市Aに確認。[探] 住民税の取扱いに申請中の扱いがあるか（取扱通知の未読の頁、市町村の案内）。

## I5 手帳の交付が年をまたいだ場合

- 前提：H2、H3。
- 場面：身体障害者手帳を令和8年11月に申請し、令和9年1月20日に4級で交付。令和8年分の確定申告を令和9年2月に出す。
- 推測：
  - 所得税 令和8年分：12月31日に手帳はない。ただし所基通2-38 により、申告書の提出時に交付済み（申請中の要件は「提出する時において…申請中であること、又は…診断書を有していること」なので、交付済みの場合をどう読むかは文言上はっきりしない）で、12月31日の現況で明らかに手帳の程度なら障害者として扱える可能性が高い（I）→ 通達による取扱いの印。
  - 住民税 令和9年度分の控除（前年12月31日の現況）：通達に当たる取扱いが見つかっていない → 未確定。
  - 住民税 令和9年度分の非課税：1月1日にも手帳がない → 12月31日・1月1日とも「障害者でない」で一致 → 障害者としての非課税には当たらない（通達の扱いを使わない場合）。
  - 令和7年分以前にはさかのぼらない（質疑応答 05/31）。
- 検証：[問] 税務署に、申告時には交付済みの場合の 2-38 の扱いと、市町村に住民税での扱いを確認。[作成] では検証できない（作成コーナーは障害者の区分を入力として受けるだけ）。

## I6 住民税の非課税の判定時点で結論が分かれる場面

- 前提：H2、H6。
- 場面：前年の合計所得金額 100万円の人。精神障害者保健福祉手帳の有効期限が12月31日で切れ、更新後の手帳が1月10日に交付された（申請は12月中）。
- 推測：12月31日には手帳あり、1月1日には有効期間外 → 2つの時点で区分が違う → コアは「未確定（判定時点が法令で決まらない／手帳の更新の扱いが不明）」を返す。市Aが「1月1日の現況」を注入データで渡すと、手帳の更新中の扱いが残るので、なお判断を求める。
- 検証：[問] 市Aに、非課税の障害者の判定時点と、手帳の更新中の扱いを確認。[探] 精神手帳の有効期限と更新の関係を厚生労働省の通知で確認（法45④ の「二年ごとに…認定を受けなければならない」の効果）。

## I7 障害年金が大きくても住民税は非課税になりうる。健保ではそうならない

- 前提：H6、H7。
- 場面：障害厚生年金2級（年額 150万円）を受け、給与収入 100万円の人Dが、親の健康保険の被扶養者で同居。
- 推測：
  - 住民税：障害年金は合計所得金額に入らない。給与所得は令和8年分なら 100万円 − 74万円 ＝ 26万円（措法29の4 の給与所得控除の特例が住民税に及ぶ前提。既存の扱い）→ 前年の合計所得金額 26万円 ≤ 135万円 → 障害者として非課税。
  - 健保：年間収入 ＝ 障害年金 150万円 ＋ 給与 100万円 ＝ 250万円 ≥ 180万円 → 被扶養者に当たらない（障害年金2級は「程度」に該当するので基準は 180万円）。
  - 所得税：障害者（手帳があれば。障害年金だけでは所令10 のどれにも当たらない）。
- 注意：障害年金を受けていても障害者手帳がない人は、税の障害者に当たらない（H1：税の根拠は手帳・判定・認定で、年金ではない）。逆に、手帳4級で年金がない人の健保の基準は保険者次第（I8）。
- 検証：[単] H6・H7 のテスト。[作成] 障害年金は作成コーナーに入力しない（非課税）ことと、障害者控除の欄で確かめる。[問] 保険者に年間収入の数え方を確認（既存の健保の調査と同じ）。

## I8 健保：手帳はあるが障害年金がない人

- 前提：H7。
- 場面：身体障害者手帳3級、障害年金なし、年間収入の見込み 150万円の親E（58歳、別居、援助額 160万円）。
- 推測：基準が 130万円なら当たらない、180万円なら当たる → 結論が分かれる → 保険者ごとの注入データ（手帳何級以上を「程度に該当」とみなすか）がなければ「未確定（障害の程度の基準は保険者の運用で決まる）」。保険者が 180万円で認定した事実が記録されていれば、それに従う。
- 検証：[問] 加入している保険者に、障害者の 180万円の確認方法（年金証書・手帳・診断書）を問い合わせる。[探] 保険者の被扶養者認定の手引き（健保組合・共済組合）で、手帳の等級を基準にしている例と、障害年金の受給を基準にしている例を集める。

## I9 所得税の寡婦と住民税の非課税の寡婦で結論が分かれる

- 前提：H5。
- 場面：離婚した女性F（合計所得金額 120万円、住民票に未届の夫の記載なし）。子G（所得なし）は元夫と生計を一にし（養育費を継続して負担）、元夫の扶養親族とされている。FもGの扶養費の一部を負担している。
- 推測：
  - ひとり親：Gは「他の者の扶養親族とされている」→ 子の要件を満たさない → 当たらない（所得税・住民税とも）。
  - 所得税の寡婦：所基通2-40 により、扶養親族は所属の結果に従う → Fは扶養親族を有しない → 寡婦に当たらない → 控除 0。住民税の寡婦控除も同じ（I：住民税の控除に 2-40 に当たる取扱いがあるかは未確認だが、第292条第4項の所属の規定は同じ構造）。
  - 住民税の非課税：取扱通知 第1の3 により、Fが扶養費の一部を負担していれば「扶養親族を有する」→ 寡婦 → 前年の合計所得金額 120万円 ≤ 135万円 → 非課税（通知による取扱いの印）。
- 検証：[問] 市Aに、第1の3 の運用（扶養費の一部負担の確認方法）を確認。[単] 非課税の判定でだけ判断「扶養費の一部負担」を使うことのテスト（控除の判定に漏れないこと）。

## I10 男性・未婚・事実婚の扱い

- 前提：H5。
- 場面と推測：
  - (a) 妻と死別した男性H（子なし、合計所得金額 200万円）：寡婦は「夫と」死別した者なので当たらない。ひとり親も子がいないので当たらない → 0（住民税の非課税にも当たらない）。
  - (b) 婚姻歴のない親J（子あり、合計所得金額 200万円、住民票の続柄の記載なし）：「現に婚姻をしていない者」→ ひとり親 35万円（令和8年分）。
  - (c) (b) の親Jが別の人と同居し、住民票に「夫（未届）」と記載：ひとり親に当たらない。記載がなく実態として事実婚の場合、コアは住民票の記載だけで判定するので当たると出す（H5 の文言どおりの読み）。
- 検証：[作成] (a)(b) は作成コーナーの寡婦・ひとり親の選択で確かめられる範囲だけ（作成コーナーは区分を入力として受ける）。[探] 住民票に記載のない事実婚の扱いを書いた国税庁の原文（Q&A・質疑応答）。

## I11 寡婦・ひとり親の 500万円の境目（給与だけの人）

- 前提：H10。
- 推測：給与収入 6,777,778円 → 給与所得 5,000,000円（1円未満切捨て）→ 500万円以下で当たる。6,777,779円 → 5,000,001円で当たらない。端数を切り捨てない実装だと 6,777,778円で誤って「当たらない」になる。
- 検証：[単] 6,777,777／6,777,778／6,777,779円の3点のテスト（期待値の出典は年末調整のしかたの注と、実測 `docs/measurements/20261109_round2_jinteki-fetch-and-checks.md` §5）。[作成] 令和7年分で給与収入 6,777,778円と寡婦を入れて、寡婦控除が出ることを確かめる。
