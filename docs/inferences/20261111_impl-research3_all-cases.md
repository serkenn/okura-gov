## 7. 推測が外れていたときに見直す仮説

- G-1〜G-4 が国税庁の計算例と合わない → H1（特に所令134② の始まる年、改定取得価額）。
- O-1 で作成コーナーの割り振りが通達の順と違う → H4（作成コーナーは納税者の選択の一つを既定にしている可能性）。
- P-2 で作成コーナーが70歳と扱う → H6 を「両方で評価」に改める（D22 S1）。
