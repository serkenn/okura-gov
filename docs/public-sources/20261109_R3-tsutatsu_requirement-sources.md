## 2. 監視の観点からの整理

- **税（所得税）**：金額は法令、範囲・判定方法・按分は通達。通達は「所得税基本通達の改正一覧」に改正通達が載る（2020年以降は年1〜3回）。TA は改正の施行日前から注記の形で新しい金額を載せる（例：TA1180 は令和8年分の62万円を注記で併記）。
- **社会保険（健康保険の被扶養者）**：数値基準そのものが**通知**で決まり、判定時点・含める収入の範囲は**事務連絡（Q&A）**で決まる。法令の監視だけでは、令和7年の150万円・令和8年の労働契約による判定のどちらも検知できない。厚労省の通知の監視が必須。
- **住民税**：地方税法（R1）。自治体の案内は反映に時間差があり、誤りや古い記述もありうる（横浜市の国保のページは150万円に触れていない）。
