## 1. 再実行の方法

```
python -I -X utf8 scripts/R2X_juminzei-tax_verify.py egov    # e-Gov 法令API v2 から取り直す（地方税法 7版、施行令・森林環境税法・同施行令・指定都市の政令・震災臨時特例法・所得税法・租税特別措置法）
python -I -X utf8 scripts/R2X_juminzei-tax_verify.py web     # 総務省・自治体のページと PDF を取り直す（robots.txt を先に読む）
python -I -X utf8 scripts/R2X_juminzei-tax_verify.py check   # 照合と再計算（ネットワークなし。約1分）
```

方法の要点：

- 条文は担当のテキスト（`scripts/results/R2X_juminzei-tax_laws/*.txt`）を使わず、e-Gov の JSON から自分で書いたテキスト化で読んだ。**条・項・号の位置は JSON の `Num` 属性で特定し**、主張の文字列がその項・号の中に（順に）あるかを確かめた。担当の検査（`evidence.md`）は条全体の中の文字列の有無だけを見ていたので、項・号の番号の誤りはそこでは見つからない。
- 計算は担当の `compute()` を使わず、条文から `fractions.Fraction` で書き直した（`juminzei()`）。
