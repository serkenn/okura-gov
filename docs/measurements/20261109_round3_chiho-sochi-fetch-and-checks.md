## 4. 結果の要約（実測として言えること）

- 「地方税法第313条第2項（第32条第2項）の『所得税法その他の所得税に関する法令』に租税特別措置法が含まれる」と、**一般的な形で書いた法令・通知の文は、取得した範囲では見つからなかった**。
- 一方で、次の文は見つかった（文言は［PS］）。
  - 政令：施行令第48条の5の2（第7条の10の5）が「法第三百十三条第二項の規定により同条第一項の総所得金額を算定する場合には」、措法第41条の3の11 と第41条の15の3 の語を読み替えて
    「これらの規定の例によるものとする」と定める（令和4年度分から。引く条は令和7年1月1日から第41条の3の11）。
  - 省令：施行規則第6条の8 が「法第三十二条第二項の規定においてその例によるものとされる租税特別措置法第二十六条第一項の規定」と書く。
  - 政令：施行令の原始附則第18条第1項が、「所得税法その他の所得税に関する法令の規定」から租税特別措置法施行令の特定の項を除いている。
  - 総務省の通知：取扱通知（市町村税）が、措置法の規定で所得税法第22条第2項の総所得金額から除かれているものは住民税の総所得金額に含まれない、と書く。
    平成30年の事務連絡が、青色申告特別控除・家内労働者等の特例の見直しは個人住民税にも適用、所得金額調整控除は「所得税に係る法令の規定が個人住民税にも適用」と書く。
    令和8年の事務連絡・概要が、令和9年度分・令和10年度分の個人住民税の給与所得控除の最低保障額をさらに5万円（合計74万円）引き上げると書く。
