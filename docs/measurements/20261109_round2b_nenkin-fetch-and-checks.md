### V2 条文から組んだ式と TA No.1600 速算表

- 式：所法35④ と措法41の15の3① をそのまま整数・分数（`fractions.Fraction`）で組んだもの（`kojo_law`）。「収入金額から五十万円を控除した残額」は収入が 50万円未満なら 0 とした（最低額が上回るので結果に影響しない）。
- 比べた点：0〜1,200万円の 1,000円刻み、境目（40万・50万・60万・90万・100万・110万・130万・330万・410万・770万・950万・1,000万円・1,000万1円）の前後 ±5円、乱数（種 20261109、`random.Random.randrange(0, 15000000)`）で選んだ 0〜14,999,999円の整数 20万個。重複を除いて 210,677 点。
- 結果：3区分（公的年金等に係る雑所得以外の合計所得金額 1,000万円以下／1,000万円超2,000万円以下／2,000万円超）× 2つの年齢区分の **6表すべてで不一致 0**。
- 区分の境目（収入 200万円での控除額）：その他の合計所得金額 10,000,000円 → 65歳未満 775,000・65歳以上 1,100,000、10,000,001円 → 675,000・1,000,000、20,000,000円 → 675,000・1,000,000、20,000,001円 → 575,000・900,000（「以下」「超」の向きどおり）。

### V3 円未満の端数

- V2 の 210,677 点のうち、雑所得の金額に円未満の端数が出る点：65歳未満 102,280 点、65歳以上 82,388 点（各区分で同じ）。
- 例（65歳未満・区分1）：収入 1,300,001 → 700,000.75、1,300,002 → 700,001.50、4,100,001 → 2,800,000.85、7,700,001 → 5,860,000.95。
- 条文にも速算表にも端数処理の定めがない（[PS] §2.1・§10）。

### V4 TA No.1600 の計算例

- 65歳以上・その他の合計所得金額 500万円・収入 350万円 → 条文の式で 2,350,000円（TA と一致）。
