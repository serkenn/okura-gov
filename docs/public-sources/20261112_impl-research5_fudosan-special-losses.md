## 1. 共通：「生じなかつたものとみなす」の範囲

措法41の4の2① と 41の4の3① は、損失の金額に相当する金額を「所得税法第二十六条第二項及び第六十九条第一項の規定その他の所得税に関する法令の規定の適用については、
生じなかつたものとみなす」。所法26②（不動産所得の金額の計算）にも及ぶので、他の不動産所得の黒字とも差し引かない。措法41の4①（土地等の負債の利子）は
「所得税法第六十九条第一項の規定その他…」だけで26②を挙げない（`docs/public-sources/20261109_round2b_fudosan-laws-and-nta.md` §4.3）。
TA1391：特定組合員等の損失は「他の不動産所得の黒字から差し引くことができませんし、損益通算の対象にもなりません」。TA2250（注4）：「※（4）により生じた損失は、国内に
ある不動産から生ずる不動産所得との内部通算（いわゆる所得内通算）もできません。」

## 2. 組合事業・信託（措法41の4の2、措令26の6の2、措規18の24）

- 措法41の4の2①：特定組合員（組合契約を締結している組合員のうち、組合事業に係る重要な財産の処分若しくは譲受け又は多額の借財に関する業務の執行の決定に関与し、
  かつ、当該業務のうち契約を締結するための交渉その他の重要な部分を自ら執行する組合員以外のもの）又は特定受益者（信託の所得税法第13条第1項の受益者〔同条第2項で
  みなされる者を含む〕）が、平成18年以後の各年に組合事業又は信託から生ずる不動産所得を有する場合の「当該組合事業又は信託による不動産所得の損失の金額として
  政令で定める金額」。②一：組合契約＝民法第667条第1項の組合契約・投資事業有限責任組合契約・外国におけるこれらに類する契約（政令で定めるものを含む）。
- 措令26の6の2①：組合員に類する者＝外国のこれらに類する契約を締結している者。⑤：外国の有限責任事業組合契約に類する契約。
- 措令26の6の2②：特定組合員かは、その年の12月31日（死亡・脱退の日、組合の解散の日）に、組合契約を締結した日以後引き続き重要業務の「すべての執行の決定に関与し、
  かつ、当該重要業務のうち契約を締結するための交渉その他の重要な部分のすべてを自ら執行しているかどうかにより、判定する」。③：業務の執行の全部を業務執行組合員等に
  委任している組合員は「特定組合員に該当するものとする」。
- 措令26の6の2④（原文）：損失の金額＝「特定組合員又は特定受益者のその年分における組合事業又は信託から生ずる不動産所得に係る総収入金額に算入すべき金額の合計額が
  当該組合事業又は信託から生ずる不動産所得に係る必要経費に算入すべき金額の合計額に満たない場合におけるその満たない部分の金額に相当する金額とする。」
- 措令26の6の2⑥・措規18の24：確定申告書に明細書を添付。措規18の24②：明細書は「各組合契約…に係る組合事業又は信託ごとに作成する」。

## 3. 国外中古建物（措法41の4の3、措令26の6の3、措規18の24の2）

- 措法41の4の3①：令和3年以後の各年。②一：国外中古建物＝個人において使用され、又は法人において事業の用に供された国外にある建物で、個人が取得して不動産所得を
  生ずべき業務の用に供したもの（償却費の計算で耐用年数を財務省令で定めるところにより算定しているものに限る）。②二：国外不動産所得の損失の金額＝国外中古建物の
  貸付けによる損失の金額（国外不動産等〔国外中古建物以外の国外にある不動産・不動産の上に存する権利・船舶・航空機〕の貸付けによる不動産所得の金額があれば、その金額の
  計算上控除してもなお控除しきれない金額）のうち国外中古建物の償却費の額に相当する部分として政令で定める金額。③：譲渡したときの取得費の調整。
- 措規18の24の2①：一 耐用年数省令第3条第1項第1号（見積り）の年数としているもの（所在国の法令の耐用年数・不動産鑑定士等・取引の相手方又は仲介者の見積りの書類で
  使用可能期間が適当であることの確認ができるものを除く）、二 同項第2号（簡便法）の年数としているもの。②：確認ができる建物は書類を添付。
  ③：共通必要経費の配分の基準は「収入金額その他の基準のうち当該資産の貸付けの内容及び費用の性質に照らして合理的と認められるもの」。
- 措令26の6の3①（原文）：「その年分の不動産所得の金額の計算上必要経費に算入した…国外中古建物…ごとの償却費の額のうち次の各号に掲げる場合の区分に応じ当該各号に
  定める金額の合計額」。一 償却費の額が損失の金額を超える場合「当該損失の金額」、二 償却費の額が損失の金額以下である場合「当該損失の金額のうち当該償却費の額に
  相当する金額」。
- 措令26の6の3②：国外不動産等の貸付けによる不動産所得の金額がある場合は、「第一号に掲げる金額から第二号に掲げる金額を控除した金額（当該金額が零を下回る場合には、零）を
  同項に規定する合計額から控除する」。一 国外不動産等の貸付けによる不動産所得の金額、二 イ（第1項第2号の国外中古建物の貸付けによる損失の金額の合計額）−
  ロ（第1項第2号の国外中古建物の償却費の額の合計額）。
- 措令26の6の3③：一 2以上の国外中古建物は建物ごとに区分して計算。二 国外中古建物・国外不動産等・それ以外の資産の区分ごとに計算。三 共通必要経費は財務省令の基準で配分。
- TA2250（注4）(4)：「令和3年分以後の各年において、国外中古建物から生じた不動産所得の損失のうち、当該建物の耐用年数を『簡便法』等により計算した減価償却費に相当する
  部分の金額」。

## 4. 土地等の負債の利子（措法41の4）との関係：措通41の4−4

- 措通41の4−4（原文）：「措置法第27条の2又は第41条の4の2の適用がある場合には、これらの規定により計算した金額に基づいて同法第41条の4を適用することに留意する。」
  措令26の6①各号の土地等の負債の利子の額は、組合事業又は受益者等課税信託に係る不動産所得を生ずべき業務の区分ごとに、「(1) 当該負債の利子の額が、…不動産所得の
  必要経費不算入額及び…不動産所得の計算について生じなかったものとみなされる金額…を超える場合　当該超える部分に相当する額」「(2) 当該負債の利子の額が、
  不動産所得の必要経費不算入額及び不動産所得の計算について生じなかったものとみなされる金額以下である場合　当該負債の利子はなかったものとする。」の合計額。
- 措法41の4の3（国外中古建物）と措法41の4 の関係を書いた通達は、措通41の4 関係（41の4−1〜41の4−4）にはない。

## 5. 住民税

- 地方税法 asof 2026-01-01・2027-01-01 の本則・附則に「国外中古建物」「特定組合員」「第四十一条の四の二」「第四十一条の四の三」の語はない（`grep_chiho_<asof>.txt`
  の語の一覧に出ない）。前年の所得は所得税の計算の例による（第313条第2項。`docs/hypotheses/20261109_round3_chiho-sochi-reading.md` H1 の読み）。
