## 1. 方法

1. 条文：他の担当と同じ 17 の (法令, asof) に、所法 asof 2025-12-01 と措法 asof 2026-11-30 を足して取得した。改正履歴（`/law_revisions/<law_id>`）は5法令。
2. 文書が引いた条文の文言を、条・項・号（または附則の改正法令番号・条・項）の位置で取り出したテキストと照合した（空白を除き、全角数字を半角にして部分一致。「…」で区切られた引用は断片ごと）。見出しは `ArticleCaption`。
3. 別表第五：`TableStruct` ごとに rowspan/colspan の占有格子を作り、列 0–2・3–5・6–8 を「以上・未満・値」として読んだ（見出しのセルは決まった語だけを許し、知らない文字列なら止まる）。読み取った区分を他の担当の CSV（`scripts/results/IMPL_kyuyo_beppyo5/beppyo5_<asof>.csv`）と全区分で比べた。
4. 給与所得の関数を自分で書き（660万円以上は第28条第2項・第3項の式で1円未満切捨て、令和8・9年分の 691,000〜2,199,999円は措置法第29条の4第2項、それ以外は年分の版の別表第五）、0〜6,700,000円の全整数で非減少を確かめた上で、文書が書いた境目・点の値を二分探索と直接計算で再計算した。
5. 地方税法（4版）・同施行令（1版）の `Sentence` 単位のキーワード出現数と出現箇所を数え直した。
6. 資料：HTML は文言を機械で照合。PDF は Read ツールで頁の画像を読み、文書の記述と目で照合した（下の §3）。

## 4. 見つけた誤り（訂正した）

1. PS §1.2：別表第五の式のセルと最後の点を漢数字（「六五〇，〇〇〇」「二〇，〇〇〇，〇〇〇円｜一八，〇五〇，〇〇〇円」）で引用していた。e-Gov の原文は全角の算用数字（「給与等の金額から６５０，０００円を控除した金額」「２０，０００，０００円」「１８，０５０，０００円」）。`verify.json` の `PS1.2-literal（訂正後）`。
2. M2 §4・H3・I4：令和8年分の年末調整（旧表）と確定申告の給与所得の差を「最大 90,000円」としていた。0〜2,299,999円の全整数で計算すると最大は **90,999円**（給与収入 740,999円：旧表 740,999−650,000＝90,999円、確定申告は措置法第29条の4第2項第1号で 0円）。差がちょうど 90,000円になるのは 740,000円と 741,000〜1,900,000円（1,159,002 点）。差が 0 でないのは 651,000〜2,199,999円（文書のとおり）。`verify.json` の `M2-4-max（訂正後）`。
