# 仮説：特定支出控除の当てはめと、authority_decision の税目（impl-research8）

根拠の記号：［PS］`docs/public-sources/20261112_impl-research8_tokutei-shishutsu-laws.md`、［M］`docs/measurements/20261112_impl-research8_tokutei-shishutsu-fetch.md`、
［GAPS］`docs/public-sources/20261109_round2_gaps-sources.md`、［KY］`docs/public-sources/20261109_impl-prep_kyuyo-sources.md`。

## H1 給与所得の金額の式

特定支出控除を受けるとき（H4）、その年分の給与所得の金額は

- 措法29の4② が当たらない年分・収入：給与等の収入金額 − 給与所得控除額（第28条第3項。令和8年分・令和9年分で収入220万円以下は措法29の4①）− （特定支出の額の合計額 − 給与所得控除額 × 1/2）
- 措法29の4② が当たるとき（令和8年分・令和9年分、収入 69万1千円以上220万円未満）：同項の給与所得の金額 − （特定支出の額の合計額 − 給与所得控除額 × 1/2）。給与所得控除額は措法29の4① の 74万円。

根拠：［PS］§1（「同項及び同条第四項の規定にかかわらず、同条第二項の残額から」）、§4（措法29の4③ の読替え）、§7.3（情報の算式）。
別表第五（第28条第4項）は使わない（第1項が「同条第四項の規定にかかわらず」と書く）。

- **様式との違い**：明細書（［PS］§7.2）は ⑭ に「確定申告の手引きで計算した所得金額」（収入 660万円未満は別表第五の額）を書き、⑮ 給与所得控除額＝⑬−⑭ とする。
  別表第五の額は収入の区分の下限で計算するので、⑮ は第28条第3項の式の控除額と数円〜数千円違いうる。法令（第57条の2①・第28条第3項）を正とし（D21 R5・D22 S2：法令＞様式）、
  作成コーナーとの照合で差が出たら記録する（推測で直さない）。

## H2 判定の「超える」と、特定支出控除の額が0以下のとき

特定支出の額の合計額が給与所得控除額の2分の1 **以下**なら第1項は当たらず、給与所得の金額は特定支出控除のない額（別表第五・措法29の4② を含む）。
明細書の「⑰ (赤字の場合は０)」「⑰欄が赤字の場合は特定支出控除の適用はありません」（［PS］§7.2、［M］§3 の 8）と同じ。

## H3 控除した金額が負になるとき

第1項の「控除した金額」が負になる場合の定めは見つからなかった（［PS］§9）。損益通算は不動産・事業・山林・譲渡の損失だけ（所法69①。既存の income_totals の実装の読み）なので、
負の給与所得の金額はほかの所得から控除されず、総所得金額・合計所得金額への効き方は 0 と同じ。判定コアは**給与所得の金額を 0 にする**（法令の読みの印）。
所得金額調整控除を引いた後の値も同じ理由で 0 未満にしない。

## H4 適用を受けるか（第3項）は申告書等の記載の選択

第3項は、確定申告書・修正申告書・更正請求書に適用を受ける旨と特定支出の額の合計額を記載し、明細書と証明書を添付した場合に限り適用する（［PS］§1・§7.1）。
当初の申告で受けなくても更正の請求で受けられる（［PS］§7.3 問19）。したがって、適用を受けるかは**納税者の選択**（その年分の申告書等の記載）として入力する。
未入力なら、受ける・受けないの両方で評価する（D21 R6・D22 の「選択の未入力は全候補で評価して最適化しない」）。特定支出の記録がない人・2分の1 を超えない人には分かれ目を開かない。

## H5 特定支出の額（記録の側と判定コアの側）

- 記録の側（法令を知らない事実）：支出ごとの区分（通勤費〔交通機関・交通用具〕・職務上の旅費・転居費・研修費・資格取得費・帰宅旅費・図書費・衣服費・交際費等）、支出金額、
  給与等の支払者により補塡される部分のうち所得税が課されない部分（明細書のⒷ。見込額でよい：［PS］§7.3）、教育訓練給付金等が支給される部分、証明をした者（給与等の支払者・キャリアコンサルタント・なし）、
  キャリアコンサルタントの証明なら教育訓練に係る部分か、特別車両料金等・航空機の客室の特別の設備の料金（内数）、通勤の交通機関の1月当たりの定期乗車券等の価額の合計（上限の材料）、
  転任の事実が生じた日（転居費）、航空機の利用（通勤費）、特定支出に数える年分（年をまたがる定期乗車券・授業料を年に分けたとき：［PS］§7.3）。
- 判定コアの側（法令）：証明のない支出・キャリアコンサルタントの証明で研修費・資格取得費でないもの・教育訓練に係る部分でないものを除く（第2項各号）、補塡・給付金の部分を除く（第2項柱書）、
  通勤費の交通機関は航空機を除き、特別車両料金等を除いた運賃の合計を定期乗車券等の価額の合計で抑える（令167の3①一）、旅費・転居費・帰宅旅費は特別車両料金等を除く（令167の3②一・③一・⑤一、所規36の5④）、
  転居費は転任の日以後1年以内の支出だけ（令167の3③）、勤務必要経費（図書費・衣服費・交際費等）は合計 65万円まで（第2項第7号）。
- 「最も経済的かつ合理的と認められる通常の経路及び方法」（旅費・帰宅旅費）、転居の宿泊費の「通常必要であると認められる額を著しく超える部分」は人の判断。
  語彙の量を抑えるため、記録の側に「そのうち通常の経路・方法によらない部分・著しく超える部分」の額（判断の結果）を書く欄は作らず、**支出金額に政令の範囲の額を書く約束**にする（ユーザーに確認：判断台帳に分けるか）。

## H6 所得金額調整控除との関係

措法41の3の11④五 の「給与所得控除後の給与等の金額」は収入金額から給与所得控除額を控除した残額（別表第五・措令19の4の2 の読替えを含む）で、特定支出控除の前の額（［PS］§5）。
第2項の 10万円の比較にはこの額を使い、控除は特定支出控除の後の給与所得の金額から行う（措通41の3の11−3：特定支出控除を受けた者にも第2項が当たる）。
第1項は給与等の収入金額で計算し、特定支出控除の後の給与所得の金額から控除する。

## H7 住民税

- 所得税の申告書等で特定支出控除を受けた人（還付申告を含む）は、住民税の所得割の総所得金額等も「所得税法…の計算の例」（地法313②・32②相当）により特定支出控除の後の給与所得の金額で計算する。
  確定申告書は住民税の申告書とみなされる（地法317の3）。判定コアは住民税の前年の所得を所得税の前年分の値から作るので、所得税の側で当てれば住民税にも及ぶ（［PS］§6）。
- 前年分の所得税の納税義務がない人が、所得税の申告をせず住民税の申告書だけで特定支出控除を受ける場合（地法313⑪・32⑪）は、所得税の給与所得と住民税の給与所得が違う。
  住民税の側で前年の所得を計算し直す必要があり、この版では実装しない（住民税の担当とユーザーに確認）。

## H8 authority_decision の税目

減免（reduction_approved）は、市町村民税（地法323。道府県民税は地法45 で同じ割合）と国保料・国保税（国保法77・地法717）の両方にある（［PS］§8）。
処分の記録に税目（住民税・国民健康保険）を持たせ、国保の規則は税目が国民健康保険のものだけを、住民税の規則は住民税のものだけを読む。
所得税は国税で、処分をするのは税務署長（市町村・保険者ではない）ので、authority_decision（処分をした者は市町村・保険者）の税目に所得税を入れない
（所得税の更正・決定は提出した申告書の記録 `filed_document` の return_type、青色申告の承認は `blue_return_procedure` で持つ）。
住民税の減免の承認は、減免の額が記録にないので、減免の前の税額を出し「減免の承認がある」ことを示す（国保と同じ扱い）。

## H9 通常の経路・著しく超える宿泊費は判断台帳に分ける（2026-11-12 の2回目。H5 の「amount に政令の範囲の額を書く約束」を改めた）

- 職務上の旅費・帰宅旅費の「最も経済的かつ合理的と認められる通常の経路及び方法」（令167の3②⑤）、転居の「旅行に通常必要であると認められる運賃及び料金」・
  「宿泊費（通常必要であると認められる額を著しく超える部分を除く）」（同③一・三）は、法令が額を決めず人が決める（D4）。記録（specific_expense）の amount には
  実際の支出金額を書き、政令の範囲に入る部分の額は判断 `判断.特定支出の通常の範囲の額`（支出ごと）に持つ（ユーザーの指示）。根拠：［PS］§2（令167の3 の文言）。
- 転居の燃料費・有料の道路の料金（同③二）と家具その他の資産の運送の費用（同③四）には「通常」の限定がないので判断を求めない（支出の別 `relocation_item`）。
- 特別車両料金等（令167の3②一・所規36の5④）は判断の額とは別に除き、除いた後の額を判断の額で抑える（法令の読み：通常の経路の運賃でも特別車両料金等は除く）。
- 判断が未入力なら、政令の範囲に入る部分は 0 以上支出金額以下なので、両端（全部・0）で評価する。特定支出の額の合計額は各支出のその額について単調に増え、
  給与所得の金額は単調に減るので、単調な判断の両端評価（D21 R6）で足りる。

## H10 地方税法第313条第11項の当てはめ（2026-11-12 の2回目）

根拠：［PS］§6（第313条第2項・第11項・第32条第11項の本文）、§1（所法57の2①）、既存 `docs/public-sources/20261109_round2_genka-laws-and-nta.md` §6.1（所令198 の損益通算の順）、
`docs/public-sources/20261109_round2_yoshiki-forms-r07.md` §2（令和7年分の手引きの一時所得の2分の1 の切捨て）。

- 要件：(1) 前年中の特定支出の額の合計額が給与所得控除額の2分の1 を超える、(2) 前年分の所得税につき納税義務を負わない、(3) 第313条第11項の適用を受ける旨と特定支出の額の
  合計額を記載した住民税の申告書の提出。所得税の申告書等で特定支出控除を受けた人は H7 のとおり第313条第2項で住民税にも及ぶので、第11項は所得税で受けない人だけに当てる。
- 「前年分の所得税につき納税義務を負わない」の定義は docs にない。前年分の所得税の額が0 の人と読み、その「所得税の額」を税額控除（配当控除・住宅借入金等特別控除など）の後の額と
  読むか前の算出税額と読むかは支えが同程度なので、両方で評価する（D22 S1）。税額控除の後の額が正なら両方で負う、算出税額が0なら両方で負わない。
- 第11項の「同法第五十七条の二第一項の規定の例により」：給与所得は所法57の2① を当てた額（措法29の4③ の読替えを含む）。住民税の前年の所得（合計所得金額・総所得金額等）は、
  第2項の「計算の例」で所得税と同じ組み立て（所得金額調整控除・損益通算・繰越控除）に、その給与所得を入れて計算する。所得金額調整控除の額は特定支出控除の前の額で決まる（H6）ので変わらない。
- 一時所得の2分の1 の1円未満：損益通算で一時所得から控除する額が奇数だけ変わるとき、令和7年分は所得税の手引きの切捨て（計算の例）、令和8年分は根拠のない端数の候補。
