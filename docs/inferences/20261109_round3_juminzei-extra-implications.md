## I1 事実台帳・判断台帳・注入データに足す項目（H1・H2・H3・H4 から）

- 推測：次の項目がないと、3つの規定を決定的に計算できない。どれも法的な解釈を含まない事実か、判断者つきの判断か、出典つきの注入データとして持てる（D3・D4・D19）。

| 置き場所 | 項目 | 使う規定 |
|---|---|---|
| 事実台帳（人 × 1月1日） | 住民基本台帳の記録のある市町村（指定都市は区）、住民登録外の課税の通知（第294条第3項）、施行地に住所があるか | H1 ①③ |
| 事実台帳（住宅） | 所在の課税団体（市町村・区）、所有か賃借か、他人に貸しているか・貸す目的か、誰が住んでいるか（家族の人 ID） | H2（判断の手がかり） |
| 判断台帳 | 「この住宅は X の家屋敷に当たる」（判断者・日時・根拠）。「その他の事務所・事業所に当たる」も同じ形 | H2-1 |
| 事実台帳（所得税の結果・外部の値） | 前年分の所得税の住宅借入金等特別税額控除額（措法第41条の3の2 を適用しない額）、所得税で適用を受けたか、居住年、特定取得・特別特定取得、震災特例・新型コロナ特例の適用 | H3-1・H3-4 |
| 事実台帳（配当・譲渡） | 配当割額・株式等譲渡所得割額（支払通知書・特定口座年間取引報告書）、支払を受けるべき日、第23条第1項第15号ロ に当たるか（同族会社と合わせて 3% 以上） | H4-1・H4-4 |
| 判断台帳（納税者の選択） | 確定申告書に記載するか（特定配当等・特定株式等譲渡所得金額ごと） | H4-1 |
| 注入データ（課税団体ごと・年度ごと） | 均等割の額（超過課税）、第295条第3項の条例の額（又はその計算の基になる級地）、家屋敷課税の運用の型（A／B、出典つき） | H1 ⑤・H2-3 |

- 検証の方法：判定コアの入力スキーマ（JSON Schema）を作ったら、下の I5 の場面（S-IY・S-HX・S-HD）をこの項目だけで書けるかを確かめる。書けない場面があれば、項目が足りない。

## I2 単身赴任・一人暮らし（D18）では、「住所」と「家屋敷の判断」と「運用の型」の3つで結論が決まり、どれかが欠けると未確定になる（H1・H2 から）

- 推測：D18 の「生計は同じで住所が別（単身赴任・一人暮らし）」の場面で、家屋敷課税の結論を決めるのは次の3つだけ。
  1. 賦課期日に、本人の住所（住民登録）がどの課税団体にあるか（家族の家と同じ課税団体なら家屋敷課税は起きない）。
  2. 家族が住む家が本人の家屋敷に当たるという判断（3団体の書き方では当たる）。
  3. その課税団体の運用の型（型 B では、同じ市町村に住む配偶者が住所地として課税されていると課さない）。
  さらに、本人の前年の合計所得金額がその課税団体の条例の額以下なら課さない（H1 ⑤）。単身赴任者は通常この額を超えるので、実際に効くのは 1〜3（推測）。
- 帰結：判定コアは、型が注入されていない課税団体で配偶者が課税されている場合、「未確定（運用の型が要る）」と返す（［実測］§5.2 F4 IY2 の形）。
  配偶者が非課税（所得が少ない）場合は、型によらず「課す」と断定できる（IY3）。
- 帰結：家屋敷課税の額は、標準税率なら 4,000円（市町村民税 3,000円＋道府県民税 1,000円）で、所得割・森林環境税はかからない。家族全体の損得（利用アプリの責務：D19）に入る金額は小さいが、
  「未確定」のまま放置すると申告の計画（D21 R2）に穴が残るので、未確定の理由（型・判断）を必ず出す。
- 検証の方法：自治体の家屋敷課税の案内を 10 団体以上（政令市・中核市・一般の市町村を混ぜる）集め、配偶者の課税の条件の有無、子の一人暮らしの住宅の扱い、区をまたぐ場合の扱いを表にする。
  型 A・B のどちらにも入らない書き方があれば、H2-3 の型の語彙を見直す。

## I3 指定都市・特別区の中の移動でも家屋敷課税が起きうるので、課税団体の粒度は「区」まで要る（H1 から）

- 推測：第737条で指定都市の区・総合区は一の市とみなされるので、同じ指定都市の中で、住所のある区と別の区に家族の家があれば、その区で家屋敷課税が起きうる（熊本市の案内もそう書く：H1 の根拠）。
  事実台帳の住所と住宅の所在は、指定都市では区まで、東京都は特別区まで持つ必要がある。
- 検証の方法：指定都市（熊本市以外に 2 つ以上）の家屋敷課税の案内で、「お住まいの区以外の区」の記載があるかを確かめる。

## I4 住宅借入金等特別税額控除は、所得税の層の値 4 つと外部の値 1 つで決まり、令和8年度分の境目は「基礎控除 − 48万円」で動く（H3 から）

- 推測：
  1. 住民税の控除額は、①（外部）、②・課税総所得金額等・基礎控除の額（所得税の層）、居住年・取得の区分（事実）だけで決まる。注入も判断も要らない（指定都市かどうかは住所の事実から）。
     既存の推測 I9 をこの調査の条文で裏づけた形になる。
  2. 令和8年度分から、控除限度額に「基礎控除の額 − 48万円」が足される（居住年 平成28年〜令和7年）。所得税の基礎控除は合計所得金額の段階で変わるので、
     控除限度額が効いている人では、合計所得金額の段階の境目で住民税の控除額が跳ぶ（既存の推測 I5 と同じ形）。D19 の「境目の説明」に、この境目を入れる。
  3. 居住年 平成28年〜令和3年で加算が結論を変える人（控除限度額が効き、上限に届かない人：［実測］§5.2 F1 HX1・HX4）には、H3-2 の提案どおり印を付ける。
     この条件に当たるのは、控除限度の基（課税総所得金額等＋加算）が小さく（3% が 58,500円に届かない＝195万円未満。2% と 39,000円でも同じ境目。H3-1 の式から）、所得税で控除しきれない額が大きい人。
  4. 控除しきれない額は消える（H3-3）。家族の中で誰が住宅借入金を負うか（持分・連帯債務）は所得税の側の事実で、住民税の側では人ごとに独立に計算すればよい。
- 検証の方法：
  - 令和8年度分の住民税の税額決定通知書の計算例、又は市町村の「令和8年度から住宅ローン控除の控除限度額の計算が変わります」といった案内を、居住年 平成28年〜令和3年の例を含めて集め、
    読み A（加算あり）で計算した値と一致するかを見る。一致すれば H3-2 の推奨（読み A）を裏づける。読み B の値なら H3-2 を見直す。
  - 令和4年法律第1号附則第10条第3項と令和8年改正の関係について、総務省の「地方税法等の一部を改正する法律の解説」や改正の Q&A があれば読む（e-Gov の API では一部改正法の本文が取れないので、
    総務省の PDF などで確かめる）。

## I5 配当割額等の控除は「還付になりうる最後の控除」として独立の出力にし、所得割を負にしない（H4 から）

- 推測：
  1. 判定コアの住民税の結果は、「所得割（控除後、0 以上）」「均等割」「森林環境税」と別に、「控除不足額（市町村民税分・道府県民税分）」を出す。控除不足額は同じ年度分の住民税・森林環境税に先に充てられるので、
     利用アプリが「納める額」を出すときは、所得割＋均等割＋森林環境税 − 控除不足額（0 未満なら残りが未納への充当・還付）になる。この引き算と未納への充当は利用アプリの責務（コアは未納を知らない）。
  2. 税額控除の順序は、配当割額等の控除を最後に固定すれば、ほかの控除の間の順序を気にしなくてよい（H4-3、既存の仮説 H8）。ただし申告特例控除は第314条の9 の基に入らず、
     両者の間の順は決まっていない（H4-3、仮説の未決 4）。申告特例控除がある人では、控除不足額の求め方が決まるまで、下の性質のテストの対象から外すか、両方の順で評価して分かれれば「未確定」とする。性質のテスト（D15④）：
     「配当割額等の控除を除く控除の順序を入れ替えても、所得割（控除後）と控除不足額が変わらない」「控除不足額 ≧ 0」「所得割（控除後）≧ 0」「控除不足額 > 0 なら所得割（控除後）＝ 0」。
  3. 住宅借入金等特別税額控除と配当割額等の控除が両方ある人では、住宅の控除で所得割が 0 になると配当割額等がまるごと控除不足額になる（［実測］§5.2 F2 HD1）。
     申告の計画（D21 R2）で「配当を確定申告書に記載するか」を比べるとき、この相互作用が効く。比較そのものは利用アプリの責務（D19）だが、コアは控除不足額を正しく出す必要がある。
- 検証の方法：
  - 上の性質のテストを、乱数で作った入力（所得割・各控除・配当割額）で 1 万件以上回す。
  - 確定申告書に配当割額控除額を記載した例で、市町村の税額決定通知書（又は自治体の計算例）に控除不足額の充当・還付がどう書かれるかを集め、出力の形が合うかを見る。

## I6 令和9年度分の配当の変更（第23条第1項第15号ロ）は、入力の「配当割が課されたか」で吸収でき、ロ かどうかの判定は第313条第12項のためだけに要る（H4-4 から）

- 推測：
  1. 配当ごとに支払通知書の配当割額（0 か正）を事実として受け取れば、令和8年度分・令和9年度分で第314条の9 の計算を分ける必要はない。違いは「ロ の配当に配当割が課されるようになった」ことで、それは入力の値に現れる。
  2. ロ に当たるかの事実（同族会社と合わせて 3% 以上）は、第313条第12項の除外（申告不要）ができないことの判定にだけ使う。所得税の側でも ロ は措法第8条の4第1項の上場株式等の配当等から除かれる配当なので（H4-4 の前提）、
     所得税の層と同じ事実を共有できる。所得税の側の申告不要（措法第8条の5）が ロ に使えるかは、この調査では確かめていない。
  3. 第23条第1項第15号ロ は既存の株の仮説で「当面は対象外」とされていたが、D21 R3 で対象に入った。上の 1・2 の形なら、対象外にしていた理由（範囲が未確認）は、施行令第7条の3 の文言を得たことで解けた。
     残るのは、ロ の配当を確定申告書に記載しなかった場合（住民税の申告書だけ）の扱いで、そのときは「未確定」を返す（H4-4-3）。
- 検証の方法：
  - 2027年に公表される令和9年度分の住民税の案内（総務省・自治体）で、ロ の配当（同族会社との合計で 3% 以上）の配当割と控除の説明を探す。
  - 令和8年分の確定申告の手引き（国税庁、2027年1月ごろ）の第二表「配当割額控除額」の説明に、ロ の配当が含まれるかを確かめる。

## I7 「申告の要否」の出力に、住宅借入金等特別税額控除は理由として入らず、配当割額等の控除は確定申告書の第二表の欄として入る（H3-4・H4-1 から）

- 推測：
  1. 住民税の申告の要否（第317条の2）の判定で、住宅借入金等特別税額控除を理由に「申告が要る」と出すことはない。所得税で適用を受けていれば、市町村が給与支払報告書・確定申告書から計算する。
  2. 配当割額等の控除は、所得税の確定申告書に配当割額控除額・株式等譲渡所得割額控除額を付記して初めて受けられる（施行規則第1条の12の2第2項）。様式の欄の対応表（D19・T5-2）に、
     第二表の「配当割額控除額」「株式等譲渡所得割額控除額」の欄を、第314条の9 の入力と対応づけて入れる必要がある（欄の番号は既存の出力の調査が持つ値を使い、この調査では確かめていない）。
  3. 家屋敷課税については、第317条の2第8項で市町村が条例により申告させることができる（熊本市は単身赴任者の配偶者に申告を求める）。これは市町村ごとの手続で、判定コアは「市町村から申告を求められることがある」という説明だけを出す。
- 検証の方法：住民税の申告の要否の既存の実装案（`docs/hypotheses/20261109_impl-prep_juminzei-judgment-model.md` 系）に、上の 1〜3 を足した場面のテストを書き、既存の場面の結果が変わらないことを確かめる。
