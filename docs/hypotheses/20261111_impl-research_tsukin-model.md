## HT1 所得税の「給与等の収入金額」は、総支給額から非課税の通勤手当を除いた額にする

- 所法9① は非課税の通勤手当に「所得税を課さない」とし、その範囲を施行令第20条の2 の「金額に相当する部分」とする (F)［PS-TK］§1.1・§2.1。非課税の部分を収入金額から除くと書いた条文はなく、除くのは「所得税を課さない」の読みである (I)［PS-TK］§5。
- 国税庁は、源泉徴収票の「支払金額」から非課税の通勤手当を除き、年末調整では新たに非課税となった額を「本年の給与総額から一括して差し引」くとする (F)［PS-TK］§5。反対の一次情報は見つからない［M-TKV］。HANDOFF D22 S1（公式の説明があり反対の一次情報がなければその読み）により、この読みで計算し、根拠に「法令の読み（所法9①柱書・五、所令20の2）＋国税庁の説明（R7リーフ §3・§4）」を付ける (I)。
- 計算（月ごとの規則。(F) は根拠の箇所）：
  1. 単位は「受給者 × 支払者 × 月」。非課税の額は、その月中に支給する通勤手当の合計額のうち、限度額に達するまでの金額 (F)［PS-TK］§4.4（質疑03-21）。日割りにしない (F)。
  2. 限度額は施行令第20条の2 の号ごとの金額（HT2 の版）。交通機関・有料道路（第1号）と定期乗車券（R8 第4号）は「最も経済的かつ合理的」な運賃等の額で上限 150,000円、交通用具（第2号）は片道の距離の区分の額（2km 未満は 0）、駐車場等（R8 第3号・第6号）は料金相当額を上限 5,000円で足す、併用（R8 第5号・第6号）は合計で上限 150,000円 (F)［PS-TK］§2.2。
  3. 総支給額（`gross`）− Σ非課税の額 を、その年分の給与等の収入金額にする。年分の割当ては給与の収入すべき時期の規則（`docs/hypotheses/20261111_impl-research_kyuyo-jiki-model.md` HJ1）に従う (I)。
- この計算の参照の関数は［M-TK］§3 C4 で国税庁の設例 6 件と一致した (F)。

## HT2 限度額の表は「受けるべき日」で選ぶ3つの版のパラメータにする（年分では選ばない）

- 適用の区切りは改正政令の附則の「受けるべき通勤手当」(F)［PS-TK］§2.3：

| 版 | 適用（受けるべき日） | 第2号の表 | 駐車場等 | 出典 |
|---|---|---|---|---|
| 改正前 | 〜2025-03-31 | 4,200／7,100／12,900／18,700／24,400／28,000／31,600（55km 以上） | なし | 所令 2025-11-19 版 |
| R7 | 2025-04-01〜2026-03-31 | 4,200／7,300／13,500／19,700／25,900／32,300／38,700（55km 以上） | なし | 令和7年政令第380号（施行 2025-11-20）附則② |
| R8 | 2026-04-01〜 | R7 と同じ〜55km 未満、38,700（55〜65）／45,700／52,700／59,600／66,400（95km 以上） | 料金相当額（上限 5,000円） | 令和8年政令第93号（施行 2026-04-01）附則第4条 |

- 「受けるべき日」は、支給日の定めがあればその支給日、なければ支給を受けた日、遡及改訂の差額は支給日（定めがなければ改訂の効力の日）とし、差額の追給は元の通勤手当の受けるべき日の版にする (F：国税庁の説明)［PS-TK］§4.3、［M-TK］§3 C5。この書き方は所基通36−9 と同じ形 (F)［PS-KJ］§2.1。
- したがって令和7年分は1〜3月に受けるべき分が改正前、4〜12月分が R7、令和8年分は1〜3月分が R7、4〜12月分が R8 になる (I)。パラメータの日付のキーは適用開始日（SCOPE T2）で、キーの意味が「受けるべき日」であることをメタデータに書く (I)。
- 令和7年政令の附則③（施行日前に受けた分の源泉徴収は従前の例）は源泉徴収の規定で、年末調整・確定申告では改正後の限度額で精算する (F：国税庁の説明)［PS-TK］§2.3・§5。判定コアは確定申告の値を出すので R7 の表を使い、源泉徴収税額は記録された事実をそのまま使う (I)。
- 2028-01-01 の予定版まで第20条の2 の本文は R8 と同じ (F)［M-TK］§2.2。

## HT3 中間表現が持つべき事実

既存の `salary_payment.amounts.commuting_allowance`（総支給額の内数）は残す。健保・共済の年間収入と所得税で扱いが違うので、中間表現の作成で通勤手当を差し引かない (I)（HT4）。足すもの (I)：

| 事実 | 置き場所の案 | 理由（根拠） |
|---|---|---|
| 支給日（受けるべき日）`due_on`、支給日の定めがないことの明示 | `salary_payment` の属性（給与の時期と共通。HJ2） | 版の選択と年分 (F)［PS-TK］§4.3、［PS-KJ］§2.1 |
| 差額の追給か、その元の支給日 | `salary_payment` の属性 | 差額の追給は元の日の版 (F)［PS-TK］§2.3・§4.3 |
| 通勤手当が対象とする期間（1か月を超える定期代などを一度に払う場合） | `salary_payment` の属性 | 限度額が「一月当たり」(F)。当て方は不明 (U)［PS-TK］§7-1 |
| 通勤手当が給与明細書などで区分して表示されているか | `salary_payment` の属性（真偽） | 「通常の給与に加算して」「区分識別」(F)［PS-TK］§4.4（質疑03-22） |
| 現物で渡された通勤用定期乗車券の価額 | `salary_payment.amounts` に新しい欄 | 第4号（R8）・第3号（改正前・R7）の対象 (F)［PS-TK］§2.2 |
| 通勤の状況：交通手段（交通機関・有料道路／交通用具／併用）、交通用具の片道の距離（km、通勤経路に沿った長さ）、期間 | 新しい事実の記録（人 × 支払者 × 期間） | 号の区分と距離の区分 (F)［PS-TK］§2.2、§4.1（TA2585） |
| 交通機関・有料道路の1か月当たりの運賃等の額 | 同上の金額。ただし「最も経済的かつ合理的」は判断（D4）とする | 判定の基準は新幹線・グリーン料金のほか見つからない (U)［PS-TK］§7-2 |
| 駐車場等：利用の有無、所在（勤務場所の周辺／駅・停留所その他の施設の周辺／自宅付近／その他）、料金の単位（月・年・都度・その他）と額と期間、都度なら月の通勤の利用回数、料金を負担するのは本人か会社か | 同上 | 施行規則第2条の2 (F)［PS-TK］§3、Q&A Q2-1〜Q4-2 (F)［PS-TK］§4.4 |
| 「常例とする」、障害のため 2km 未満で自動車を使う特別の事情 | 判断（D4） | 質疑03-18 は「差し支えありません」という取扱い (F)［PS-TK］§4.4 |

- 代わりの経路：支払者が付けた区分（給与明細の「非課税通勤費」、源泉徴収票の「支払金額」）を記載の事実として受け取り、通勤の状況の事実がないときに使う（根拠「支払者の記載」）。HANDOFF §3 は「源泉徴収票の支払金額」を事実と言える段階の値に挙げる。両方あって食い違えば、両方の値と食い違いを返す (I)。どちらを優先するかはユーザーの判断事項。

## HT4 健保・共済の年間収入とは別の概念として扱う

- 所得税の給与等の収入金額は非課税の通勤手当を除く（HT1）。健保の労働契約による判定の「賃金」は諸手当を含む (F)［PS-K］§1.2。従来の判定方法では、通勤手当を含めることを明記した厚労省・日本年金機構・協会けんぽの一次情報がない (F：見つからなかった)［PS-K］§7、［PS-TK］§6。共済組合は組合で「含む」「除く」が分かれる (F)［PS-KY］§6.2。
- よって `所得税.給与等の収入金額` と `健保.年間収入` は別の ID のままにし、どちらからも他方を導かない。健保の側で通勤手当を含めるかは保険者データ（注入）とし、なければ「含む」「含まない」の両方で評価する（既存の扱いと同じ）(I)。
- 中間表現は、通勤手当の額を総支給額の内数として持ち、非課税の限度を差し引いた値を持たない（差し引くのは判定コアの所得税の系統だけ）(I)。

## HT5 事実が足りないときは「ありうる場合の全部」で評価する（HANDOFF D21 R6）

- 通勤手当があるのに通勤の状況も支払者の区分もないとき、非課税の額は月ごとに 0 から min(通勤手当, その月の版の取りうる最大の限度額) の範囲にある (I)。最大の限度額は、交通機関なら 150,000円、交通用具だけなら R8 で 66,400＋5,000＝71,400円、R7 で 38,700円、改正前で 31,600円 (F)［PS-TK］§2.2。
- 範囲の両端で判定（扶養親族の所得要件など）が分かれれば「未確定」とし、「通勤の状況」か「支払者の区分」を入力すれば決まると返す。金額は幅で返す (I)。
- 現在の判定コアの「対象外（未対応）」をこの扱いに置き換えられる (I)。

## HT6 端数

- 駐車場等の料金相当額の計算（都度の料金×回数、年額÷12 など）に端数の定めはない (F)［PS-TK］§3。国税庁の Q&A の例は「1円未満端数切上げ」(F)［PS-TK］§4.4、［M-TK］§3 C6。HANDOFF D21 R5（法令＞通達＞手引き＞国税庁の説明）により、切上げを使い根拠に「国税庁の説明（R8QA Q3-3 例2）」の印を付ける。途中の値は有理数で持つ (I)。
- 限度額と支給額の比較は有理数のまま行い、1円未満が収入金額に残るのは「支給額＞限度額」で限度額に端数があるときだけ (I)。

## HT7 住民税

- 地方税法第313条第2項は総所得金額を所得税法の計算の「例により算定」する (F)［PS-KYS］§3.1。非課税の通勤手当も同じく除かれると推論するが、総務省・地方公共団体の一次情報では確かめていない (U)［PS-TK］§7-6。住民税の系統で使うときは根拠に「法令の読み（地法313②）」を付ける (I)。
