## H1 給与所得の金額は、年分ごとに次の3つの規則のどれか1つで決まる

- 内容：
  1. 給与等の収入金額（その年中の合計）が 660万円以上：所得税法第28条第2項・第3項の式（その年分に適用される版）。
  2. 令和8年分・令和9年分で、収入が 69万1千円以上 220万円未満：措置法第29条の4第2項の表（5区分）。別表第五は使わない。
  3. それ以外（660万円未満）：その年分に適用される版の別表第五（第28条第4項）。
- 根拠：
  - 第28条第4項「六百六十万円未満である場合には…前二項の規定にかかわらず…別表第五…」[PS §1.1]。措法第29条の4第2項「前項及び所得税法第二十八条第二項から第四項までの規定にかかわらず」[PS §2.1]。国税庁 No.1410（注3）「220万円未満である場合の給与所得の金額は、上記（注2）の表の金額」[PS §4.1]。
  - この規則で作った関数の値は、国税庁の令和7年分・令和8年分の表と 152 点すべて一致した [M1 §4]。所得要件の境目の給与収入は、国税庁資料の 35 項目すべてと一致した [M2 §2]。
- 「両者が食い違う範囲」への答え：令和8年分の別表第五（e-Gov の所得税法の表）と措置法第29条の4第2項は、[691,000, 2,200,000) のすべての収入で違う（別表第五のほうが 600〜50,999円大きい。措置法のほうが大きい点はない）[M1 §5]。条文上は措置法が優先する（上の根拠）。0〜690,999円は両方 0、220万円以上は別表第五だけが使われる [M1 §5]。
- 年分と版の対応：令和7年分＝asof 2025-12-31 の別表第五（令和7年法律第13号附則第3条で第28条は令和7年分以後）、令和8年分・令和9年分＝asof 2026-12-01 の別表第五（令和8年法律第12号附則第3条）[PS §1.4]。asof 2026-11-09（現行）の別表第五は令和7年分の表と同一 [M1 §3.2]。

## H2 別表第五は「式」ではなく「表のデータ」としてパラメータに持つのが安全

- 内容：別表第五の金額の区分は、第28条第3項の式を区分の下限で評価した値と一致するが、表に固有の例外があるので、式から再生成せず、e-Gov の表を機械抽出したデータ（区分の下限・上限・値または式）を版ごとに持つ。
- 根拠：
  - 金額の区分は全版で式と一致 [M1 §3.1]。
  - 例外：①「◯円未満 → 0」の区分では、式なら 1〜999円になる収入でも 0 [M1 §3.1]。②令和8年分の [2,026,000, 2,028,000) の 2,000円の区分 [M1 §3]。式の区分（収入−69万円）の終わり 2,026,000円は、第28条第3項第1号の「8万円＋収入×30%」が 69万円と等しくなる収入（約 2,033,333円。[IT] §2 の式から）と一致しない。③令和6年分の 1,000円・2,000円の区分 [M1 §3]。
  - 機械抽出は国税庁の表と一致し [M1 §4]、区分の隙間・重なりは 0 [M1 §3]。

## H3 旧の別表第五を使う経過措置（最後の支払が12月1日前の給与等）は年末調整にだけ効き、確定申告の給与所得は新しい規定で計算する

- 内容：令和7年法律第13号附則第9条第2項・令和8年法律第12号附則第13条第2項は、年末調整（第190条）の計算にだけ旧の別表第五を残す。確定申告の給与所得（第28条第4項）は、その年分に適用される新しい別表第五（令和8・9年分は措置法第29条の4第2項も）で計算する。
- 根拠：
  - 両附則の見出しは「給与所得に係る源泉徴収に関する経過措置」、第28条の適用年分は別の附則（附則第3条「令和八年分以後の所得税について適用」）[PS §1.4]。
  - 措置法側も、附則第36条第1項が支払日で制限するのは年末調整の第4項だけ [PS §2.2]。
  - 国税庁 Q&A：最後の給与が11月30日以前の人の年末調整には「改正後の控除等」（改正後の表を含む）が適用されず、改正後の控除等の適用を受けるには確定申告が必要 [PS §4.2 Q1−3・Q7−1、§4.3 1−12]。
- 確かさ：条文の文言だけでは決まらない [PS §1.4・§6]。国税庁の説明（二次的な一次情報）に依る。
- 影響の大きさ：令和8年分では、確定申告で旧表と新表が違うのは措置法の範囲外の [651,000, 691,000) だけ（旧表は収入−650,000、新表は 0）[M1 §3.2・§5]。年末調整の値（源泉徴収票）と確定申告の値は [651,000, 2,200,000) で最大 90,999円（給与収入 740,999円）違いうる [M2 §4]。

## H4 住民税の給与所得は「前年分の所得税の計算の例」で、措置法第29条の4 も含む（令和9年度分・令和10年度分に 74万円）

- 内容：個人住民税（所得割）の給与所得は、地方税法第313条第2項により、前年分の所得税の給与所得と同じ規則（H1）で計算する。措置法第29条の4（「令和八年又は令和九年において」）は「所得税に関する法令の規定」に当たるので、令和9年度分（令和8年の所得）と令和10年度分（令和9年の所得）に及ぶ。令和8年度分（令和7年の所得）は令和7年分の別表第五（最低 65万円）による。
- 根拠：
  - 第313条第2項「この法律又はこれに基づく政令で特別の定めをする場合を除くほか、それぞれ所得税法その他の所得税に関する法令の規定による…計算の例により算定する」。除外は所得税法第60条の2〜第60条の4 だけ [PS §3.1]。
  - 地方税法・地方税法施行令の全文に、措置法第29条の4 を住民税で適用しない・読み替える規定はない（asof 2025-12-31〜2028-01-01）[M1 §6]。
  - 総務省（案）：「給与所得控除の最低保障額を74万円（現行:65万円）に引き上げる。※令和９年度分の個人住民税から適用（…５万円は２年間の時限措置）」、単身の非課税ライン 110万円→119万円 [PS §5.1]。仙台市・大阪府・熊本市も令和9年度・令和10年度に 74万円とし、仙台市は「租税特別措置法第29条の4 適用後」と明記 [PS §5.2]。
  - この扱いで計算した住民税の境目は、仙台市の扶養・勤労学生・非課税早見表の値（136万円の行を除く）と一致し、総務省（案）の 119万円とも一致した [M2 §3]。
- 確かさ：地方税法に直接の明文はない [PS §6]。成立後の総務省の通知・解説は未取得。

## H5 住民税の所得要件の換算値（年度 → 前年の給与収入）

- 内容（H4 が正しい場合）：令和8年度分 扶養 58万→給与収入 1,230,000円、勤労学生 85万→1,500,000円、特定親族 満額45万の上限 95万→1,600,000円、上限 123万→1,880,000円、未成年者等の非課税 135万→2,043,999円。令和9年度分 扶養 62万→1,360,000円、勤労学生 89万→1,630,000円、特定親族 95万→1,690,000円・123万→1,970,000円、非課税 135万→2,090,000円。令和10年度分は令和9年分の条文が今のままなら令和9年度分と同じ。
- 根拠：[M2 §3]、扶養の所得要件と年度の対応 [PS §3.3]（地方税法第292条第1項第9号と令和7年法律第7号附則第8条第1項・令和8年法律第2号附則第11条第2項）、特定親族の区分 [PS §3.3]（第314条の2第1項第12号）、非課税 [PS §3.3]（第295条第1項第2号）。

## H6 660万円以上の給与所得の1円未満は切り捨てる

- 内容：第28条第2項・第3項の式で1円未満が出たら、給与所得を切り捨てる（＝控除額を切り上げる）。
- 根拠：別表第五の備考（660万円以上は切り捨て）[PS §1.2]。国税庁の「665万5,556円以下」（基礎控除 489万円の境目）は切り捨てで一致し、切り捨てないと 6,655,555円になる [M2 §2・§5]。第28条自体には端数の定めがない [PS §1.1・§6]。
- 子供の給与には通常関係しない（660万円以上）。

## H7 別表第五・措置法の表は、全支払者の合計の収入金額に1回だけ当てる

- 内容：給与の支払者が複数（バイト先が2か所など）でも、給与所得は「その年中の給与等の収入金額」の合計に対して1回だけ求める。支払者ごとに求めて足さない。
- 根拠：第28条第4項・措法第29条の4第2項の「その年中の給与等の収入金額」[PS §1.1・§2.1]、国税庁 No.1410（注4）[PS §4.1]。
- 刻みがあるので、支払者ごとに求めて足すと値が変わる（例：令和7年分で 4,000円刻みの区分に入る合計）[M1 §3]。それより影響が大きいのは、最低保障額（令和7年分 65万円、別表第五の「651,000円未満 0」と「収入−650,000円」の区分）が支払者ごとに重ねて引かれること（例：令和7年分 100万円＋100.2万円 → 合計に当てると 1,320,000円、支払者ごとに当てて足すと 702,000円）[MV §5]。（2026-11-09 の独立検証で追記）

## H8 R1 の「千円単位のずれ」の懸念は、子供の所得要件については生じない

- 内容：扶養親族・勤労学生・特定親族の境目（令和7年分・令和8年分）は、別表第五の式の区分（令和7年分 [651,000, 1,900,000)）か措置法第29条の4第2項の区分に入るので、R1 の式だけの計算値は1円単位で正しい。ずれが出るのは収入 190万円以上（令和7年分）・220万円以上（令和8年分）の境目（令和7年分：配偶者特別控除 133万円、基礎控除 132万円・336万円、令和8年度住民税の非課税 135万円など。令和8年分：基礎控除 336万円など。令和8年分の配偶者特別控除 133万円・基礎控除 132万円と令和9年度住民税の非課税 135万円は措置法第29条の4第2項の区分に入り、ずれは 0 [M2 §2・§3]）。（例の年分の書き分けは 2026-11-09 の独立検証で追記）
- 根拠：[M2 §2・§3]、R1 の値 [R1M §4]。

## H9 仙台市の非課税早見表の「136万円以下（2,059,000円）」は誤記の可能性がある

- 内容：令和8年度は 2,059,999円、令和9年度は 2,100,000円が条文からの値。
- 根拠：同じ表の他の行は本調査の値と一致し、この行だけが両年度で同じ 2,059,000円になっている [M2 §3]、[PS §5.2]。
- 実装には影響しない（地方公共団体の説明ページの値はテストの期待値に使わない）。

## H10 中間表現に必要な給与の事実

- 内容：給与所得の計算に必要な事実は「年分ごとの給与等の支払（支払者、支払日、支払金額）」。判定コアが年分ごとに合計し、H1 の規則を当てる。源泉徴収票の「給与所得控除後の金額」は年末調整の結果（旧表の場合がある）なので、給与所得の入力には使わず、照合用の事実として持つ。
- 根拠：H3（年末調整と確定申告で値が違いうる）[M2 §4]、H7（合計に当てる）。最後の支払日は旧表の経過措置の判定に要る [PS §1.4・§2.2]。
