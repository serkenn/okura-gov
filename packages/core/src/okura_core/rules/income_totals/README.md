# rules/income_totals：所得の合計・損益通算・繰越・繰戻し

登録済み。約束の16件を全部実装した（所得金額調整控除は第1項・第2項）。足した概念は §1 の表の後。

このディレクトリだけで規則を足す（packages/core/README.md §10「規則モジュールの足し方」）。共有のファイルは触らない。

前年分の申告で前々年分に繰り戻した額）と還付請求額（2026-11-11）。

  `所得税_所得金額調整控除の第1項を当てたとした回収不能額等の前の総所得金額と退職所得金額の合計額`）：回収不能額等が生じた時の直前に確定している総所得金額＋退職所得金額
  （所基通64−3：損益通算の後、純損失・雑損失の繰越控除の後。docs/public-sources/20261112_impl-research4_shotoku-laws-and-nta.md §1.1・§1.3）。給与所得は kyuyo の
  `所得税_所得税法第64条第1項を当てる前の給与所得の金額`、公的年金等に係る雑所得は income_kinds の `所得税_回収不能額等の前の公的年金等に係る雑所得の金額` を使い、
  所得金額調整控除もその額で計算し直す（給与所得の金額・所得金額調整控除の変数は kyuyo の段の出力に依存するので引かない）。kyuyo の段 `未払の給与の回収不能` が読む。
  第1項の「有するか」は扶養の判定の段の後にしか決まらないので偽・真の2つを出す（kyuyo が、どちらでも同じ結論かを確かめる：kyuyo の KY-10）。回収不能額等のない人だけの評価では0。
- `所得税.回収不能額等の前の公的年金等に係る雑所得以外の合計所得金額`（所得の種類ごとの所得の層）：`所得税.公的年金等に係る雑所得以外の合計所得金額` と同じ式で、給与所得を前の額にしたもの。

## 2. 上流と下流

上流：income_kinds（配当・不動産・事業・雑・業務雑・その他雑・公的年金雑・一時・退職・上場配当・上場譲渡・青色の承認）、kyuyo（給与所得の金額・給与等の収入金額）、
personal_deductions（特別障害者に当たるか・所得金額調整控除の対象の親族等を有するか：第1項）。
損失は負の値で来る前提（不動産・事業・上場譲渡）。配当・雑・一時の負の値は0として合計する（所法69①の対象外）。
下流：personal_deductions（合計所得金額・総所得金額等・判定用の合計所得金額）、other_deductions（総所得金額等）、tax（総所得金額・申告分離課税の値・退職所得金額）、
kyuyo（回収不能額等の前の総所得金額と退職所得金額の合計額：段 `未払の給与の回収不能`）、income_kinds（回収不能額等の前の公的年金等に係る雑所得以外の合計所得金額）。
上流に足したもの（2026-11-12）：kyuyo の `所得税_所得税法第64条第1項を当てる前の給与所得の金額`・`所得税_回収することができないこととなった給与等の金額`、income_kinds の `所得税_回収不能額等の前の公的年金等に係る雑所得の金額`。

## 3. 提出した申告書の記載の読み方（中間表現の語彙の意味はこの読み。inputs.py の先頭にも書いた）

`filed_document` のうち document_type が `final_return`・`loss_return`・`quasi_final_return` のものを申告書として読む。年分は `attributes.tax_year`。同じ年分に2件以上は対象外。

| item | 読み |
|---|---|
| `net_loss_total` | その年分に生じた純損失の金額 |
| `net_loss_carryback` | その年分の純損失のうち繰り戻した額 |
| `net_loss_carryforward_used`（`origin_tax_year` 必須） | その年分の繰越控除で使った、生じた年分 origin の純損失 |
| `casualty_loss_carryforward`・`listed_stock_loss_carryforward`（`origin_tax_year` 必須） | origin の年に生じ、この申告書の年分の後へ繰り越す額（前年の申告書の値を読む） |
| `taxable_income_total`・`income_tax_after_credits` | 前年分（前々年分への繰戻しでは前々年分）の課税総所得金額・税額控除後の所得税の額（繰戻し） |

対象外にする場合：連続して申告したか記録から分からない（途中の年分の申告書がない）、純損失の年分が青色か決まらない、生じた年分の欄がない、3年を超える繰越の記載（特定非常災害は後の段：D22 S12）、記載の合計が合わない。

青色の判定（`blue_evidence`）：承認の通知（`blue_return_procedure` の `approval_notice`、`first_tax_year` ≦ その年）があり、却下・取消し・取りやめ・廃止の記録がないときだけ青色とする（中間表現の申告書に青色かの欄がないための安全側の代わり。みなし承認の年分は対象外になる）。
その年分より後の年の事業の全部の譲渡・廃止の記録（business_transfer_or_closure）は、その年分の青色に関係しないので見ない（2026-11-11。所法140⑤ の事実そのもの）。

## 4. 実装の注意・未対応

- **所得金額調整控除**：第1項（給与等の収入金額850万円超で、特別障害者か、年齢23歳未満の扶養親族・特別障害者である同一生計配偶者又は扶養親族を有する者）＋第2項。
  第1項の「有する」は personal_deductions の段（所得金額調整控除の対象の親族等）が、判定用の合計所得金額（第1項の前）で親族の組ごとに決める（同じ子を夫婦の双方が有する：措通41の3の11−1）。
  第1項の1円未満は TA No.1411 の切上げ（国税庁の説明：`calc.ADJUSTMENT_1_CEIL`。根拠の種類で分かる）。第2項は第1項の控除の後の給与所得から控除する。850万円超の人を対象外にする検出は外した。
- 損益通算：不動産・事業の損失 → 経常 → 一時 → 退職（所令198）。総合譲渡・山林は範囲外。不動産所得の損失のうち生じなかったものとみなす部分（措法41の4・所法69②）は、
  income_kinds の `所得税_不動産所得の金額` が除いた値で来る（docs/measurements/20261111_impl-research_fudosan-existing-check.md）。不動産所得が負の人を対象外にする検出は外した。
- 一時所得の2分の1の1円未満は、令和7年分は手引きの切捨て（第一表⑪の計算欄の注記。根拠の種類は手引き・様式の注記：`calc.ICHIJI_HALF_TEBIKI_R7`）。
  令和8年分は手引きが未公表で根拠のない端数（RoundingSlotSpec。金額だけが違えば幅）。候補は令和8年分で端数が出る人がいるときだけ式で引く。
- 繰越控除：純損失（全部）→ 雑損失。純損失は総所得金額 → 退職所得金額（所令201。上場分には及ばない：所法70 は措法8の4③三・37の10⑥五の読替えの対象外）。
  雑損失は総所得金額 → 上場株式等に係る配当所得等 → 上場株式等に係る譲渡所得等 → 退職所得金額（所令204①二を措令4の2⑨・25の11の2⑳ で読み替えた順。上場分は損益通算・繰越控除の後：⑰⑱）
  （`calc.split_casualty`、docs/public-sources/20261111_impl-research_joto-junjo-laws.md §2）。一般株式等・山林は範囲外。雑損失の順序の検出は外した。
- 上場株式等：損益通算（第1項）と繰越控除（第5項）は選択。未入力なら真偽の両方で評価（分かれ目は上場株式等の記録がある人だけ）。
- 繰戻し：繰り戻す額が前年分の課税総所得金額を超える場合は、残りを前年分の課税山林所得金額、次に課税退職所得金額から控除する（所令271①三。2026-11-11 に実装。
  記載 `taxable_retirement_income`・`taxable_timber_income`）。各号の所得税の額は、課税総所得金額と課税退職所得金額のそれぞれに所法89① を当てた額の合計を百円未満切捨て
  （様式 ⑬・㉑）。課税山林所得金額が正なら範囲外、2つの記載がなければ対象外（§6 IT-11・IT-12）。前年に平均課税がある場合（所令271①六）は後の段。繰り戻す額が未入力のときの候補は「繰り戻さない」「全額」の2つ（一部の額は候補にしない）。
  計画.申告の方法と時期は income_kinds と同じ1か所（kind・key＝人の ID・候補が同じ）。
- 前々年分への繰戻し（所法140⑤・141④、所令272。2026-11-11、§6 IT-13）：その年に事業の全部の譲渡・廃止（`blue_return_procedure` の `business_transfer_or_closure`）、
  事業の全部の相当期間の休止・重要部分の譲渡（`判断.事業の休止・重要部分の譲渡`。所令272① の「繰越控除を受けることが困難となる」までを含めた判断と読む）、又は死亡があった人の、
  前年の純損失の残り（前年分の申告書の net_loss_total − net_loss_carryback）を、`選択.損失申告と繰戻し` の `second_prior_year_carryback_amount` の額（残りが限度）だけ前々年分に繰り戻す
  （前年分・前々年分の青色申告書が要件）。還付請求額は前々年分の課税総所得金額、次に課税退職所得金額から控除した税額の差（`calc.second_prior_refund`。所令272②：前年分の申告で
  前々年分に繰り戻した額〔net_loss_carryback〕があれば、その額を控除した課税総所得金額等と、その還付額を控除した限度を使う。「所得税の額」を限度と読む法令の読み）。
  繰り戻した額は、その年分の繰り越された純損失の金額から除く（所法70① かっこ書。残りは繰越控除）。
  選択に額を書くことを、その年分の確定申告期限までの請求と読む（期限内の請求かの別の語彙がない）。未入力の扱い：事実か休止等の判断があって選択が未入力なら「繰り戻さない」「全額」、
  事実がなく選択に額があって判断が未入力なら判断の候補の全部で評価する（D21 R6・D22 S20）。事実・判断・選択のどれもない人は請求がないものとして0（繰戻しには還付の請求〔所法140⑤・141④〕が要るため。根拠に法令の読みの印：basis.SECOND_PRIOR_RULE。2026-11-12 統括の決定。入力すれば評価する）。
  税率の表は令和5年分〜令和8年分で同文なので前年分の繰戻しと同じパラメータ（令和5年分・令和6年分：docs/public-sources/20261112_impl-research4_shotoku-laws-and-nta.md §2。2026-11-12 に IT-15 を解いた）。
- 繰越の期間（3年）は build_inputs の定数（`inputs.CARRY_YEARS`。パラメータの木は build_inputs から引けない）。根拠は basis.py。
- 使う記録は filed_document のうち申告書（final_return・loss_return・quasi_final_return）だけ（`RecordKind`。扶養控除等申告書などは personal_deductions が使う）。
- 金額の合計が int32 を超えるときは式で OverflowError（判定コアの誤り）。

### 7.1 地方税法第313条第11項の前年の所得の窓口（2026-11-12 の3回目。tokutei.py。juminzei の JM-42。kyuyo の担当が足した）

前年分の所得税の納税義務がない人が住民税の申告書だけで受ける特定支出控除（地法313⑪・32⑪）の前年の所得を、「所得税の計算の例」（第313条第2項）で
所得税と同じ関数で計算し直す（docs/public-sources/20261112_impl-research8_tokutei-shishutsu-laws.md §6、仮説 impl-research8 H6・H10）。
所得税_特定支出の額の合計額が給与所得控除額の2分の1を超えるか（kyuyo）が偽の人は0（juminzei の段は読まない。行を0にするので一時所得の端数の候補も引かない）。
以前は juminzei の段が所得税の合計所得金額との差で計算し、回収不能額等のある人・公的年金等控除額の区分が変わりうる人を c-限界 の対象外にしていた。
