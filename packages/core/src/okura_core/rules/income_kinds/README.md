# rules/income_kinds：所得の種類

登録済み（rules/__init__.py）。所得の種類ごとの所得（配当・不動産・事業・雑・一時・退職・上場株式等）と、その内訳を作る。給与所得は kyuyo。

このディレクトリだけで規則を足す（packages/core/README.md §10「規則モジュールの足し方」）。共有のファイル
（evaluate.py・situation.py・country/__init__.py・concepts/structure.yaml など）は触らない。登録は rules/__init__.py の1行だけ。

## 1. このモジュールが作る概念（concepts.yaml）

約束の18件を全部実装（2026-11-11）。名前・単位（値の型）・期間（全部「年」）・層は約束で、変えるときは引くモジュールの担当と合わせる。表の正は concepts.yaml。

住民税への窓口（2026-11-12。`jumin.py`、juminzei JM-23）：`所得税.退職所得を除いた区分による公的年金等に係る雑所得の金額`（公的年金等控除額の区分の基を income_totals の `所得税.退職所得を除いた公的年金等に係る雑所得以外の合計所得金額` にした額。式・パラメータ・端数は公的年金等控除額と同じ）。

地方税法第313条第11項の前年の所得の窓口（2026-11-12 の3回目。`tokutei.py`、juminzei JM-42。kyuyo の担当が足した）：`所得税.特定支出控除を当てた場合の回収不能額等の前の公的年金等に係る雑所得の金額`・
`所得税.特定支出控除を当てた場合の公的年金等に係る雑所得の金額`・`所得税.特定支出控除を当てた場合の退職所得を除いた区分による公的年金等に係る雑所得の金額`
（公的年金等控除額の区分の基を income_totals の `所得税.特定支出控除を当てた場合の…公的年金等に係る雑所得以外の合計所得金額` にした額。式・パラメータ・端数は公的年金等控除額と同じ）。
後の2つは区分の基が中心の概念の層（回収不能額等の後の給与所得に依存する）なので、中心の概念の層に置いた。住民税の申告書だけで特定支出控除を受ける人の
公的年金等控除額の区分の変化（以前は juminzei の JM-42：c-限界）を計算する。

kyuyo への窓口（2026-11-12）：
- `所得税.退職手当等に当たらないとした給与等の収入金額`（事実。IK-25）：判断.退職の性質 で退職手当等に当たらず給与とした retirement_payment の総支払額。年分は支払の日（`inputs._retire_salary`）。kyuyo が段 `事業専従者のみなし給与` で給与等の収入金額に足す。
- `所得税.回収不能額等の前の公的年金等に係る雑所得の金額`（`uncollectible.py`。kyuyo KY-08）：公的年金等控除額の区分の基を income_totals の `所得税.回収不能額等の前の公的年金等に係る雑所得以外の合計所得金額` にした額（所令180②一の「直前に確定している」総所得金額の材料。式は公的年金等控除額と同じ）。

申告書の欄の途中の値（2026-11-12。`filing.py`。様式の欄の対応表 forms が写す）：
- `所得税.一時所得の特別控除前の金額`（総収入金額−支出した金額。負になりうる）・`所得税.一時所得の特別控除額`（所法34③）：第二表の一時所得の差引金額、第四表（一）72 の Ⓒ・Ⓓ。
- `所得税.退職所得の{一般・短期・特定役員}の{収入金額・退職所得控除額}`（6件）：第三表「退職所得に関する事項」の3行。一つの区分だけならその行に全部、二以上の区分なら所令71の2 の割り振り（calc.retirement_income_multi と同じ）。

総収入金額・必要経費の内訳と事業専従者の事業主（2026-11-12。`breakdown.py`。様式の欄の対応表 forms の決算書・収支内訳書の科目〔design-output UO19〕と第二表の事業専従者の行〔UO23〕）：
- `所得税.{事業所得|不動産所得}の必要経費の内訳.<キー>`（各 25 件）：必要経費（減価償却費・専従者給与等の前）をキーごとに分けた額。キーは中間表現の費目
  `business_expense.attributes.expense_category`（2026-11-12 に閉じた語彙：`okura_ir.vocabulary.EXPENSE_CATEGORIES`。業務の支出でない `dividend_debt_interest` を除く21）と、
  `payroll_wages`（給与の支払）・`payroll_professional_fee`（報酬の支払）・`consumption_tax`（税込経理の納付税額・資産の仮払消費税等）・`asset_loss`（除却損・災害等の損失・譲渡の費用）。
  inputs.py が `_Sides.exp` に足す箇所で同じ額を `_Sides.brk`（`Breakdown`）に足し、所法56 の移し替え（全部・記録ごと・物件ごと・資産の仮払消費税等）でも同じに移す。
- `所得税.{事業所得|不動産所得}の必要経費のうち内訳のない額`：必要経費 − 内訳の合計（0 が正常）。内訳を足さずに必要経費を足す箇所が増えたときに、
  様式の科目ごとの額を黙って雑費に入れないための値（forms は 0 でなければ科目の欄を「未対応」にする）。**必要経費を足す箇所を増やすときは `brk` にも足す。**
- 総収入金額の内訳：`所得税.事業所得の総収入金額のうち{売上の金額|その他の収入の金額}`、`所得税.不動産所得の総収入金額のうち{賃貸料の金額|礼金・権利金・更新料の金額|名義書換料・その他の金額}`
  （その他は総収入金額との差）。
- `所得税.事業専従者の事業主`（区分。いなければ「なし」）・`所得税.事業専従者の専従者給与等の額`：専従者の側の値（青色は届出・相当性の範囲の額、白色は事業専従者控除額）。
  二以上の事業主の専従者は対象外（行の割当てを決められない）。
- 減価償却費の計算の行の列に `本年分の割増償却費`（2026-11-12 の5回目。IK-112）を足した。`本年分の償却費合計` は普通償却費＋割増（特別）償却費。
- 業務に係る雑所得の内訳は作っていない（業務に係る雑所得の収支内訳書は前々年の収入の概念がなく forms が作らない）。
- 科目の割当ての利用者の選択（2026-11-12。`form_override.py`。選択.様式への割当て C-18。IK-120）：`所得税.{事業所得|不動産所得}の科目の割当ての選択`（区分。
  「なし」か「費目=費目;…」の正規の形）。`expense_category` の費目の額を、`form_item` の費目の既定の科目（forms/data/r07/割当て/科目.yaml）に載せる選択で、
  forms の fill が科目の欄の内訳のキーを入れ替える（forms/README.md §4.1）。必要経費・所得・税額は変えないので、未入力のときに候補で評価せず既定の表どおり
  （DecisionSpec は宣言だけで、入力があるときだけ `ctx.choices` で読む：`判断.雇用か請負か` と同じ形）。`business_id` があればその業務の所得の側の表だけ
  （不動産所得の業務なら不動産所得、`判断.事業と称するに至る程度` が真なら事業所得〔判断の由来も値に付く〕、業務に係る雑所得なら様式がないので当てない）、
  なければ両方の表。表は人ごと（その側の全部の業務の同じ費目を移す）。仕入（merchandise・materials）は売上原価の欄が仕入金額の概念から計算されるので
  移す元にも先にもできない。科目名を書く空欄の行（作成コーナーの「任意科目」）への割当ては、語彙の `form_item` が符号で科目名を持てないので受け付けない。

## 3. このモジュールの概念を使う、ほかのモジュール

income_totals（各所得。回収不能額等の前の公的年金等に係る雑所得：KY-08）、tax（公的年金等の収入金額など）、kyuyo（事業専従者のみなし給与・所法56 で受取側の給与から除く額・退職手当等に当たらないとした給与を段で読む）、personal_deductions（専従者の判定は未接続）。源泉徴収税額の事実は `所得税_公的年金等の源泉徴収税額`・`所得税_退職所得の源泉徴収税額`・`所得税_配当等の源泉徴収税額`・`所得税_上場株式等の譲渡の源泉徴収税額`（申告しない配当・口座を除いた額）。

## 4. 実装の要点

- 規則の置き場所：`calc.py`（純粋関数と根拠のある端数）、`parameters/所得税/*.yaml`（基準額・率。別表第八の償却率は千分率）、`inputs.py`（中間表現 → 入力）、`assets.py`（減価償却）、`consumption.py`（消費税等）、`family.py`（専従者）、`variables.py`（式）、`basis.py`（入力の段の規則の根拠）。
- **端数**（D21 R5・D22 S3）：公的年金等の雑所得は切捨て（手引き）。償却費は切上げ（国税庁の説明：`calc.DEPRECIATION_CEIL`）。根拠のない端数は2つの分かれ目：`端数:所得の金額の1円未満（退職所得）`（式で読む）と `端数:必要経費の1円未満（按分・一括償却・事業専従者控除）`（入力の段で `ctx.round_unfounded`）。
- 判断・選択（`inputs.DECISIONS`）：業務関連性（未入力の支出は人ごとに全部 true・全部 false の両端評価：`単調:業務関連性:<人>`）、減価償却の選択（`単調:減価償却の選択:<人>`）、大口株主等（`単調:大口株主等:<人>`）、経理方式（税込・税込未払・税抜）、事業的規模、外国の年金の性質、生計を一にするか（専従者・家族の支払）など。
- 減価償却（`assets.py`）：少額・一括・措法28の2（取得日で区分。年の上限：入力した選択で超えれば c-入力、未入力の候補で超えれば分かれ目〔判断〕）・通常の償却。通常の償却の方法は、償却の方法の届出（`bookkeeping_status.depreciation_method_notice`）がなければ法定償却方法（所令125：平成19年3月31日以前の取得は旧定額法〔125①一イ：120①一イ・二の資産。120①一ロ・四は選べる方法が旧定額法だけ。docs/public-sources/20261112_impl-research4_shotoku-laws-and-nta.md §3、仮説 H3・推測 I3。2026-11-12 に照合して一致〕、以後は定額法）、届出があれば資産の種類（`判断.減価償却の区分` の `asset_class`。なければ耐用年数の表の行から）と取得の日で選べる方法（所令120①・120の2①：建物は平成10年3月31日以前の取得だけ旧定率法・平成19年4月1日以後は定額法だけ、附属設備・構築物は平成28年3月31日以前だけ定率法、無形は定額だけ）を `選択.減価償却` の `depreciation_method` で当てる（未入力なら候補の全部。読んだときだけ開く）。選べない方法を選んだ記録は c-入力。定額法（別表第八・1円まで）・定率法（別表第九・第十、保証率・改定償却率）・旧定額法（別表第七、残存割合は別表第十一）・旧定率法（別表第七）、旧償却は95%まで・その後5年の均等償却（所令134①②③。docs/public-sources/20261111_impl-research3_genka-laws.md）。家事兼用は判断の割合を掛ける（未償却残高は全額で減らす：案A。家族の使用の割合 `family_use_share` だけなら業務の部分は 1−割合：語彙の約束）。処分は除却損（所法51①④）。
