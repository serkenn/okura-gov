## H1 令和7年分と令和8年分で、医療費控除の「計算の規則」は同じ。違うのはセルフメディケーション税制の対象医薬品の範囲だけ

- 所法第73条・第22条・第87条、所令第207条、所規第40条の3、措法第41条の17・措令第26条の27の3・措規第19条の10の2の2 の本文は、2025-12-31 版と 2026-12-31 版で同じ［LAW］§0.1、［MEAS］§3.1。所法第120条第4項・第5項と所規第47条の2第12項は、機関名の改称のほかは同じ［LAW］§0.1。
- 違い：措法第41条の17第3項の経過措置（「効果が低いと認められる医薬品を除く」を外す）は令和7年12月31日で終わり、令和8年1月1日以後の購入では4成分（L-アスパラギン酸カルシウム、フッ化ナトリウム、メコバラミン、ユビデカレノン）を含むスイッチOTC が対象外［LAW］§4.3、［NM］§6.3。
- したがって判定コアのパラメータ（年分ごと）は次で足りる (I)：

| パラメータ | 令和7年分 | 令和8年分 | 根拠 |
|---|---|---|---|
| 通常：足切りの率 | 5% | 5% | ［LAW］§1 |
| 通常：足切りの上限 | 100,000円 | 100,000円 | ［LAW］§1 |
| 通常：控除の上限 | 2,000,000円 | 2,000,000円 | ［LAW］§1 |
| セルフ：足切り | 12,000円 | 12,000円 | ［LAW］§4.1 |
| セルフ：控除の上限 | 88,000円 | 88,000円 | ［LAW］§4.1 |
| セルフ：対象となる支払の期間 | 2017-01-01〜2026-12-31 | 同左 | ［LAW］§4.1 |
| セルフ：経過措置の末日（参考） | 2025-12-31（年分の中は全部が期間内） | 期間外 | ［LAW］§4.2・§4.3、［NM］§6.3 |

- 令和9年分は措法第41条の17が変わる（期間が区分ごと、薬局製造販売医薬品・体外診断用医薬品が加わる）［LAW］§4.4。対象年分（D14）の外だが、D9 の監視で検知すべき改正として既に確定している。

## H2 記録層（事実）に持つ医療費の支払の項目

医療費の支払1件ごとに、次の事実を持つ。どれも領収書・レシート・振込記録・医療費通知から読める事実で、法令の解釈を含まない (I)。

| 項目（案） | 内容 | なぜ要るか［根拠］ |
|---|---|---|
| `id` | 支払の取引ID | 補塡・判断・出力の根拠から参照する（D13） |
| `payer` | 実際に支払った人 | 控除を受けるのは「医療費を支払つた」居住者［LAW］§1、［NM］§7（QA05/25・05/83） |
| `patient` | 医療・医薬品を受けた人（受診者） | 生計一・親族の判定、明細書の「医療を受けた方の氏名」［LAW］§5.2（所規47の2⑫二）、［NM］§5.1 |
| `provider` | 病院・薬局などの支払先の名称 | 明細書の「支払先の名称」［LAW］§5.2（所規47の2⑫三）。セルフの明細書の「販売を行った者」［LAW］§4.5 |
| `paid_on` | 現実に支払った日 | 年分の帰属は「その年中に支払つた」［LAW］§1、［NM］§1（73−2）、§8（QA05/24 未払、05/81 借入金）。生計一の判定の時点の一つ［NM］§1（73−1） |
| `incurred_on` | 支出すべき事由が生じた日（受診日・購入日） | 生計一の判定の時点のもう一つ。「医療費を支出すべき事由が生じた時、すなわち、その医療費の請求の基となった治療等を…受けた時」［NM］§7（QA05/57） |
| `amount` | 支払った金額（税込、割引後） | ［LAW］§1。セルフについては税込・割引後の額［NM］§6.4（厚労QA Q30・Q31） |
| `kind` | 支払の内容の種類（H3 の語彙。複数可） | 明細書の「医療費の区分」と、判定コア・人の判断が見る材料［NM］§3 |
| `evidence` | 証憑の種類と識別（領収書、レシート、医療費通知の行、証明書） | 5年間の提示・提出の求め［LAW］§5.1、［NM］§5.2。証明書の要る費用［NM］§3 |
| `selfmed_mark` | レシート等にセルフメディケーション税制の対象である旨の表示があるか（あり／なし／不明）と、商品名 | 対象医薬品は「レシート等の表示」で見分ける［NM］§6.3（厚労QA Q33）、§6.4（厚労レシート、厚労QA Q7・Q41） |
| `deposit_applied_on` | 保証金が医療費に充当された日（保証金の場合だけ） | 保証金は充当された年分［NM］§8（QA05/86） |

- **記録層に持たないもの**（判定コアか人の判断 D4 に置く）：その支払が「医療費」に当たるか、「通常必要」か、治療目的か予防目的か、生計一か、どの年分に入るか (I)。
- 支払の日付を2つ（`incurred_on` と `paid_on`）持つのは、生計一の判定が「支出すべき事由が生じた時**又は**現実に支払った時」のどちらかで足りるため［NM］§1（73−1）、§7（QA05/57）。R4 の H2.1 で (I) とした「支出すべき事由が生じた時＝受診日」は、QA05/57 の原文で裏づけられた。
- 医薬品の購入は `incurred_on = paid_on`（購入日）とする (I)。

## H4 補塡は「給付の事実」と「対象の支払の集合」で持ち、限度の計算は判定コアで行う

- 記録層：補塡1件ごとに、受取人、金額、受取日、給付の種類（入院給付金、高額療養費、出産育児一時金、互助会の給付金など）、確定か見込みか、**対象の支払IDの集合**（給付の目的となった医療費）を持つ［NM］§1（73−8〜73−10）、§4。
- 判定コアの規則［NM］§4：
  1. 補塡額は、対象の支払の合計を限度として差し引く。超えた分は他の医療費から差し引かない（TA1120、QA05/28）。
  2. 受取人が支払者と違っても差し引く（QA05/26）。
  3. 対象の支払が2つの年分にまたがるときは、原則として各年分に支払った額に応じてあん分する（QA05/61）。
  4. 確定していなければ見込額で計算し、確定額が違えば遡って訂正する（73−10、QA05/59）。受領額が見込額より多ければ修正申告、少なければ更正の請求（手引008）。
  5. 返還した補塡は、控除を受けた年分の是正になる（QA05/60）。
- 補塡に当たるかどうか（傷病手当金・出産手当金・見舞金などは当たらない：73−9、QA05/27）は、給付の種類から判定コアが決める。種類から決まらないもの（任意の互助組織の給付金が「医療費の補塡を目的として」いるか等）は D4 の判断にする (I)。
- 限度の単位（対象の支払の集合）は、法令の文言（「補てんされる部分の金額を除く」）からは機械的に決まらない。どの給付がどの医療費の補塡かは人が記録する事実とし（保険会社の支払明細などに書かれていることが多い：I）、決められないときは D4 の判断にする (I)。
- 出力層では、明細書の「(5) 補塡される金額」に**限度を当てはめた後の額**を書く。様式の C＝A−B は行の B の合計から計算するので、限度前の額を書くと他の医療費から差し引いたことになる［NM］§2.2、§5.1、［MEAS］§4 (I)。1件の補塡が明細書の複数の行にまたがるときの行への割り振りは控除額を変えないので、名前つきの関数で決める（例：対象の行の支払額の比で割り振り、端数は最後の行）(I)。

## H5 「総所得金額等」は判定コアが「合計所得金額」と別の変数として計算する

- 足切りの基礎 D は「総所得金額、退職所得金額及び山林所得金額の合計額」で、総所得金額は純損失・雑損失の繰越控除の**適用後**［LAW］§1、§3.1。合計所得金額（扶養の判定）は繰越控除の**適用前**［IT］§4、［NM］§2.1。2つは繰越控除があるときだけ違う。
- 分離課税の所得は、措法の読替えで「総所得金額」に加わる（上場株式等の配当所得等、土地等の事業所得等、長期譲渡所得、一般株式等の譲渡所得等、先物取引の雑所得等など）［LAW］§3.2。国税庁は「申告分離課税の所得金額（長（短）期譲渡所得については特別控除前の金額）」を加えると書く［NM］§2.1・§2.2。
- 退職所得金額は「確定申告が不要な場合でも計算に当たって加算する」［NM］§2.1。
- したがって判定コアに `total_income_for_deductions`（総所得金額等）を `total_income_sum`（合計所得金額）と別に持つ (I)。対象の家族（扶養されている子供と親）では、まず総合課税の所得だけを実装し、退職所得・山林所得・分離課税の所得・繰越控除が入力にあるときは「未対応」として計算を止める（黙って0として扱わない）(I)。

## H6 5%の円未満の端数処理は一次情報がない。名前つきの関数にし、作成コーナーで確かめる

- 法令にも国税庁の様式・手引き・TA にも、E 欄（D×0.05）の端数の扱いは書かれていない［LAW］§6、［NM］§2.2・§9。作成コーナーの計算はサーバー側で、ブラウザからは確かめられない［SAK］§5。
- D は円単位の整数なので、D×0.05 の端数は 0.05 円の倍数になる（D が20の倍数でないときだけ端数が出る）(I)。
- 様式の欄は円単位なので、出力では整数にする必要がある［NM］§5.1 (I)。
- 仮説：E は**円未満切り捨て**とする関数 `threshold_5pct_floor(D)` を置き、これが作成コーナーの結果と一致するかを確かめるまで「未確認」の印を結果の根拠に付ける (I)。D が20の倍数のときは端数が出ないので、どの処理でも結果は同じ。
- 控除額 G・C・E はほかに端数の出る計算を含まない（A・B は円単位の合計、F は E と10万円の小さい方）(I)。

## H7 セルフメディケーション税制は「取組」と「表示のある購入」の事実で判定し、対象医薬品の一覧は判定コアに持たない

- 取組は**申告する本人が**その年中に行ったもの（生計を一にする親族の取組は使えない）［NM］§6.1（TA1129・TA1133、厚労QA Q16）。記録層に、人 × 年の事実として取組（種類：健康診査／予防接種／定期健康診断／特定健康診査・特定保健指導／がん検診、実施主体の名称、受けた日、証明書類）を持つ［LAW］§4.5（明細書の記載事項）、［NM］§6.2 (I)。
- 取組に当たらないもの（任意で全額自己負担の健診、自治体独自の健診、要再検査で受けた検査、中断した特定保健指導）は種類と実施主体から判定コアが決め、決められないものは D4 にする［NM］§6.2（厚労QA Q19・Q27・Q28）(I)。
- 対象医薬品かどうかは、購入時のレシート等の表示（★印か、対象商品だけの合計の別記）で見分ける。表示のない購入は申告に使えない［NM］§6.3（厚労QA Q33）、§6.4（厚労レシート、厚労QA Q41）。成分・品目の一覧（厚生労働省が月1回更新）を判定コアに持つと、品目の追加・削除の追随が D9 の監視の対象になり、しかもレシートの表示が優先する運用と食い違いうる (I)。
- ただしレシートの表示には誤りの例がある（対象外に印、対象に印なし）［NM］§6.4（厚労誤表示）。記録層の `selfmed_mark` は事実として記録し、誤りが分かったときは D4 の判断で上書きする（判断者・日時・根拠つき）(I)。
- 令和8年分の4成分の除外は、令和8年1月1日以後のレシートの表示に反映されているはずなので、判定コアでは成分を見ない (I)。2025年中の購入を2026年に支払った場合のように、表示と年分がずれる場合は D4 にする (I)。
- 取組の証明書類と領収書は添付しないが、5年間の提示・提出の求めに備えて証憑として記録に残す［LAW］§4.1（措法41の17④）、［NM］§6.1。

## H8 通常の医療費控除とセルフメディケーション税制は、判定コアが両方を計算し、選ぶのは人（D4）。提出した選択は事実として記録する

- 選択適用で、併用できない。提出後に更正の請求・修正申告で選択を変えられない［NM］§6.1（TA1129・TA1131）。
- セルフの対象医薬品の購入で、治療・療養に必要なものは通常の医療費控除の対象にもなる［NM］§6.1（特集セルフの注）。同じ支払が2つの計算の候補に入るが、どちらか一方しか使わないので二重にはならない (I)。
- 判定コアの出力：申告者ごとに「通常の控除額」「セルフの控除額」「有利な方」を返し、どちらを申告するかは人の判断（D4）とする。申告後は「どちらを選んで提出したか」を事実として記録し、それ以後の再計算（補塡の見込みの訂正など）は同じ選択で行う (I)。
- 選択は申告者ごと。同じ世帯で、ある人は通常、別の人はセルフを選べる［NM］§7（厚労QA Q13）。

## H9 誰が控除するか：支払1件に支払者は1人。生計一は支払ごとに2つの時点のどちらかで判定し、扶養の所属とは無関係

- 控除するのは実際に支払った人。対象は自己と、生計を一にする配偶者その他の親族（6親等内の血族・配偶者・3親等内の姻族）。扶養親族かどうか・所得は問わない［NM］§7（QA05/25・05/58・05/82・05/83）、［LAW］§1。
- 生計一の判定時点は「支出すべき事由が生じた時（＝治療等を受けた時）又は現実に支払った時」［NM］§1（73−1）、§7（QA05/57）。被相続人の死亡後に相続人が支払った医療費は、治療時に生計一なら相続人の控除になり、被相続人の準確定申告では控除できない（QA05/57）。
- 同じ医療費を2人が控除できないことは、厚生労働省の Q&A には書かれているが、国税庁の原文は見つからなかった［NM］§7。条文は「医療費を支払つた場合」の支払った人に控除を認める形［LAW］§1。
- そこで中間表現の検査で、1件の支払（`id`）の `payer` は必ず1人、同じ証憑（領収書の識別）が2件の支払に使われていたら拒否する (I)。1件の請求を2人で分けて払ったときは、記録では2件の支払として持つ（それぞれ実際に払った額）(I。国税庁の資料で確かめていない)。
- クレジットカード・口座振替・家族の共有口座からの支払で「誰が支払ったか」「いつ支払ったか」は資料が見つからなかった［NM］§9。記録層は「どの口座・カードから、いつ引き落とされたか」の事実を持ち、支払者・支払日の当てはめが事実から決まらないときは D4 にする (I)。

## H10 医療費通知は、当面の出力では使わない（明細書の「2」だけで作る）

- 医療費通知を添付すると明細書の記載を簡略化できるが、通知の行は前年支払分を含みうるうえ、通知に書いた分は「2」に書いてはいけない［NM］§5.2・§5.3。通知の行と領収書の支払を突き合わせる処理が要る (I)。
- 明細書の法定の記載事項は、医療費の額・診療等を受けた者の氏名・病院等の名称・参考事項だけ［LAW］§5.2。医療費通知の添付は選択肢で、すべてを「2」に書いても要件を満たす (I)。
- したがって最初の実装では、出力は「2 医療費（上記1以外）の明細」と「3 控除額の計算」だけを作り、「1 医療費通知に記載された事項」は空欄にする (I)。医療費通知（マイナポータルのデータを含む）は、記録層の支払と突き合わせる照合の材料として後で使う (I)。

### H11.4 すべての出力に付ける根拠（D13）

- 行ごと：含めた支払の `id`、差し引いた補塡の `id` と限度前・限度後の額、生計一の判断・医療費該当の判断の ID（D4）。

- 検査：明細書の A−B の合計と、判定コアが計算した「控除の対象となる医療費（補塡後）」が一致すること (I)。

## H12 年分をまたぐ事実の更新と、過去の年分の訂正

- 医療費に当たるかどうかが後の事実で変わる場合がある：健康診断の後に重大な疾病の治療をした場合（73−4）、特定健康診査の後に積極的支援の特定保健指導を受けた場合（QA05/72）。このとき医療費になるのは**支払った年分**の医療費で、翌年の事実で前年分が変わる［NM］§1、§8。
- 補塡の確定額が見込額と違う場合、補塡の返還の場合も、過去の年分が変わる［NM］§4。
- したがって判定コアは「年分 Y の結果」を、年分 Y の支払だけでなく、Y より後に記録された事実・判断も含めて計算する必要がある (I)。D12（判断は追記のみ、畳み込みで現在の状態）と組み合わせると、ある年分の結果が後から変わったことを、版つきの結果の差（D13 の決定性）として検知できる (I)。出力層は、申告済みの年分の結果が変わったときに「修正申告か更正の請求の候補」として知らせる (I)。
