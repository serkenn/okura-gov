# 推測：地方税法第313条第11項の窓口と様式の対応表の変更から出る結果と、確かめる方法（impl-research9）

- 前提の仮説：`docs/hypotheses/20261112_impl-research9_jm42-windows.md`（H1〜H5）、`docs/hypotheses/20261112_impl-research9_tokutei-jumin-reading.md`（H3〜H5）。
- 作成：2026-11-12（kyuyo の担当）。

## I1 回収不能額等のある人（H1・H3）

- 例：給与等の収入 300万円（令和7年分）・回収不能額等 100万円・特定支出 60万円・事業所得 −150万円で、所得税の申告をせず住民税の申告書だけで特定支出控除を受ける人。
  特定支出控除を当てた給与所得は 1,910,000円、二号の差額は 850,000円、一号（直前の総所得金額）は 410,000円なので、住民税の給与所得は 1,500,000円、合計所得金額は 0円。
  以前の実装はこの人を対象外にしていた（JM-42）。
- 確かめ方：ユニットテスト `packages/core/tests/test_juminzei_tokutei.py` の TestWindows（一号・二号のどちらが低い場合も）。住民税の値は作成コーナーで確かめられないので、
  市町村の住民税の申告の手引き・計算例で「所得税の計算の例」の当てはめを示した資料を公開資料の情報として探す。

## I2 公的年金等控除額の区分が変わる人（H1）

- 例：70歳・公的年金等の収入 200万円。所得税の値は公的年金等に係る雑所得以外の合計所得金額が 1,000万円を超えて控除 100万円（雑所得 100万円）だが、
  特定支出控除の後の給与所得 970万円＋事業所得 20万円＝990万円で 1,000万円以下になり、控除 110万円（雑所得 90万円）。住民税の合計所得金額は所得税の値の差より 10万円少ない。
- 確かめ方：TestWindows の test_pension_bracket_changes_with_the_salary。一次情報で確かめるなら、公的年金等控除額の区分（所法35④）を住民税で当てる計算例。

## I3 所得金額調整控除の第2項（H2）

- 公的年金等に係る雑所得の金額が区分の変化で減ると第2項の額も減り、給与所得の金額（調整控除の後）が増える。第1項は所得税の値のまま。
- 確かめ方：TestWindows の test_adjustment_second_paragraph_follows_the_pension。

## I4 様式の対応表（tokutei-jumin-reading H3〜H5）

- 第一表 ㋔ の区分 G13 は所得金額調整控除の区分（1・2・3）、⑥ の区分 G16 は特定支出控除を受ける人の明細書の区分番号の和、⑥ は所得金額調整控除の後の給与所得の金額。
  以前の表（G13＝特定支出、G16＝所得金額調整控除）で出した値は逆の欄に入っていた（ただし以前はどちらも未確定か空欄で、値は出していなかった）。
- 給与所得者の特定支出に関する明細書（KOB070）の ⑮〜⑱ は未確定（様式の計算と法令の計算が収入660万円未満で違いうる：impl-research8 I2）。
- 確かめ方：作成コーナー（令和7年分、架空の数字）で、所得金額調整控除の第1項・第2項に当たる人と、特定支出控除を受ける人（区分を2つ以上）を入れ、
  第一表の ㋔・⑥ の区分の表示、明細書の ⑫・⑮〜⑱、第二表「特例適用条文等」の表示（措法27 と並ぶときの区切り）を記録する（`docs/measurements/` に。ユーザーの手で行う照合）。
