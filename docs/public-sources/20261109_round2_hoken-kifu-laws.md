## 2. 生命保険料控除（所得税法第76条。所法R7〜R9 で同文）

### 2.1 控除額（第1項〜第4項）

各区分の式（「支払った保険料の金額の合計額」は、その年に受けた剰余金の分配・割戻金の割戻し（政令で定める部分）を差し引いた残額。以下 x）：

| 区分 | 条 | x ≦ a | a < x ≦ b | b < x ≦ c | x > c |
|---|---|---|---|---|---|
| 新生命保険料 | ①一イ〜ニ | 2万円以下：x | 4万円以下：2万円＋(x−2万円)/2 | 8万円以下：3万円＋(x−4万円)/4 | 4万円 |
| 旧生命保険料 | ①二イ〜ニ | 2万5千円以下：x | 5万円以下：2万5千円＋(x−2万5千円)/2 | 10万円以下：3万7千5百円＋(x−5万円)/4 | 5万円 |
| 介護医療保険料 | ②一〜四 | 新生命保険料と同じ式（上限4万円） | | | |
| 新個人年金保険料 | ③一イ〜ニ | 新生命保険料と同じ式（上限4万円） | | | |
| 旧個人年金保険料 | ③二イ〜ニ | 旧生命保険料と同じ式（上限5万円） | | | |

- 新生命保険料と旧生命保険料の両方を支払った場合（①三）：それぞれの式の額の合計（**4万円**を超えれば4万円）。個人年金保険料も同じ（③三、4万円）。
- 第4項：第1項〜第3項の控除額の合計が **12万円** を超える場合は 12万円。
- 第11項：第1項〜第4項の控除を「生命保険料控除」という。
- 端数の処理を定める文言は第76条にない（[M-HKF] §3.5）。

### 2.2 新・旧と契約の範囲（第5項〜第10項）

- 新生命保険契約等（第5項）：**平成24年1月1日以後に締結**した契約（同日前に締結し、失効し、同日以後に復活したものを除く）、他の保険契約に附帯して締結した新契約、同日以後に承認・認可を受けた確定給付企業年金等の規約。**保険金等の受取人のすべてを、保険料・掛金の払込みをする者又はその配偶者その他の親族とするもの**に限る。対象の契約は第5項第1号〜第4号（生命保険会社の生存・死亡保険〔保険期間5年未満の政令で定めるもの・外国生命保険会社等が国外で締結したものを除く〕、旧簡易生命保険、生命共済、確定給付企業年金等）。
- 旧生命保険契約等（第6項）：**平成23年12月31日以前に締結**した契約（失効し同日後に復活したものを含む）。第4号に、疾病・傷害等で保険金等が支払われる保険契約のうち医療費等支払事由に基因するもの（いわゆる医療保険・介護保険で、旧契約のもの）を含む。受取人の要件は第5項と同じ。
- 介護医療保険契約等（第7項）：平成24年1月1日以後に締結した、医療費等支払事由に基因して保険金等が支払われる契約。受取人の要件は同じ。
- 新個人年金保険契約等（第8項）：平成24年1月1日以後に締結した年金給付契約で、次の要件の定めのあるもの。一　年金の受取人は、保険料の払込みをする者又はその配偶者が生存している場合にはこれらの者のいずれか。二　保険料の払込みは年金支払開始日前**10年以上**の期間にわたって定期に行う。三　年金の支払は受取人の年齢が**60歳**に達した日以後の日で契約で定める日以後**10年以上**の期間又は生存している期間にわたって定期に行うことその他の政令で定める要件（所令第212条）。
- 旧個人年金保険契約等（第9項）：平成23年12月31日以前に締結した年金給付契約で、第8項各号の要件の定めのあるもの。
- 第10項：平成24年1月1日以後に、旧生命保険契約等・旧個人年金保険契約等に**附帯して新契約を締結した場合**は、その旧契約は同日以後に締結した契約とみなす。
- 所令第208条の3〜第212条（新生命保険料の対象、旧生命保険料の対象外、剰余金の控除額、介護医療保険料の支払事由、生命保険料控除の対象とならない保険契約等〔第209条：保険期間5年未満の一定の保険契約〕、生命共済契約等の範囲、年金給付契約の範囲と要件）は、所令R7〜R9 で同文（[M-HKF] §2）。中身の要点は本文書では読み込んでいない（見出しと第1項の冒頭だけ確かめた）。

### 2.3 措法第41条の15の5（年齢二十三歳未満の扶養親族を有する場合の生命保険料控除の特例）

原文（措法 asof 2026-04-01 以後。2026-11-09・2026-12-31・2027-01-01 も同文）の要点：

- 第1項：居住者が**年齢23歳未満の扶養親族**（所得税法第2条第1項第34号に規定する扶養親族をいう）を有する場合における**令和8年分又は令和9年分**の生命保険料控除については、所法第76条第1項中「各年」を「令和八年又は令和九年」と、同項**第1号**イ「二万円」→「三万円」、ロ「二万円」→「三万円」・「四万円」→「六万円」、ハ「四万円」→「六万円」・「八万円」→「十二万円」・「三万円」→「四万五千円」、ニ「八万円」→「十二万円」・「四万円」→「六万円」、同項**第3号**「四万円」→「六万円」と読み替える。
  - したがって変わるのは**新生命保険料**の式（3万円以下：全額／6万円以下：3万円＋(x−3万円)/2／12万円以下：4万5千円＋(x−6万円)/4／超：6万円）と、新旧両方の場合の合計の上限（4万円→6万円）だけ。旧生命保険料（第1項第2号）、介護医療保険料（第2項）、個人年金保険料（第3項）、合計の上限 12万円（第4項）は読み替えていない。
- 第2項：23歳未満の扶養親族に該当するかの判定は、**その年12月31日**（居住者が年の中途で死亡・出国する場合はその時）の現況による。判定に係る者がその当時既に死亡している場合は、その死亡の時の現況による。
- 第3項：所法第190条第2号ロ（年末調整）、第196条第1項（保険料控除申告書の記載事項に「扶養親族の氏名及び個人番号…その他の財務省令で定める事項」を加える）、第196条第1項第3号、第198条第4項の読替え。
- 当初の文言（asof 2026-01-01・2026-03-31）は「令和八年分」だけで、判定日も「令和八年十二月三十一日」だった（[M-HKF] §3.1）。
- 所得税法施行規則第47条第3項第24号（確定申告書の記載事項に、この扶養親族の氏名・生年月日・続柄・個人番号）は 2026-01-01 施行の版から（既存：`docs/measurements/20261109_impl-prep_output-verification.md`）。

### 2.4 証明書（所令第262条第1項第4号、所規第47条の2第1項）

- 所令第262条第1項第4号：確定申告書に生命保険料控除に関する事項を記載する場合、控除額の計算の基礎となる新生命保険料・旧生命保険料・介護医療保険料・新個人年金保険料・旧個人年金保険料の金額（剰余金等を差し引いた残額）その他財務省令で定める事項を証する書類又は電磁的記録印刷書面を添付・提示する。ただし**旧生命保険料に係るものは、その金額が9千円を超える旧生命保険契約等に係るものに限る**。
- 所規第47条の2第1項（財務省令で定める事項）：新・旧生命保険料と介護医療保険料は「保険契約者（共済契約者）の氏名」と「新生命保険料（旧生命保険料・介護医療保険料）に該当する旨」。新・旧個人年金保険料は「契約の種類、保険契約者の氏名、**年金受取人の氏名及び生年月日、年金の支払開始日及び支払期間、保険料の払込期間**、個人年金保険料に該当する旨」。
- 所法第120条第6項（所法R9、2027-01-01 施行）：令和8年分以後の確定申告書を令和9年1月1日以後に出す場合、生命保険料控除などの証明書類の添付・提示に代えて、記載事項を書いた明細書を添付できる（既存：[PS-ZG]）。

## 3. 地震保険料控除（所得税法第77条。所法R7〜R9 で同文）と旧長期損害保険料

- 第1項：居住者が、**自己又は自己と生計を一にする配偶者その他の親族の有する家屋で常時その居住の用に供するもの**、又はこれらの者の有する所法第9条第1項第9号の資産（生活に通常必要な家具・じゅう器・衣服などの資産）を保険・共済の目的とし、地震・噴火・これらによる津波を原因とする火災・損壊・埋没・流失による損害（地震等損害）をてん補する保険金・共済金が支払われる損害保険契約等に係る**地震等損害部分の保険料・掛金**（政令で定めるもの〔所令213〕を除く）を支払った場合、その年中に支払った地震保険料の合計額（剰余金・割戻金を差し引いた残額）を控除する。**5万円**を超える場合は5万円。
- 第2項：損害保険契約等は、損害保険会社等の損害保険契約（第76条第6項第4号の契約と外国損害保険会社等が国外で締結したものを除く）、農協の建物更生共済・火災共済その他政令で定める共済（所令214）に**附帯して締結されるもの又はこれと一体となって効力を有する**契約。
- 平成18年法律第10号附則第10条（地震保険料控除に関する経過措置）：
  - 第2項：平成19年以後の各年に、**平成18年12月31日までに締結**した長期損害保険契約等（満期返戻金を支払う旨の特約のある契約その他政令で定めるこれに準ずる契約で、保険期間・共済期間が**10年以上**、かつ**平成19年1月1日以後に契約の変更をしていない**もの。保険期間の始期が平成19年1月1日以後のものを除く）の損害保険料（旧長期損害保険料）を支払った場合、控除額を次のとおりとして第77条を適用することができる。
    - 一　契約のすべてが損害保険契約等（地震保険料）：地震保険料の合計（上限5万円）
    - 二　契約のすべてが長期損害保険契約等：旧長期損害保険料の合計が1万円以下はその額、1万円超2万円以下は 1万円＋(x−1万円)/2、2万円超は **1万5千円**
    - 三　両方がある場合：地震保険料の合計と、旧長期損害保険料について第2号に準じて計算した額との合計（**5万円**を超える場合は5万円）
  - 第3項：一の契約が第1号・第2号のいずれの契約にも該当する場合は、いずれか一の契約のみに該当するものとして適用する。
- 証明書（所令262①五、所規47の2②）：地震保険料の金額その他「保険契約者の氏名、保険又は共済の種類及びその目的、地震保険料に該当する旨」。所令262①五には、生命保険料の「9千円」のような金額の例外はない。

## 4. 寄附金控除（所得税法第78条）

- 第1項：居住者が各年に特定寄附金を支出した場合、第1号の金額が第2号の金額を超えるときは、その超える金額を控除する。一　その年中に支出した特定寄附金の額の合計額（その年分の総所得金額・退職所得金額・山林所得金額の合計額の**100分の40**を超える場合は100分の40の額）。二　**2千円**。
- 第2項（特定寄附金。**学校の入学に関してするものを除く**）：
  - 一　国又は地方公共団体（港務局を含む）に対する寄附金（寄附をした者が設備を専属的に利用することその他**特別の利益**がその者に及ぶと認められるものを除く）
  - 二　公益社団法人・公益財団法人その他公益を目的とする法人・団体に対する寄附金のうち、広く一般に募集され、公益の増進に寄与する支出で緊急を要するものに充てられることが確実であるとして財務大臣が指定したもの（指定寄附金）
  - 三　別表第一の法人その他特別の法律により設立された法人のうち、公益の増進に著しく寄与するものとして政令（所令217）で定めるものに対する、主たる目的である業務に関連する寄附金（特定公益増進法人）
  - 四　（所法R8 以後の版。公益信託に関する法律の施行の日から）公益信託の信託財産とするために支出した、その公益信託の信託事務に関連する寄附金
- 所法R7 の第3項（所法R8 で削除）：特定公益信託の信託財産とするために支出した金銭は特定寄附金とみなす。
- 措法第41条の18（政治活動に関する寄附）・第41条の18の2（認定特定非営利活動法人等）：寄附金控除の特例又は所得税額の特別控除（税額控除）を定める。第41条の18の3（公益社団法人等）は見出しが「公益社団法人等に寄附をした場合の所得税額の特別控除」で、所得税額の特別控除だけを定める（所得控除は所法78②三の特定公益増進法人の側）。どちらを使うかの選び方の条文は、この文書では読み込んでいない（2025-12-31→2026-11-09 で文言が変わったことだけ確かめた。[M-HKF] §2）。
- 書類（所令262①六、所規47の2③。所規R8 の文言）：特定寄附金の明細書その他財務省令で定める書類。一般の特定寄附金は「受領した者の受領した旨、特定寄附金の額及びその受領した年月日を証する書類」（特定公益増進法人・公益信託の受託者は、業務・信託事務に関連する寄附金である旨を含む）、又は「**特定事業者**（地方公共団体と特定寄附金の仲介に関する契約を締結している者で国税庁長官が指定したもの）の、地方公共団体が受領した旨、地方公共団体の名称、特定寄附金の額及び受領した年月日を証する書類」。政治活動の寄附金・認定NPO法人等への寄附金は別の書類。

## 5. 小規模企業共済等掛金控除（所得税法第75条。所法R6〜R9 で同文）

- 第1項：居住者が各年に小規模企業共済等掛金を支払った場合、**支払った金額**を控除する（上限の定めはない）。
- 第2項：小規模企業共済等掛金とは、一　小規模企業共済法第2条第2項の共済契約（政令〔所令208の2：旧第二種共済契約に当たるもの〕で定めるものを除く）に基づく掛金、二　**確定拠出年金法**第3条第3項第7号の2 の**企業型年金加入者掛金**又は同法第55条第2項第4号の**個人型年金加入者掛金**、三　所法第9条第1項第3号ハの政令で定める共済制度（地方公共団体の心身障害者扶養共済制度）に係る契約に基づく掛金。
- 第3項：この控除を「小規模企業共済等掛金控除」という。
- 証明書：所令262①三（小規模企業共済等掛金の額を証する書類又は電磁的記録印刷書面）。
- 生命保険料控除（第76条第1項）と違い、条文は「居住者が…支払つた場合には、その支払つた金額」で、他の者の掛金を支払った場合の扱いを条文の上で区別していない。誰の掛金を誰が払えば控除できるかを定める条文・通達は、この文書では読んでいない。

## 6. 雑損控除（所得税法第72条。所法R6〜R9 で同文）

- 第1項：**居住者又はその者と生計を一にする配偶者その他の親族で政令で定めるもの**の有する資産（第62条第1項の**生活に通常必要でない資産**と、第70条第3項の**被災事業用資産**を除く）について、**災害又は盗難若しくは横領**による損失が生じた場合（関連して政令で定めるやむを得ない支出をした場合を含む）、その年の損失の金額（支出を含み、**保険金、損害賠償金その他これらに類するもの**により補てんされる部分を除く）の合計額が次の金額を超えるときは、その超える部分を控除する。
  - 一　損失の金額に含まれる**災害関連支出**の金額が**5万円以下**（ない場合を含む）：総所得金額・退職所得金額・山林所得金額の合計額の**10分の1**
  - 二　災害関連支出の金額が5万円超：「損失の金額の合計額 −（災害関連支出の金額のうち5万円を超える部分）」と第1号の額のいずれか低い額
  - 三　損失の金額がすべて災害関連支出：5万円と第1号の額のいずれか低い額
- 所令第205条：
  - 第1項（政令で定める親族）：居住者の配偶者その他の親族で、**その年分の総所得金額・退職所得金額・山林所得金額の合計額が 58万円以下（所令R7）／62万円以下（所令R8・R9）**のもの（施行・適用は §1）。
  - 第2項（所属）：その親族と生計を一にする居住者が2人以上ある場合は、いずれか一の居住者の親族にのみ該当するものとし、一　その親族が同一生計配偶者又は扶養親族に該当する場合は、その者を自己の同一生計配偶者又は扶養親族としている居住者の親族、二　該当しない場合は、イ　配偶者ならその夫又は妻である居住者、ロ　配偶者以外の親族なら、総所得金額・退職所得金額・山林所得金額の合計額が**最も大きい**居住者の親族とする。
- 所令第206条（所令R7〜R9 で同文）：
  - 第1項（やむを得ない支出）：一　災害による住宅家財等の取壊し・除去の支出など、二　災害のやんだ日の翌日から1年（大規模な災害などは3年）を経過する日の前日までにした、障害物の除去・原状回復（損失の金額に相当する部分を除く）・損壊等の防止の支出、三　被害の拡大・発生を防止するため緊急に必要な措置の支出、四　**盗難又は横領**による損失が生じた住宅家財等の原状回復の支出など。
  - 第2項（災害関連支出の金額＝所法72①一の「政令で定める金額」）：第1項**第1号〜第3号**の支出の金額（保険金等で補塡される部分を除く）。第4号（盗難・横領の原状回復）は災害関連支出に入らない。
  - 第3項：損失の金額は、損失を生じた時の直前の**その資産の価額**を基礎として計算する（取得費の規定〔所法38②〕の対象の資産などは、その価額又は取得費相当額）。
  - 第4項・第5項：特定非常災害による損失と他の損失がある場合の順序。
- 所法第87条第1項：雑損控除を先に行う（既存：[PS-ZG] §1.1）。
- 書類：所令262①一（やむを得ない支出の金額の領収を証する書類）。損失そのものの金額を証する書類の定めは同号にない。
- 雑損失の繰越控除（所法71、71の2）と、災害被害者に対する租税の減免、徴収猶予等に関する法律（災免法）は、この文書では条文を読んでいない。

## 8. ふるさと納税（寄附金税額控除と特例控除、申告の特例）

### 8.1 寄附金税額控除（地法第314条の7第1項。市町村民税）

- 所得割の納税義務者が前年中に次の寄附金を支出し、その合計額（前年の総所得金額・退職所得金額・山林所得金額の合計額の**100分の30**が上限）が**2千円**を超える場合、その超える金額の**100分の6**（指定都市に住所がある場合は**100分の8**）を所得割の額（第314条の3・第314条の6 の適用後）から控除する。前年中に**特例控除対象寄附金**を支出し、その合計額が2千円を超える場合は、これに**特例控除額**を加算する。控除額が所得割の額を超えるときは所得割の額。
  - 一　都道府県、市町村又は特別区（都道府県等）に対する寄附金（特別の利益が及ぶものを除く）
  - 二　共同募金会・日本赤十字社に対する寄附金（住所の道府県内の事務所等に限る）で政令で定めるもの
  - 三　所法78②二・三（2027-01-01 の版は「二から四まで」）の寄附金と措法41の18の2② の特定非営利活動に関する寄附金のうち、住民の福祉の増進に寄与するものとして**市町村の条例で定めるもの**
  - 四　特定非営利活動法人の特定非営利活動に係る事業に関連する寄附金のうち、**市町村の条例で定めるもの**
- 道府県民税（第37条の2第1項）は同じ形で **100分の4**（指定都市は**100分の2**）。第3号・第4号は道府県の条例。
- 第2項：特例控除対象寄附金は、第1号の寄附金（第一号寄附金）で、総務大臣が**指定**する都道府県等に対するもの。第9項：特例控除対象寄附金に当たるかは、**寄附金を支出した時**にその都道府県等が指定されているかで判定する。

### 8.2 特例控除額（地法第314条の7第11項、附則第5条の5・第5条の6）

- 第11項（2026-11-09 の版）：特例控除額 ＝（前年中に支出した特例控除対象寄附金の合計額のうち**2千円を超える金額**）× 次の割合 × **5分の3**（指定都市は**5分の4**）。ただし所得割の額（第314条の3・第314条の6 の適用後）の**100分の20**を超えるときは100分の20の額。
  - 第1号：課税総所得金額を有し、課税総所得金額 − 人的控除差調整額 ≧ 0 のとき、その額の区分ごとの割合（本則）：195万円以下 85%、195万円超330万円以下 80%、330万円超695万円以下 70%、695万円超900万円以下 67%、900万円超1,800万円以下 57%、1,800万円超4,000万円以下 50%、4,000万円超 45%。
    - **人的控除差調整額**（令和8年度分から）＝ 第314条の6第1号イの金額 ＋ max(0, 前年分の所得税の基礎控除の額〔措法41の16の2① の加算後〕− 48万円)。令和7年度分までは第314条の6第1号イの金額だけ（§1）。
  - 第2号：課税総所得金額 − 人的控除差調整額 < 0 で、課税山林所得金額・課税退職所得金額がないとき **90%**。
  - 第3号：課税総所得金額 − 人的控除差調整額 < 0 のとき又は課税総所得金額がない場合で、課税山林所得金額・課税退職所得金額があるとき：それぞれ 1/5 の額・その額の区分の割合（低い方）。
- 附則第5条の6第2項（平成26年度から**令和20年度**までの各年度分）：第1号の表の割合を 84.895%・79.79%・69.58%・66.517%・56.307%・49.16%・44.055% と読み替える（附則第5条の5 の 50%・60%・75% も 49.16%・59.37%・74.685% に）。（＝90% − 所得税率×1.021。[M-HKF] とは別の検算 `docs/measurements/20261109_round2_hoken-kifu-formula-checks.md` §6）
- 附則第5条の5第2項：分離課税の所得（附則第33条の2 など）がある場合の割合の特例。
- 道府県民税（第37条の2第11項、附則第5条の5第1項・第5条の6第1項）は同じ形で **5分の2**（指定都市は**5分の1**）。
- 令和10年度分以後は上限に定額（§1）が加わる。

### 8.3 申告の特例（ワンストップ特例。地法附則第7条。地法 2025-12-31〜2027-01-01 で同文）

市町村民税の項（第8項〜第14項）で書く。道府県民税は第1項〜第7項が同じ形。

- 第8項（申告特例対象寄附者）：特例控除対象寄附金を支出する者で、
  - 支出する年の年分の所得税について**所法第120条第1項の申告書を提出する義務がないと見込まれる者**、又は**所法第121条（第1項ただし書を除く）の適用を受けると見込まれる者**であって、
  - 寄附金税額控除額の控除を受ける目的以外に、**支出する年の翌年の4月1日の属する年度分の市町村民税の所得割について第317条の2第1項〜第5項の申告書の提出（第317条の3第1項により申告書が提出されたものとみなされる所法第2条第1項第37号の確定申告書の提出を含む）を要しないと見込まれるもの**
  は、当分の間、寄附金税額控除額の控除を受けようとする場合、申告書の提出に代えて、特例控除対象寄附金を支出する際、受領する都道府県知事等に対し、**申告特例通知書**を賦課期日現在の住所地の市町村長に送付することを求めることができる。
- 第9項：申告特例の求めは、その年（申告特例対象年）に支出する特例控除対象寄附金について申告特例の求めを行う**都道府県知事等の数が5以下**であると見込まれる場合に限り、行うことができる。
- 第10項：申請書の記載事項（氏名・住所・生年月日、申告特例対象寄附者である旨、特例控除対象寄附金の額、前項の要件に該当する旨など）。
- 第11項：申告特例の求めの日から賦課期日までに氏名・住所・生年月日が変わったときは、申告特例対象年の翌年の**1月10日**までに届け出る。
- 第12項：都道府県知事等は、申告特例対象年の翌年の**1月31日**までに、住所地の市町村長に申告特例通知書を送付する。
- 第13項（申告特例の求めが**なかったものとみなす**場合）：次のいずれかに当たると、申告特例対象年に支出した特例控除対象寄附金に係る申告特例の求めと通知書の送付は、いずれもなかったものとみなす（第4号は、その号に係るものに限る）。
  - 一　申告特例対象年の年分の所得税について**所法第121条の規定の適用を受けないこととなったとき**
  - 二　申告特例対象年の翌年の4月1日の属する年度分の市町村民税の所得割について**第317条の2第1項〜第5項の申告書の提出をしたとき**（第8項のかっこ書で、第317条の3第1項により申告書が提出されたものとみなされる**確定申告書の提出を含む**）
  - 三　申告特例通知書を送付した都道府県知事等の数が**5を超えたとき**
  - 四　申告特例通知書の送付を受けた市町村長が、賦課期日現在の住所地の市町村長と**異なったとき**
- 地法第317条の3第1項（2027-01-01 の版で確認）：第294条第1項第1号の者が前年分の所得税につき所法第2条第1項第37号の**確定申告書**を提出した場合（政令で定める場合を除く）は、その確定申告書が提出された日に第317条の2第1項〜第4項の申告書が提出されたものとみなす。
- 所法第2条第1項第37号：確定申告書は「第二編第五章第二節第一款及び第二款（確定申告）（第百六十六条において準用する場合を含む。）の規定による申告書（期限後申告書を含む）」。第一款「確定申告」には第120条〜第123条（還付等を受けるための申告〔第122条〕を含む）がある（[M-HKF] §3.5）。

### 8.4 申告特例控除額（地法附則第7条の2第4項・第5項、附則第7条の3）

- 第4項：市町村は、当分の間、所得割の納税義務者が前年中に特例控除対象寄附金を支出し、申告特例通知書の送付があった場合、**申告特例控除額**を所得割の額（第314条の7第1項・第11項の適用後）から控除する。

## 9. 分からなかったこと・読んでいないこと

- **生命保険料控除・地震保険料控除の1円未満の端数**：所法・措法・地法の条文に定めがない。所法・所令の「一円未満」の全文検索でも見つからなかった（[M-HKF] §3.5）。国税庁の説明は「切り上げ」（[PS-HKN]）。所得税法施行規則・地方税法施行令・地方税法施行規則の側は検索していない。
- **措法第41条の15の5 の「扶養親族を有する」と、所法第85条第6項（二以上の居住者の扶養親族に該当する者は、いずれか一の居住者の扶養親族にのみ該当するものとみなす）の関係**：所法第85条第6項の原文は [PS-IT] の取得範囲（`scripts/results/R1_egov_articles/shotoku_2026-12-01.txt`）で「二以上の居住者の扶養親族又は特定親族に該当する者がある場合には、その者は、政令で定めるところにより、これらの居住者のうちいずれか一の居住者の扶養親族又は特定親族にのみ該当するものとみなす。」と読める。夫婦の両方が特例を受けられるとする国税庁の説明（[PS-HKN]）と条文の関係を説明する一次情報は見つけていない。
- 措法第41条の18〜第41条の18の3（税額控除との選択）、所令第217条（特定公益増進法人の範囲）、所令第208条の3〜第214条の中身、地法第34条（道府県民税の所得控除）の文言、地方税法施行令第7条の13（道府県民税の雑損控除の親族）の額と附則、災免法、雑損失の繰越控除（所法71・71の2）は読み込んでいない。
- 地方税法施行規則（申告特例の申請書の様式、第2条の3 の確定申告書の付記事項）は取得していない。
- 地法第317条の3第1項のかっこ書「（政令で定める場合を除く。）」の政令の中身（確定申告書を出しても住民税の申告書の提出とみなされない場合）は読んでいない。ワンストップ特例の無効事由（附則第7条第13項第2号）との関係はこの政令による。
- 「公益信託に関する法律（令和6年法律第30号）の施行の日」が 2026-04-01 であることは、所得税法の改正履歴 `340AC0000000033_20260401_506AC0000000008`（令和六年法律第八号、施行 2026-04-01）と、2026-03-31／2026-04-01 の版の切り替わりから確かめた。施行期日を定める政令そのものは読んでいない。
- 総務大臣の指定の告示（どの都道府県等が指定されているか）は取得していない。寄附をした時点の指定の有無は、利用側が出典つきで入力する事実になる。
- 地法附則第5条の6・第7条の3 の期間は「令和20年度まで」（2027-01-01 の版まで同じ）。所得税側の復興特別所得税の期間の延長（[PS-ZG]）との関係は、令和20年度より後の年度の話なので確かめていない。
