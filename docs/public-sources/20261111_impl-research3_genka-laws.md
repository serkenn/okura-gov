## 1. 所令第120条（平成19年3月31日以前に取得した減価償却資産の償却の方法）

- 第1項柱書：「平成十九年三月三十一日以前に取得された減価償却資産（…）の償却費（…）の額の計算上選定をすることができる同項に規定する政令で定める償却の方法は、次の各号に掲げる資産の区分に応じ当該各号に定める方法とする。」
- 第1号（建物）イ：平成10年3月31日以前に取得された建物は（1）旧定額法・（2）旧定率法。ロ：それ以外の建物は旧定額法。
  - 旧定額法の定義（第1号イ（1））：「当該減価償却資産の取得価額からその残存価額を控除した金額にその償却費が毎年同一となるように当該資産の耐用年数に応じた償却率を乗じて計算した金額を各年分の償却費として償却する方法」
  - 旧定率法の定義（第1号イ（2））：「当該減価償却資産の取得価額（第二年目以後の償却の場合にあつては、当該取得価額から既に償却費として各年分の不動産所得の金額、事業所得の金額、山林所得の金額又は雑所得の金額の計算上必要経費に算入された金額を控除した金額）にその償却費が毎年一定の割合で逓減するように当該資産の耐用年数に応じた償却率を乗じて計算した金額を各年分の償却費として償却する方法」
- 第2号（建物の附属設備、構築物、機械装置、船舶、航空機、車両運搬具、工具器具備品〔第6条第1号〜第7号〕）：イ 旧定額法、ロ 旧定率法。
- 第4号（無形固定資産・生物）：旧定額法。第3号・第5号・第6号（鉱業用・鉱業権・国外リース）は家族の記録では使わない。
- R7 と R8 で第120条は同文（`scripts/results/R2X_genka_laws/diff_shotoku-rei_2025-12-31_vs_2026-12-31.diff` に第120条の差分なし。差分は第6条第8号ロ・第120条の2第1項第5号・第123条第3項・第125条第2号・第132条第1項・第134条第1項第2号の「貯留権」「生産高等比例法」の追加と、第198条（損益通算の順序）第3号・第6号の「及び」→「又は」だけ。差分の位置は ［M3-F］§3 の手順で確かめた）。

## 2. 所令第120条の2（平成19年4月1日以後に取得したもの）の定率法

- 第1項第1号イ（2）定率法：「当該減価償却資産の取得価額（第二年目以後の償却の場合にあつては、…控除した金額）にその償却費が毎年一から定額法償却率に二（平成二十四年三月三十一日以前に取得された減価償却資産にあつては、二・五）を乗じて計算した割合を控除した割合で逓減するように当該資産の耐用年数に応じた償却率を乗じて計算した金額（当該計算した金額が償却保証額に満たない場合には、改定取得価額にその償却費がその後毎年同一となるように当該資産の耐用年数に応じた改定償却率を乗じて計算した金額）を各年分の償却費として償却する方法」
- 第1号イ：平成28年3月31日以前に取得された建物以外の第6条第1号・第2号の資産（建物附属設備・構築物）は定額法・定率法、ロ：それ以外（建物、平成28年4月1日以後の附属設備・構築物）は定額法。第2号（機械装置・車両・器具備品など第6条第3号〜第7号）：定額法・定率法。
- 第2項第1号 償却保証額＝取得価額×耐用年数に応じた保証率。第2号 改定取得価額：イ 調整前償却額（取得価額〔期首未償却残高〕×償却率）が償却保証額に満たない最初の年はその年の取得価額、ロ 連続して満たないときは最も古い年の取得価額。
- R8 の差分は第5号（鉱業権・貯留権）だけ（§1）。

## 3. 所令第134条（償却累積額による償却費の特例）

- 第1項第1号（平成19年3月31日以前に取得し旧定額法・旧定率法などによるもの）イ（第6条第1号〜第7号の有形の資産）：累積額と当年の償却費の合計が「その取得価額（…）の百分の九十五に相当する金額」を超えるときは、超える部分を控除した金額を当年の償却費とする。ロ（坑道・無形固定資産）：取得価額。ハ（生物）：取得価額から財務省令の残存価額を控除した金額。
- 第1項第2号（平成19年4月1日以後に取得し定額法・定率法などによるもの）イ：「その取得価額から一円を控除した金額」。ロ（無形）：取得価額。
- 第2項：第1項第1号イ又はハの資産で、前年分以前の累積額が同号イ又はハの金額（95% など）に達しているもの：「当該減価償却資産の取得価額から同号イ又はハに定める金額及び一円を控除した金額を五で除して計算した金額（当該計算した金額と…累積額との合計額が当該減価償却資産の取得価額から一円を控除した金額を超える場合には、その超える部分の金額を控除した金額）をもつてその年分の償却費の額とする。」
- 第3項：第132条（年の中途で業務の用に供した場合等の月数按分）は第2項の償却費に準用する。
- 第134条の2（堅牢な建物等）：鉄骨鉄筋コンクリート造等の建物で累積額が95% に達したものは、（取得価額の5% − 1円）÷（耐用年数×3/10、1年未満切上げ）を各年分の必要経費に算入「することができる」（選択）。
- R8 の第134条の差分は第1項第2号の「生産高等比例法」の追加だけ（§1）。

## 4. 耐用年数省令の本則（償却率・残存価額の委任先）

- 第4条第1項：平成19年3月31日以前に取得をされた減価償却資産の旧定額法・旧定率法の償却率は「別表第七（平成十九年三月三十一日以前に取得をされた減価償却資産の償却率表）に定めるところによる。」（第2項・第3項は法人の事業年度が1年に満たない場合で、個人には当たらない）
- 第5条第1項：定額法の償却率は別表第八、定率法の償却率・改定償却率・保証率は、平成24年3月31日以前に取得をされたものは別表第九（250%）、平成24年4月1日以後は別表第十（200%）。
- 第6条第1項：平成19年3月31日以前に取得をされた減価償却資産の残存価額は「別表第十一（…残存割合表）の『種類』及び『細目』欄の区分に応じ、同表に定める残存割合を当該減価償却資産の所得税法施行令第百二十六条（減価償却資産の取得価額）…の規定による取得価額に乗じて計算した金額とする。」第2項：牛・馬は同項の金額と10万円のいずれか少ない金額。
