# impl-research4：仮説から導いた具体例と、検証の方法

- 種類：推測。前提の仮説：`docs/hypotheses/20261112_impl-research4_all-model.md`（以下 H1〜H12）。
- 金額は架空。個人の情報は使わない。

## I1（H1）未払給与の回収不能

- 例：ある年分の給与の収入金額 300万円（うち支給日がその年で未払のまま 30万円）、ほかの所得なし。翌年に勤務先が破産し、その30万円の弁済を受けられないことが明らか（所基通51-12 に準ずる）になった。
  - 給与所得の金額：収入 300万円のときを G(300万)、270万円のときを G(270万) とすると、令180②二 は G(300万) − G(270万)、令180②一 は総所得金額 G(300万)。いずれか低い方＝G(300万) − G(270万)。
  - その年分の給与所得は G(270万) になる（＝回収不能額を収入から除いたのと同じ）。申告済みなら、明らかになった日の翌日から2月以内に更正の請求。
  - 未払の部分は源泉徴収されていないので、H1-a により回収不能額等は30万円の全額。
- 例2：同じ30万円のうち 24万円を未払賃金の立替払で受けた。24万円は退職の日に支払を受けるべき退職手当等（措法29の4）。回収不能額等は残りの 6万円（立替払の後に残りが回収できないと明らかになった場合）。
- 検証の方法：作成コーナー（令和7年分、架空の数字）で、給与の収入金額を回収不能額だけ減らした値と、所令180② の式の値が同じになるかを手で確かめる（ユーザーの手の確認。D24①）。
  国税庁に「使用人の未払給与への法64①」の説明があるかを、質疑応答事例の一覧（所得税・各種所得）で再度探す。

## I2（H2）令和7年分の純損失の繰戻し（前々年分＝令和5年分）

- 例：令和5年分の課税総所得金額 400万円 → 195万円×5% ＋（330万−195万）×10% ＋（400万−330万）×20% ＝ 97,500 ＋ 135,000 ＋ 140,000 ＝ 372,500円（令和6年分の表と同じ）。
- 検証の方法：`scripts/IMPL4_verify_recheck.py` の CHECKS に asof 2023-03-31・2023-09-30 を足して、年の途中の版でも表が同じかを確かめる。国税庁の「令和5年分 所得税の税額表」（手引き）と照合する。

## I4（H4）学生等の第10号

- 例：看護師養成所（保健師助産師看護師法第21条第3号）→ 国年則77の6第5号 → 学生等（当たる）。
  認定日本語教育機関の、認定基準第17条第1項本文の課程 → 第25号の3（当たる）。それ以外の課程 → 第25号の3 には当たらない（ほかの号・各種学校の第9号を確かめる）。
  一時保護施設の養成施設 → 第29号の2（2026-04-01 から）。
- 検証の方法：日本年金機構の対象校一覧（エクセル）を取得し、施設の種類の欄と国年則77の6 の号の対応を確かめる。第34号の大臣指定の告示を官報以外の一次情報（厚生労働省の法令等データベース）で探す。

## I5（H5）施行前の出産と育児期間の免除

- 例：出産予定日 2026-05-15、第88条の2 の適用あり（第1号被保険者）。第88条の3第1項の期間は、3月を経過した日（2026-08-15）の属する月＝2026年8月から、12月を経過した日（2027-05-15）の属する月の前月＝2027年4月まで。
  附則第10条により 2026年10月以後の月に当てる → 免除は 2026年10月〜2027年4月の7か月（8月・9月は当てない）。
- 例2：出産予定日 2025-08-01 → 期間は 2025年11月〜2026年7月 → 2026年10月以後の月がないので 0か月。
- 検証の方法：日本年金機構「国民年金保険料の育児免除制度」のページ（`scripts/results/IMPL4_web_fetch/kokunen/nenkin_gakutokutaisyouko.txt` のリンクの一覧にある）を取得し、施行前の出産の扱いの説明と照合する。

## I7（H7）入院等の特例

- 例：A市で親と同じ世帯の被保険者が、B市の特別養護老人ホーム（措置入所）に入所し住民票を移した → A市の国保の被保険者（第116条の2①、第5号）。世帯は施設での世帯（事実）で、保険料の世帯主・平等割はその世帯で計算（法令の読み）。
- 例2：親（扶養義務者）と同じ世帯の子が、措置で他市の児童福祉施設に入所し住民票を移した → 元の市の被保険者（第116条の2①二）。世帯は「施設での世帯」と「親元の世帯」（柏市の運用）の両方で評価し、親元の世帯の平等割・世帯主への賦課などで保険料が分かれれば未確定（決める手段：市町村の運用の注入）。
- 検証の方法：厚生労働省の住所地特例の説明（国保の事務の通知。柏市の後段の根拠）を探し、世帯の扱いの記載と照合する。見つかれば公開資料の情報に足し、法令の読みの印を外すか決める。

## I8（H8）上場株式等の譲渡損失の繰越控除がある人の国保

- 例：前年の上場株式等の譲渡所得等 50万円、前年前3年内の繰越損失 80万円（申告の要件を満たす）→ 国保の所得割の算定基礎・軽減の判定の所得とも、上場株式等の譲渡所得等は 0円（繰越控除の後。残りの繰越損失 30万円）。
- 検証の方法：市町村の国保料の案内（注入データの出典になるもの）で「譲渡損失の繰越控除後の所得で算定」の記載を探す。国保税（地方税法703の4）の条文で同じ括弧書きがあるかを e-Gov で確かめる。

|---|---|

## I10（H11）所得税の共同募金会への寄附

- 例：共同募金会への 1万円 → 特定寄附金。寄附金控除は 1万円 − 2千円 ＝ 8千円（ほかの特定寄附金がなく限度内のとき）。指定寄附金か特定公益増進法人かで額は変わらない。
- 検証の方法：所法78② の本文（第2号・第3号）を e-Gov で取り直し、第3号の「業務に関連する寄附金」の要件が共同募金会への寄附で満たされない場合があるかを確かめる（満たされなくても第4号の2 の指定寄附金で当たるかを、寄附の使途で確かめる）。

## I11（H12）被扶養者の3か月の窓の例外

- 例：月額基準 108,334円。7月〜9月の平均が 115,000円、12月までは月 60,000円の勤務の予定で、認定日以後のどの12か月も 130万円未満の見込み。
  - FUKUOKA 型：判断「明らか」が入力されていれば例外（被扶養者のまま）、未入力なら取消し（10月1日）とそのままの両方で評価して未確定。
  - 広島大学支部の型：申立てをして12か月の見込みが基準未満なら被扶養者のまま。後で超えたら最初に月額基準以上になった月の給与支給対象期間の初日に遡って取消し。
- 検証の方法：福岡県市町村職員共済組合・文部科学省共済組合に「明らか」の判断の資料を問い合わせる（ユーザーの判断。自動では行わない）。協会けんぽ・健保組合の認定基準で3か月の窓を持つものを探す。
