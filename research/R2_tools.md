# R2 ツールの調査：OpenFisca-Core と plain text accounting

## 目的

D3（記録は plain text accounting）と D6（判定は OpenFisca-Core 上でスクラッチ）で使う2つのツールについて、
安全性・ライセンス・保守状況・適合性を確認し、採用してよいかを判断できる材料を作る。

**ユーザーのグローバル指示：** OSS は使う前にそのコードベースを確認し、致命的な安全上の問題がないかを確かめる。
問題があれば報告する。

## A. OpenFisca-Core

### 安全性

- 依存パッケージの一覧と、既知の脆弱性
- YAML の読み込みに安全な読み込み（`safe_load` 相当）を使っているか（パラメータもテストも YAML）
- 計算式やリフォームの読み込みで、`eval` / `exec` / 動的 import などを使っていないか。外部からの入力で任意のコードが実行される経路がないか
- Web API（`openfisca serve`）の初期設定：待ち受けるアドレス、CORS、認証の有無、リクエストの大きさや計算時間の上限
  - 機微な情報（所得、医療費）を流すので、外部に公開しない前提で、ローカルだけで待ち受けられるかを確認する
- 大きな入力や深い依存関係の計算で、止まらなくなったり資源を使い果たしたりしないか

### 適合性

- **グループ（エンティティ）を複数定義できるか。** 1人が複数のグループに同時に属せるか
  - 例：生計の単位、住民票上の世帯、健康保険の被保険者とその被扶養者。R4 のモデリングがそのまま載るかどうか
- 役割（ロール）の定義の自由度：1つのグループ内で、1人が複数の役割を持てるか
- 期間の扱い：年・月・特定の日。暦年（所得税）と、将来の見込み（社会保険の被扶養者判定）の両方を扱えるか
- パラメータの施行日の管理、改正（reform）の仕組み、テスト（YAML）の書き方
- 変数名・パラメータ名に日本語を使えるか（報告書では可能とされている）
- 名前空間がない問題（報告書 p.17-18）への対処法：拡張パッケージを分けるなど

### ライセンス・保守

- AGPL の範囲。自作パッケージにも AGPL が及ぶか。Web API を呼ぶだけの側（TS のクライアントなど）には及ばないか
- 最新のバージョン、対応する Python のバージョン、リリースの頻度、メンテナの状況

### 参考として：OpenFisca-Japan のコード（使わないが学ぶ）

- 報告書の主張（家族の単位が同居世帯だけ、「子」は未成年だけ、世帯主の簡略化）が、現在のコードでも成り立つかを確認する
- 所得税・住民税・社会保険料の実装のうち、参考になる部分はあるか（ライセンスに注意）
- リポジトリ：`project-inclusive/OpenFisca-Japan`（GitHub）

## B. plain text accounting（beancount / hledger / ledger から選ぶ）

### 比較する観点

- **日本語の勘定科目名を使えるか。**（beancount は勘定科目名の文字種に制約があるとされる。最新版で確認する）
- 「誰の取引か」の表し方：勘定科目の階層で表すか、メタデータやタグで表すか
- 証憑ファイル（領収書の画像など）を取引に結びつける機能があるか（beancount の `document` ディレクティブなど）
- D4 の「人の判断」を別ファイルに分けて、取引と結びつけられるか（取引IDなどの安定した識別子を振れるか）
- 中間表現（JSON）を作る集計を、どう書けるか（クエリ言語、プラグイン、エクスポート）
- 入出力の形式と、他のツールとの互換性

### 安全性

- beancount のプラグインは任意の Python コードを実行する。信頼できないファイルから、プラグインを読み込む指示（`plugin` 行）を受け付けてしまわないか
- 取り込み機能（CSV、OFX など）で、外部のファイルを処理するときのリスク
- 依存パッケージと、既知の脆弱性

### ライセンス・保守

- beancount（GPL）：v3 の状況（beanquery、beangulp に分割されたこと）
- hledger（GPL）、ledger（BSD）のバージョンと保守の状況

## 成果物

`AGENTS.md` のドキュメント規約に従う（title1 は `R2-tools` を推奨）。

- `docs/public-sources/`：コードを読んで分かったこと。確認したバージョン、コミット、見た箇所（ファイル：行番号）を必ず書く。OpenFisca-Core と plain text accounting で別ファイルにする
