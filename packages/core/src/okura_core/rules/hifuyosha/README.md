# rules/hifuyosha：健康保険・共済組合の被扶養者の判定

SCOPE §5.5：健康保険法の健康保険と共済組合（国家公務員・地方公務員・私学）の被扶養者の判定（判定日ごと、「今後1年の見込み」は判断台帳の値）。
保険者ごとの運用は注入するデータ。

状態（2026-11-12）：**実装・登録済み**（`rules/__init__.py`）。概念は 34 件（雛形の約束 13 件＋事実の層に足した 14 件＋共有の担当が足した窓口 3 件：
`健保.配偶者の収入の基準額`・`健保.同一の世帯の収入の割合`〔kokunen の第3号〕・`健保.年間収入が収入の基準額未満か`〔境目の説明〕＋2026-11-12 に足した境目の説明 4 件）。
問いの `dependent_judgment_dates` の判定日ごとに、全員の `健保.被扶養者に当たるか`・`健保.主として被保険者により生計を維持するか`・
`健保.年間収入`・`健保.収入の基準額` を出す（被扶養者として届け出ていない人は `被扶養者に当たるか` が偽）。

## 1. 持ち場

| する | しない（ほかの担当） |
|---|---|
| 判定日の被扶養者の判定（続柄の範囲・同一の世帯・収入の基準・2分の1・援助・国内居住・重複・夫婦共同扶養） | 第3号被保険者（kokunen。保険者の運用を使わない） |
| 被扶養者の所属（健康保険のグループ：被保険者・被扶養者・対象外）の組み立て | 所得税・住民税の値（健保は他の制度に依存しない：`concepts/structure.yaml`） |
| 保険者の運用の注入データの読み方と、未注入のときの運用の型の全部での評価 | 保険者のデータそのもの（注入データ） |

## 3. 判定の流れ

1. **割当て**（`健保.被扶養者の割当て`）：`選択.被扶養者の届出`（判定日を含む・真）＞ `medical_insurance`（capacity＝dependent）＞ `insurer_decision`（最新の認定・届出）。
   同じ順位で2人の被保険者に届け出ていれば、夫婦共同扶養なら主として生計を維持する者へ（このときは育児休業等で止めない）、それ以外は最初の被保険者に置き `選択.被扶養者の届出` の分かれ目で未確定。
   被扶養者を持つ被保険者は、ほかの人の被扶養者の役割に置かない。
2. **続柄**（`健保.被扶養者の範囲の親族か`）：健保は直系尊属・配偶者（事実婚を含む）・子・孫・兄弟姉妹が同居不要、共済は配偶者・子・父母・孫・祖父母・兄弟姉妹が同居不要（曾祖父母は同居要）。
3. **同一の世帯**：`判断.健保の同一の世帯` ＞ 保険者の運用（注入 `健保.同一の世帯の運用`）と事実（cohabitation・resident_record・separation_reason・
   `判断.一時的な別居`・institution_stay・dwelling_stay の site_id）。共済は `判断.共済の生計を共にする` も要る（運用方針 5「生計を共にし、かつ、同居」）。
4. **年間収入**：判定日が 2026-04-01 以後で、労働契約（labor_contract）が使え（給与収入のみの申立て・契約期間1年以上・シフト制でない・手当と賞与の金額が明確）、
   見込みに給与以外がなければ労働契約の額。それ以外は従来の方法：`見込み.年間収入`（when.on＝判定日）の種類ごとの額に保険者の運用
   （通勤手当・事業収入の経費・直近の確定申告）を当て、事業主の証明（連続2回まで）がない一時的な収入増を足し戻す。実績の窓の型なら判定日の前の月の給与で年額換算。
   直近の確定申告の運用の事業収入（business_receipt の実績）は、`判断.収入の恒常性` が一時的（temporary）とした受取を除く（2026-11-12：HF-14。§4）。
5. **基準額**：判定日で版を選ぶ（19歳以上23歳未満〔12月31日現在・配偶者を除く〕の150万円は 2025-10-01 から）。60歳以上（判定日の年齢）・障害者は180万円。制度ごとの出典（健保は通知、共済は大臣の定め）。
5の2. **夫婦共同扶養の主たる扶養者**（`inputs._kyodo_rule`）：①届け出た被保険者が育児休業等（`childcare_leave`）の期間中なら異動しない（別紙3。その休業の子
   〔`child_ids`〕は新たに誕生した子として②以下で判定。`child_ids` がなく結論が変わるなら分かれ目）、②共済の扶養手当の認定（別紙1(3)）、③保険者間の協議が整わない
   （`insurer_decision.attributes.joint_support_agreement` が偽）なら初めの届出〔notification_filed〕の日の属する月の標準報酬月額
   （`medical_insurance.amounts.standard_monthly_remuneration`）の高い方、同額は届出（別紙1(5)）、④年間収入の多い方（差が1割以内は届出）。
   私学共済は、認定対象者から見て加入者より近い親族等（配偶者〔事実婚を含む〕が最も近い。親等は民法第726条、中間表現の人に限る）が被用者保険の被保険者か、
   国保で収入が加入者より多ければ主たる扶養者でない（PMAC-01。組合の案内で「原文未確認」）。
6. **生計維持**：年間収入 ＜ 基準額（実績の窓も）で、同一の世帯なら被保険者の年間収入の2分の1未満（S52 ただし書を含む）、別居なら仕送りの基準の型（注入 `健保.別居の仕送りの基準`。
   未注入なら S52 を含む6つの型）。夫婦共同扶養で主でない・共済で他の者が扶養手当を受ける・`判断.主たる扶養者` が偽（共済）なら不可。
7. **被扶養者に当たるか**：割当て・制度・続柄（同居要なら同一の世帯）・国内居住・被保険者等でない（健保則第37条の3：`civil_status` の `designated_activity`
   が医療を受ける活動等・観光保養等で、`japanese_national` が真でない者を含む）・生計維持。
8. **境目の説明**：収入の基準（`健保.被扶養者の年間収入の基準`）、同一の世帯の2分の1（`健保.同一の世帯の収入の基準`：基準は被保険者の年間収入の2分の1の
   1円未満切上げ。整数の年間収入との「未満」の比較が同じになる額）、別居の仕送り（`健保.別居の仕送りの下限`：型ごとの援助の年額の下限。月額の型の上限の条件と
   S52 記1 のただし書は含まない）。どれも比較だけの判定の概念に付け、生計維持の判定そのものは変えない。
   2026-11-12：この3つの判定を `健保.被扶養者に当たるか` の直接の依存にした（`boundaries.undeclared`）。収入の基準額未満は生計維持の必要条件なので値に掛け
   （値は変わらない）、2分の1・仕送りの比較はただし書・型の条件があるので読むだけ。

材料が入力にないとき（`見込み.年間収入`・`見込み.援助額`・`見込み.被保険者の年間収入`・ただし書の判断・保険者が個別に判断する経費・重複）は、
その材料で結論が変わりうるときだけ入力に分かれ目（`missing`）を付け、依存する値を未確定にする（決める手段＝判断・事実）。
判断の1か所（`判断.共済の生計を共にする`・`判断.主たる扶養者`〔ただし書〕・`選択.夫婦共同扶養の届出`・`判断.国内居住の例外第5号`・`判断.障害の程度`・
`判断.健保の経費の費目`〔単調：差し引く・差し引かないの両端〕・`判断.収入が基準額以上とならないことが明らか`〔読んだときだけ開く。2026-11-12。FUKUOKA の型では「明らか」、広島大学支部の型では申立て〕・`判断.収入の恒常性`〔直近の確定申告の運用の受取に判断があるときだけ。読んだときだけ開く。2026-11-12〕）と注入点（保険者ごと・判定日）は、被扶養者の値が変わりうるときだけ宣言する（候補の直積を小さくする）。
`健保.年間収入の見込みの型` の候補は、このモジュールでの効き方が同じものを1つにまとめる（名前は「・」でつなぐ）。候補は8つ（2026-11-12 に文部科学省共済組合広島大学支部の申立書の型を足した：HF-08）。
実績の窓の例外は月額の連続超過の窓にだけ当て、任意の連続する12か月の実績の窓は当てたままにする（`calc.window_after_exception`）。

## 4. 読み（根拠に「法令の読み」の印）と、決めたこと

- 60歳の判定の時点は出典にないので判定日の年齢。19歳以上23歳未満で障害者は180万円（通知は130万円の区分だけを読み替える。共済は組合の案内 KT-943）。
- 労働契約の時給・日給の年額換算は52週（出典にない）。1円未満は根拠のない端数（`労働契約による年間収入の1円未満`）として候補で評価。
- 事業主の証明の「連続」は、証明の暦年が1年ずつ続く数（判定日の前の1年以内に今回の証明があること）。令和5年10月20日より前の証明は数えない。
- `見込み.年間収入` の事業・不動産の額は総収入の見込み。経費は business_expense（従来の方法は判定日から1年、直近の確定申告の型はその年分）を、
  `判断.健保の経費の費目`（2026-11-11 に中間表現に足した。expense_category → 保険者の表の費目の名前）で保険者の表に当てる。
- `判断.収入の恒常性`（J-29。2026-11-12：HF-14）：年間収入は「恒常的な収入の状況」で算定し、恒常的な収入は「継続して入るもの」（昭和61年 庁保発第18号を引く
  日本年金機構の疑義照会回答 整理番号6・8：`docs/public-sources/20261109_round2_gaps-sources.md` §6.3）、一時的な収入は含めない（組合の基準：
  `docs/public-sources/20261109_round2_kyosai-law-and-criteria.md` §6.2）、確定申告の事業収入は「今後も同程度の収入が見込まれる場合」に恒常的とみなす（同 §6.3 FUKUOKA-KIJUN 第3 5(3)）。
  これを、記録の実績から年間収入を作る箇所のうち **直近の確定申告の運用の事業収入**（business_receipt）に当てる：一時的とした受取を総収入から除き、恒常的・判断なしは含める
  （判断がないときの扱いは運用の定め〔確定申告の総収入〕どおりで、候補を広げない。食い違う判断があれば違う値の候補で評価する：lazy な1か所）。根拠に法令の読みの印。
  効かない箇所（法令の読み）：`見込み.年間収入` の額（記録でなく見込みそのもの。一時的な収入は見込みに入れない）、実績の窓の給与（窓の運用は超えれば「恒常的に超える
  ものとみなす」ので、一時的かは事業主の証明・`判断.収入が基準額以上とならないことが明らか` で受ける）、労働契約による判定（契約の賃金で決まる）、経費（business_expense。
  経費が一時的かで差し引くかを決める一次情報がない）。これらの記録への判断は値を変えない。
- 援助額は `見込み.援助額`、なければ判定日の前の1年の送金の実績。手渡しを認めない運用では現金・現物の送金を除いた実績。
- S52 ただし書の「世帯の生計維持の中心的役割」は中間表現に語彙がないので `判断.主たる扶養者`（person＝認定対象者、supporter＝被保険者）で受ける。
- 夫婦共同扶養：共済の組合員で扶養手当の認定を受けている側を主（別紙1(3)「差し支えない」）。一方が国保なら同額は届け出た側。
- 国内居住：`判断.住所の所在` ＞ 住民票 ＞ abroad_stay。国外の留学・赴任に同行・観光等（abroad_stay の purpose）は例外、それ以外は `判断.国内居住の例外第5号`。
- 船員保険の被保険者の被扶養者は範囲外（SCOPE §5.5）としてその人の値を対象外にする。

## 5. 未決・申し送り（実装していないもの）

- 境目の説明：収入の基準・2分の1・仕送りの下限を出す（§3-8）。実績の窓（`健保.実績による年額`。0 は「窓の型でない・窓で超えない」）には境目を付けていない
  （0 を基準と比べる説明が誤解を招くため。対象外は返さない）。
- 第3号被保険者への部品：`健保.配偶者の収入の基準額`・`健保.同一の世帯の収入の割合` を kokunen が引く（名前を変えない）。kokunen は 判断.障害の程度 の1か所を
  このモジュールと同じ key（`<人>:<判定日>`）で宣言する。
- 判定日の範囲（2025-01-01〜2027-12-31）は仮（`timepoints.SUPPORTED_JUDGMENT_DATES`。共有）。
- 2026-11-12：共有の変更が要るとしていた HF-03・HF-04・HF-08 を、足された注入点・語彙でつないだ（下の一覧）。範囲内なのに未対応の (c) は 0。
- 夫婦の一方が国保で協議が整わず、直近の課税（非課税）証明書の所得金額が同額のときの扱いは通知（別紙2(3)）に書かれていないので分かれ目（一次情報）。
