## 1. 方法

- 担当のスクリプト・出力・抜き出したテキストを使わず、一次情報を **取り直して** 確かめた。担当のスクリプトは import も実行もしていない
  （e-Gov の JSON の読み方は `scripts/R1_egov_articles.py`・`scripts/IMPL_kyuyo_fetch.py` を参考に書き直した）。
- 担当の検査（`_checks.py` など）は「条の全体に文字列が含まれるか」を見ていて、**項・号の番号は機械的に確かめていなかった**。この検証は、文書が書く
  条・項・号の単位で、その位置に文字列があるかを確かめた（例：V1-08 は第317条の2 の **第8項** にあるか）。
- PDF の文字の取り出しは自前で書き直した（担当の `_pdftext.py` とは別の実装：ファイルの中の obj と ObjStm を読み、頁木をたどり、ToUnicode で文字にする）。
  令和8年法律第2号の本文 PDF の p.224・p.225 は、Read ツールで頁の画像としても読んだ（§4 の E1）。
- HTML は自前の html.parser でテキストにした（画像の代替テキスト（alt）も `[alt]…[/alt]` として残す）。
- 計算例は、附則第5条の4・第314条の9 の式を条文から書き直して再計算した（担当のコードは使っていない。`cases.md`）。
- ダウンロードしたもの（信頼できないデータ）は、ダウンロードごとに新しい空のディレクトリに置いた。中では何も実行していない（スクリプトはリポジトリのルートで動き、パスを受け取って読むだけ）。
