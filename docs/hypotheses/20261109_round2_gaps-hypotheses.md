## HG1 勤労学生の「自己の勤労に基づいて得た」は、所得区分から決められない。所得の源ごとの人の判断（D4）として受け取る

- 根拠：所得税法第2条第1項第32号は「自己の勤労に基づいて得た事業所得、給与所得、退職所得又は雑所得」と書くが、所得税法の中にこの語を定義・説明する規定はない［M］C1、［PS］§1.1。所得税基本通達の勤労学生の項（2−43〜2−45の２）にも範囲を示す項はない［PS］§1.2。国税庁は「給与所得などの勤労による所得」「勤労によらない所得」と書くだけで、アフィリエイト・広告収入・物品販売などの例はない［M］C1 の表、［PS］§1.3。アフィリエイトなどは「原則、事業所得又は雑所得（業務）」とされている［PS］§1.4 が、これは所得区分の説明で、「勤労に基づく」かとは別の問いである。一次情報は見つからなかった［PS］§1.5。
- 内容：
  1. 所得区分（事業・業務に係る雑・その他の雑）は既存の設計どおりコアが判定する（事業と言える程度かは D4）。そのうえで、**事業所得・雑所得の源（取引先・事業の単位）ごとに「自己の勤労に基づくか」を D4 の判断として受け取る**。値は「基づく」「基づかない」「未判断」。
  2. 給与所得・退職所得は、国税庁の説明が「給与所得などの勤労による所得」と書く［PS］§1.3 ので、既定で「基づく」とする（ただし既定であることを根拠に表示する）。
  3. 「未判断」の源があるとき、コアは「基づく」「基づかない」の両方で評価し、結論（勤労学生に当たるか、それに依存する値）が同じならその結論を返し、違えば「未確定」と、どの源の判断が結論を分けるかを返す（D19 の「取りうる範囲で評価、決まらなければ未確定」と同じ扱い）。
  4. 「給与所得等以外の所得に係る部分の金額」（10万円以下の判定）は、「基づかない」と判断された事業所得・雑所得と、給与所得等以外の所得の金額で計算する。事業所得に損失がある場合の計算は所得税基本通達 2−44 による［PS-ZG］§6.2。
- 反証になるもの：「自己の勤労に基づいて得た」の範囲を示す通達・質疑応答・裁決が見つかり、所得区分だけで決まる（例：事業所得・雑所得はすべて当たる）と書かれていること。そのときは D4 の判断をやめ、規則としてコアに置く。
- 実装に向けて：

| 区分 | 内容 |
|---|---|
| 入力として必要な事実 | 12月31日の在学（学校の種類：学校教育法第1条の学校か、専修学校・各種学校・認定職業訓練か、課程）、所得の源ごとの収入・経費（明細）、給与・退職の収入 |
| 人の判断（D4） | 事業所得か業務に係る雑所得か（既存）、**源ごとの「自己の勤労に基づくか」**、専修学校等の課程の要件を満たすか（証明書の有無は事実） |
| コアに置く構造 | 合計所得金額の要件（令和7年分 85万円、令和8年分 89万円）、給与所得等以外 10万円、12月31日の現況、2−44 の損失の扱い、「未判断」のときの両方評価と未確定。住民税（地方税法第314条の2第9項が所得税法の定義を準用）と国民年金の学生納付特例でも同じ判断を使う［PS-JU］§5、［PS-ZG］ |
| 注入するデータ | なし（国の法令だけで決まる） |
| 一次情報で決まらないこと | 「自己の勤労に基づく」の範囲そのもの（上の D4）。端数はない（金額の比較だけ） |

## HG2 TA No.1810 の令和7年分の（注）は、改正前の1文の形を引き継いだ書き方で、扶養の上限は条文どおり 123万円（令和7年分）・131万円（令和8年分）とする

- 根拠：
  - 条文の値からは、家内労働者等の特例の所得しかない人の総収入金額で、扶養控除・配偶者控除の対象の上限は 令和7年分 123万円・令和8年分 131万円、本人に所得税がかからない上限は 160万円・173万円［M］C2、［PS］§2.3。
  - 現在の TA No.1810 は、令和8年分を2つの文（173万円／131万円）で書き、令和7年分の（注）だけを1つの文（160万円で両方）で書く［PS］§2.1。
  - 令和7年4月1日現在の版（Internet Archive の保存。2026-09-15 の保存が現在の配信とバイト列で一致したことから、保存の忠実さはある程度確かめた［M］§3）は、令和7年分を「160万円以下…本人に所得税は課されません。また、…123万円以下の場合は、…配偶者控除あるいは扶養控除の対象」と2つの文で書いていた［PS］§2.2。
  - 令和6年分以前の文は1つの文だが、その年分は2つの上限が同じ値（103万円）だった［PS］§2.2、［M］C2。
- 内容：
  1. 現在の（注）の「160万円以下…扶養控除の対象」は、令和8年分の本文を書き換えたときに、令和7年分を改正前の1文の形（103万円の文）に合わせて書いたためにできた食い違いで、扶養の上限を示す意図ではない（I）。160万円が指すのは「本人に所得税がかからない上限」だけである。
  2. コアは TA の金額を使わず、条文の値（特例額、扶養親族の要件、基礎控除）から計算する。境目の説明（D19）では、2つの上限を別々に出す。
  3. 令和7年分で総収入が123万円を超え160万円以下（特例の所得だけ）の人は、本人の所得税はかからないが、扶養親族・同一生計配偶者には当たらない。19歳以上23歳未満なら特定親族、配偶者なら配偶者特別控除の対象になりうる［M］C2。
- 反証になるもの：令和7年分について、家内労働者等の特例の所得しかない人を扶養親族とする特別の規定（経過措置など）。既存の調査の附則の範囲には見当たらない［PS-JG］§2.1。国税庁が（注）を正しいとして説明する資料。
- 付記（既存の未解決への参考）：令和7年4月1日現在の版は、給与がある場合を「給与の収入金額が65万円以上あるときは、この特例は受けられません。…給与所得控除額が65万円以上ある場合（つまり、給与の収入金額が65万円以上ある場合）」と書いていた［PS］§2.4。これは、令和7年分の措法27 の「給与所得控除額」を、給与の収入金額が65万円未満なら収入金額と同額として読む書き方で、既存の仮説 `docs/hypotheses/20261109_impl-prep_jigyo-calculation-model.md` H2 の既定（給与の収入金額を使う）と合う（国税庁の通達ではなく、保存版の TA の書き方である）。

## HG3 所得金額調整控除は、国の法令だけで決まる構造としてコアに置く。人をまたぐ依存（23歳未満の「扶養親族」）があり、端数の切上げは TA だけが根拠

- 根拠：租税特別措置法第41条の3の11 は令和6年分〜令和8年分の版で本文が同一で、令和7年分・令和8年分の要件と額は同じ［M］C3、［PS］§3.1。
  - 第1項：給与等の収入金額 850万円超で、本人が特別障害者、または**年齢23歳未満の扶養親族**、または特別障害者である同一生計配偶者・扶養親族を有する者 → （min(給与等の収入金額, 1,000万円) − 850万円）× 10/100 を給与所得の金額から控除。
  - 第2項：給与所得控除後の給与等の金額と公的年金等に係る雑所得の金額の**両方がある**者で、合計が10万円を超える者 → min(給与所得控除後, 10万円) ＋ min(公的年金等の雑所得, 10万円) − 10万円 を、第1項の控除後の給与所得の金額から控除。
  - 判定の時点はその年12月31日（死亡・出国はその時）［PS］§3.1 第3項。扶養親族は所得税法第2条第1項第34号の扶養親族（第4項第3号）。
  - 総所得金額の計算（所得税法第22条）の「給与所得の金額」を控除後の額と読み替える（第5項）。第2項の控除は確定申告不要の判定（所得税法第121条第3項）にも効く（第6項）［PS］§3.1。
  - 令和8年分は、措法第29条の4第2項（給与等の収入金額 69万1千円以上220万円未満）の適用がある場合、第2項の「給与所得控除後の給与等の金額」を同項による給与所得の金額と読み替える（措令第19条の4の2。asof 2026-12-31 版にあり、asof 2025-12-31 版にない。措法第29条の4 自体が「令和八年又は令和九年において」の規定）［PS］§3.3。
  - 年末調整で扱えるのは第1項だけ（措法第41条の3の12）［PS］§3.2。
  - 2人以上の居住者の23歳未満の扶養親族に当たる者がいれば、どちらの居住者も要件を満たす（措通41の3の11−1、TA No.1411 の夫婦の例）［PS］§3.4・§3.5。
  - 条文・政令・省令に端数の定めはなく、TA No.1411 だけが「1円未満の端数があるときは、その端数を切り上げます」と書く［M］C3、［PS］§3.5。
- 内容：
  1. 所得金額調整控除は「給与所得の金額」を減らすので、総所得金額と合計所得金額（所得税法第2条第1項第30号イ(2)：第22条の総所得金額等の合計［PS-CON］）も減ると読む（I）。したがって計算の順は「給与所得 → 所得金額調整控除 → 総所得金額・合計所得金額 → 人的控除・扶養判定」で、SCOPE.md の層の規則（所得区分ごとの所得 → 中心の概念）に合う。
  2. 第1項の「23歳未満の扶養親族を有する」は、**扶養される側の合計所得金額（58万円・62万円）で決まる扶養親族**であり、扶養控除の申告でだれの控除対象扶養親族にしたか（所属）とは関係がない（措通41の3の11−1）。年齢16歳未満の子も扶養親族に含まれる（第4項第3号が引く所得税法第2条第1項第34号の扶養親族には年齢の要件がなく、年齢16歳以上の要件は第34号の2 の控除対象扶養親族のもの［PS-IT］§4 の表）。所得税法第85条第6項（二以上の居住者の扶養親族に当たる者は、いずれか一の居住者の扶養親族にのみ該当するとみなす［PS-IT］§4）とは別に、措通41の3の11−1 は「これらの居住者はいずれも…扶養親族…を有することとなることに留意する」とする［PS］§3.4 ので、所属の割当て（SCOPE.md の扶養の重複・連鎖）の結果をこの判定には使わない。人をまたぐ依存（子の合計所得金額 → 親の給与所得）として概念辞書に明記する。
  3. 端数の切上げは、名前つきの関数（例：`所得金額調整控除.第1項の端数＝1円未満切上げ`）にし、出典を「TA No.1411（法令の文言にはない）」とする（D13）。
  4. 公的年金を対象に含める決定（D20）により、第2項も第1段で必要になる。
  5. 住民税で同じ控除がどう扱われるかは、地方税法に「所得金額調整控除」の語がないため［M］C3、［PS］§3.6、本調査では決められない（住民税の担当の調査に渡す）。
- 反証になるもの：端数を切り捨てる（または端数を生じさせない）と定める法令・通達。合計所得金額の計算で所得金額調整控除を差し引かないとする規定。

  2. 同じ改正で、令和8年分以後の確定申告書（2027-01-01 以後の提出）では、社会保険料控除・小規模企業共済等掛金控除・生命保険料控除・地震保険料控除の証明書類の添付・提示に代えて明細書を添付できる（所法120⑥）。出力の整形で、令和8年分から明細書の形を選べることを持つ必要がある（明細書の記載事項は所規第47条の2 の新しい項。本調査では読んでいない）。

## HG6 健保の「今後1年間の見込み」は、収入に波がある人でも計算式が一次情報で決まっていない。コアは見込みを作らず、判断（D4）と、見込みの作り方の記録と、保険者ごとの確認方法（注入データ）を分けて持つ

- 根拠：
  - 原則：過去の収入・現時点の収入・将来の収入の見込みなどから今後1年間の収入を見込む（令和2年4月10日 事務連絡 記2、ワクチン特例 Q&A A1、日本年金機構の Q&A）［PS］§6.1・§6.2・§6.5。機構の疑義照会回答は「認定対象者が被扶養配偶者に該当する時点での**恒常的な収入**の状況により算定」「継続して入るもの」と書く［PS］§6.3。
  - 一時的な増加：直近3か月の収入を年収に換算して130万円以上となっても直ちに取り消さず、過去の課税証明書・給与明細書・雇用契約書等と照らして総合的に判断する。過去1年間の収入が一時的な事情でその1年だけ上がって130万円以上になっても、原則として遡って取り消さない（令和2年4月10日 事務連絡 記3・記4、令和3年2月12日 再周知）［PS］§6.1。
  - 保険者ごとに確認の時期と書類が違う（直近3か月の収入証明、直近1年間、年度当初からの通算、毎月の給与 108,334円、課税証明書、給与支払見込証明書）。厚労省の Q&A は「各保険者の判断」とする［PS］§6.2。
  - 自営業の収入：確認書類は直近の確定申告書［PS］§6.5。総収入から売上原価を差し引き、社会通念上明らかに必要な経費だけを控除し、減価償却費は控除できない（疑義照会回答 整理番号6）［PS］§6.3。協会けんぽの除外経費の例は［PS-K］§1.2。
  - 将来の分かっている変化は見込みに入る（整理番号1：3月31日をもって障害年金の加給金がなくなり、その結果180万円未満になるなら4月1日から認定してよい）。一時金で恒常的でない収入は年間収入に入らない（整理番号7）［PS］§6.3。
  - 収入に波がある人の計算式を定めた厚労省・機構・協会けんぽの一次情報はない。総務省は2011年に、機構の業務マニュアルに「日額や月額に変動が大きい場合の対応方法」が明示されていないと指摘したが、その後マニュアルにどう書かれたかは公表資料から分からない［PS］§6.4・§6.7。
- 内容：
  1. 既存の仮説（`docs/hypotheses/20261109_impl-prep_kenpo-input-facts.md` HK2：見込みは収入の種類ごとの D4 判断）を保ち、**コアは見込みの値を作らない**（D19：見込みの作り方はアプリの責務）。
  2. D4 の見込みには、値のほかに「見込みの作り方」の記録を付ける：材料にした期間（例：前年1〜12月、直近3か月、判定日以後の契約）、方法（実績の合計、月平均×12、契約からの計算、季節の型を当てはめたもの など）、使った証憑（確定申告書、課税証明書、給与明細書）、一時的と判断した増加とその理由、分かっている将来の変化。コアはこれを結果の根拠にそのまま載せ、「見込み」の印を付ける（D19）。
  3. **保険者ごとの確認方法は注入するデータ**（D17・D19）：確認の時期、見る期間（直近3か月・直近1年・年度の通算）、連絡の基準（月額など）、求める書類、事業収入から差し引ける経費の範囲。コアはこのデータがあれば「その保険者が見る期間の実績を年換算した目安」を見込みとは別の値（目安）として出してよいが、見込み（D4）を置き換えない。データがなければ目安を出さない（既定値を使わない）。
  4. 見込み（D4）がない判定日は、収入の要件について「未確定」を返す。ただし、どの作り方でも同じ結論になる場合（例：どの期間で年換算しても基準を大きく下回る）を「取りうる範囲で評価」して結論を出せるかは、アプリが作った複数の見込み（シナリオ）を一括評価する形で扱う（D19）。コア自身は作り方を列挙しない。
  5. 実績が基準を超えた過去の期間について、コアは「遡って外れる」とは判定しない（記4）。外れた日は保険者の決定（事実）として受け取る（既存の推測 `docs/inferences/20261109_impl-prep_kenpo-test-cases.md` の候補日の扱いと同じ）。
  6. 事業収入の年間収入は、税の事業所得とは別の量（総収入 − 売上原価 − 社会通念上明らかに必要な経費。減価償却費・青色申告特別控除などは引かない）として、健保の系統で計算する。経費の科目ごとに「差し引けるか」は保険者ごとの注入データ、判断の分かれる科目は D4。
- 反証になるもの：収入に波がある人の見込み方（期間・換算方法）を定めた厚労省の通知・事務連絡、または機構の公表資料が見つかること。そのときは、その方法を「既定の目安」としてコアに置くかを検討する（それでも保険者の判断を置き換えない）。

| 区分 | 内容 |
