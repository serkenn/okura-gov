## SH0 全体の形：死亡・出国の申告は「年分の計算」に7つの差分を足したもので、すべて国の法令で決まる

- 根拠：［M］§3.3（所法124〜127 は第二節「確定申告並びにこれに伴う納付及び還付」の第二款「死亡又は出国の場合の確定申告」）、［M］§5.1 T01・T02、［PS］§1・§2・§3・§11。
- 内容：
  1. (F) 所法124〜127 の申告書は「確定申告書」（所法2①三十七は第二節の第一款・第二款の申告書を引く）。所法70・71（繰越控除）、所法140（繰戻し）の「確定申告書を提出する居住者」「青色申告書を提出する居住者」の文言は、死亡・出国の申告書にもかかる。
  2. (I) したがって、所得・損益通算・繰越控除・所得控除・税率は通常の年分と同じ規則を使い、次の7つだけを足す：
     (a) 本人の所得の期間の終わり（死亡の日・出国の時。SH2）、(b) 判定の時点（SH2・SH3）、(c) 所得控除の対象になる支払の期間（SH2）、
     (d) 法令が求める見積り（SH4）、(e) 申告する人（相続人）と按分（SH6）、(f) 期限（SH5）、(g) 適用する法令の版が提出日で決まる場合（SH7）。
  3. (F) どれも国の法令・通達・国税庁の資料で決まり、市町村・保険者の注入データは要らない。
  4. (I) 申告の種類を概念にする：`所得税.申告の種類` ＝ 確定申告（所法120・122・123）／死亡の翌年の申告（所法124）／死亡の年の申告（所法125）／出国の翌年の申告（所法126）／出国の年の申告（所法127）。
     「準確定申告」は所法172（非居住者）の申告書の名にも使われる（［PS］§11）ので、ID に使わない。所法172 の申告は対象外（D20）。
  5. (I) 判定コアは、事実（死亡日・出国・提出した申告書）から申告の種類を導く。利用者が種類を指定するのではない（指定と食い違えば印「食い違い」）。

## SH2 期間と判定の時点は、人と年分ごとの1つの関数 `判定時点(人, 年分)` で決める

- 根拠：［PS］§4.1（所法85①③）、§4.2（所基通85−1、72−4）、§2.2（所基通124・125−4）、§3.1（所法127①）、§3.2（所基通127−1）、§5、［M］§5.1 T06・T07・T14、§5.5。
- 内容：
  1. (F) `判定時点(人, 年分)` ＝ その年の中途に死亡 → 死亡の日、その年の中途に出国 → 出国の日、それ以外 → 12月31日。
  2. (F) 本人の所得の期間は 1月1日 〜 判定時点（所法127① は文言で、死亡は［TA2022］の「1月1日から死亡した日までに確定した所得金額」）。
     (I) 死亡の日の後の日付で死亡した人に帰属する収入・支払が入力にあれば、入力の検査で止める。死亡の後に受け取る収入（未払の給与など）が誰の何の所得かは取得した資料で決まらないので、そうした入力は「対象外」と返す。
     〔検証で追記：所基通9−17（［PS］§2.2）は、死亡後に支給期の到来する給与等・公的年金等・退職手当等で相続税の課税価格の計算の基礎に算入されるものには所得税を課さないとする。この種類は「対象外」ではなく「所得税の計算に入れない（通達）」と扱える。支給期の定め（所基通36−9 ほか）と、それ以外の種類（事業の未収金など）は未取得。扱いはユーザーの判断：［M-VER］§8〕
  3. (F) 所得控除の対象になる支払（雑損失、医療費、社会保険料・小規模企業共済等掛金・生命保険料・地震保険料、特定寄附金）は判定時点まで（所基通124・125−4、出国は127−1 で準ずる）。
  4. (F) 親族が生計を一にしていたか・親族関係にあったかは判定時点の現況、その前に死亡した親族はその死亡の時（所基通85−1(1)、所法85③ただし書）。
  5. (I) 年齢も判定時点で数える（所法85③ の判定に老人・特定扶養親族・控除対象扶養親族の年齢の区分が含まれ、その区分は所法2①三十四の二〜四 の年齢で決まる：［M］§5.1 T14）。年齢の数え方は［PS-MISC］§1 の方法。境をまたぐ例は［M］§5.5。
  6. (F) 本人の障害者・寡婦・ひとり親・勤労学生の判定は判定時点（所法85①）。
  7. (F) 親族の合計所得金額は、判定時点の見積りで 1月1日〜12月31日（SH4）。

## SH3 所法85②③ の「その年十二月三十一日」は、① の括弧書きにより、死亡・出国した居住者については死亡・出国の時と読む

- 根拠：［PS］§4.1（所法85①〜③ の本文）、§4.2（所基通85−1、79−2）、§2.3［TA2022］（4）、［M］§5.1 T06・T07。
- 内容：
  1. (F) 所法85① の括弧「（その者がその年の中途において死亡し、又は出国をする場合には、その死亡又は出国の時。以下この条において同じ。）」の「以下この条において同じ」が、②③ の「その年十二月三十一日」にかかる（本文の構造。全時点で同文）。
  2. (F) ③（配偶者・扶養親族・特定親族）については、所基通85−1 と［TA2022］（4）が同じ扱いを明示している。
  3. (I) ②（同一生計配偶者・扶養親族が障害者・特別障害者・同居特別障害者に当たるか）について死亡・出国の時で判定することを明示した国税庁の資料は、取得した範囲にない。所基通79−2 は、死亡・出国した居住者が障害者控除を受けたことを前提に書いている。② も ① の括弧で読むが、結果に印「出典未確認（読み）」を付ける。
  4. (F) 死亡の申告の条文（所法125）には「現況」の語がなく、判定の時点は所法85 からだけ来る。出国の申告の条文（所法127①②）は「その時の現況により」と書く（［M］§5.1 T06）。
- 根拠の種類（〈OUT〉の語）：③ は法令＋法令解釈通達＋国税庁の説明、② は法令（読み）。

## SH4 法令が求める見積り（D21 R2）：死亡・出国した本人の申告での親族の所得の見積りを、判断台帳の別の種類として持ち、印を付けて申告用の値まで流す

- 根拠：［PS］§4.2（所基通85−1(2)、72−4(2)、83から84の2−1、79−2）、§2.3［TA2022］（4）、§3.2［TA1920］、［PS-SP］§1.8（TA1191 の Q&A Q3：判定後に偶発的に配偶者に所得が生じても判定に影響しない）、［M］§5.2（取得した資料で「見積り」が求められるのは2か所だけ）、［M］§5.7（比べる上限が提出日で変わる）。
- 内容：
  1. (F) このトピックで法令（通達・国税庁の説明）が見積りを求める値は2つ：
     (a) 死亡・出国した本人の申告で、親族等の 1月1日〜12月31日 の合計所得金額。同一生計配偶者・生計を一にする配偶者・扶養親族・特定親族に当たるかの判定と、合計所得金額の段階で額が変わる控除（配偶者特別控除・特定親族特別控除）の額に使う。
     (b) 同じ申告の雑損控除で、資産の損失の対象になる親族の総所得金額等の合計額（所基通72−4(2)）。
  2. (F) 見積りでないもの：本人の所得と支払（判定時点までの実績）、生計・親族関係・年齢（判定時点の事実）。
  3. (I) 記録：判断台帳に新しい種類 `見積り.<名前>`（例 `見積り.親族の合計所得金額`、`見積り.雑損控除の親族の所得`）を置く。D19 の `見込み.<名前>`（予測）とは別の種類にする（D21 R2）。
     項目：対象の人（見積りを使う本人と見積もられる親族）、年分、**見積りの基準時点**（死亡の日・出国の日。SH2 の判定時点と一致しなければ入力の誤り）、見積った値（合計所得金額、又は所得の種類ごと）、
     見積った人（相続人・本人）と日時（D12。基準時点より後になるのが普通）、材料（基準時点までの実績の事実 ID、基準時点で分かっていた将来の事実）。
  4. (I) 判定コアの扱い：
     - 見積りを使うのは、死亡・出国した本人の、その年分の判定だけ。
     - 値に印「法令が求める見積り」を付け、依存する値（控除の額、所得控除の合計、課税所得、税額、欄値）に伝える。欄値表（申告用の値）は止めない（D21 R2、〈OUT〉§1.2）。
     - 親族の実績が後で記録されても、本人の年分の判定は見積りのまま（TA1191 Q3）。基準時点までの実績（記録）と見積りが整合しない（例：基準時点までの給与だけで見積りを超える）ときは、印「食い違い（入力と記録）」を情報として付ける（止めない）。
  5. (I) 同じ親族について、見積りを使わない判定：親族本人の申告（実績）、相続人など他の居住者の12月31日の判定（所基通83から84の2−1・79−2。実績で判定）、住民税（前年の実績）、健保の被扶養者（D19 の見込み）。
  6. (I) 見積りが入力されていないとき（D21 R6）：ありうる場合の全部で評価する。
     - 親族の所得が、年の残りで減ることのない種類だけ（給与・公的年金等のように、収入が増えても所得が減らないもの）で、判定時点までの実績だけで上限を超えている → 「当たらない」と断定（根拠に「見積りなしで、基準時点までの実績が上限を超えた」と書く）。
     - それ以外（事業・不動産など年の残りで損失が出うる所得がある、又は実績が上限以下）→ 「未確定（判断）」と、`見積り.親族の合計所得金額` を入力すれば決まること、境目（上限の値）を返す。
  7. (F) 比べる上限は提出日で変わることがある（令和8年分：2026-11-30 以前の提出で 58万円、2026-12-01 以後で 62万円。［M］§5.7、SH7）。

  8. (I) 出国する人の年末調整の見積り（［TA1920］）は源泉徴収の側の話で、判定コアの範囲外（申告の値には使わない）。

## SH6 相続人の按分と端数

- 根拠：［PS］§2.1（所規49①三、所令263②③、267⑤、通則法5②③）、§2.2（所基通124・125−3）、§2.3（［付表の書き方］［付表］）、［M］§4 [5]。
- 内容：
  1. (F) 納付：所得税と復興特別所得税の合計（100円未満切捨て後）を相続分で按分し、各人 100円未満切捨て（所基通124・125−3）。根拠の種類は通達なので、印「端数の根拠が法令以外」（D21 R5）。
  2. (F) 還付：相続人等の協議で分割していればその割合、なければ相続分で按分し、各人 1円未満切捨て（［付表の書き方］）。根拠の種類は様式・記入要領なので同じ印。
  3. (I) 切り捨てた差（［M］§4 [5] の 100円・1円など）は、誰かに寄せる根拠が見つからないので寄せない。各人の額と差を出す。
  4. (I) 相続分は入力（法定／指定の区別と、有理数の割合）。判定コアは合計が1であることを検査する。民法第900条〜第903条は取得していないので、法定相続分を家族の構成から計算しない。相続放棄した人は相続人から除いた相続分で入力する（［付表］の注は放棄した人の記入を要しないとする）。限定承認はその旨を記載事項として写す（所規49①二）。
  5. (F) 相続人が2人以上なら連署の1通、又は他の相続人の氏名を付記して各別に提出（所令263②）。判定コアは提出の形を事実として受けるだけ。
  6. (I) 純損失の繰戻しの還付請求書の「各相続人別の還付を受けようとする所得税の額」（所規54②四）の決め方は見つからない。入力（相続人の選択）にし、なければ相続分で按分した値を候補として出し、印「出典未確認」を付ける。

## SH8 非居住者の期間がある年、納税管理人を届け出て国外に移る場合、国外転出時課税は対象外（D20）

## SH9 相続人による純損失の繰戻し還付（所法141①④、所基通140・141−1）を対象に含める

- 根拠：［PS］§9（所法141①〜④、所令272②・273、所規54②、所基通140・141−1、70−15）、［PS-AO］§5.3（所法140、所令271・272①、所基通140・141−2〜4、記載要領）、［M］§4 [6]、§5.1 T08・T09、§5.6。
- 内容：
  1. (F) 3つの経路：
     - (a) 所法141①：死亡の年の純損失 → 被相続人の前年分。要件：死亡の年の申告書（所法125①③⑤）が青色申告書、前年分が青色申告書、その申告書を提出期限までに提出（やむを得ない事情の認定は税務署長。所法141③）。
     - (b) 所法141④：死亡の前年の純損失（死亡の年に所法70①で控除したものと、既に繰戻しの基礎にしたものを除く）→ 前前年分。要件：前年分と前前年分が青色申告書、死亡の年分の確定申告期限（所法2①四十一 により所法125① の期限）までに請求。
     - (c) 所基通140・141−1：翌年1月1日〜提出期限に死亡し、相続人が前年分を所法124 で青色申告書として出すとき、前年の純損失を前前年分へ所法140①。
  2. (F) 計算：〈AOI〉H9 の関数（課税標準1,000円未満切捨て → 所法89 → 100円未満切捨て、限度は前年分の税額控除後の所得税額）を被相続人の年分の値で使う。所法141④ は所令272② で前前年分を基礎にし、前前年分に既に所法140①・141① を適用していればその純損失を控除した後の額を使う。
  3. (F) 死亡の年の後に残る純損失は相続人が使えない（所基通70−15）。(I) 結果に「消滅（相続人に引き継がない）」と理由を出す。前年が赤字なら所法141① の還付は 0 で、死亡の年の純損失はそのまま消える（［M］§5.6）。
  4. (I) 繰り戻す額は相続人の選択（〈AOI〉H9）。選択がないときの扱いは〈OUT〉の未決（選択に D21 R6 を当てるか）に従う。
  5. (I) 相続人別の還付の額は SH6-6。期限内の判定は SH5（相続人ごと、条件つき）。
  6. (I) 出国の申告書（所法127）で所法140① の繰戻しを請求できるか：所法127 の申告書は確定申告書（T01）で、出国の時まで居住者なので、所法140①④ の文言に当たると読める。国税庁の説明は見つからない（［PS］§12）ので、計算はするが印「出典未確認（読み）」を付ける。所法141 は所法127 を引かない（T08）。
  7. (F) 復興特別所得税は繰戻しの還付の対象にならない（〈AOI〉H9 と同じ。［PS-AO］§5.3）。
  8. 住民税に繰戻しの仕組みがあるかは読んでいない。

## SH10 雑損失の繰越控除（所法71）は死亡・出国の年分でも使い、死亡の後は消える

- 根拠：［PS］§8（所法71①〜③、所令204①②、所基通71−1・71−2）、§2.2（所基通124・125−4(1)）、§4.2（所基通72−4）、§12、［M］§4 [7]、§5.1 T01・T03・T10・T11。
- 内容：
  1. (F) 死亡・出国の申告書も確定申告書（T01）なので、その年分で前年以前3年内の雑損失を控除する（所法71② の連続提出が要件。T11）。
  2. (F) 所法71 には青色の要件がない（T10）。白色の人も対象。
  3. (F) 順序：古い年から、総所得金額 → 山林所得金額 → 退職所得金額（所令204①。［M］§4 [7]）。純損失の繰越控除があれば先に所法69・70（所令204②）。
  4. (F) 合計所得金額は繰越控除の前の金額（T03）なので、繰越控除はその人が他の人の扶養親族に当たるかの判定に影響しない。
  5. (I) 死亡の後：残った雑損失を相続人が使えることを示す条文の文言はない（所法71① は「確定申告書を提出する居住者の…各年において生じた雑損失の金額」）。純損失の所基通70−15 のような明示は取得した範囲にない（［PS］§12）。結果は「消滅」とし、印「出典未確認（読み）」を付ける。
  6. (F) 死亡の年の雑損控除は死亡の日までに生じた損失・支出（所基通124・125−4(1)）。対象の親族の所得は見積り（SH4-1(b)）。
  7. (I) 出国の後の非居住者の年分は対象外（SH8）。再び居住者になった年分の「連続して確定申告書を提出」の判定は対象外の年分をはさむので、その年分の雑損失の繰越控除も「対象外」と返す。
  8. (I) 所法71の2（特定非常災害、5年）は第1段では対象外（〈AOI〉H8 が所法70の2 を対象外にしたのと同じ。所令204③・206④⑤の順序の特例がある）。入力に「特定非常災害による損失」があれば「対象外」。
  9. 繰越雑損失がある場合の源泉徴収の猶予（［手続A1-36］）は判定コアの範囲外。

## SH11 住民税と、同じ年の他の人の判定への影響

- 根拠：［PS］§10（地法9・294①②・318）、§4.2（所基通83から84の2−1、79−2）、［PS-SP］§2.2（地法314の2⑧）。
- 内容：
  1. (F) 個人の市町村民税の賦課期日は1月1日（地法318）で、市町村内に住所を有する個人に課す（地法294①）。(I) 死亡した人には、死亡の翌年度以後の住民税を計算しない（1月1日に住所を有する個人でない）。
  2. (F) 既に課された年度の住民税は相続人が承継する（地法9）。(I) 税額の計算は変わらないので、判定コアは承継の計算をしない（納付の手続はアプリ・利用者の側）。
  3. (I) 出国した人の翌年度の住民税は、1月1日に住民基本台帳に記録されているか（地法294②）で決まる。住民基本台帳法は取得していないので、住民票の記録（F-P06）を事実として受ける。
  4. (F) 死亡・出国した人の申告で控除の対象にした親族を、相続人など他の居住者が12月31日の現況でもう一度対象にできる（所基通83から84の2−1・79−2）。
     (I) 所属の一本化（所法85④〜⑥、所令218・218の2・219：［PS-MISC］§3。所令220 は所法85⑦ の再婚の特例）は、死亡・出国した人の年分と他の居住者の年分の間では行わない（同じ親族が両方で控除されても「食い違い」にしない）。
  5. (F) 死亡した親族を扶養していた人の住民税の判定の時点（前年の中途の死亡はその時）は［PS-SP］§2.2。

## SH12 様式と出力

- 根拠：［PS］§2.3（［付表］［付表の書き方］［委任状］［e-Tax準確定］）、§7.2、［M］§7。
- 内容：
  1. (F) 申告書の標題の余白に「準確定」と書き、付表（兼相続人の代表者指定届出書）を添える。ただし［付表の書き方］は相続人等が1人の場合には付表の提出を省略して差し支えないとし、［e-Tax準確定］は e-Tax では1人でも付表（XML）が要るとする（［PS］§2.3）。還付金の受領を代表者に委任するときは委任状。
  2. (I) 様式の欄の対応表に、付表の「5 相続人等に関する事項」「6 納める税金等」（［PS］§2.3。［PDF目視］）の行（相続人ごと：相続分、納付・還付の額）を足す。個人番号の欄は「出力しない欄」（〈OUT〉）。
  3. (F) e-Tax では相続人が2名以上なら確認書のイメージ（PDF）を送る。(I) ファイルを作るのはアプリ（D17 T5）。
  4. (F) 作成コーナーでは準確定申告書を作れない（［e-Tax準確定］）。(I) D15⑤（作成コーナーとの照合）はこのトピックでは使えない。推測の文書に代わりの検証方法を書く。
