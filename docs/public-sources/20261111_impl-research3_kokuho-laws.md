## 2. 年度の途中の資格の取得・喪失の月割り

- 国保法・国保令・地方税法・地令の全条を「月割」で探した（`grep_*_<asof>.txt`）。地方税法では自動車税（第157条「自動車税の納税義務の発生、消滅等に伴う賦課」）・鉱区税（第183条）・給与の特別徴収（第321条の5・第321条の6）にだけ当たり、**国民健康保険税（第703条の4・第703条の5）には年度の途中の取得・喪失の月割りの定めがない**。国保法・国保令にも「月割」の語はない。
- 国保令29の7①：保険料の賦課額は基礎賦課額・後期高齢者支援金等賦課額・介護納付金賦課額・子ども・子育て支援納付金賦課額の合算額。年度の途中の取得・喪失の扱いは国保令にない。
- **月割りは市町村の条例の事項（法令に定めがない）**。条例の一次情報（各市町村の国民健康保険条例・国民健康保険税条例）は取得していない。

## 3. 産前産後の減額

- 国保令29の7⑥八：「世帯に出産する予定の被保険者又は出産した被保険者（以下この号及び次号において『出産被保険者』という。）がある場合においては、当該世帯の世帯主に対して賦課する所得割額（出産被保険者につき…算定した所得割額に限る。…）並びに被保険者均等割額及び十八歳以上被保険者均等割額（出産被保険者につき…算定した…（第一号から第五号までに規定する基準に従い…減額するものとした場合にあつては、その減額後の…））を減額するものであること。」
- ⑥九：「前号の規定に基づき減額する額は、当該市町村の当該年度分の保険料に係る所得割額並びに被保険者均等割額及び十八歳以上被保険者均等割額のうち、出産被保険者の出産の予定日（厚生労働省令で定める場合には、出産の日）の属する月（以下この号において『出産予定月』という。）の前月（多胎妊娠の場合には、三月前）から出産予定月の翌々月までの期間に係る額**を基準として算定した額**であること。」
- 国保税：地法703の5（国保税の減額）と地令56の89 に同じ形（`chihorei_<asof>.txt` の Num=56_89：「減額は、所得割額（納税義務者の世帯に属する出産する予定の国民健康保険の被保険者又は出産した国民健康保険の被保険者…）…」）。
- 「期間に係る額を基準として算定」の具体（年額の12分の4 か、月ごとの額か、年度をまたぐときの割り振り）は政令に書かれていない（条例・通知の事項。通知は取得していない）。

## 4. 特定世帯・特定継続世帯の平等割

- 国保令29の7②八（基礎賦課額の世帯別平等割額）：
  - イ「ロ又はハに掲げる世帯以外の世帯　第二号イ及びロの世帯別平等割総額を被保険者が属する世帯の数から特定同一世帯所属者（法第六条第八号に該当したことにより被保険者の資格を喪失した者であつて、当該資格を喪失した日の前日以後継続して同一の世帯に属する者をいう。以下同じ。）と同一の世帯に属する被保険者が属する世帯であつて同日の属する月（以下このイにおいて『特定月』という。）以後五年を経過する月までの間にあるもの（当該世帯に他の被保険者がいない場合に限る。以下この条において『特定世帯』という。）の数に二分の一を乗じて得た数と…特定月以後五年を経過する月の翌月から特定月以後八年を経過する月までの間にあるもの（当該世帯に他の被保険者がいない場合に限る。以下この条において『特定継続世帯』という。）の数に四分の一を乗じて得た数の合計数を控除した数に按分すること。」
  - ロ「特定世帯　イに定めるところにより算定した額に二分の一を乗じること。」
  - ハ「特定継続世帯　イに定めるところにより算定した額に四分の三を乗じること。」
- 後期高齢者支援金等賦課額（③）・子ども・子育て支援納付金賦課額（⑤）の世帯別平等割額も同じ形（イ・ロ 1/2・ハ 3/4）。介護納付金賦課額（④）には特定世帯の定めはない（④の本文に「特定世帯」の語なし）。
- 国保税：地法703の4 に「特定世帯」の語がある（`grep_chiho_<asof>.txt`）。地令の側は今回の grep（「特定世帯」「特定継続世帯」）で当たりがなかった（法律の側に書かれている。本文は `chiho_<asof>.txt` の Num=703_4）。
- 判定の時点（特定月から5年・8年を「経過する月」の数え方、賦課期日の1か所か月ごとか）は政令の文言では月単位で書かれ、年度の途中での切替わりの月割りは条例の事項（§2）。
