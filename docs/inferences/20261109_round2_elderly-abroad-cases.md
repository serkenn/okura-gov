## IE4 単身赴任と同居老親等（HE2.2・U2）

- 場面：居住者Aが国内の別の市に転勤して住所を移した。Aの配偶者Bと、Aの母C（72歳、所得なし、生計を一にする）は元の住居で同居を続けている。
- 期待（仮説の既定）：C は「居住者又は配偶者のいずれかとの同居」に当たり、同居老親等（所得税 58万円）。住民税も同居直系尊属（45万円）［LW］§2.1・§5.1。
- 対照：Aの転勤でBもAと一緒に移り、Cだけが元の住居に残った → 同居でない（年末調整のしかたの (3)）［GD］§1.1。
- 検証方法：(1) 国税庁の質疑応答事例・タックスアンサーを「単身赴任」「同居老親」で探す。(2) 見つからなければ、根拠に「原文の読み、国税庁の明示なし」の印を付けたまま実装し、ユーザーに確認する（D4 の判断で上書きできるようにする）。

## IE5 配偶者の父：所得税と健保の違い（HE2.1・HE5.2）

- 場面：被保険者・居住者A、配偶者B、Bの父D（74歳、公的年金のみ、年間収入 170万円）。
- 所得税：D はAの配偶者の直系尊属。Aと生計を一にし、Dの合計所得金額が所得要件以下で、AかBと同居なら同居老親等（58万円）。公的年金だけなら、令和8年分は公的年金等の収入 172万円以下で合計所得金額 62万円以下（国税庁の目安：［GD］§2.2）→ 170万円は扶養親族の範囲。
- 健保：D はAの直系尊属ではなく、三親等内の親族（第2号）。**Aと同一の世帯に属することが要件**。同一世帯なら 180万円未満（60歳以上）かつAの年間収入の2分の1未満が目安。別世帯なら被扶養者にならない［LW］§6.1、［GD］§5.2。
- 検証方法：(1) 協会けんぽの手引きの図（配偶者の父母は「同居していることが要件の人」）と照合［GD］§5.2。(2) 公的年金等控除の計算を実装したら、収入 172万円・172万1円で合計所得金額 62万円・62万1円になるか（令和8年分、65歳以上）を境目のテストにする（条文で確認してから）。

## IE7 国外に住む72歳の親（HE3.1・HE3.3）

- 場面：居住者A。Aの父E（72歳、外国に住み、外国の年金収入がある）。Aは銀行から毎月 Eに送金（年 60万円）。
- 期待：E が扶養親族（生計を一にし、合計所得金額が所得要件以下：外国の年金の扱いは別の調査）なら、区分1（70歳以上）で控除対象扶養親族・老人扶養親族（48万円）。同居でないので同居老親等ではない。確定申告では親族関係書類（Aの出生証明書など）と送金関係書類（その年の全送金。年3回以上なら明細書と最初・最後の書類）が要る［LW］§3.2、［GD］§3.2・§3.4・§3.5。
- 書類の事実がない → 扶養控除は適用しない、不足している書類を根拠に出す。書類の事実が記録されていない → 未確定（HE3.3）。
- 翌年度の住民税：同じ区分で老人扶養 38万円。住民税の書類は確定申告で出していれば不要［LW］§5.3。
- 検証方法：(1) 作成コーナー（令和7年分）で、第二表の国外居住の区分「1」の扶養親族を入れ、扶養控除が 48万円になるか照合。(2) 区分「5」なら 0 になるか照合（手引きの（注１））。

## IE8 30〜69歳の国外の親：38万円の境目（HE3.2・U4）

| ケース | 支払（その年、銀行の為替取引、各人あて） | 換算・手数料 | 合計（円） | 期待 |
|---|---|---|---|---|
| a | 2,520 USD（1回） | 送金日の仲値 150.50 | 379,260 | 38万円未満 → 区分5（扶養控除なし） |
| b | 同じ | 仲値 151.00 | 380,520 | 区分4（38万円送金書類が要る） |
| c | 円で 375,000 を送金、手数料 5,000（38万円送金書類に記載あり） | 手数料を含める | 380,000 | 区分4 |
| d | c で手数料が書類に記載なし | 含めない | 375,000 | 区分5 |
| e | 送金 300,000 ＋ 知人を通じた現金の手渡し 100,000 | 手渡しは数えない | 300,000 | 区分5（手渡しは送金関係書類に当たらない） |
| f | 12月28日に 50,000 を送金、入金は翌年1月5日（ほかに同年 340,000） | 送金日で計上 | 390,000 | 区分4 |

- 出典：［LW］§3.1・§3.2、［GD］§3.4（所基通2-50、Q7・Q39）。
- a・b は、同じ支払でも仲値の金融機関・日（J5 と E9 の事実）で結論が変わる例。判定コアは相場を持たず、事実として受け取った相場を使う（HE3.2）。
- 端数：a は 2,520×150.50＝379,260.00 で端数なし。端数が出る例：2,521.37 USD×150.73＝380,046.1001 は、切り捨ても四捨五入も 380,046 円（切り上げなら 380,047 円）で、38万円の判定は変わらない。2,533.33 USD×150.00＝379,999.50 は、切り捨てなら 379,999 円（38万円未満 → 区分5）、四捨五入なら 380,000 円（38万円以上 → 区分4）で結論が変わる → 未確定（U4）。
- 検証方法：(1) 所基通2-50 と［QA-KG］Q7 の例（37万円の送金＋手数料1万円で38万円）を c と同じ形のテストにする。(2) 端数の扱いは国税庁の資料を引き続き探す。

## IE9 1年以上留学する31歳の子（HE3.1・HE4）

- 場面：子F（31歳、日本国籍）が外国の大学院に2年の予定で留学し、住所を移した。所得なし。親Aが学費・生活費を送金。
- 期待：F は12月31日に非居住者（J1。1年以上の留学：［GD］§3.3 Q16）。30歳以上70歳未満で留学 → 区分2。親族関係書類・送金関係書類・留学ビザ等書類（外国の査証・在留カードに相当する書類の写し）が要る［LW］§3.2、［GD］§3.2・§3.3。
- 変種：F が日本国籍でない → 留学ビザ等書類だけでは足りず、留学の直前に日本に住所又は居所を有していたことの公的機関の書類が要る（Q31）。
- 変種：F（31歳）が留学ではなく就労で国外に住み、送金が年 40万円 → 区分4（38万円送金書類）。ただし扶養親族の所得要件（現地の給与）を満たすかは別。
- 検証方法：作成コーナー（令和7年分）で区分「2」「4」の扶養親族を入れ、扶養控除が 38万円になるか照合する。

## IE10 短期の留学と、年の途中の移住（HE4・U7）

- a：子G（20歳）が8か月の交換留学に出た（住民票はそのまま）。→ 国外居住親族に当たらない（1年以上の居住を通常必要としない：Q16）→ 居住者の扶養親族として扱い、国外居住親族の書類は要らない［GD］§3.3。健保では住民票が国内なので国内居住要件を満たす［GD］§5.3。
- b：親H（70歳）が2026年6月に外国の親族のもとへ永住のため移った。12月31日に非居住者（J1）。→ 令和8年分は国外居住親族（区分1）で、送金関係書類はその年の支払について要る。H が移る前の1〜5月に国内で現金で生活費を渡していた分は、送金関係書類に当たらない（手渡し）が、生計を一にする判断の材料にはなる。**移る前の期間の支払がない（6月以後の送金だけ）ときに、送金関係書類の要件を満たすか**は資料がない → 未確定（U7）。
- 検証方法：b は国税庁の［QA-KG］の未読の Q（Q19〜Q27）と質疑応答事例を探す。見つからなければ「未確定」の扱いをユーザーに確認する。

## IE11 1年以上留学する20歳の子：所得税と健保で違う（HE4・HE5.3）

- 場面：子J（20歳、所得なし）が2年の予定で留学し、海外転出の届出で住民票を除いた。親Aは協会けんぽの被保険者。
- 所得税：J は非居住者（区分1、16歳以上30歳未満）。親族関係書類と送金関係書類が要る。特定扶養親族（19〜22歳）に当たり 63万円（控除対象扶養親族のうち19歳以上23歳未満：既存［R1］）。

- 期待：同じ人が「所得税では非居住者」「健保では例外として被扶養者」になる。判定コアは二つの判定を別の関数で行い、互いの結果を使わない（HE5.3）。
- 検証方法：R01 Q6（留学の期間は問わない）・Q7（現地で就職したら例外でなくなる）を、留学の区間の終わりと就職の日を変えたテストにする。

## IE13 住民税の非課税限度額と国外の16歳未満の扶養親族（HE3.3）

- 場面：市A（非課税限度額の級地のデータは注入済み）に住む納税義務者K。国内の扶養親族1人、国外に住む10歳の子L（扶養親族）。
- 期待：Lを数えると非課税限度額の制度の適用を受け、Lを除くと受けない場合に、Lに係る国外扶養親族証明書類（親族関係・送金）の事実がなければ、Lを数えない（＝非課税にならない）。書類の事実が記録されていなければ未確定［LW］§5.3、［GD］§3.2（手引き※2）。

## IE14 公務員である家族（HE4）

- 場面：居住者Mの子N（26歳、日本国籍）が地方公務員として外国の事務所に3年の予定で派遣されている。N の配偶者Pが同行。
- 期待：N は所法3①で国内に住所を有するものとみなされ、居住者として扱う（N 自身の所得税は居住者として計算）。P は公務員でないので所法3①の対象ではない。所令15②（国内に住所を有しない者と推定される個人と生計を一にする配偶者等の推定）が、所法3①で国内に住所を有するものとみなされる N についても働くかは、原文の組み合わせからは決まらない → P が非居住者かは判断 J1 とし、推定は出さない（I）。

## IE15 国外で配偶者と同居する配偶者の親（HE2.1）

- 場面：居住者Q（国内）、配偶者R（国外の実家で親Sの介護のため1年以上滞在、非居住者）、Rの母S（75歳、国外に住む、生計を一にする）。
- 期待（原文の読み）：S は Q の配偶者の直系尊属で、配偶者Rとの同居を常況としている → 同居老親等（58万円）の要件を満たしうる。S は非居住者なので国外居住親族（区分1）で書類が要る［LW］§2.1・§3.1。R が12月31日に Q の配偶者であること、R 自身が Q の同一生計配偶者か等は別の判定。
- 検証方法：国税庁の資料で「国外居住親族」と「同居老親等」の組み合わせを書いたものを探す。作成コーナー（令和7年分）で、国外居住の区分「1」と「同居老親等」の両方を選べるか（入力の制約）を確かめる（選べなければ、国税庁の様式の上では想定していないことの材料になる）。

## IE16 性質のテスト（HE2.3・HE3.1）

1. 老人扶養親族・同居直系尊属について、所得税の控除額−住民税の控除額＝地法314の6 の表の額（10万円・13万円）。パラメータの年分を足しても崩れないことを毎回確かめる（崩れたら法令の変更の検知）。
2. 同じ人・同じ年の事実から、所得税の非居住者の区分（その年分）と、翌年度の住民税の区分（前年分）が同じになる。違うのは書類の要件と判定の文言（「この法律の施行地」）だけ。
3. 換算方法の選択（J5）を変えても、外貨の支払がない親族の結果は変わらない。
4. 「同居」の候補の規則を変えても、老人扶養親族でない人の結果は変わらない（同居老親等は老人扶養親族の部分集合）。
- 検証方法：判定コアの性質テスト（D15 ④）として、事実をランダムに作って上の等式を確かめる。
