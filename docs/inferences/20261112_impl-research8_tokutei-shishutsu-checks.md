# 推測：特定支出控除の実装の結果と、確かめる方法（impl-research8）

前提の仮説：`docs/hypotheses/20261112_impl-research8_tokutei-shishutsu-reading.md`（H1〜H8）。

## I1 境目（H1・H2）

- 令和7年分、給与等の収入金額 500万円：給与所得控除額 144万円、2分の1 は 72万円。特定支出の額の合計額が 72万円ちょうどなら適用されず給与所得の金額は 356万円（別表第五の額）、
  72万1円なら 500万 − 144万 − 1 = 355万9,999円。
- 令和8年分、収入 200万円：措法29の4② 第2号で給与所得の金額 126万円、給与所得控除額は措法29の4① の 74万円で2分の1 は 37万円。特定支出 50万円なら 126万 − 13万 = 113万円。
- 確かめ方：ユニットテスト `packages/core/tests/test_kyuyo_tokutei.py`（TestTokuteiShotoku）。作成コーナー（令和7年分）に架空の数字（収入 500万円、
  特定支出の明細 72万円と 72万1円）を入れて、給与所得の欄の値を比べる（完成の確認。ユーザーが手で行う：D15⑤・D24①）。

## I2 様式との差（H1）

- 収入 660万円未満で、第28条第3項の式の給与所得控除額と、明細書の ⑮（⑬−⑭。⑭ は別表第五の額）が違う人がいる。例：令和7年分 収入 3,001,234円では
  式の控除額は1円未満を含み（収入×30％＋8万円の区分）、別表第五の給与所得の金額との差から出る ⑮ は区分（4,000円ごと）の下限で計算した額
  （`test_kyuyo_tokutei.py` の test_beppyo5_is_not_used で、別表第五の額と式の額が違うことを確かめた）。特定支出控除の後の給与所得の金額は数円〜数千円違いうる。
- 確かめ方：作成コーナーで、660万円未満の収入（区分の境目でない額）と2分の1 を超える特定支出を入れ、⑱（作成コーナーの給与所得の金額）と判定コアの値を比べる。
  違えば `docs/measurements/` に記録し、法令（第57条の2第1項・第28条第3項）を正として、様式の扱いを公開資料の情報に足す（推測で直さない）。

## I3 所得金額調整控除の第2項（H6）

- 公的年金等に係る雑所得の金額 10万円以上の人で、特定支出控除の後の給与所得の金額が 10万円未満になると、第2項の控除額は特定支出控除の前の額で計算するので
  給与所得の金額を超えることがあり、超える部分は総所得金額に効かない（給与所得は 0 として損益通算しない）。
- 確かめ方：作成コーナーで、給与と公的年金等の両方がある架空の人に特定支出控除を入れて、給与所得の欄と総所得金額を比べる。

## I4 住民税（H7）

- 所得税の申告書等で特定支出控除を受けた人は、翌年度の住民税の所得割の総所得金額等が特定支出控除の後の値で計算される（判定コアは前年分の所得税の値を引く）。
- 前年分の所得税の納税義務がない人が住民税の申告書だけで受ける場合（地法313⑪）は判定コアで計算しない。確かめ方：総務省の通知・市町村の住民税の申告書の様式で
  「特定支出控除」の欄の扱いを公開資料の情報として集め、住民税の担当とユーザーに範囲を確認する。

## I5 authority_decision の税目（H8）

- 住民税の減免の承認（税目 resident_tax）を国保の減免として読まない。国保の減免（national_health_insurance）は住民税の減免として読まない。
- 確かめ方：ユニットテスト（`test_juminzei.py` の `test_resident_tax_reduction_is_read_by_tax_item`、`test_kokuho.py` の `TestAuthorityDecision`）。

## I6 通常の範囲の判断（H9。2026-11-12 の2回目）

- 旅費 9万円（特別車両料金 8千円を含む）で通常の経路の額の判断が 7万円なら特定支出の額は 7万円、判断が 8万5千円なら 8万2千円（特別車両料金等を除いた額で抑える）。
  判断が未入力なら 0〜8万2千円の両端で評価し、給与所得の金額が分かれれば未確定（決める入力：その支出の 判断.特定支出の通常の範囲の額）。
- 確かめ方：ユニットテスト `packages/core/tests/test_kyuyo_tokutei.py`（test_route_judgment_caps_after_special_fees・test_which_expenses_need_the_route_judgment）。
  旅費の通常の範囲の判断（特別車両料金等を除いた後に抑えるか、判断の額から除くか）は、作成コーナー（令和7年分）で特別車両料金を含む旅費を入れ、明細書のⒶの扱いを観察する。

## I7 住民税の申告書だけで受ける特定支出控除（H10。2026-11-12 の2回目）

- 例：所得税の額が0（扶養が多い）の給与 200万円の人が所得税で受けず住民税の申告書だけで受けると、住民税の給与所得・合計所得金額は特定支出控除の後の額になり、
  基礎控除・非課税の判定・所得割の額、扶養する人の側の住民税の扶養の判定（allocation.py）が変わる。所得税の値（扶養の判定を含む）は変わらない。
- 確かめ方：ユニットテスト `packages/core/tests/test_juminzei_tokutei.py`（段の要件・読みの候補・損益通算の順が income_totals と同じこと・窓口の値）。
  「納税義務を負わない」の読みは、総務省の通知（市町村税課長通知など）・市町村の住民税の申告書の様式と記載の手引きの「特定支出控除」の欄を公開資料の情報として集めて確かめる。
