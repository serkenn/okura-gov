# 株式等の配当・譲渡の申告の選択が家族の判定に与える影響（推測）と、その検証方法

- 作成日：2026-11-09
- 種別：推測。担当トピック `kabu`（第2ラウンド追加分）。
- 前提にした仮説：[H] `docs/hypotheses/20261109_round2b_kabu-model.md`（H1〜H8）。基準額は [H] の根拠に挙げた文書の値（令和7年分の扶養親族 58万円以下、勤労学生 85万円以下かつ給与所得等以外 10万円以下、特定親族 58万円超123万円以下、特定扶養親族の控除 63万円、特定親族特別控除 85万円以下 63万円。住民税の令和8年度分 扶養親族 58万円以下・特定扶養 45万円・特定親族 95万円以下 45万円）。
- 例の計算：`scripts/R2B_kabu_scenarios.py` → `scripts/results/R2B_kabu_scenarios/scenarios.md`（実測の文書 `docs/measurements/20261109_round2b_kabu-fetch-and-verify.md` §6）。計算は [H] H2 の算入規則を写したもので、法令の正しさの確認ではない。
- 例はすべて架空の一般的な家族（学生の子・親・配偶者）で、特定の家族の情報ではない。

## I1. 学生の子の配当を「申告する」と、扶養親族から特定親族に移り、勤労学生から外れる

- 前提：[H] H1（配当は1回ごと・口座ごとに申告不要を選べる）、H2（申告不要は合計所得金額に入らない、総合・分離は入る）、H2-2。
- 例（S1、令和7年分）：20歳の学生。給与収入110万円（給与所得45万円）、源泉徴収口座で上場株式の配当20万円。
  - 申告不要：合計所得金額 45万円 → 親の扶養親族（特定扶養親族）。勤労学生の「給与所得等以外」0円。
  - 総合課税・申告分離課税：合計所得金額 65万円 → 扶養親族ではなく特定親族（58万円超123万円以下）。給与所得等以外 20万円 > 10万円 で勤労学生でなくなる。
- 推測：
  - 親の所得税の控除額は、特定扶養控除 63万円 → 特定親族特別控除 63万円（85万円以下）で、この例では**変わらない**。住民税（令和8年度分）も特定扶養 45万円 → 特定親族 45万円（95万円以下）で変わらない。ただし合計所得金額が 85万円（住民税は 95万円）を超える額の配当なら親の控除が減り始める。
  - 子の側では、申告すると所得税の源泉徴収税額（15.315%）が戻りうる一方、住民税の所得割・均等割の非課税の判定や勤労学生控除に効く。どちらが得かは住民税の額（市町村のデータ）と健保の扱い（I7）で変わるので、ライブラリは結論を出さずシナリオごとの値を返す（[H] H4-1）。
- 検証の方法：
  1. 作成コーナー（令和7年分）に架空の数字（給与110万円の源泉徴収票、配当20万円）で、総合課税と申告分離課税の両方の申告書を作り、第一表・第三表の「所得金額の合計」相当の値と判定コアの `所得税.合計所得金額` を照合する（D15 ⑤、D16）。
  2. 親の側の申告書で、その子を「特定親族（合計所得金額 65万円）」として入力したときの控除額が 63万円になることを作成コーナーで確かめる。
  3. 住民税の値は、市町村の税額試算（公開されていれば）か、住民税の担当トピックの計算と照合する。

## I2. 源泉徴収口座の小さな譲渡益は、申告しても判定が変わらないことが多い

- 前提：[H] H1（口座ごとの申告不要）、H2。
- 例（S2）：給与収入100万円の学生、源泉徴収口座の譲渡益8万円。申告すると合計所得金額 35万円 → 43万円、給与所得等以外 8万円（10万円以下）。扶養親族・勤労学生のまま。
- 推測：譲渡益を申告する利点は、ほかの口座・一般口座の損失との通算か、損失の繰越のためがほとんどで、益だけの口座を申告すると国保（I6）や健保（I7）の側の値だけが増えうる。ライブラリは「申告するかどうかで変わる判定の一覧」を境目の説明として出す（D19）。
- 検証の方法：作成コーナーで源泉徴収口座の特定口座年間取引報告書の値（架空）を入力した場合としない場合で、第三表 ㋡・73 と第一表の合計の違いを確かめる。

## I3. 譲渡損失と配当を通算するには、配当を申告分離にする必要がある

- 前提：[H] H1（総合／分離は年で1つ）、H2、H5 の 4.。
- 例（S3）：一般口座で上場株式の譲渡損 30万円、上場株式の配当 10万円。
  - 申告分離で損益通算：上場株式等に係る配当所得等の金額 0円、合計所得金額 0円（損失の残り 20万円は繰越できる）。
  - 総合課税：通算できず、配当 10万円が合計所得金額に入る。
- 推測：同じ年に通算したいなら配当は申告分離しか選べず、その年の申告する特定上場株式等の配当等はすべて分離になる（H1 の制約）。判定コアは「総合課税を選び、かつ損益通算の記載がある」入力を拒否する。
- 検証の方法：作成コーナーで、譲渡損と配当（架空）を入力し、配当を総合課税にした場合に損益通算の付表が作れない（または通算されない）ことを確かめる。第三表 74・97 と付表の値を記録する。

## I4. 繰越控除は合計所得金額を下げないが、医療費控除の足切りの基礎は下げる

- 前提：[H] H2（合計所得金額は繰越控除前、総所得金額等は繰越控除後）、H5 の 5.〜7.。
- 例（S4）：前年からの繰越損失 40万円。本年、源泉徴収口座の譲渡益 30万円を申告、申告分離の配当 20万円。合計所得金額 50万円、総所得金額等 10万円（繰越控除はまず譲渡 30万円、残り 10万円を配当から）。
- 推測：
  - 扶養・勤労学生・基礎控除の段階は 50万円で判定し、医療費控除の足切り（総所得金額等の5%と10万円の少ない方）は 10万円の 5%＝5,000円で計算する。
  - 繰越を続けるには、損失の年から毎年連続して確定申告（付表つき）が要る（譲渡のない年も）。判定コアは繰越損失の入力に「連続して申告した事実」を求め、欠けていれば繰越控除を使わず「要件の事実が不足」と返す。
  - 住民税の合計所得金額も繰越控除前、国保の軽減判定は繰越控除後（[H] H2 の根拠）。同じ人の同じ年で「扶養の判定に使う額」と「国保の軽減に使う額」が違う。
- 検証の方法：作成コーナーで前年の繰越損失（架空）と医療費（架空、例えば 3万円）を入力し、医療費控除額が 3万円−5,000円＝2万5,000円になるか（足切りの基礎が繰越控除後か）を確かめる。

## I5. 住民税で別の課税方式を選ぶ設計は要らない（令和6年度分以後）

- 前提：[H] H1（住民税の課税方式は選択なし）、H5 の 10.、H5-2。
- 推測：令和8年度分・令和9年度分の住民税は、前年分の所得税の確定申告書の記載で課税方式が決まる。中間表現に「住民税の申告書での課税方式の選択」の項目は作らない。市町村の古い案内（令和5年度分以前の「住民税の申告で申告不要を選べる」という説明）が見つかっても、令和6年度分以後には当てはまらない。
- 例外：令和6〜8年度分に限り、令和2〜4年に生じた譲渡損失の繰越控除について、改正前の住民税の申告書で要件を満たせる経過措置がある（[H] の根拠の [PS] §8.1）。令和8年度分（令和7年の所得）では、令和4年の損失の繰越の最終年に当たる（I）。
- 検証の方法：令和8年度の住民税の税額決定通知書（架空の例は作れないので、公開された市町村の記載例）で、確定申告で申告不要にした配当が住民税の所得に入っていないことを確かめる。経過措置は地方税法の改正附則（令和4年法律第1号附則第11条第2項）を住民税の担当トピックと共有する。

## I6. 国保の保険料と軽減は、申告した株式等の所得で上がりうる

- 前提：[H] H2（国保は住民税の総所得金額等＋分離課税の所得）、H5 の 11.。
- 推測：申告した配当・譲渡益は国保の所得割の基礎と、均等割・平等割の軽減（7割・5割・2割）の判定の合算額に入る。申告不要にしたものは入らない。令和6年度分以後は住民税だけ申告不要にする方法がなくなったので、国保を考えて申告不要を選ぶと、所得税の源泉徴収税額は戻らない（総務省の資料が述べる改正の趣旨と一致：[H] の根拠の [PS] §8.1）。
- 検証の方法：国保の担当トピック（第2ラウンド）の計算に、S1・S4 の値（住民税の総所得金額等と分離課税の所得）を入れ、軽減の判定が変わる境目を確かめる。市町村の国保料の試算ページ（公開されていれば）でも照合する。

## I7. 健保の被扶養者の年間収入は、税の申告の選択から作ってはいけない

- 前提：[H] H2（健保は保険者による）、H5 の 12.、H6。
- 推測：
  - 配当を年間収入に含める保険者（公表例は4つ）では、**税で申告不要を選んでも配当は年間収入に入る**。逆に、申告した譲渡益を「一時的」として入れない保険者もありうる。したがって `健保.年間収入` を `所得税.合計所得金額` から導いてはいけない（SCOPE.md §6 の3「別の系統」）。
  - 配当の額を源泉徴収前で数えるか後で数えるか、NISA の配当を数えるかは、公表例のどれにも書かれていない。保険者データがない場合は、配当を「入れる／入れない」の両方で評価し、130万円（150万円・180万円）の境目をまたげば「未確定」と、何のデータ（保険者の規則）があれば決まるかを返す（D19）。
- 検証の方法：被保険者の保険者（家族ごとに違う）の公表資料か問い合わせで、配当・譲渡益・NISA の扱いと額の定義を確かめ、注入データの出典として記録する。国（厚労省・協会けんぽ・日本年金機構）の資料に明記が出たら一次情報として追加する。

## I8. 判定の境目の説明に「どの株式等の所得が効いたか」を出す

- 前提：[H] H4-1、H5-1。
- 推測：扶養・勤労学生・特定親族・住民税の非課税・国保の軽減の各判定について、合計所得金額などの内訳（配当の各回・各口座・各課税方式、譲渡の各口座、損益通算・繰越の額）を根拠の事実 ID つきで返すと、利用アプリが「この口座を申告不要にすれば…」というシナリオを作れる（シナリオの選び方はアプリの責務：D19）。
- 検証の方法：S1〜S5 を判定コアの場面のテスト（D15 ③）にし、結果の根拠に入る事実 ID と金額の合計が、合計所得金額などと一致することを性質のテスト（D15 ④）で確かめる。`scripts/R2B_kabu_scenarios.py` の性質 P1〜P4（申告不要の値 ≦ 申告した値、総所得金額等 ≦ 合計所得金額、住民税＝所得税の合計所得金額、NISA は入らない）をそのまま性質のテストにできる。

## I9. 確かめていない計算の順序は、作成コーナーとの照合で決める

- 前提：[H] H6（所得控除を総合と分離の間でどの順に当てるか、課税標準ごとの千円未満切捨て）。
- 推測：所得控除は総所得金額から先に差し引き、残りを分離課税の所得から差し引く（所法第87条第2項の「順次控除」と措法の読替えの組合せ）。分離課税の課税所得金額もそれぞれ千円未満切捨て（第三表の欄の「000」の印字）。
- 検証の方法：作成コーナーで、給与なし・申告分離の配当 100万円・社会保険料控除 20万円（すべて架空）の申告書を作り、第三表 82（74 対応分）の課税される所得金額が 100万円−（所得控除の合計）の千円未満切捨てになるかを確かめる。次に給与所得 30万円を足して、所得控除がまず ⑫ 対応分（78）から引かれるかを確かめる。結果は実測の文書に記録し、名前つきの関数の「出典未確認」の印を外すかどうかを決める。
