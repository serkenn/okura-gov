## I1 判定コアの入口は「年分」でよいが、住民税は「年分＋1 の年度」として別の結果に出す

- 前提：H1、H7。D7 の `evaluate(中間表現, 年分)`。
- 推測：
  - `evaluate(中間表現, 年分=令和8年分)` は、所得税（令和8年分）と、住民税（**令和9年度分**）の両方を返すのが自然。住民税の判定に要る所得は同じ年の所得だから。
    結果の住民税の部分には「年度」「所得の年分」「賦課期日」「使った法令の版（asof＝年度の1月1日）」を必ず書く（D13 の根拠）。
  - 対象の組み合わせ（D14）は、所得の年分で数えると「令和7年分 → 令和8年度分」「令和8年分 → 令和9年度分」。令和8年度分の住民税は令和7年分の所得で決まるので、
    令和7年分の実装は住民税の令和8年度分の判定にも使う。
  - パラメータ（基準額）の施行日の持ち方：所得税は「年分」（1月1日〜12月31日）に適用、住民税は「年度」に適用で、その値が使われる所得はさらに1年前になる。
    パラメータを「施行日」だけで引くと取り違えが起きる。住民税のパラメータは「年度」をキーにし、ファイルに「適用年度」「所得の年」「版（asof）」を並べて書くのがよい。
    例：扶養親族の所得要件は、所得税は令和8年分から 62万円、住民税は令和9年度分（＝令和8年の所得）から 62万円。所得の年で見れば同じ値になる［H］H7
    （検証で追記：元は H7 に所得税の側の記述がなく、前提が仮説に置かれていなかった。H7 に所得税の側（令和8年法律第12号附則第2条）を足した）。
  - （検証で追記）住民税の「年度」をキーにしたパラメータの適用年度は、施行日ではなく改正附則の適用年度で決める［H］H1-2 の訂正。
    1月1日より後に施行された改正でも、その年度分に効くことがある（令和8年法律第2号附則第11条第1項）。
  - 所得の計算（給与所得など）は、住民税でも「前年分の所得税の法令」で行う（H1-3）。したがって給与所得の関数は所得税と住民税で共有し、引数は「所得の年分」にする。
    住民税側に別の給与所得の関数を作らない。
- 検証の方法：
  1. 令和7年分・令和8年分の同じ中間表現で、所得税と住民税の結果を出し、住民税の年度が年分＋1 になっていること、扶養親族の要件が 58万円（令和8年度）・62万円（令和9年度）になることを単体テストにする。
  2. ［H］H1 の 3（措法第29条の4 が住民税に及ぶ）は未決 JU2。総務省の資料で確認できたら「行政の資料による」の注記を外す。確認できるまで、結果の根拠に注記を残す。

## I2 非課税の境目のテスト（D15 ②）は実測の計算表をそのまま使える

- 前提：H2、H6、H7。
- 推測：［H］の根拠である実測（`scripts/results/IMPL_juminzei_thresholds/thresholds.json`）の境目は、江戸川区・柏市（令和8年度）・神戸市（令和9年度）の公表値と一致したので、
  境目の両側（境目の給与収入と +1 円）をテストケースにできる。例（給与収入だけ、1級地、扶養なし）：
  - 令和8年度分：1,100,000 円 → 均等割・所得割とも非課税、1,100,001 円 → 課税。
  - 令和9年度分：1,190,000 円 → 非課税、1,190,001 円 → 課税。
  - 未成年者：令和8年度分 2,043,999 円 → 非課税、2,044,000 円 → 課税（合計所得金額 1,350,800 円）。令和9年度分 2,090,000 円 → 非課税、2,090,001 円 → 課税。
  - 期待値には出典として、条文（法295、令47の3、規則9の21、法附則3の3）と、一致を確かめた自治体の公表値を並べて書く。
  - （検証で訂正）上の「+1 円 → 課税」は、**非課税の基準に当たらなくなる**（均等割が課される）という意味に限る。所得割は、法附則第3条の3第4項の非課税に当たらなくなっても、
    同条第5項（道府県民税は第2項）は、境目の額が「総所得金額等 −（市町村民税と道府県民税の所得割額の合計）」を超える分を、市と県の所得割額の比で所得割額から差し引く。
    このため境目 +1 円では所得割はほぼ 0 になる（総所得金額等が境目 +1 円のとき、第5項の式を整理すると、調整後の市町村民税の所得割は「市町村民税の所得割 ÷（市町村民税と道府県民税の所得割の合計）」円で、
    1 円未満。例：令和8年度分・扶養なし・給与収入 1,100,001 円＝総所得金額等 450,001 円）。テストで「所得割 > 0」を期待値にしない。
    根拠は［H］H2 の 2（法附則第3条の3④⑤）。調整の計算そのものは判定の対象外（D14：住民税は扶養と非課税の判定のみ）。
- 柏市の令和9年度の表のうち 5 値は条文からの計算と合わない（未決 JU5）。テストの期待値には使わない。
- 検証の方法：テストを実装したら、同じ値が `IMPL_juminzei_thresholds.py` の出力と一致することを CI で確かめる。他の自治体が令和9年度の早見表を出したら、照合の対象に足す。

## I3 未成年者の判定は「1月1日の年齢」で、生年月日の境目は年度ごとに決まる

- 前提：H3。
- 推測：
  - 令和8年度分（賦課期日 2026-01-01）の未成年者＝ 2008-01-03 以後に生まれた人。令和9年度分（2027-01-01）＝ 2009-01-03 以後に生まれた人。
    （令和5年度分＝2005-01-03 以後という自治体の案内と同じ数え方を当てはめた）
  - 2008-01-02 生まれの人は、令和8年度分では未成年者ではない（1月1日に18歳になっている扱い）。
  - 控除の判定（特定扶養親族＝19歳以上23歳未満など）は前年12月31日の年齢なので、同じ人について「控除の年齢」と「非課税の年齢」を別の時点で計算する。
    例：2008-01-02 生まれの子は、2025-12-31 時点では17歳（控除対象扶養親族・16歳以上）、2026-01-01 時点では18歳（未成年者ではない）。
  - 子供の事業収入が多い場合の差が大きい：17歳以下（1月1日時点）なら前年の合計所得金額 135万円まで均等割・所得割とも非課税、18歳・19歳なら（1級地・扶養なしで）45万円を超えると課税される。
- 検証の方法：
  1. 令和8年度分・令和9年度分について「〇年1月3日以降生まれ」と書いた自治体の案内を探して照合する。
  2. 取扱通知（市町村税関係）の改正後全文の未読の頁、または総務省の逐条解説で、未成年者の判定時点の記述を探す（未決 JU1 と同じ作業）。
  3. 1月1日・1月2日・1月3日生まれの3人で、年度ごとの未成年者の判定をテストにする。

## I4 中間表現に足りない事実がある

- 前提：H3、H4、H5、H6。
- 推測：住民税の判定には、所得税の判定にない次の事実が要る。D5 の「役割つきの事実」として持つ。
  1. 1月1日現在の住所の市町村（課税する市町村と、均等割の非課税の条例・級地を決める）。~~前年12月31日の市町村の級地~~
     （検証で訂正）級地は人の事実ではなく市町村のパラメータ：**課税する市町村（1月1日の住所地）が前年12月31日に該当した級地区分**（施行令47の3 二・三「当該市町村が同日において該当した」）。
     本人が前年12月31日に住んでいた市町村の級地ではない。
  2. 1月1日現在の生活扶助の受給の有無。
  3. 1月1日現在で給与・公的年金等を受けている支払者があるか、その支払者が源泉徴収義務者（給与支払報告書の提出義務者）か。前年に辞めた支払者からの給与の総額（30万円以下なら給与支払報告書が出ない：法317の6③）。
  4. 扶養の記載：所得税の確定申告書、扶養控除等申告書（年末調整 → 給与支払報告書）、住民税の申告書、施行令46の5 の申請書のどれに、誰を扶養・特定親族として書いたか（書類の種類と提出日つき）。
  5. 前年分の所得税の確定申告書を出したか（出す予定か）。
- 検証の方法：中間表現のスキーマ案を作るとき、S1〜S8 の場面（`docs/inferences/20261109_R4-modeling_scenarios.md`）に住民税の判定を足し、上の事実なしで判定できない場面があるかを机上で確かめる。

## I5 出力は「非課税かどうか」だけでなく「申告が要るか」と「条例しだいの部分」を分けて返す

- 前提：H5、H6。
- 推測：
  - 住民税の結果は、(a) 法律で決まる部分（法295①、附則3の3、控除額）、(b) 条例で決まる部分（均等割の非課税の額、申告の免除）、(c) 申告の要否、に分けて返すのがよい。
    (b) は市町村のパラメータがなければ「政令基準の上限を仮に使った」と明記する。
  - 子供の事業所得・雑所得のケースでは、所得税の確定申告をしないと住民税の申告が要る（条例の免除に当たる場合を除く）。出力に「住民税の申告書（3月15日まで、1月1日の住所の市町村へ）」の要否を出すと、申告漏れを防げる。
- 検証の方法：札幌市（条例を取得済み）を例に、合計所得金額 43万円以下・以上、確定申告あり・なし、1月1日に給与あり・なし、の組み合わせを表にして、出力が条文・条例どおりかを確かめる。
  （検証で追記：札幌市の免除の額は、条例の引用（第28条の３第15号ア＝45万円）と語（基礎控除額＝43万円）が食い違い、確かめられない［H］H5-3 の訂正・未決 JU7。
  札幌市を例にするなら 43万円と 45万円の両方の境目を作り、どちらが正しいかは札幌市に確認してから決める）
  別の政令指定都市の条例（申告の免除の書き方）を1つ取得して、パラメータの形で表せるかを確かめる。

## I6 扶養の所属は、所得税と住民税で「同じ記載から、別の規則で」決める

- 前提：H4。
- 推測：
  - 普通は所得税の確定申告書または年末調整（給与支払報告書）の記載が住民税にもそのまま使われるので、所得税と住民税で所属は一致する。
  - ずれるのは、(1) 記載がない・重複している場合（所得税は所令219②、住民税は施行令46の5②で規則が違う）、(2) 住民税だけ申請書（施行令46の5①ただし書）や住民税の申告書で別の記載をした場合。
  - （検証で追記）(3) 給与所得だけの人が年末調整の後に確定申告で扶養を付け替えた場合。施行令46の5① の文言では、この人（給与所得等以外の所得を有しなかつた者）の住民税の所属は
    給与支払報告書（または申請書）によるので、確定申告書の記載と住民税の所属がずれうる［H］H4 の訂正。実務でどう扱われるかは未確認（未決 JU6）。
    実装では、所属の根拠に「どの書類の記載によったか」を出し、(3) に当たるときは結果に注記する。
  - したがって、所属のグループ（R4 の「扶養所属」）は年分ごとに1つ作り、住民税の年度＝年分＋1 で再利用するが、「規則で決めた」場合は住民税用に作り直す。
- 検証の方法：夫婦の両方が子を扶養に記載した場面（重複）で、所得税と住民税の所属が違う結果になりうる例（前年の所得の大小と、既に申告書等で扶養としていた側が違う場合）を作り、条文どおりの結果が出るかをテストにする。
  ただし所令219② の「既に申告書等で扶養としている」の意味は R4 の資料で確認してから。

## I7 年度の切り替わりと法令の改正の取り込み

- 前提：H1、H7。
- 推測：住民税の改正は「〇年度分から適用」と附則に書かれ、施行日は1月1日が多い（令和7年法律第7号は 2026-01-01、令和8年法律第2号の扶養の部分は 2027-01-01）。D9 の監視で地方税法の改正を検知したら、
  「適用年度」と「所得の年」を issue に書き、テストケースは「年度」で追加する。施行日が年の途中（例 2026-11-01）の改正は、その年度の判定には効かない（賦課期日 1月1日の版を使う）ことが多い。
- 検証の方法：e-Gov の改正履歴（`scripts/results/IMPL_juminzei_laws/revisions_chiho*.json`）で、2025年以後の施行日と改正法令を並べ、それぞれの附則の適用年度を読んで、1月1日の版の考え方と合わない改正（年度の途中から適用されるもの）があるかを確かめる。
- （検証の結果）**合わない改正があった**。令和8年法律第2号は 2026-04-01 施行（附則第1条本文）で、附則第11条第1項が「別段の定めがあるものを除き、新法の規定中個人の市町村民税に関する部分…は、
  令和八年度以後の年度分の個人の市町村民税について適用」とする（実測 `docs/measurements/20261109_impl-prep_juminzei-verification.md` §2.4。`law_checks.md` の L64）。したがって「年の途中の改正はその年度の判定には効かないことが多い」は誤り。
  年度の途中に施行される改正でも、附則の書き方しだいでその年度分から効く。D9 の監視では「施行日」ではなく「附則の適用年度」を issue に書き、テストケースの年度もそれで決める［H］H1-2 の訂正。
  なお、扶養・非課税・申告の条の金額・要件の文言は 2026-01-01 と 2026-11-09 の版で同じなので、令和8年度分の値は変わらない。令和9年度分は、2027年の改正（未成立）で変わりうる（未決 JU8）。
